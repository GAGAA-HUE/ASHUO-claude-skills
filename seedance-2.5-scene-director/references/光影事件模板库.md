# 光影事件模板库 — 标准场景动态光影序列

## 使用说明
以下为常见场景类型的典型光影事件序列，可直接引用并根据具体叙事需求调整。
每个事件格式：`[光影事件 @ Xs-Xs] 变化描述：物理动机 → 情绪意图`

---

## 室内日景类

### 清晨卧室（从睡眠到清醒）
```
[光影事件 @ 0s-4s] 窗帘边缘透入的蓝灰色晨光（5200K）覆盖床面右侧约 30% 区域，光束角度低斜（约 15°），边缘柔和。情绪意图：时间刚刚开始，世界尚未施压。
[光影事件 @ 4s-8s] 人物翻身导致窗帘微动，光束宽度扩大约 20%，色温轻微上移至 5600K。情绪意图：外部世界渗入的第一个信号。
[光影事件 @ 10s] Rack Focus 触发瞬间，光束完整打亮人物面部，眼神光出现（来自窗户方向的矩形反射）。情绪意图：意识苏醒的视觉确认。
```

### 餐桌对话（午后）
```
[光影事件 @ 0s] 主光：窗外漫射日光（5600K），光比 1:4，无明确光束边缘。人物面部顺光，情绪暴露度高。
[光影事件 @ 3s-6s] 叙事转折词出口瞬间，窗外云层遮挡导致主光强度下降约 30%，色温微降至 5000K，光比推至 1:6。情绪意图：对话进入不舒适区域的光影确认。
[光影事件 @ 8s] 人物离座，主光从顺光转为侧光，形成面部阴影面积约 40%。情绪意图：人物立场的视觉位移。
```

### 室内夜谈（台灯为主光）
```
[光影事件 @ 0s] 主光：台灯暖黄光（3200K），光比 1:8，照射范围限于桌面及人物脸部下半区，眼部处于阴影边缘（产生神秘感）。
[光影事件 @ 0s-全程] 轮廓光：窗外月光蓝色（5800K），仅打亮人物左侧发际及肩膀边缘，色温差 2600K，产生强烈的冷暖分裂。
[光影事件 @ 5s-8s] 台灯灯泡因电压不稳轻微闪烁（每次闪烁持续 0.1-0.2s），频率约 0.3 次/秒。情绪意图：环境本身的不稳定性作为叙事压力。
```

## 室内夜景类

### 空屋独处
```
[光影事件 @ 0s] 主光：走廊透入的冷白荧光灯（4100K），以细缝形式从门缝穿入，在地面形成约 15cm 宽的光带。整体光比 1:16，场景极暗。
[光影事件 @ 0s-全程] 色调基准：深蓝灰（RGB 约 60/70/85），禁止出现任何暖色光源，除非有明确的叙事触发。
[光影事件 @ 4s] 人物靠近门缝，光带扩展打亮其手部，面部仍处于阴影中。情绪意图：行动先于意识的可见化。
```

### 蜡烛场景（孤独/仪式感）
```
[光影事件 @ 0s] 主光：单支蜡烛（2800K），光照半径约 0.8m，光比 1:12，明暗对比极强，人物面部阴影侧占 60% 以上。
[光影事件 @ 0s-全程] 蜡烛火焰不规律摆动，导致所有阴影边缘以约 2Hz 频率轻微颤动，无规律。情绪意图：脆弱感，生命在微小干扰下摇晃。
[光影事件 @ 6s-12s] 蜡烛蜡量减少导致光源高度下降约 2cm，面部阴影结构微调，眉骨阴影加深。情绪意图：时间正在流逝且无可挽回。
```

## 户外场景类

### 阴天城市街道
```
[光影事件 @ 0s] 主光：阴天散射光（6500K），无定向阴影，光比约 1:2，接近无主光的平光状态。情绪意图：世界感觉没有重心和方向。
[光影事件 @ 0s-全程] 路灯（3800K 钠灯）提供地面局部暖色光斑，色温与天光差 2700K，产生暖/冷割裂的街道色彩逻辑。
[光影事件 @ 3s] 人物经过路灯正下方，面部从冷色散射光切换至暖黄顶光，眼窝阴影加深。情绪意图：人物在不同情绪区域间穿行。
```

### 黄昏户外对峙
```
[光影事件 @ 0s] 主光：低角度黄昏日光（3000K），水平照射角度约 10°，产生极长的侧面阴影，光比 1:6。
[光影事件 @ 0s] 两个人物因低角度主光，一人处于受光面（面朝日落方向），另一人处于逆光（仅有轮廓光）。情绪意图：权力关系的即时视觉化。
[光影事件 @ 4s-8s] 太阳接近地平线，色温从 3000K 继续下降至 2400K（橙红），整体画面暖度持续提升。情绪意图：时间紧迫感，不可逆的时刻正在结束。
```

### 雨天外景
```
[光影事件 @ 0s] 主光：阴雨散射（6800K 偏蓝），光比 1:3，场景整体偏冷青调，禁用暖色辅光（除非有室内光源动机）。
[光影事件 @ 0s-全程] 雨水落在人物面部产生高光点，以约 15Hz 随机频率闪烁，形成「光的噪声」。
[光影事件 @ 5s] 路边橱窗灯光（3400K 暖黄）在湿润路面形成反射光斑，向镜头方向延伸，形成冷场景中的唯一暖色视觉锚点。
```

## 工业/特殊空间类

### 工厂/机房
```
[光影事件 @ 0s] 主光：工业荧光灯（4200K），顶光 90° 垂直照射，产生强烈的顶光阴影（眼窝、鼻底、下颌下方），去除所有情感化光线。
[光影事件 @ 0s-全程] 设备指示灯（多色点光源：红/绿/蓝，约 1W），在场景暗部产生多色光点，色温混乱，强化工业感异质性。
[光影事件 @ Xs（叙事触发时）] 警报灯激活：红色（620nm）频闪，节奏 2Hz，覆盖全场景，所有物体表面获得间歇性红色染色。情绪意图：紧急状态的视觉声明。
```

### 地下空间/地铁
```
[光影事件 @ 0s] 主光：高压钠灯（2200K 橙黄），渲染所有颜色为黄橙调，皮肤失去真实肤色，接近单色。情绪意图：地下世界的色彩规则与地表不同。
[光影事件 @ 3s-5s] 列车经过时，隧道内气流导致悬挂灯轻微摆动，所有阴影边缘产生缓慢的摆动运动，持续约 4s。
[光影事件 @ 全程] 远处隧道灯在景深层产生重复的点光源序列，形成向消失点汇聚的光点透视线，强化纵深感。
```
