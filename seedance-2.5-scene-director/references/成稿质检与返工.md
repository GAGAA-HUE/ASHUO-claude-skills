# 成稿质检、参考转写与返工

本文件负责"写完之后怎么查"和"参考怎么用"。摄影调度规则见 SKILL.md，容量见 `时长容量与连续性.md`。

## 一、双向反查

成稿后查两遍，方向相反：

**第一遍：查漏写**（对照用户提供的全部内容）
- 每句台词是否逐字保留？
- 每个人物是否都在场且方位明确？
- 每个关键动作是否被写到？
- 用户指定的画幅、时长、风格约束是否都在？

**第二遍：查擅自新增**（这一遍更容易被跳过）
- 有没有人物做了用户没写的动作？
- 有没有出现用户没提到的道具、人物、环境细节？
- 有没有替人物补了表情、心理、动机？
- 有没有把"画面的氛围"写成新的剧情事实？

摄影调度、焦段、景别、机位、运动、焦点、停顿属于本 skill 的创作空间，可以设计；**但不得改变人物意图、不得新增情节动作、不得新增对白**。

## 二、删一层

成稿最后通读一遍，删除：
- 同义堆叠的修饰词（"缓缓地慢慢地""巨大而庞大"）
- 重复解释同一个动作的两三句话
- 没有功能的镜头（删了不影响叙事、情绪、空间、线索的）
- 后文内容溢出到前文
- 面向制作者的说明（"这个镜头是为了表现……"）

**不能为了变短而删除**：对白、用户原有动作、必要镜头、已确认的风格特征、焦点转移与视觉锚点。

不要用字数更少判断稿子更好。

## 三、参考名与风格的转写规则

导演名与作品名**可以**写进正式提示词，但必须满足"名字定坐标、特征承担描述"：

- 名字后面紧跟一组可执行特征：光源位置与色温、光比、色彩关系、焦段区间、机位高度、运动方式、材质密度、颗粒与锐度、构图节奏、负向排除项。
- 名字只负责把模型拉进正确的语义区间，**不负责代替描述**。删掉名字之后这段话仍然能执行，才算合格。
- 单条不超过 2—3 个参考名。堆三个以上会互相污染：一个要固定机位、一个要手持、一个要高饱和。
- 名字与后面写的特征冲突时，以**特征为准**，删掉冲突那一半。例如写了"李沧东"却又要"高饱和霓虹"，二者只能留一个。
- 引用维度要具体：写"参考某某开场追车的运动能量"而不是"参考某某"。

参考图、剧照的用途要先分开：身份事实 / 空间结构 / 造型 / 构图 / 光色 / 节奏 / 反例。**参考图里的剧情、人物关系、文字内容不会自动成为当前项目的事实**。

## 四、素材编号与用途窄化

- 有正式编号时用编号：【C01】人物、【S02】场景、【P03】道具、【音频1】音色。不重排、不新增编号。
- 没有编号、用户直接上传图片时，按上传顺序用【图片1】【图片2】。
- 每条绑定都要写**窄用途**，不能只写"参考【C01】"：
  - 人物图 → 锁身份与已确认造型
  - 场景图 → 锁空间结构与固定陈设
  - 站位图 → 锁人数、位置、朝向、视线
  - 道具图 → 锁结构
  - 音频 → 锁音色
- 只绑定本段实际用到的素材，不列全套资产。
- 绑定只锁稳定事实与开场状态。道具在段内被放下、打碎、递出，由镜头顺序呈现，不写"始终握着""全程完好"。
- 没有素材就不写绑定段，也不写"暂无参考图""本段不使用外部素材"这类制作状态。

## 五、常见失败模式

**写成了制片报告**
出现"本镜头旨在表现""此处应该让观众感受到"——删掉，直接写画面。

**对白没有画面支撑**
"甲说：'……'"孤零零出现，没有姿态、视线、镜头位置。补上，或改写成一句完整调度。

**一段里两位角色连续接话**
一个镜头只承载一位说话人的连续发言。换说话人必须换镜；听者可以同框做无对白反应，不能同镜接话。同一人的同一轮连续发言，只要动作、视线、关系连续，可以留在同一镜。

**摄影机贴脸走路**
摄影机从人群后方一路冲到主体正前方，中间穿过两三个人还保持同一焦段。不合理就改路径或改切镜。

**焦点凭空跳**
焦段提示词让焦点转移了，但摄影机没动、人物没动、没有引导视线的动作。焦点转移必须有一个物理触发点。

**视觉锚点只出现一次**
建立了却没回收，或者中途从画面消失后再也不提。要么回收，要么一开始就不要设。

**抽象词被渲染成特效光**
"眼神光""红晕""气场全开""浑身散发着"→ 改写为可见的肌肉收缩、血管扩张、皮肤高光点位置变化、布料位移。

**模板化收尾**
每条都以俯视全景或一秒静止镜头结束。删掉，按自然落点收。

**来源说明混进正文**
"按原文""根据剧本""本段必须""保持与上一稿一致"——这些是写作者自己的核对口令，模型会照抄。正文直接写人物说什么。

**后期包装混进提示词**
人物身份条、时间地点条、片名、章节标题、"为字幕留白"——不进入生成提示词。场景里真实存在的招牌、屏幕、标语按剧情保留。

## 六、返工范围

用户提出结果不对时：

1. 先判断是哪一层的问题：
   - **执行层**（已经确认的风格没落实）→ 保留目标，改执行描述
   - **审美层**（落实了但用户不喜欢）→ 只改那一个轴，保留脸、年龄、服装、关系、动作
   - **技术层**（模型崩了、闪烁、运动破碎）→ 改技术参数，不靠改剧情掩盖
   - **事实层**（人物、道具、空间错了）→ 改事实描述，不动调度
2. 同一原因或互相依赖的问题一起改；互相独立且会干扰判断的分批。
3. 保留已经通过的剧情、对白、身份、镜头与基调，不借关联修复扩成整段重写。
4. 只要求诊断时，只说原因，不自动改稿。
