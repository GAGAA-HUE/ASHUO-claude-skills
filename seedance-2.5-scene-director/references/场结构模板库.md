# 场结构模板库 — 30秒叙事场的内部节拍划分

## 使用说明

每个模板提供该场类型的典型时间轴切割建议、各阶段叙事功能与情绪弧线走向。
模板是决策起点，不是固定格式——根据具体叙事需求调整节拍时长和数量。

格式：`[阶段名 @ Xs-Xs] 叙事功能 / 情绪状态 / 摄影机建议`

---

## 一、开场建立场（世界观/人物引入）

### 1.1 空间优先型开场（先场景后人物）
```
[空间建立 @ 0s-8s] 建立场景风格、材质体系、时代语义、气氛密度 / 观察者情绪 / 推荐远景或中景稳定横移
[人物进入 @ 8s-18s] 人物出现于已成立的空间中，外观亮相，基础气质读取 / 从观察到认知 / 推荐中景跟随或静止等待
[关系建立 @ 18s-30s] 人物与空间产生第一次有意义的接触或行为，叙事意图浮现 / 沉浸→期待 / 推荐靠近至近景，结尾停于人物或道具
```

### 1.2 人物优先型开场（先人物后环境）
```
[人物特写 @ 0s-6s] 先建立人物面部或关键特征，气质即时锁定 / 强代入感 / 推荐近景或大特写，焦段85-135mm
[人物行动 @ 6s-16s] 人物开始运动或做出动作，空间信息随镜头运动逐步暴露 / 行动中的世界 / 推荐中景跟随
[环境确认 @ 16s-30s] 拉开或切至更广视角，完成空间确认，人物与环境关系成立 / 理解→定位 / 推荐拉镜或切至远景
```

### 1.3 事件触发型开场（以行动代替介绍）
```
[事件爆发 @ 0s-5s] 直接从已发生的事件切入，无解释 / 惊醒、冲击 / 推荐中景或近景，快速建立事件主体
[空间补全 @ 5s-15s] 镜头运动或切换补全空间关系，让观众理解"这是哪里/发生了什么" / 追赶信息 / 推荐横移或跟随
[人物定位 @ 15s-30s] 人物在事件中的角色清晰，情绪状态确认，场景叙事意图明朗 / 理解→投入 / 推荐近景停驻
```

## 二、冲突发展场（张力升级）

### 2.1 对峙型冲突（双方正面交锋）
```
[对峙建立 @ 0s-8s] 确立双方位置、力量关系、空间轴线 / 压力积累 / 推荐正反打或双人中景，焦段50-85mm
[试探交锋 @ 8s-20s] 首次实质性冲突行为——语言、动作或意志碰撞 / 张力爆发点 / 推荐快速景别交替，近景与中景切换
[余震停顿 @ 20s-30s] 冲突完成后的短暂停止，双方重新审视，场的结论尚未到来 / 余震、悬停 / 推荐静止或极慢推，结尾停于表情
```

### 2.2 单线追逐/压力型冲突
```
[威胁出现 @ 0s-6s] 确立威胁来源与方向，主角感知到危机 / 压力导入 / 推荐静止镜头突然跟随，焦段24-50mm
[逃离/对抗 @ 6s-22s] 主要行动段，动作链连续发展，节奏加速 / 持续紧张 / 推荐跟随+短切，节奏加密
[临界点 @ 22s-30s] 到达危险最高点或完成脱离，结果悬置 / 决定性瞬间 / 推荐极端特写或骤然拉远
```

### 2.3 内部心理型冲突（独角戏/内心戏）
```
[外部平静 @ 0s-8s] 场景表面安静，但通过光影、道具、人物小动作暗示内部张力 / 表面张力 / 推荐静止或极慢推，焦段85-135mm
[内部爆发迹象 @ 8s-20s] 人物行为出现异常、矛盾或难以压制的情绪泄露 / 控制瓦解 / 推荐靠近至大特写，捕捉微表情
[收束或崩溃 @ 20s-30s] 人物完成内心抉择或彻底情绪释放，场的情绪主题明确 / 结论感 / 推荐结尾停于人物状态
```

## 三、高潮场（情绪或事件顶点）

### 3.1 动作高潮（物理事件顶点）
```
[蓄力前摇 @ 0s-8s] 高潮前的最后积累——呼吸暂停、肌肉紧绷、环境信号 / 极端紧张 / 推荐静止+特写，焦段85-135mm
[爆发释放 @ 8s-20s] 高潮动作发生，能量全部释放，视觉冲击最强 / 完全释放 / 推荐快速景别跳切+慢动作关键帧强调
[余波沉降 @ 20s-30s] 事件结束，尘埃落定，结果呈现 / 后果感 / 推荐长镜头静止或缓慢拉开
```

### 3.2 情感高潮（情绪顶点）
```
[情绪积压 @ 0s-10s] 情绪在人物或空间中持续积累，光影参与配合 / 沸点前 / 推荐慢推，焦段100-135mm
[情绪破防 @ 10s-22s] 情绪释放——哭泣、呼喊、沉默、拥抱或离开 / 情感高点 / 推荐近景停驻或极慢推进
[消散收束 @ 22s-30s] 情绪开始消散，进入余韵状态，场的情感主题完成 / 余韵 / 推荐镜头轻微拉开或停留空间
```

### 3.3 揭示型高潮（信息/反转顶点）
```
[悬疑积累 @ 0s-8s] 通过构图、遮挡、焦外等手段积累悬念 / 期待感 / 推荐偏轴构图，焦段100mm+
[揭示瞬间 @ 8s-16s] 关键信息完整暴露，视觉上需清晰、准确、无歧义 / 冲击感 / 推荐正对特写，焦段50-85mm
[消化停顿 @ 16s-30s] 留出空间让信息落地，人物与观众共同处理 / 理解→震撼 / 推荐静止镜头，结尾停于人物反应
```

## 四、情感转折场（叙事方向改变）

### 4.1 希望→绝望型转折
```
[希望建立 @ 0s-10s] 场景明亮、人物状态积极、空间开阔 / 暂时的轻松 / 推荐顺光宽景
[危机信号 @ 10s-20s] 环境或人物开始出现异常信号，气氛逆转 / 不安渗入 / 光影配合变化，推进至近景
[绝望确认 @ 20s-30s] 转折完成，情绪完全逆转，场的基调重新定义 / 落差感 / 推荐暗部特写或空间收窄
```

### 4.2 对立→和解型转折
```
[对立状态 @ 0s-8s] 双方处于对立位置，轴线隔离 / 冷漠/紧张 / 推荐两人分处画面两端，中间留空
[转折触发 @ 8s-20s] 某个动作、话语或事件打破对立 / 解冻 / 推荐打破轴线，镜头靠近
[和解完成 @ 20s-30s] 关系重建，身体语言或空间位置发生明确变化 / 温度回升 / 推荐双人同框，焦段收紧
```

### 4.3 日常→超常型转折（现实被打破）
```
[日常建立 @ 0s-10s] 普通场景、正常行为、无明显异常 / 熟悉感 / 推荐自然光、标准景别
[异常侵入 @ 10s-20s] 第一个不符合日常逻辑的元素出现 / 陌生感 / 推荐焦段压缩或视角异化
[规则瓦解 @ 20s-30s] 日常秩序完全崩解，新的视觉规则成立 / 迷失→新世界 / 推荐大幅度光影或空间变形
```

## 五、收尾场（余韵/结论）

### 5.1 静止余韵型结尾
```
[行动收束 @ 0s-10s] 最后一个主动行为完成，人物或事件停止 / 完成感 / 推荐跟随至停止
[空间停留 @ 10s-22s] 镜头停驻于最终状态，不急于退出 / 沉浸 / 推荐静止凝视，焦段85-135mm
[画面悬停 @ 22s-30s] 镜头可轻微拉开或保持不动，画面在此定格成为叙事结论 / 余韵收束 / 让空间或人物状态自行成为结论
```

### 5.2 抽离型结尾（距离感）
```
[最终状态确认 @ 0s-12s] 确认人物/事件的最终状态，情绪完整 / 收束感 / 推荐近景或中景
[镜头撤离 @ 12s-24s] 镜头开始拉开或横移离开，人物变小 / 疏离→结束 / 推荐拉镜或无人机后退
[消失点 @ 24s-30s] 人物或核心元素退至画面边缘或消失，场地空出 / 空白感 / 场以空间为结论
```

### 5.3 循环型结尾（首尾呼应）
```
[结尾状态建立 @ 0s-12s] 建立与开场相似的视觉状态（构图、光影、人物位置） / 熟悉感 / 有意识地复现开场元素
[差异暴露 @ 12s-24s] 在相似状态中暴露关键变化——某个元素改变了 / 时间感、变化感 / 推荐相同焦段，但细节不同
[差异停驻 @ 24s-30s] 镜头停于改变的那个细节 / 主题陈述 / 推荐特写停驻，让差异成为叙事结论
```

## 节拍调整原则

- **节拍可压缩**：若叙事节奏需要加快，各阶段时长可按比例缩短，但不建议任何单阶段低于 4s（否则视觉信息无法建立）
- **节拍可扩展**：若强调某一情绪状态，可拉长该阶段至 15s 以上，同时压缩其他阶段
- **节拍可合并**：两个相邻阶段情绪连续时，可在单段叙事中同时完成双重功能
- **节拍可省略**：结构完整性服务于叙事，若某阶段与叙事意图无关，可直接跳过
