# AI 绘画提示词通用技巧

## 提示词基础原则

### 1. 具体优于笼统
❌ 不好的描述：
- "一个漂亮的女人"
- "好看的风景"
- "可爱的动物"

✅ 好的描述：
- "一位25岁亚洲女性，精致五官，长发及腰，温柔微笑"
- "瑞士阿尔卑斯山，雪山湖泊，蓝天白云，绿色草甸"
- "一只橘色虎斑猫，圆眼睛， fluffy毛发，慵懒地伸懒腰"

### 2. 结构化描述
按重要性排序描述元素：
1. **主体**（必须）- 画面核心是什么
2. **细节**（重要）- 主体的具体特征
3. **动作**（如有）- 主体在做什么
4. **场景**（重要）- 背景环境
5. **光线**（氛围）- 照明效果
6. **风格**（调性）- 艺术表现方式
7. **质量**（增强）- 画质提升词

### 3. 使用形容词堆叠
多个形容词可以增强描述精度：
```
[形容词1], [形容词2], [形容词3] + [名词]

例如：
- 柔和、温暖、金色的 + 阳光
- 古老、破旧、神秘的 + 城堡
- 精致、优雅、华丽的 + 礼服
```

## 负面提示词策略

### 通用负面词
```
低质量、模糊、变形、畸形、多余手指、残缺肢体、
水印、文字、logo、签名、噪点、过曝、欠曝、
丑陋、扭曲、不自然、简单背景、纯色背景
```

### 人像负面词
```
畸形面部、不对称眼睛、多余手指、融合手指、
扭曲肢体、不自然姿势、塑料质感、过度磨皮、

```

### 场景负面词
```
杂乱、拥挤、不连贯、透视错误、比例失调、
模糊背景（如需要清晰背景）、过暗、过亮
```

## 高级技巧

### 1. 权重控制（部分模型支持）
```
(关键词:1.2)  # 增加权重
[关键词:0.8]  # 降低权重
((关键词))     # 双重增强
```

### 2. 分步描述
```
[基础描述] + [细节增强] + [风格修饰]

例如：
少女 + 银发紫眼猫耳 + 樱花树下 + 日系动漫风格
```

### 3. 参考融合
```
[主体] in the style of [艺术家/作品]

例如：
山水风景 in the style of 张大千
```

### 4. 色彩指定
```
主色调：[颜色] + 辅助色：[颜色] + 点缀色：[颜色]

例如：
主色调：深蓝 + 辅助色：金色 + 点缀色：白色
```

## 常见错误与修正

| 错误 | 修正 |
|------|------|
| 提示词太长 | 保留核心描述，删除冗余形容词 |
| 矛盾描述 | 检查并删除相互冲突的关键词 |
| 过于笼统 | 添加具体细节（颜色、材质、形状） |
| 忽视光线 | 补充光源和氛围描述 |
| 忽略背景 | 明确场景环境，避免随机背景 |
| 风格混杂 | 选择主导风格，其他作为辅助 |
