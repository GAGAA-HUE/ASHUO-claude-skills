## 各模型最佳应用场景

### Seedream / 即梦
**最适合**：
- 东方人像摄影（尤其是亚洲面孔）
- 商业产品图
- 国风/古风场景
- 室内设计效果图
- 需要精准中文理解的场景

**优势**：
- 中文提示词理解最准确
- 东方人脸生成自然
- 商业摄影质感强
- 与抖音/剪映生态整合

**局限**：
- 极度复杂的西方奇幻场景
- 某些特定艺术风格的还原

### Nano Banana
**最适合**：
- 二次元动漫角色
- 国风插画
- 绘本/儿童插画
- 社交媒体配图
- 快速迭代设计

**优势**：
- 生成速度快
- 动漫风格精准
- 对中文网络用语理解好
- 标签式提示词友好

**局限**：
- 超写实风格不如 Seedream
- 复杂场景构图

### 可灵 AI
**最适合**：
- 视频内容创作
- 电影感画面
- 动态场景概念设计
- 短视频素材
- 影视分镜

**优势**：
- 视频生成能力领先
- 镜头语言理解强
- 电影调色质感
- 动态表现自然

**局限**：
- 纯图像生成不是最强
- 某些静态细节精度

### Midjourney（参考对比）
**最适合**：
- 艺术概念设计
- 创意探索
- 美学实验
- 英文用户

**优势**：
- 艺术性强
- 美学默认优秀
- 社区资源丰富

**局限**：
- 中文支持弱
- 需要 Discord
- 可控性较低

### Stable Diffusion（参考对比）
**最适合**：
- 本地部署
- 高度定制
- 专业工作流
- 学术研究

**优势**：
- 完全可控
- 生态丰富
- 免费开源
- 可训练模型

**局限**：
- 学习曲线陡峭
- 需要硬件支持
-  setup 复杂

## 提示词适配策略

### 从 Seedream 适配到其他模型

**原 Seedream 提示词**：
```
一位汉服女子，站在樱花树下，淡粉色长裙，
手持团扇，温柔微笑，春日午后，柔和光线，
国风工笔风格， masterpiece
```

**适配 Nano Banana**：
```
汉服少女，粉色长裙，团扇，樱花树，
温柔微笑，春日，柔和光线，
国风，工笔， masterpiece，精致细节
```

**适配可灵（电影感）**：
```
中景，汉服女子立于樱花树下，
手持团扇，微风拂动裙摆，春日午后，
柔和侧光，浅景深，国风意境，
cinematic lighting， film grain
```

### 通用适配原则

1. **Seedream → Nano Banana**
   - 增加标签式关键词
   - 简化长句描述
   - 添加动漫/插画风格标签

2. **Seedream → 可灵**
   - 添加镜头语言
   - 强调光线和氛围
   - 加入电影相关词汇

3. **Nano Banana → Seedream**
   - 扩展标签为完整句子
   - 添加写实/摄影关键词
   - 补充材质和质感描述

4. **通用 → Midjourney**
   - 转为英文
   - 简化描述，强调美学
   - 添加艺术家参考

## 选择建议

### 按内容类型选择
- **人像摄影** → Seedream
- **动漫插画** → Nano Banana
- **视频创作** → 可灵 AI
- **艺术创作** → Midjourney / SD

### 按使用场景选择
- **商业设计** → Seedream / 可灵
- **社交媒体** → Nano Banana / Seedream
- **影视制作** → 可灵 AI
- **个人创作** → 根据风格偏好

### 按技术能力选择
- **新手友好** → Seedream / Nano Banana
- **专业控制** → Stable Diffusion
- **快速出图** → Nano Banana
- **视频需求** → 可灵 AI
