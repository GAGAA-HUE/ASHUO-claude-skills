# 可灵 AI / 快影 提示词规范

## 模型概述

可灵 AI 是快手推出的 AI 创作平台，支持图像生成和视频生成，擅长动态场景和电影感画面。

## 核心特性

### 视频生成优势
- **动态理解**：对动作、运动轨迹理解准确
- **镜头语言**：支持运镜描述（推、拉、摇、移）
- **时间连贯**：多帧之间保持一致性

### 图像生成特点
- **电影感**：画面具有强烈的叙事性和氛围感
- **真实感**：写实风格自然，适合影视概念设计
- **动态捕捉**：能表现瞬间动作和动态姿态

## 提示词结构

### 图像生成格式
```
[镜头类型], [主体描述], [动作/状态], [场景环境],
[光线氛围], [色彩风格], [情绪基调], [技术规格]
```

### 视频生成格式
```
[镜头运动], [场景描述], [主体动作], [运镜方式],
[时间/天气], [氛围渲染], [转场效果], [时长标注]
```

## 技术参数

### 画幅比例
- `2.39:1` - 电影宽银幕
- `1.85:1` - 标准电影
- `16:9` - 标准视频
- `9:16` - 竖屏视频
- `4:3` - 复古电视
- `1:1` - 方形

### 帧率（视频）
- `24fps` - 电影标准
- `30fps` - 电视标准
- `60fps` - 流畅动作
- `120fps` - 慢动作素材

## 高级技巧

### 1. 时间描述
```
[时间点], [光线变化], [时间流逝感]
例如：黄昏时分, 光线渐暗, 日转夜过渡
```

### 2. 空间层次
```
[前景], [中景], [背景]
例如：前景虚化的树枝, 中景行走的人物, 背景连绵的山脉
```

### 3. 动态描述
```
[动作], [速度感], [运动方向]
例如：奔跑, 高速动态, 从左向右
```

## 负面提示建议

```
静态, 僵硬, 不自然动作, 画面抖动,
过曝, 欠曝, 色偏, 失焦,
低帧率卡顿, 画面撕裂, 运动模糊过度
```
