# Seedream / 即梦 AI 提示词规范

## 模型概述

Seedream 是字节跳动旗下的 AI 绘画模型，在即梦平台提供中文原生支持的图像生成服务。

## 核心特性

### 语言支持
- **中文理解**：对中文语境、成语、古诗词有良好理解
- **中英文混合**：可同时使用中英提示词，中文描述主体，英文增强画质

### 优势领域
1. **写实人像**：东方人脸特征自然，肤质细腻
2. **商业摄影**：产品图、时尚大片效果出色
3. **东方美学**：国风、古风、新中式风格表现优异
4. **室内设计**：空间感和材质还原度高

## 提示词结构

### 标准格式
```
[主体描述], [细节特征], [动作/姿态], [服装/道具],
[场景环境], [光线氛围], [艺术风格], [质量标签]
```

## 参数设置

### 画面比例
- `--ar 1:1` - 方形（默认，适合社交媒体）
- `--ar 16:9` - 横屏（适合壁纸、视频封面）
- `--ar 9:16` - 竖屏（适合手机壁纸、海报）
- `--ar 3:4` - 人像竖版
- `--ar 4:3` - 横版标准

### 风格强度
- `--style 写实` / `photorealistic`
- `--style 动漫` / `anime`
- `--style 国风` / `chinese_style`
- `--style 油画` / `oil_painting`
- `--style 水彩` / `watercolor`

## 负面提示词（Negative Prompt）

### 通用负面词
```
模糊, 低质量, 变形, 畸形, 多余手指, 残缺肢体,
水印, 文字, logo, 签名, 噪点, 过曝, 欠曝,
丑陋, 扭曲, 不自然, 卡通, 素描
```

### 人像专用负面词
```
畸形面部, 不对称眼睛, 多余手指, 融合手指,
扭曲肢体, 不自然姿势, 塑料质感, 过度磨皮
```

## 高级技巧

### 1. 权重控制
使用括号调整关键词权重：
- `(关键词)` - 权重 1.1 倍
- `((关键词))` - 权重 1.21 倍
- `[关键词]` - 权重 0.9 倍

### 2. 分步渲染
使用 `|`` 分隔不同阶段的描述：
```
[初始描述] | [细节增强] | [最终润色]
```

### 3. 参考图引导
支持上传参考图进行风格迁移或构图参考

## 画质增强词

### 基础
- `masterpiece` - 杰作级
- `best quality` - 最佳质量
- `highly detailed` - 高度细节
- `ultra detailed` - 超精细

### 摄影
- `professional photography` - 专业摄影
- `cinematic lighting` - 电影光
- `studio lighting` - 影棚光
- `bokeh` - 背景虚化

### 分辨率
- `8k resolution` - 8K 分辨率
- `sharp focus` - 锐利对焦
- `crisp details` - 清晰细节
