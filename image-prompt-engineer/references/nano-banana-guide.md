# Nano Banana 提示词规范

## 模型概述

Nano Banana 是美团推出的 AI 绘画模型，针对中文用户习惯优化，在动漫、插画领域表现突出。

## 核心特性

### 语言优势
- **中文原生**：对中文网络用语、流行文化理解深刻
- **语境理解**：能理解复杂的中文描述和意境表达

### 优势领域
1. **二次元动漫**：日系动漫风格精准还原
2. **插画设计**：商业插画、绘本风格
3. **国风创作**：古风人物、仙侠场景
4. **创意场景**：幻想、科幻、概念设计

## 提示词结构

### 标准格式
```
[画面主体], [角色特征], [服装道具], [场景描述],
[情绪氛围], [艺术风格], [质量标签], [特殊效果]
```

### 关键词标签系统

Nano Banana 对标签式提示词响应良好：
```
标签1, 标签2, 标签3, [详细描述], 标签4...
```

- ` ultra-detailed` - 超精细

## 特殊技巧

### 1. 色彩控制
```
[主色调]色调, [辅助色]点缀, 色彩和谐
例如：暖色调, 金色点缀, 色彩和谐
```

### 2. 情绪表达
```
[情绪]氛围, [情绪]表情, 情绪渲染
例如：忧郁氛围, 温柔表情, 治愈系
```

### 3. 细节强化
在关键元素后添加 `detailed`：
```
detailed eyes, detailed hair, detailed background
```

## 推荐提示词长度

- **简洁版**：30-60 字，适合快速生成
- **标准版**：60-120 字，平衡质量与速度
- **精细版**：120-200 字，追求极致细节

## 负面提示建议

```
低质量, 模糊, 变形, 畸形, 多余手指,
水印, 文字, 签名, 噪点, 过曝,
丑陋, 扭曲, 不自然, 简单背景
```
