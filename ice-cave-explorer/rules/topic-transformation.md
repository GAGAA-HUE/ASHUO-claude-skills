# 衍生选题三步转化法

任何来源选题，必须经过三步翻译才能进入剧本。

---

## 来源权重

1. **平台热点**（最高权重）：B 站热门 / 抖音热门 / 小红书热门 / YouTube trending
2. **长青题材**（中权重）：探险 / 美食 / 科普 / 萌宠 / 极限运动 / 解谜
3. **跨域挪用**（低权重）：游戏 / 影视奇观 / 神话传说 / 节日习俗

---

## 三步转化法

### 第 1 步：识别核心吸引力

**任务**：把"它为什么火"抽象成 1–2 个情感钩子词。

常见钩子词：
- 反差（严肃 vs 萌 / 危险 vs 安全）
- 紧张（求生 / 解谜 / 限时）
- 奇观（视觉冲击 / 猎奇）
- 利益（寻宝 / 变现 / 实用）
- 共鸣（怀旧 / 治愈 / 热血）

**输出**：`钩子词 = [反差, 紧张]`

---

### 第 2 步：保留情感钩子，置换物理载体

**任务**：钩子保留，但场景 / 角色 / 物体换成冰洞内的。

例：
- 奶龙"反差"钩子保留 → 冰洞里出现一只正襟危坐喝热可可的奶龙
- 温泉涮火锅"利益"钩子保留 → 冰洞里用温泉水涮火锅
- 密室逃脱"紧张"钩子保留 → 冰洞本身变成密室（限时逃出）

**输出**：`翻译后的看点 = [冰洞里正襟危坐喝热可可的奶龙]`

---

### 第 3 步：与冰洞原型 L1 强制配对

**任务**：翻译后的看点，必须能塞进 L1 母体（或 L2 派生）。

例：
- 温泉涮火锅 → 必须配 L1-1（蓝冰洞）或 L1-5（冰下湖），才能有"在冰里涮火锅"的反差
- 冰封巨兽 → 必须配 L1-2（钟乳冰洞）或 L1-7（黑色火山冰洞），才合理"封存"
- 正襟危坐喝热可可的奶龙 → 必须配 L1-8（雪洞），才有温暖感

**输出**：`L1 配对 = L1-8（雪洞）`

---

## 亮点设计产出格式

步骤 1 完成后，必须输出：

```
## 衍生选题转化结果

**来源**：[平台热点 / 长青题材 / 跨域挪用] + [具体选题]
**钩子词**：[情感钩子 1, 情感钩子 2]
**翻译后的看点**：[具体描述]
**L1 配对**：[L1-X（原型名）]
**派生规则**：[无 / 杂交 / 变量替换 / 尺度畸变]
**派生来源**：[如果用了派生，标注来源]
```

---

## 风险过滤

**无**。用户直接担责。

---

## 检查点

衍生选题转化完成后，必须检查：
1. 是否明确标注了钩子词？
2. 是否完成了载体置换（不是硬塞原选题）？
3. 是否配对到了 L1 母体（或 L2 派生）？
4. 是否显式标注了派生来源（如果用了派生）？
