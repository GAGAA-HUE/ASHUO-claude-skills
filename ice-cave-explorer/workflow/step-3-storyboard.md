# 步骤 3：分镜脚本流程

## 任务

基于步骤 2 的"场景设定文档"，产出一份 120 秒三幕分镜表。

## 输入

- 步骤 2 的"场景设定文档"
- `config/explorer-profile.md`（探险者 IP 风格档）
- `rules/timing-template.md`（节奏模板）
- `rules/narration-voice.md`（旁白语感指南）
- `rules/arsm-tags.md`（音效标签表）

## 执行步骤

### 1. 读取节奏模板

从 `rules/timing-template.md` 中读取时间分配：

- [0–5s] 钩子镜头 + 字幕悬念
- [5–25s] 抵达 + 环境建立
- [25–75s] 核心段落：亮点 1 + 过渡 + 亮点 2
- [75–105s] 高潮：亮点 3
- [105–120s] 余韵 + 结尾钩子

### 2. 读取旁白语感

从 `rules/narration-voice.md` 中读取语感约束：

- 语感：冷静理性型
- 信息密度：中密度（2.5-3.5 字 / 秒，120 秒约 300-420 字）
- 与画面咬合：画面为主，旁白为辅

### 3. 读取音效标签

从 `rules/arsm-tags.md` 中读取音效分类法：

- A: Ambient（环境底噪）
- R: Room（空间混响）
- S: SFX（一次性音效）
- M: Movement（运动音）

### 4. 读取探险者 IP

从 `config/explorer-profile.md` 中读取探险者的 6 维度档案。

### 5. 设计分镜表

基于步骤 2 的"场景设定文档"和节奏模板，设计每个镜头：

**每个镜头必须包含**：

| 字段 | 说明 |
|------|------|
| 时段 | 时间范围（如 [0-5s]） |
| 时长 | 秒数 |
| 视角 | 第一人称 / 第三人称 |
| 画面内容 | 具体描述（构图、动作、特效） |
| 探险者动作 | 基于 explorer-profile.md |
| 旁白 | 基于 narration-voice.md |
| 音效 | 基于 arsm-tags.md（A/R/S/M 标签） |
| 音乐 | 情绪描述（留给下游 AI 工具） |

**分镜表格式**：

```
| 时段 | 时长 | 视角 | 画面内容 | 探险者动作 | 旁白 | 音效 | 音乐 |
|------|------|------|----------|------------|------|------|------|
| [0-5s] | 5s | 第一人称 | 洞口特写 | 扶头灯 | 无 | A: 低频嗡鸣, R: 中等混响, S: 风声 | 紧张悬疑 |
| ... | ... | ... | ... | ... | ... | ... | ... |
```

### 6. 控制旁白字数

统计所有旁白的总字数，确保在 300-420 字之间。

如果超字数，精简旁白。
如果不足字数，增加旁白（但不要破坏"画面为主"原则）。

### 7. 检查亮点分层

确保三个亮点分层清晰：

- 亮点 1（铺垫）：中等奇观
- 亮点 2（递进）：比亮点 1 更强
- 亮点 3（高潮）：最强奇观

### 8. 自检

执行 `workflow/quality-checklist.md` 中的"步骤 3 检查点"。

### 9. 等待用户过目

将分镜表提交给用户。

- 用户接受 → 完成步骤 3，建议将完整剧本固化到 `examples/episode-01.md`（如果是第 1 集）
- 用户打回 → 根据反馈修订，重新执行步骤 5-8
- 用户改 → 按用户意见修订，重新执行步骤 8-9

## 输出

一份"分镜脚本"，包含：

1. **分镜表**（每个镜头的 8 个字段）
2. **旁白总字数统计**
3. **亮点分层说明**（亮点 1 / 亮点 2 / 亮点 3 分别在哪几个镜头）

## 完成标志

用户明确说"通过"或"OK"或"完成"。

## 第 1 集特殊处理

如果是第 1 集，完成后将完整剧本（衍生选题转化结果 + 场景设定文档 + 分镜脚本）固化到 `examples/episode-01.md`。
