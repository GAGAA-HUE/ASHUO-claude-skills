# 步骤 2：场景设定流程

## 任务

基于步骤 1 的"衍生选题转化结果"，产出一份冰洞场景设定文档。

## 输入

- 步骤 1 的"衍生选题转化结果"（含 L1 配对）

## 执行步骤

### 1. 读取 L1 原型

从 `config/l1-prototypes.md` 中读取 L1 配对的写实原型。

如果用了派生，从 `rules/l2-derivation.md` 中读取派生规则。

### 2. 设计场景设定

基于 L1 原型（和派生规则），设计以下内容：

**2.1 写实基底**
- 地质成因（这个冰洞是怎么形成的）
- 地理位置（虚构或真实）
- 物理特征（尺寸、形状、温度、光线）

**2.2 超现实增量**
- 基于步骤 1 的"翻译后的看点"，设计 1-2 个超现实变体
- 每个变体必须明确"哪个变量被替换了"

**2.3 光影系统**
- 光源类型（自然光 / 生物光 / 极光 / 岩浆等）
- 光影氛围（冷色调 / 暖色调 / 对比度）
- 光影变化（随时间 / 随剧情变化）

**2.4 与看点的结合**
- 场景设定如何服务于步骤 1 的"翻译后的看点"
- 亮点 1 / 亮点 2 / 亮点 3 分别在哪里发生

### 3. 产出场景设定文档

按以下格式输出：

```
## 场景设定文档

### 写实基底

**L1 原型**：L1-X（原型名）
**派生规则**：[无 / 杂交 / 变量替换 / 尺度畸变]
**派生来源**：[如果用了派生，标注来源]

**地质成因**：[描述]
**地理位置**：[描述]
**物理特征**：[尺寸、形状、温度、光线]

### 超现实增量

**变体 1**：[描述]
- 变量替换：[哪个变量被替换]
- 视觉效果：[描述]

**变体 2**：[描述]
- 变量替换：[哪个变量被替换]
- 视觉效果：[描述]

### 光影系统

**光源类型**：[自然光 / 生物光 / 极光 / 岩浆等]
**光影氛围**：[冷色调 / 暖色调 / 对比度]
**光影变化**：[随时间 / 随剧情变化]

### 与看点的结合

**亮点 1（铺垫）**：在 [位置] 发生，看点是 [描述]
**亮点 2（递进）**：在 [位置] 发生，看点是 [描述]
**亮点 3（高潮）**：在 [位置] 发生，看点是 [描述]
```

### 4. 自检

执行 `workflow/quality-checklist.md` 中的"步骤 2 检查点"。

### 5. 等待用户过目

将场景设定文档提交给用户。

- 用户接受 → 进入步骤 3
- 用户打回 → 根据反馈修订，重新执行步骤 2-4
- 用户改 → 按用户意见修订，重新执行步骤 4-5

## 输出

一份"场景设定文档"，包含：
- 写实基底（L1 原型、派生规则、地质成因、地理位置、物理特征）
- 超现实增量（变体 1、变体 2）
- 光影系统（光源类型、光影氛围、光影变化）
- 与看点的结合（亮点 1、亮点 2、亮点 3）

## 完成标志

用户明确说"通过"或"OK"或"继续"。
