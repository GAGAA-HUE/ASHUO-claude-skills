# 质量检查表

每步完成后必须执行本检查表。未过项必须修订后才能进入下一步。

---

## 步骤 1 检查点（亮点设计）

- [ ] 是否明确标注了来源（平台热点 / 长青题材 / 跨域挪用）？
- [ ] 是否明确标注了钩子词（1-2 个情感钩子）？
- [ ] 是否完成了载体置换（不是硬塞原选题）？
- [ ] 是否配对到了 L1 母体（从 `config/l1-prototypes.md`）？
- [ ] 如果用了派生，是否标注了派生规则（杂交 / 变量替换 / 尺度畸变）？
- [ ] 如果用了派生，是否标注了派生来源（哪个 L1 + 哪条规则）？

---

## 步骤 2 检查点（场景设定）

- [ ] 是否基于步骤 1 的 L1 配对？
- [ ] 是否显式标注了 L1 原型编号？
- [ ] 是否包含地质成因、地理位置、物理特征（写实基底）？
- [ ] 是否包含 1-2 个超现实变体？
- [ ] 每个超现实变体是否明确"哪个变量被替换了"？
- [ ] 是否包含光影系统（光源类型、光影氛围、光影变化）？
- [ ] 是否明确标注了亮点 1 / 亮点 2 / 亮点 3 的位置？
- [ ] 场景设定是否服务于步骤 1 的"翻译后的看点"？

---

## 步骤 3 检查点（分镜脚本）

### 时间分配

- [ ] [0-5s] 钩子镜头 + 字幕悬念？
- [ ] [5-25s] 抵达 + 环境建立？
- [ ] [25-75s] 核心段落：亮点 1 + 过渡 + 亮点 2？
- [ ] [75-105s] 高潮：亮点 3？
- [ ] [105-120s] 余韵 + 结尾钩子？
- [ ] 总时长是否 ≤ 120 秒？

### 亮点分层

- [ ] 亮点 1（铺垫）：中等奇观？
- [ ] 亮点 2（递进）：比亮点 1 更强？
- [ ] 亮点 3（高潮）：最强奇观？
- [ ] 三个亮点时长大致 25/25/30 秒（可微调 ±5s）？

### 旁白

- [ ] 总字数是否在 300-420 字之间？
- [ ] 是否保持冷静理性型语感（无惊呼、无过度煽情）？
- [ ] 奇观镜头是否留白（0 旁白）？
- [ ] 每段旁白之间是否留了 2-5 秒纯画面呼吸？

### 音效

- [ ] 每个镜头是否至少标注了 1 个 ARSM 标签？
- [ ] 是否区分了 Ambient（持续）和 SFX（一次性）？
- [ ] 是否考虑了 Room（空间混响）？
- [ ] 是否标注了 Movement（运动音）？

### 探险者一致性

- [ ] 探险者动作是否基于 `config/explorer-profile.md`？
- [ ] 探险者服装是否一致？
- [ ] 探险者装备是否一致？
- [ ] 探险者签名动作是否出现？

### 视角

- [ ] 默认第一人称？
- [ ] 第三人称镜头是否服务于内容？

### 平台适配

- [ ] 钩子是否在前 3 秒（抖音改编友好）？
- [ ] 节奏是否可以支持抖音改编（剪辑前置亮点 1）？

---

## 通用检查点

- [ ] 是否产出了所有要求的字段？
- [ ] 格式是否符合步骤要求的格式？
- [ ] 是否提交给用户过目？
