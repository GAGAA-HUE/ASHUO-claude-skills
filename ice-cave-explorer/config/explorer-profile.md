# 探险者 IP 风格档

## 占位人设

**陈漠**（chén mò）

## 6 维度档案

### 1. 基础身份

- 性别：男性
- 年龄段：22 岁左右
- 国籍：未知（旧世界国家已不存在）
- 职业假身份：后末日冰洞独立生存者 + 视频记录者
- 代际：父辈已逝，今年是他**一个人过的第三个冬天**

### 2. 五官特征

- 脸型：偏瘦，下颌线清晰（长期营养不足感，但筋骨分明）
- 发色发型：黑色、短发、常被帽子压乱
- 瞳色：深棕色（眼白微带辐射蓝光反射）
- 标志特征：右耳有一处旧冻伤疤、左手无名指缺失半截（早年事故）
- 表情基调：克制、极少大幅表情、专注

### 3. 身材体型

- 身高区间：175cm 左右
- 体格：精瘦但结实，长期冰洞生存的肌肉记忆
- 姿态：低重心、警觉、走路时身体略前倾

### 4. 服装系统

- 外层：自制的兽皮 / 旧布料混编大衣（深灰偏土黄，带风帽）
- 内层：捡来的旧世界羊毛衫（已补过多个补丁）
- 裤子：黑色工装裤（多处缝补）
- 靴子：自制兽皮靴（内衬异变苔藓纤维，触感温暖）
- 配饰：黑色半指手套、颈部系一条**褪色红围巾**（父亲留下的唯一遗物）

### 5. 签名装备

- **头灯**：旧世界头灯改装，能耗高（每天需用异变萤火虫尸体充一次电）
- **胸挂相机**：旧世界机械 / 数码混合相机（他父亲的，是他拍摄记录的全部理由）
- **冰镐**：自制的短柄冰镐（柄用异变冰晶骨磨成，刃是旧金属磨成）
- **背包**：自制兽皮背包（绳是异变苔藓搓的）
- **辐射计**：旧世界医疗箱改装的辐射计（每集开篇他会测一下）
- **辐射地图**：一块兽皮上画着他探索过的所有区域（用炭笔）
- **小本**：父亲留下的最后一页研究笔记（只剩一页，其余失落）

### 6. 签名动作 / 口头禅

- **动作**：
  - 进洞前先蹲下测辐射（最常用签名动作）
  - 装相机时习惯性摸一下相机快门
  - 出洞前回头看一眼洞口
  - 看见异变生物时不惊呼，只摸下巴思考
- **口头禅**：
  - 报告式开头："北纬 47度，冰下 X 米。气温 X，辐射 X。"
  - 偶尔的击中心智句："金属是这个世界最难得到的东西。"
