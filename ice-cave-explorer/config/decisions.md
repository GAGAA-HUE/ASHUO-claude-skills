# 决策摘要

本文件记录 Q0–Q12 全部决策，作为 LLM 执行时的硬约束锚点。每次启动 skill 前必读。

---

## 世界观锚点（Q0）

### 时代
- 设定年代：旧世界核战 → 冰河期 → 后末日复苏期，跨度约 1500 年
- 当下：冰川开始消融、辐射值回落、万物种复苏
- 主角位置：地表已进入"清雪期"，但地表仍有大量焦土、辐射区、禁区

### 主角代际
- 祖父辈：旧世界科学家 / 研究员
- 父辈：在冰洞中求生，技能传承为主，知识传承断代
- **主角代（陈漠这一代）**：技能 + 习惯（拍摄记录）保留，文字 / 科学知识基本失传
- 陈漠自身：父母已逝，今年是他**一个人过的第三个冬天**

### 主角基地
- 类型：地下冰洞庇护所（L1-8 雪洞原型）
- 选址逻辑：低辐射、低温、物资相对富集
- 周边环境：美丽奇幻但也暗藏危机，多异变生物 / 植物

### 世界母题三轴
1. **文明残骸**：旧世界人造物（地铁、车站、医疗箱、罐、金属、玻璃）散落冰川中，是稀缺资源
2. **复苏奇观**：冰下异变生物 / 植物，少数神奇、多数不可描述
3. **禁区 / 高辐射区**：边缘高风险地带，是系列后期拓展方向

### 系列叙事节奏
- 第 1 集：**日常 + 微奇观**（物资采集、出门日）
- 第 2–5 集：缓慢引入更强的复苏奇观、异变生物、禁区线索
- 第 6 集+：进入禁区 / 揭示世界观真相 / 父亲留下的研究笔记逐渐清晰

## Q1 视频形态

- **时长**：90–120 秒（默认 120 秒，可压缩）
- **画幅**：横屏 16:9
- **视角**：默认第一人称，少数第三人称为内容服务
- **风格**：伪纪录片 + 探险 VLog + 后期文学化击中心智
- **视觉核心**：写实 + 后末日异变奇观（强光影、克制奇观，留白多于堆叠）
- **AI 分工链**：场景设定 / 亮点 / 衍生选题 / 剧本 / 分镜 / 旁白 → LLM | 冰洞环境 → Seedance 2.5 | 探险者 → 图生视频 + 参考一致性 | 音乐 → Suno / Udio | 音效 → LLM 出描述文本（ARSM 体系）

## Q2 受众与平台

- **主阵地**：B 站（中视频）
- **辅阵**：抖音 + 小红书横屏改编版
- **改编方式**：纯剪辑处理（不另写剧本、不另做设定）
- **核心平台逻辑**：节奏按中视频平台发布逻辑设计（钩子前置 + 完整情节 + 结尾留接口）

## Q3 内容母题

- **系列母题三轴**：文明残骸 / 复苏奇观 / 禁区高辐射
- **单集结构**：A 单集独立成片（每集独立任务 / 独立奇观 / 独立钩子）
- **系列连贯**：陈漠 IP 跨集一致 + 世界观逐步揭示
- **角色一致性**：视为硬约束，不考虑实现难度

## Q4 单集内部结构

- **节奏骨架**：经典三幕 + 钩子前置
- **时间分配**：
  - [0–5s] 钩子镜头 + 字幕悬念
  - [5–25s] 抵达 + 环境建立（含日常起手）
  - [25–75s] 核心段落：亮点 1 + 过渡 + 亮点 2
  - [75–105s] 高潮：亮点 3
  - [105–120s] 余韵 + 结尾钩子（系列接口）
- **第 1 集特例**：钩子强度低于后续集数（日常 + 微奇观），奇观克制度高
- **结尾钩子强度**：第 1 集留小悬念（让观众等第 2 集）；后续集数逐步升级

## Q5 冰洞母题库

- **L1 母体库**：8 个写实原型（保留），加入 **3 个后末日母体**：
  - L1-A 后末日庇护所（雪洞 + 人造残骸混搭）
  - L1-B 冰下人造隧道（地铁 / 通道被冰封后的人造物 + 冰混合）
  - L1-C 异变生物栖息洞（冰 + 异变生物共生）
- **L2 派生规则**：杂交 / 变量替换 / 尺度畸变（LLM 自主生成新原型）
- **L3 创造性扩展**：需经用户审后入 L1

## Q6 衍生选题

- **三步转化法**：钩子识别 → 载体置换 → L1 配对
- **来源权重**：
  1. 后末日日常（最高权重）：采物资、修工具、记录、探险
  2. 长青题材（中等权重）：生存、奇观、解谜
  3. 跨域挪用（最低权重）：旧世界物品再生（如旧医疗箱当温度计）
- **风险过滤**：无（用户直接担责）

## Q7 探险者 IP

- **方向**：后末日探险者写实风格化（不取用任何游戏角色）
- **占位人设**：陈漠
- **可独立修改**：修改 explorer-profile.md 不影响其他内容，仅影响分镜脚本中探险者动作 / 服装 / 装备的具体描述

## Q8 叙事节奏

- **旁白形式**：第一人称旁白 + 字幕 + 后期文学化击中心智
- **语感**：**纪录者 + 文学化击中心智**
  - 主体冷静理性（测辐射、报位置）
  - 偶尔一句带末日历史厚度（"金属是这个世界最难得到的东西"）
  - 极少惊呼
- **信息密度**：中密度（2.5–3.5 字 / 秒，120 秒约 300–420 字）
- **与画面咬合**：画面为主，旁白为辅

## Q9 音效

- **ARSM 分类法**：Ambient / Room / SFX / Movement
- **用途**：仅作分镜脚本"音效"一列的分类标签
- **不产出**：具体音效描述文本

## Q10 Skill 范围

- **纯剧本层**：亮点设计 / 场景设定 / 分镜脚本
- **不产**：AI 工具提示词、操作手册
- **3 步流程**：每步完成后等待用户过目，前一步未通过不进入下一步
- **第 1 集母题选型**：已锁定为「出门日·物资清单」+「未标支洞钩子」

## Q11 产出物与文件结构

- **核心文件**：决策摘要 + 世界观档案 + 探险者 IP + L1 原型库 + 规则 + 工作流
- **第 1 集样例**：第 1 集做完后固化进 examples/episode-01.md
- **世界观独立**：worldbuilding.md 与 l1-prototypes.md 分开

## Q12 第 1 集核心约束

- **场景范围**：陈漠家（雪洞庇护所）+ 采物资路线（冰隧道）+ 翼骨采集点（局部钟乳冰洞）
- **物资清单（3 样）**：异变冰晶翼骨刀、异变苔藓搓绳、异变萤火虫晒火种
- **采物资目的**：冬季物资储备（第 3 个独自冬天）
- **结尾钩子**：走进一个未在地图上标过的支洞（系列接口）
- **第 1 集不承担**：禁区、辐射真相、父亲笔记揭示
