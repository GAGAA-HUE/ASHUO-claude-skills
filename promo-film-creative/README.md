# promo-film-creative

国际级宣传片创意启发大师（Promo Film Creative Master）。

这个 skill 用于为以下类型项目提供高质量创意启发与方案输出：
- 城市/国家形象片
- 品牌宣传片
- 产品发布片
- 公益 / 社会议题片
- TVC / viral video / 创意提案

它融合了 Cannes Lions、D&AD、One Show、Clio Awards、戛纳 / Sundance 等国际获奖作品的方法论，重点输出四类价值：
- 创意概念（Big Idea）
- 叙事结构建议
- 视听语言方向
- 国际参考案例拆解

## 适用场景

当你需要：
- 想一个宣传片的大创意
- 为品牌片、城市片、公益片找突破口
- 做创意提案，需要国际案例参考
- 希望把“普通宣传片”升级成更有奖项气质的创意方案
- 对现有想法不满意，想换一个更高级的表达方向

都可以直接使用这个 skill。

## 两种工作模式

### 1. `/generate`
适合信息已经比较完整时使用。

会直接输出完整创意方案，通常包含：
- 项目理解
- 战略洞察
- Big Idea
- 三个差异化创意方向
- 视听语言建议
- 国际参考案例
- 创意风险提示

### 2. `/deepen`
适合项目还比较模糊、需要一步步发掘时使用。

会用苏格拉底式问答逐步推进，常见深化顺序为：
- 洞察
- 张力
- 表达角度
- 情感
- 视觉语言

## 推荐输入方式

为了得到更好的结果，建议尽量提供这些信息：
- 客户 / 品牌 / 城市名称
- 宣传目的
- 目标受众
- 预算量级
- 播出平台
- 时长要求
- 已有素材、品牌资产或限制条件

## 示例用法

### 示例 1：直接出方案
```text
请用 promo-film-creative 帮我做一个城市宣传片创意。
项目：某地级市文旅宣传片
目标：吸引年轻游客和新媒体传播
时长：90 秒
平台：抖音、B站、招商推介会
预算：中等
希望方向：不要太传统政府宣传片
```

### 示例 2：先做创意深化
```text
请用 promo-film-creative /deepen 模式帮我梳理这个品牌宣传片。
品牌是做智能家居的，但我现在只知道“不想拍得像普通产品广告”。
```

### 示例 3：要国际参考
```text
请用 promo-film-creative 给我 3 个适合公益短片的国际获奖案例，并说明可以借鉴什么。
```

## 输出特点

这个 skill 偏向：
- 先找洞察，再做创意
- 强调人性真相、文化张力和表达角度
- 区分“安全方案”和“有奖项潜力的大胆方案”
- 提供可迁移的国际案例方法论，而不是只给片名

## 注意事项

- 如果项目信息不充分，skill 会更适合先走 `/deepen`。
- 如果你已经有明确需求和条件，直接 `/generate` 更高效。
- 这个 skill 强于“创意开发与提案”，不是直接输出拍摄执行表或完整分镜表。
- 如果后续要继续细化镜头、导演风格、AI 视频提示词，可再配合其他导演/分镜类 skill 使用。
