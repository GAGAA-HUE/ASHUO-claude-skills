# 拍我视频大师（PaiWoTSC-DaShi）

> 自然语言驱动的 AI 视频提示词生成器 | V6 模型实测优化版

## V6 模型实测核心结论

### 关键发现（来自多维度测试）

| 测试维度 | 核心发现 | 应对策略 |
|---------|---------|---------|
| **微表情演技** | 视线直视镜头破坏共情，需明确空间关系 | 使用"四分之三侧面"、"画外左侧"等空间术语 |
| **物理规律** | 复杂术语（抛物线、Worthington jet）理解偏差 | 自然语言描述物理过程，避免学术术语 |
| **15秒叙事** | 模型自动切镜规避长镜头生成错误 | 复杂场景主动切镜，简单场景控制在 8-10 秒 |
| **多镜头调度** | 用户原始自然语言优于"专业化改写" | 最小化干预，仅添加必要约束 |
| **音画同步** | "连贯旋律"等词导致音频无停顿 | 用动作节奏暗示音频（敲击-停顿-敲击） |

### 核心原则：空间叙事 > 时间控制

V6 模型对**清晰的空间关系**响应更好，对**精确的时间标记**（@5s）理解不稳定。

## 提示词生成原则

### DO（推荐做法）

| 维度 | 正确做法 | 示例 |
|------|---------|------|
| **语言风格** | 自然语言为主，嵌入必要专业术语 | "四分之三侧面"、"rim light"、"画外左侧" |
| **视线处理** | 明确看向何处 | "视线落在信纸"、"移向画外左侧的窗户" |
| **机位描述** | 明确空间关系 | "侧面平视"、"略俯视 15 度"、"过肩视角" |
| **时序控制** | 用顺序词描述 | "停顿片刻后...慢慢...然后...最后..." |
| **音画同步** | 动作节奏暗示音频 | "敲击-停顿-敲击"、"水流持续，落勺前已平静" |
| **切镜策略** | 复杂场景主动切镜 | 15秒拆为 8+7 秒，机位/角度有明显变化 |

### DON'T（避免做法）

| 维度 | 错误做法 | 原因 |
|------|---------|------|
| **结构化标记** | @5s、镜头1/2/3、表格化参数 | 增加噪声，模型理解不稳定 |
| **过度术语化** | 堆砌专业术语制造"专业感" | 用户原始自然语言效果更好 |
| **精确时间** | "@3.2s 眼泪滑落" | V6 时间精度不足，导致错位 |
| **连续音频暗示** | "连贯的旋律"、"流畅的" | 模型生成无停顿音频，音画不同步 |
| **强制长镜头** | 15秒复杂场景强制一镜到底 | 模型自动切镜，空间关系断裂 |

## 工作流程

### Step 1：解析用户输入

从自然语言中提取：

| 要素 | 提取目标 | 示例 |
|------|---------|------|
| `总时长` | 判断是否需要切镜 | 15秒→考虑拆分为 8+7 秒 |
| `核心动作` | 确定空间主体和关系 | "找书→抽出→发现照片" |
| `情绪基调` | 选择光影术语 | 治愈→柔和侧逆光；紧张→顶光、高对比 |
| `硬性约束` | 必须明确的参数 | 一镜到底/切镜、不要看镜头、固定机位 |

### Step 2：构建空间叙事

**优先建立空间关系**：

```
用户："一个人在房间里打字"
↓
转化："安静的房间里，一盏台灯照亮桌面。一只手进入画面，手指悬在机械键盘上方"
↓
空间锚点：台灯（光源位置）、桌面（动作平面）、画面边缘（手部进入方向）
```

### Step 3：嵌入专业术语

在关键位置插入必要术语，增强精确性：

| 场景 | 自然语言 | +专业术语 |
|------|---------|----------|
| 面部角度 | "侧脸对着画面" | "面部呈四分之三侧面朝向画面" |
| 光影 | "光线从窗户照进来" | "侧逆光从窗户照入，形成 rim light" |
| 视线 | "看向窗外" | "视线移向画外左侧的窗户方向" |
| 机位 | "从侧面看" | "侧面平视，固定机位，无 camera movement" |

### Step 4：生成最终提示词

**结构**：
1. 环境建立（空间锚点）
2. 主体动作（时序描述）
3. 专业术语（精确化关键细节）
4. 硬性约束（时长、分辨率、固定声明）

## 多镜头场景处理

### 何时切镜

| 情况 | 建议 |
|------|------|
| 动作复杂（找书→抽出→翻开→发现） | 主动切镜，每镜 5-8 秒 |
| 空间跳跃（室内→室外） | 必须切镜，明确新空间关系 |
| 情绪转折（平静→惊讶） | 可用切镜强化，也可用长镜头保持克制 |
| 简单动作（浇水→发现嫩芽→微笑） | 一镜到底，8-10 秒 |

### 切镜原则

**必须满足**：机位或角度有**显著变化**，否则不如长镜头。

| 错误切镜 | 正确切镜 |
|---------|---------|
| 正面特写 → 正面近景（仅景别微调） | 正面中景 → 侧面特写（角度变化） |
| 侧面 45度 → 侧面 60度（无实质变化） | 侧面平视 → 俯拍桌面（视角变化） |

## 音画同步策略

### 核心：用视觉节奏驱动音频

**错误**："一段连贯的打字旋律"
**正确**："敲击，停顿，再敲击，节奏逐渐加快"

### 同步标记方法

| 方法 | 示例 | 适用 |
|------|------|------|
| 动作-声音绑定 | "食指落下击中键帽，敲击声响起" | 精确同步点 |
| 节奏暗示 | "敲击-停顿-敲击-连击" | 复杂节奏 |
| 状态描述 | "水流持续，落勺前已平静" | 避免音频重叠 |

## 示例对比

### 示例 1：微表情演技

**用户输入**：
> "一位中年女性收到旧信，眼眶泛红，最后含泪微笑。15秒，不要看镜头。"

**旧版（错误）**：
```
[镜头1 | 0-5s] 正面特写，眼神平静...
[镜头2 | 5-10s] 正面特写，眼眶泛红...
[镜头3 | 10-15s] 正面特写，含泪微笑...
```
❌ 问题：伪多镜头，角度无变化，模型生成跳切

**新版（正确）**：
```
一位中年女性坐在窗边，面部呈四分之三侧面朝向画面，视线落在手中的信纸上。
她的手指捏着泛黄的信封，停顿片刻后拆开。视线从信纸缓缓移向画外左侧的窗户
方向，眼眶内侧慢慢泛红，下眼睑微微颤抖。一滴泪水滑落，嘴角却轻轻上扬，
形成含泪的微笑。侧逆光从窗户照入，在她的面部轮廓形成柔和的 rim light。
8秒，一镜到底，固定机位。
```
✅ 修正：缩短时长，明确空间关系，自然语言+必要术语

---

### 示例 2：多镜头叙事

**用户输入**：
> "女生在书房找书，抽出旧书，发现里面夹着老照片。15秒。"

**旧版（错误）**：
```
女生站在书房的书架前，侧身对镜头。切镜，正面中景，手指勾住书脊抽出。
切镜，过肩特写，书在手中翻开...
```
❌ 问题："切镜"标记被模型误读，机位变化过于频繁

**新版（正确）**：
```
女生站在书房的书架前，手指划过书脊，停在一本褐色封面的旧书前，抽出。
[切镜] 她坐在桌前，书在手中翻开，泛黄的纸页间滑出一张对折的老照片，
飘向桌面。[切镜] 俯拍桌面，照片正面朝上摊开，是一个小孩站在槐树下的
黑白影像。女生的手指进入画面，指尖悬在照片上方，没有触碰。
8秒 + 7秒，1080p。
```
✅ 修正：仅两处切镜，每镜有明确空间变化（书架前→桌前→俯拍桌面）
