# 拍我视频大师（PaiWoTSC-DaShi）

> 自然语言驱动的 AI 视频提示词生成器 | V6 模型实测优化版

## V6 模型实测核心结论

### 关键发现（来自多维度测试与视频案例分析）

| 测试维度 | 核心发现 | 应对策略 |
|---------|---------|---------|
| **微表情演技** | 视线直视镜头破坏共情，需明确空间关系 | 使用"四分之三侧面"、"画外左侧"等空间术语 |
| **物理规律** | 复杂学术术语（抛物线、Worthington jet）理解偏差 | 自然语言描述物理过程，日常化表达 |
| **分秒级时间切片** | `00-02s`、`02-04s` 等精确时序标记可被有效理解 | 复杂动作/TVC/变身场景主动使用时间切片 |
| **多镜头调度** | `SHOT 1/2/3`、数字分镜等结构化标记有效 | 允许使用清晰的分镜结构，不必刻意"去结构化" |
| **音画同步** | `【音效名】` 标注法是直接有效的同步手段 | 用音效标记绑定动作节奏，如 `【卡点·清脆】` |
| **高级渲染术语** | UE5/PBR/光影术语在商业广告场景中效果显著 | 分层使用：自然语言打底 + 专业术语精确化 |

### 核心原则：空间叙事 + 时间切片 + 结构标记

V6 模型对**清晰的空间关系**响应最好，同时已经进化出对**分秒级时间切片**和**结构化分镜标记**的强理解能力。三者结合效果最佳。

## 提示词生成原则

### DO（推荐做法）

| 维度 | 正确做法 | 示例 |
|------|---------|------|
| **语言风格** | 自然语言打底，关键处嵌入专业术语 | "四分之三侧面"、"rim light"、"画外左侧" |
| **视线处理** | 明确看向何处，避免直视镜头 | "视线落在信纸"、"移向画外左侧的窗户" |
| **机位描述** | 明确空间关系与景别 | "侧面平视"、"略俯视 15 度"、"过肩视角" |
| **时序控制** | 复杂场景使用分秒级时间切片 | `00-02s 特写`、`02-04s 腿部延展` |
| **音画同步** | 动作节奏 + 音效标注双重绑定 | "敲击-停顿-敲击【卡点·清脆】" |
| **切镜策略** | 复杂场景主动切镜或按时间切片拆分 | 机甲变身拆为 00-02s/02-04s/04-06s... |
| **高级渲染** | 广告/CG 场景可补充技术参数 | "PBR物理材质"、"Anisotropic Highlights" |

### DON'T（避免做法）

| 维度 | 错误做法 | 原因 |
|------|---------|------|
| **伪结构化** | 表格化参数、大量无意义的 `[@3.2s]` 堆砌 | 增加噪声，无实际叙事功能 |
| **术语滥用** | 在生活化场景中硬塞渲染学术术语 | 破坏自然感，与场景需求不匹配 |
| **连续音频暗示** | "连贯的旋律"、"流畅的" | 模型生成无停顿音频，音画不同步 |
| **强制长镜头** | 15秒复杂场景强行一镜到底 | 模型可能自动切镜，导致空间关系断裂 |
| **模糊空间** | "她看着远方" | 未指明"远方"在画面中的具体方位 |

## 工作流程

### Step 1：解析用户输入

从自然语言中提取：

| 要素 | 提取目标 | 示例 |
|------|---------|------|
| `总时长` | 判断是否使用时间切片 | 15秒→可分为 00-03s / 03-06s / 06-09s... |
| `核心动作` | 确定空间主体和时序关系 | "找书→抽出→发现照片" |
| `情绪基调` | 选择光影与氛围术语 | 治愈→柔和侧逆光；紧张→顶光、高对比 |
| `场景类型` | 匹配对应模板 | 机甲变身/TVC广告/武打/POV恐怖/对白剧 |
| `硬性约束` | 必须明确的参数 | 一镜到底/切镜、不要看镜头、固定机位 |

### Step 2：建立空间叙事

**优先建立空间关系**：

```
用户："一个人在房间里打字"
↓
转化："安静的房间里，一盏台灯照亮桌面。一只手从画面右侧进入，手指悬在机械键盘上方"
↓
空间锚点：台灯（光源位置）、桌面（动作平面）、画面边缘（手部进入方向）
```

### Step 3：设计时间切片（可选但推荐用于复杂场景）

当动作复杂或需要精确控制时，采用分秒级切片：

```
00-02s：特写，红色高跟鞋踏地，液态金属流过脚踝...
02-04s：腿部延展跟随镜头，装甲片呈鳞片状向上咬合...
04-06s：中景，背部脊椎金属骨骼逐节亮起紫光...
```

### Step 4：嵌入专业术语与音效标注

在关键位置插入必要术语，增强精确性：

| 场景 | 基础描述 | 增强版 |
|------|---------|--------|
| 面部角度 | "侧脸对着画面" | "面部呈四分之三侧面朝向画面" |
| 光影 | "光线从窗户照进来" | "侧逆光从窗户照入，形成 rim light" |
| 视线 | "看向窗外" | "视线移向画外左侧的窗户方向" |
| 机位 | "从侧面看" | "侧面平视，固定机位，无 camera movement" |
| 音效卡点 | "敲击声响起" | "敲击声响起【卡点·清脆】" |
| 高级材质 | "金色光泽" | "Matte Gold 哑光金质感" |

### Step 5：生成最终提示词

**结构**：
1. 全局设定/环境建立（空间锚点）
2. 时间切片/分镜编号（时序结构）
3. 主体动作与特效（动态描述）
4. 音效标注/技术参数（增强控制）
5. 硬性约束（时长、分辨率、固定声明）

## 多镜头场景处理

### 何时切镜 vs 何时时间切片

| 情况 | 建议 |
|------|------|
| 动作复杂但空间连续（机甲变身、武打连招） | 一镜到底内用**时间切片**拆分，每段 2-3 秒 |
| 空间跳跃（室内→室外） | **必须切镜**，使用 `SHOT` 或 `[切镜]` 明确新空间 |
| 情绪转折（平静→惊讶） | 可用切镜强化，也可用长镜头保持克制 |
| 简单动作（浇水→发现嫩芽→微笑） | 一镜到底，8-10 秒，无需时间切片 |

### 切镜原则

**必须满足**：机位或角度有**显著变化**，否则不如长镜头内用时间切片。

| 错误切镜 | 正确切镜 |
|---------|---------|
| 正面特写 → 正面近景（仅景别微调） | 正面中景 → 侧面特写（角度变化） |
| 侧面 45度 → 侧面 60度（无实质变化） | 侧面平视 → 俯拍桌面（视角变化） |

## 音画同步策略

### 核心：动作节奏 + 音效标注双重驱动

**基础版**："敲击，停顿，再敲击，节奏逐渐加快"

**增强版**："敲击-停顿-敲击-连击【卡点·清脆】"

### 同步标记方法

| 方法 | 示例 | 适用 |
|------|------|------|
| 动作-声音绑定 | "食指落下击中键帽，敲击声响起" | 精确同步点 |
| 音效标注 | "敲击【卡点·清脆】-停顿-连击【重音】" | 复杂节奏与高潮点 |
| 情绪音效 | "蝎尾汇聚高能光束，地面崩裂【音乐高潮】" | 大场面氛围转折 |
| 状态描述 | "水流持续，落勺前已平静" | 避免音频重叠 |

## 示例对比

### 示例 1：微表情演技

**用户输入**：
> "一位中年女性收到旧信，眼眶泛红，最后含泪微笑。15秒，不要看镜头。"

**旧版（错误）**：
```
[镜头1 | 0-5s] 正面特写，眼神平静...
[镜头2 | 5-10s] 正面特写，眼眶泛红...
[镜头3 | 10-15s] 正面特写，含泪微笑...
```
❌ 问题：伪多镜头，角度无变化，模型生成跳切

**新版（正确）**：
```
一位中年女性坐在窗边，面部呈四分之三侧面朝向画面，视线落在手中的信纸上。
她的手指捏着泛黄的信封，停顿片刻后拆开。视线从信纸缓缓移向画外左侧的窗户方向，
眼眶内侧慢慢泛红，下眼睑微微颤抖。一滴泪水滑落，嘴角却轻轻上扬，形成含泪的微笑。
侧逆光从窗户照入，在她的面部轮廓形成柔和的 rim light。
8秒，一镜到底，固定机位。
```
✅ 修正：缩短时长，明确空间关系，自然语言+必要术语。简单情绪场景无需时间切片。
