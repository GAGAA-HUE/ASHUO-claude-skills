# 时间轴模板库

> 常见视频类型的时间轴结构模板

---

## 模板A：Vlog 开场（15秒）

**结构**：钩子→建立→预告

```
[0s-3s] 钩子镜头
├─ 功能: 抓住注意力
├─ 内容: 最精彩的瞬间/悬念/金句
├─ 镜头: 特写或动态镜头
└─ 音频: 音乐强起或音效冲击

[3s-8s] 建立镜头
├─ 功能: 交代时间地点人物
├─ 内容: 环境展示+人物出场
├─ 镜头: 全景→中景
└─ 音频: BGM主旋律进入

[8s-15s] 预告/过渡
├─ 功能: 预告内容，引导观看
├─ 内容: 快速剪辑精彩片段
├─ 镜头: 多镜头快切
└─ 音频: 音乐节奏加速
```

## 模板B：产品广告（30秒）

**结构**：问题→解决方案→产品展示→行动号召

```
[0s-5s] 问题/痛点建立
├─ 功能: 引起共鸣
├─ 内容: 展示问题场景
└─ 情绪: 困扰、不便

[5s-10s] 解决方案引入
├─ 功能: 产品首次亮相
├─ 内容: 产品优雅出场
└─ 情绪: 希望、期待

[10s-20s] 产品展示
├─ 功能: 核心卖点展示
├─ 内容: 3-4个卖点，每点2-3秒
├─ 镜头: 特写+动态展示
└─ 情绪: 惊喜、赞叹

[20s-25s] 使用场景
├─ 功能: 代入感建立
├─ 内容: 真实使用场景
└─ 情绪: 满足、愉悦

[25s-30s] 行动号召
├─ 功能: 引导购买/关注
├─ 内容: 产品+Slogan+购买信息
└─ 情绪: 紧迫感/期待
```

## 模板C：情感短片（60秒）

**结构**：三幕式（建立→冲突→解决）

### 第一幕：建立（0-15s）
```
[0s-5s] 日常展示
├─ 内容: 主角日常生活
├─ 情绪: 平静、普通
└─ 色调: 中性偏暖

[5s-15s] 关系建立
├─ 内容: 人物关系展示
├─ 情绪: 温馨、亲密
└─ 音乐: 轻柔主题旋律
```

### 第二幕：冲突/转折（15-45s）
```
[15s-25s] 冲突出现
├─ 内容: 问题/分离/挑战
├─ 情绪: 紧张、不安
├─ 色调: 转冷
└─ 音乐: 小调/节奏变化

[25s-35s] 冲突升级
├─ 内容: 情绪最低点
├─ 情绪: 悲伤、挣扎
└─ 镜头: 特写，孤立感

[35s-45s] 转折/希望
├─ 内容: 转机出现
├─ 情绪: 希望萌芽
├─ 色调: 回暖
└─ 音乐: 主旋律回归
```

### 第三幕：解决/升华（45-60s）
```
[45s-55s] 解决/重逢
├─ 内容: 问题解决/人物重逢
├─ 情绪: 释然、感动
└─ 镜头: 中景，拥抱/微笑

[55s-60s] 升华/余韵
├─ 内容: 美好结局/主题升华
├─ 情绪: 温暖、满足
├─ 色调: 暖金
└─ 音乐: 主题高潮+渐弱
```

## 模板D：节奏快闪（15秒）

**结构**：节拍驱动，每拍一个画面

```
假设音乐: 120BPM = 每拍0.5秒

[0.0s] 拍1: 画面A（建立）
[0.5s] 拍2: 画面B（切镜）
[1.0s] 拍3: 画面C（切镜）
[1.5s] 拍4: 画面D（切镜）
[2.0s] 拍5: 画面E（加速）
...
[14.0s] 最后1秒: 品牌/Slogan定格
```

**要点**：
- 每个画面不超过2秒
- 切镜点与音乐节拍精确对齐
- 画面内容形成视觉节奏（快-快-慢-快）
- 最后1-2秒留给品牌信息

## 模板E：治愈系自然（30秒）

**结构**：自然流动，情绪渐进

```
[0s-5s] 大景建立
├─ 内容: 山川/海洋/森林全景
├─ 镜头: 航拍/广角，缓慢移动
├─ 情绪: 开阔、宁静
└─ 音频: 自然环境音（风声/水声）

[5s-12s] 中景过渡
├─ 内容: 中景自然元素（树木/花朵/水流）
├─ 镜头: 中焦，轻微运动
├─ 情绪: 亲近、细腻
└─ 音频: 轻音乐渐入

[12s-20s] 细节特写
├─ 内容: 自然细节（露珠/花瓣/纹理）
├─ 镜头: 特写/微距，浅景深
├─ 情绪: 惊叹、治愈
└─ 音频: 音乐主旋律

[20s-25s] 人物融入
├─ 内容: 人物与自然互动（背影/手部/侧脸）
├─ 镜头: 中景，人物与环境关系
├─ 情绪: 和谐、归属
└─ 音频: 音乐情绪高点

[25s-30s] 收束/余韵
├─ 内容: 远景或空镜，人物渺小
├─ 镜头: 远景，静止或极慢运动
├─ 情绪: 沉淀、余韵
└─ 音频: 音乐渐弱，环境音回归
```

## 模板F：悬疑紧张（20秒）

**结构**：悬念建立→紧张升级→释放

```
[0s-3s] 悬念建立
├─ 内容: 神秘场景，局部展示
├─ 镜头: 特写，浅景深
├─ 光影: 高对比，阴影主导
└─ 音频: 低频嗡鸣，不规则节奏

[3s-8s] 信息揭示
├─ 内容: 缓慢揭示环境信息
├─ 镜头: 缓慢推镜或横移
├─ 情绪: 好奇、不安
└─ 音频: 音乐渐入，紧张感上升

[8s-15s] 紧张升级
├─ 内容: 关键元素出现/人物反应
├─ 镜头: 快速剪辑，特写为主
├─ 运动: 手持晃动或急促运动
├─ 情绪: 紧张、恐惧
└─ 音频: 节奏加快，音效密集

[15s-18s] 高潮/惊吓
├─ 内容: 关键事件/惊吓点
├─ 镜头: 极短镜头，冲击性画面
├─ 情绪: 恐惧/震惊
└─ 音频: 音效峰值，音乐骤停或强音

[18s-20s] 余韵/悬念
├─ 内容: 黑场或静止画面
├─ 镜头: 固定，长镜头
├─ 情绪: 余悸、悬念
└─ 音频: 寂静或远音效
```

## 时间轴设计检查清单

- [ ] 总时长是否符合平台要求？
- [ ] 情绪曲线是否有起伏（避免平淡）？
- [ ] 前3秒是否有钩子？
- [ ] 是否有明确的开始和结束？
- [ ] 音频层是否与画面同步设计？
- [ ] 镜头数量是否适合 AI 生成（每镜5-10秒）？
- [ ] 切镜点是否有明确的视觉/音频动机？
