# 焦距情绪映射表

> 镜头焦距与情绪效果的对照参考

---

## 焦距心理学基础

**焦距不仅是光学参数，更是情绪工具。**

不同焦距通过以下方式影响观众情绪：
- **透视变形**：广角拉伸空间，长焦压缩空间
- **景深控制**：浅景深孤立主体，深景深展示环境
- **面部比例**：不同焦距改变面部特征比例
- **观察者距离**：焦距暗示观众与主体的物理/心理距离

---

## 焦距分段详解

### 超广角（14-24mm）

**光学特性**：
- 极大视野（114°-84°）
- 强烈透视变形
- 边缘拉伸效应
- 深景深（f/8时从1米到无限远都清晰）

**情绪效果**：
| 焦距 | 情绪关键词 | 适用场景 |
|------|-----------|----------|
| 14mm | 迷失、梦境、超现实 | 精神异常、幻觉、史诗环境 |
| 16mm | 压迫、渺小、震撼 | 人物被环境吞噬、自然灾害 |
| 20mm | 开阔、自由、孤独 | 风景、独处、探索 |
| 24mm | 环境主导、观察者 | 纪录片、环境人像 |

**使用警示**：
- 近距离拍摄人物会严重扭曲面部（大鼻子、小耳朵）
- 除非故意追求变形效果，否则避免在人物尊严场景使用

**示例**：
```
场景: 人物站在摩天大楼之间
焦距: 16mm
效果: 建筑向天空汇聚，人物渺小如蚁
情绪: 都市压迫感、个体渺小
```

---

### 广角（28-35mm）

**光学特性**：
- 接近人眼视野（63°-54°）
- 轻微透视变形
- 较好的环境包容性
- 纪录片常用焦距

**情绪效果**：
| 焦距 | 情绪关键词 | 适用场景 |
|------|-----------|----------|
| 28mm | 真实、中立、观察者 | 新闻摄影、街头摄影 |
| 35mm | 自然、舒适、亲和 | 环境人像、旅行视频 |

**使用建议**：
- 28mm：当需要"我在场"的见证感
- 35mm：最通用的广角，适合建立镜头

**示例**：
```
场景: 咖啡厅内，人物与环境
焦距: 35mm
效果: 自然呈现人物与环境关系
情绪: 真实、生活化
```

---

### 标准（50mm）

**光学特性**：
- 最接近人眼单眼视野（46°）
- 透视自然，无明显变形
- "所见即所得"

**情绪效果**：
- **真实感最强**：观众感觉"我就在那里"
- **情绪中性**：不偏向任何情绪方向
- **万能焦距**：文戏、武戏、人像、风景都能用

**使用建议**：
- 不知道用什么焦距时，用50mm
- 需要客观、中立视角时
- 文戏对话的标准选择

**示例**：
```
场景: 两人对话
焦距: 50mm
效果: 自然视角，观众成为隐形第三者
情绪: 中立观察，不介入
```

---

### 中焦（85-135mm）

**光学特性**：
- 轻微背景压缩
- 面部比例自然（85mm）到轻微扁平（135mm）
- 容易获得浅景深

**情绪效果**：
| 焦距 | 情绪关键词 | 适用场景 |
|------|-----------|----------|
| 85mm | 亲密、专注、温柔 | 人像、情绪近景、爱情戏 |
| 100mm | 观察、审视、距离 | 微表情、侦查、偷窥视角 |
| 135mm | 孤立、压缩、平面感 | 肖像、观察者、城市丛林 |

**使用建议**：
- 85mm：人像摄影的"黄金焦距"
- 100mm：微表情捕捉，审讯场景
- 135mm：创造与主体的距离感

**示例**：
```
场景: 人物眼神特写
焦距: 85mm
效果: 面部比例完美，背景柔和虚化
情绪: 亲密、深入内心
```

---

### 长焦（200mm+）

**光学特性**：
- 强烈背景压缩
- 极窄视野（12°以下）
- 浅景深极易实现
- 需要远距离拍摄

**情绪效果**：
| 焦距 | 情绪关键词 | 适用场景 |
|------|-----------|----------|
| 200mm | 监视、猎物、距离 | 跟踪、监视、体育 |
| 300mm | 窥视、孤立、抽离 | 野生动物、偷拍视角 |
| 400mm+ | 抽象、图案、超现实 | 建筑局部、抽象构图 |

**使用建议**：
- 创造"观察者"而非"参与者"的感觉
- 城市丛林感（建筑压缩）
- 体育、野生动物（物理距离需要）

**示例**：
```
场景: 人群中的人物
焦距: 200mm
效果: 前后景压缩，人物被环境包围
情绪: 孤独、被淹没、城市疏离
```

## 焦距与情绪曲线

### 渐进式情绪积累

```
情绪强度: 低 ──────────────────────────────→ 高

焦距序列:
24mm（建立）→ 35mm（发展）→ 50mm（接近）→ 85mm（亲密）→ 135mm（深入）

效果:
观众从远处观察者逐渐变为亲密参与者
```

### 爆发式情绪冲击

```
情绪强度: 极高 ─────────────────────────────→ 释放

焦距序列:
135mm（紧张特写）→ 突然切 24mm（环境揭示）

效果:
从极度紧张突然释放，展示更大图景
```

### 震荡式情绪对比

```
情绪强度: 高 → 低 → 高 → 低

焦距序列:
85mm（亲密）→ 24mm（疏离）→ 85mm（亲密）→ 24mm（疏离）

效果:
情绪起伏，人物关系张力
```

## 焦距选择决策树

```
开始
  │
  ├─ 需要展示环境？
  │   ├─ 是 → 广角（14-35mm）
  │   └─ 否 → 继续
  │
  ├─ 需要情绪亲密？
  │   ├─ 是 → 中焦（85-135mm）
  │   └─ 否 → 继续
  │
  ├─ 需要观察者距离？
  │   ├─ 是 → 长焦（200mm+）
  │   └─ 否 → 继续
  │
  └─ 不确定 → 标准（50mm）
```

## AI 视频提示词中的焦距描述

### 直接描述法

```
"35mm lens, wide angle"（35mm镜头，广角）
"85mm portrait lens, shallow depth of field"（85mm人像镜头，浅景深）
"200mm telephoto, compressed background"（200mm长焦，压缩背景）
```

### 情绪描述法（推荐）

```
"intimate close-up, 85mm lens"（亲密特写，85mm镜头）
"epic wide shot, 16mm lens"（史诗广角，16mm镜头）
"observational medium shot, 50mm lens"（观察中景，50mm镜头）
```

### 效果描述法

```
"shallow depth of field, subject isolated from background"（浅景深，主体与背景分离）
"deep focus, everything in sharp detail"（深景深，所有细节清晰）
"compressed perspective, layers stacked together"（压缩透视，层次堆叠）
```

## 常见焦距组合

### 电影感三镜头组合

```
建立镜头: 24mm 或 35mm（环境+人物）
主镜头: 50mm（标准对话）
特写镜头: 85mm 或 135mm（情绪高点）
```

### 短视频快节奏组合

```
广角动作: 24mm（动态、速度感）
标准展示: 50mm（产品、人物）
特写强调: 85mm（细节、情绪）
```

### 纪录片观察组合

```
环境建立: 35mm（自然、真实）
主体跟随: 50mm（标准、灵活）
细节捕捉: 100mm（不介入、观察）
```
