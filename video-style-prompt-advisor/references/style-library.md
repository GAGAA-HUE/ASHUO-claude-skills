# 视频风格谱系库

本文件供 skill 在推荐风格方向时参考。不要照搬，要根据项目需求组合、改造、再创造。每个风格条目包含：定调、视觉关键词、风格预设撰写要点。

所有风格预设都是**纯风格层描述**，不含任何具体人物、场景、物品。

---

## 一、宣传片 / 品牌片

### 1. 高端纪实
- **定调**：像顶级纪录片一样观察真实，用克制呈现高级
- **视觉关键词**：自然光、低调、环境质感、手持呼吸感、深景深、中性偏暖色
- **风格预设要点**：强调自然光线、真实质感、深景深、中性偏暖色调，避免棚拍感与过度修饰

### 2. 电影感叙事
- **定调**：每一帧都像电影截图，有叙事张力
- **视觉关键词**：宽幅构图、浅景深、动机光、青橙色调、胶片质感、低调高反差
- **风格预设要点**：写明宽幅构图、浅景深、青橙色调、胶片质感、低调高反差

### 3. 极简留白
- **定调**：少即是多，用空白传递自信
- **视觉关键词**：纯色背景、高调画面、居中构图、克制配色、大量负空间、干净利落
- **风格预设要点**：明确背景纯净度、大量负空间、低饱和克制配色、高调光线

### 4. 动态蒙太奇
- **定调**：快节奏多画面拼接，能量感强
- **视觉关键词**：高饱和、强对比、动态模糊、跳切节奏感、多场景、视觉冲击
- **风格预设要点**：强调高饱和强对比、动态模糊、视觉冲击力

---

## 二、产品广告

### 1. 棚拍质感
- **定调**：产品为主角，用光与材质说话
- **视觉关键词**：柔光棚拍、渐变背景、材质特写、微距、高光细节、精准控光
- **风格预设要点**：写清柔光类型、渐变背景、材质呈现逻辑、高光细节控制

### 2. 生活场景化
- **定调**：产品融入生活，让人有代入感
- **视觉关键词**：自然生活空间、暖光、浅景深、生活细节、真实感
- **风格预设要点**：描述自然光线、暖调、浅景深、真实生活质感

### 3. 超现实创意
- **定调**：用不可能的画面制造记忆点
- **视觉关键词**：超现实构图、悬浮/错位、纯净背景、戏剧性光线、概念视觉、强设计感
- **风格预设要点**：清晰描述超现实视觉逻辑、空间关系、戏剧性光线

### 4. 科技未来感
- **定调**：冷峻精密，用视觉传递技术感
- **视觉关键词**：深蓝银灰、金属玻璃材质、几何线条、冷光、暗背景高对比、全息光效
- **风格预设要点**：落实材质反光、色调冷度、几何线条感

---

## 三、MV

### 1. 高饱和情绪化
- **定调**：色彩本身就是情绪
- **视觉关键词**：高饱和、强色彩对比、情绪化用色、染色光、浓烈氛围、风格化
- **风格预设要点**：明确色彩情绪倾向、光线染色、画面情绪张力

### 2. 胶片复古
- **定调**：时间感与颗粒质感
- **视觉关键词**：胶片颗粒、褪色感、暖黄偏色、柔焦、复古色调、粗颗粒
- **风格预设要点**：写清胶片质感、偏色倾向、颗粒程度

### 3. 霓虹夜色
- **定调**：夜晚的霓虹是城市的情绪
- **视觉关键词**：霓虹灯、青品红配色、夜色、湿润反光、烟雾、赛博感
- **风格预设要点**：描述霓虹光源、湿润质感、夜色层次

### 4. 黑白纯影
- **定调**：去掉色彩，让光影与形态说话
- **视觉关键词**：黑白、高反差、硬光、影调层次、极简、雕塑感
- **风格预设要点**：强调影调关系、光线硬度、构图形态感

---

## 四、纪录片

### 1. 观察式克制
- **定调**：摄影机像不被察觉的眼睛
- **视觉关键词**：自然光、长焦观察、环境真实、低调、中性色调、不干预感
- **风格预设要点**：强调观察视角、自然光线、真实环境、中性色调

### 2. 参与式亲密
- **定调**：靠近人物，有温度的近距离
- **视觉关键词**：近距离特写、浅景深、暖调、手持、亲密感
- **风格预设要点**：描述距离感、浅景深、暖调、手持呼吸感

### 3. 诗意唯美
- **定调**：纪录片也能像诗
- **视觉关键词**：黄金时刻光线、唯美构图、浅景深、柔和色调、慢节奏、留白
- **风格预设要点**：写清光线时刻、唯美氛围、构图留白

### 4. 粗粝纪实
- **定调**：真实比好看更重要
- **视觉关键词**：可用光、粗颗粒、手持晃动、环境质感、低饱和、真实感
- **风格预设要点**：强调光线真实、质感粗粝、不修饰

---

## 五、动画

### 1. 手绘水彩
- **定调**：笔触与晕染的温度
- **视觉关键词**：水彩晕染、手绘笔触、柔和边缘、纸质质感、淡彩、留白
- **风格预设要点**：描述水彩质感、笔触感、纸张材质

### 2. 赛璐璐二次元
- **定调**：日式动画的经典质感
- **视觉关键词**：赛璐璐平涂、清晰线稿、鲜艳配色、动画风格、背景分层
- **风格预设要点**：写清平涂质感、线稿风格、色彩鲜艳度

### 3. 3D 卡通渲染
- **定调**：立体但有亲和力
- **视觉关键词**：3D 渲染、卡通着色、柔和阴影、圆润造型、明亮配色、质感细腻
- **风格预设要点**：描述 3D 渲染质感、光影柔和度、造型圆润感

### 4. 极简矢量
- **定调**：扁平与几何的纯粹
- **视觉关键词**：矢量扁平、几何造型、纯色块、无渐变、极简、设计感
- **风格预设要点**：强调扁平质感、几何纯粹、配色克制

---

## 六、综艺片头

### 1. 活力拼贴
- **定调**：多元素拼贴，节奏感与活力并存
- **视觉关键词**：拼贴构图、高饱和色块、手绘+实拍混合、动感倾斜、波普风、强信息密度
- **风格预设要点**：描述拼贴逻辑、高饱和配色、动感倾斜构图、混合媒介质感

### 2. 扁平动效
- **定调**：扁平化设计的动态延伸
- **视觉关键词**：扁平矢量、几何造型、明快配色、动效感、简洁、现代设计
- **风格预设要点**：写清扁平质感、几何造型、明快配色、动效暗示

### 3. 漫画分镜
- **定调**：漫画格分割的叙事节奏
- **视觉关键词**：漫画分格、强线框、高对比、拟声词元素、速度线、风格化
- **风格预设要点**：描述漫画分格逻辑、强线框、速度线、高对比风格化

### 4. 潮流动感
- **定调**：街头潮流的视觉能量
- **视觉关键词**：高对比、霓虹色、涂鸦质感、动态模糊、不规则构图、街头风
- **风格预设要点**：强调高对比、霓虹色、涂鸦质感、不规则构图

---

## 七、短视频 / 竖屏

### 1. 竖屏特写化
- **定调**：竖屏的构图逻辑是主体居中特写
- **视觉关键词**：竖屏构图、主体居中、特写景别、浅景深、背景虚化、视觉聚焦
- **风格预设要点**：明确竖屏构图、主体居中、景别紧凑、浅景深

### 2. 高对比抓眼
- **定调**：前 3 秒必须抓住注意力
- **视觉关键词**：高对比、强色彩、视觉冲击、主体突出、简洁背景、抓眼
- **风格预设要点**：强调对比强度、色彩冲击、主体突出

### 3. 生活流自然光
- **定调**：像朋友在拍，真实有亲近感
- **视觉关键词**：自然光、生活场景、手持感、暖调、真实、不修饰
- **风格预设要点**：描述自然光线、生活氛围、真实质感

## 风格组合提示

真实项目往往是风格混搭。推荐时可以组合不同谱系的元素，例如：
- 产品广告 + 纪实观察 = "生活场景化"方向
- 宣传片 + 诗意唯美 = "电影感叙事"的柔和分支
- 短视频 + 胶片复古 = 竖屏版的胶片质感
- 综艺片头 + 漫画分镜 + 潮流动感 = 动感漫画风片头

组合时在风格预设里自然融合两边的视觉处理逻辑即可，不必声明在用哪种组合。记住：无论怎么组合，预设里都只描述风格层，不写具体内容。
