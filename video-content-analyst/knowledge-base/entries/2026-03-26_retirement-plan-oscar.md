## 维度一：创意与选题策略

**选题切入角**：老龄化社会 + 黑色幽默 —— 用荒诞包装残酷现实

**核心隐喻**：
- "退休" = 社会性死亡，从有用到无用的断崖
- 养老金 = 维持生命的最低燃料，随时可能耗尽
- 老年公寓 = 等待区，排队进入虚无

**受众筛选机制**：前5秒日常场景 + 微妙的不对劲感，筛选喜欢《黑镜》风格的观众

**不可替代性**：老年题材在动画中的罕见性，年龄歧视的直面

**选题公式**：
```
[老龄化焦虑] + [制度性冷漠] + [黑色幽默缓冲] + [存在主义选择]
```

## 维度四：文案与语言风格

- **语言调性**：机构公告式旁白，无情感的政策语言
- **声音设计**：
  - 环境：荧光灯嗡嗡声、打印机声、广播通知
  - 老人：沉默为主，偶尔的叹息
  - 制度：机械语音，去人性化
- **对白风格**：官僚术语 vs 日常语言的冲突

**叙事技巧**：
- 数字倒计时：剩余天数、养老金余额
- 表格与档案：人的数据化呈现
- 广播通知：制度的声音无处不在

## 核心可复用原则

1. **制度的视觉化** —— 用空间、颜色、声音让抽象制度具象可感
2. **数字的暴力** —— 年龄、余额、天数，量化即控制
3. **黑色幽默的缓冲** —— 荒诞让观众笑，笑后无法忘记
4. **沉默的主角** —— 老人的沉默是制度的噪音
5. **开放式讽刺** —— 不提供答案，只呈现困境
6. **对称的压迫** —— 构图的秩序感 = 制度的不可逃避
