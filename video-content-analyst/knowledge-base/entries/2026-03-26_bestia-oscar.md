## 维度一：创意与选题策略

**选题切入角**：历史记忆 + 心理惊悚 —— 用狗的视角看独裁统治

**核心隐喻**：
- 狗 = 政权看门人，忠诚与暴力的矛盾体
- 陶瓷质感 = 脆弱的历史记忆，易碎且被粉饰
- 兽性 = 既是狗的兽性，也是人的兽性，更是制度的兽性

**受众筛选机制**：前5秒可爱黏土狗 + 逐渐显露的暴力暗示，筛选能接受黑暗转折的观众

**不可替代性**：智利独裁历史的第一人称（狗）叙述，黏土动画的诡异质感

**选题公式**：
```
[历史创伤] + [动物视角的安全距离] + [黏土材质的诡异感] + [共谋伦理]
```

## 维度四：文案与语言风格

- **语言调性**：**完全无对白**
- **声音设计**：
  - 狗：呼吸声、爪子声、内心沉默
  - 环境：70年代智利街景音，远处军乐
  - 地下室：回声、金属声、人的呜咽（暗示）

**叙事技巧**：
- 限制视角：观众只知道狗知道的
- 暗示而非展示：暴力的间接呈现
- 历史符号：特定年代的服装、车辆、建筑

## 核心可复用原则

1. **动物视角的安全距离** —— 让观众通过狗"间接"经历创伤
2. **可爱与恐怖的反差** —— 黏土材质的天然可爱 vs 主题的黑暗
3. **限制视角的悬疑** —— 狗看不到的，观众也看不到
4. **材质的隐喻力量** —— 黏土的可塑性 = 历史被塑造、被改写
5. **共谋的伦理困境** —— 狗不是无辜受害者，也是加害者一环
6. **情感陷阱的叙事** —— 先建立爱，再揭示恐惧
