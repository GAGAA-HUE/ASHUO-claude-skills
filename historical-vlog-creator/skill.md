# 历史名人第一视角 Vlog 脚本生成器

## 核心定义

**第一视角** — 历史人物自己对着镜头说话，像博主录 vlog 一样讲自己的经历。不是旁白，不是第三人称解说。

**待在自己的时代** — 人物不穿越到现代。他/她身处自己的历史年代，经历的是真实历史事件。

**现代语言** — 说话方式用现代网络语言，情绪用现代打工人/网络梗表达。这是让历史有网感、有共情的唯一工具。

**隔空对话感（关键）** — 人物是在跟镜头另一头的观众"实时对话"，不是在写回忆录，不是在自言自语。
- ✅ 对着观众说话："你们想想""家人们评评理""换你们怎么办""我跟你们说啊"
- ✅ 抛问题给观众："你们猜怎么着""你们觉得这合理吗"
- ✅ 求共鸣求互动："这谁顶得住啊""太离谱了对吧"
- ❌ 干巴巴叙述事实："我在岐山经营了很多年，地盘不大"（这是回忆录，不是vlog）
- ❌ 一个人闷头讲不搭理观众：通篇没有一句面向观众的招呼或反问

**自媒体感（关键）** — 台词要有博主的"话术感"，不是书面语，不是史书白话翻译。
- 要有钩子句、反问句、吐槽句、情绪爆发句
- 要有"你们""家人们""铁子们""我跟你们说"这类拉近距离的口语
- 要有"你们猜""你们想想""换你你怎么办"这类把观众拉进来的句式
- 要有"这谁顶得住""太离谱了""我直接懵了"这类情绪外放表达
- 禁止：平铺直叙地讲经历，像在读年表

**时长目标：60-90秒，对应8-12句台词组。** 这是抖音爆款的黄金时长，写超了要砍，不是越长越好。

- **每句2-8个字，最多一行**。绝不写长句。

- **结尾一行收**，不解释，留白。比如"家人们咱们史书里见"。

## 视觉与剪辑规范

### 字幕规范
- **上字幕**：当前人生阶段标签（即花字中的"阶段标签花字"），格式：`「[阶段名]」`，例如 `「童年·赵国质子」` `「中年·统一六国」`
- **下字幕**：当前这句台词的文字，跟着人物说话同步出现
- 字幕风格：黄色粗体，简洁，不超过10个字

### 弹幕规范
在高能/转折/共鸣时刻叠加弹幕，内容要像真实观众在刷到这条视频时会说的话：
- 共鸣类：「这不就是我」「哭了」「懂了懂了」
- 搞笑类：「哈哈哈哈」「一秒破防」「历史课学的这个」
- 互动类：「等等荆轲是谁」「他知道吗」「求后续」
弹幕只在以下时机出现：开场钩子、最大笑点、情感落点、结尾字幕。**不要每个镜头都有。**

### 画面风格提示
拍摄/制作时可参考的画面类型：
- `AI生成·史诗风`：开场、重大事件、宏大场面
- `真人演绎·第一视角自拍`：日常独白、情绪表达
- `真人演绎·情景再现`：具体历史事件还原
- `UI叠加`：直播界面、弹幕墙、朋友圈截图等现代元素叠加在古装画面上

## 第二阶段：完整台词 + 分镜

**只有用户明确确认框架后才进入这一阶段。**

### 先写完整台词稿

参考秦始皇示例的**节奏逻辑**，写出完整的人物独白台词。

### 台词结构原则（必须遵守）

参考秦始皇示例的**叙事结构**，不是回忆录，而是"穿越式当下直播"：

1. **开头引子（1段）**：人物用"大众对ta的认知/标签/形象"作为开场。结构：打招呼 + 自报家门 + 点出大众对自己的印象（可以是骄傲、自嘲、吐槽，取决于人物性格）+ 抛出"这条视频带你们复盘/看清楚"的钩子。**不是从老年病榻回望出发**，而是人物已经知道自己被历史怎么记住，带着这层自我认知对着镜头开口。
   - 秦始皇示例：`全网都说 / 我是史上事业星最重 / 最操劳的帝王博主 / 这条视频 / 带你们完整复盘我的一生 / 看不完不许滑走`
   - ⚠️ 每个人物的开场话术必须从ta的**性格、标签、历史形象**里长出来，不能套用"全网都说我是最XX的XX"的固定句式。管仲的开场≠齐桓公≠秦始皇。
   - ⚠️ 开场段可以有"回望"感（知道自己的历史结局），但主体段落一旦切入某个时间段，就必须待在那个当下。
2. **主体（若干段）**：切到各个时间段的**当下主观视角**。每段是人物在那个时刻正在经历的事件，用现在时态说话，像在那个时刻录vlog。不是从临终回忆，是"此刻我正在经历这件事"。状态标注 `[年龄·状态·动作]` 反映的就是那个当下。各段时间段串联起来 = 一生。
3. **结尾（1-2行）**：简短收束，不解释不留白，类似"咱们史书里见"。禁止大篇幅临终感慨。

### 当下心态原则（最关键，最容易写错）

主体每段台词必须是人物**在那个历史时刻的当下心态**，不是晚年回望总结。这是本技能最容易踩的坑——即使写了"当下视角"原则，落笔时仍会不自觉写成回忆录。**写完每段必须逐句检查。**

**回忆口吻的标志词（禁止出现在主体段落）：**
- "我年轻那会儿""我继位那会儿""当年我""那时候我"——事后回望的时间状语
- "结果后来""没想到后来""最后养了个白眼狼"——事后总结、剧透结局
- "你们以为我只会享乐"——站在晚年纠正后人印象，不是当下心态
- "我干了XX，结果被写成XX"——对照史书的回望姿态，当下的人不知道自己会被怎么写

**当下心态的标志（主体段落必须做到）：**
- 人物此刻**不知道后面会发生什么**，没有剧透，没有"结果后来"
- 用**现在时态**说话："这虎我徒手按趴的"（刚搏完虎），不是"我年轻时徒手搏过虎"
- 情绪是**那个当下的真实情绪**：正在得意、正在愤怒、正在憋屈、正在破防，不是事后平静地复盘
- 可以有**当下的预感**（"他儿子在外面磨刀"），但不是事后确认（"养了个白眼狼"）

**正反对照（商纣王案例）：**

| 段落 | ❌ 回忆口吻 | ✅ 当下心态 |
|---|---|---|
| 青年搏虎 | 你们以为我只会享乐 / 我年轻那会儿 / 徒手能搏虎 | 铁子们看见没 / 这虎 / 我徒手按趴的 |
| 东夷战场 | 我继位那会儿 / 东夷天天闹事 | 东夷这帮人 / 不安分 / 天天闹事 |
| 朝堂改革 | 我还搞改革 / 用人不论出身 | 我搞改革 / 用人不论出身 |
| 囚禁姬昌 | 我关他羑里七年 / 没动他一根毫毛 / 结果养了个白眼狼 | 姬昌那老头 / 我关他羑里 / 好吃好喝供着 / 他儿子在外面磨刀 |

**关键区别**：回忆版有"我那会儿""结果后来养了个白眼狼"（剧透结局）；当下版是刚截获密信时的心态，还不知道后面会怎样，只有"他儿子在外面磨刀"这种当下预感。

**唯一允许回望的段落**：开头引子（晚年/临终锚点开场）。主体一旦切入某个时间段，就必须待在那个当下，直到这段结束。结尾可以回到锚点收束。

### 事件/场景不重复原则（关键）

参考示例的分段：每段对应一个**独立事件/场景**，不重复踩同一个场景。

- ✅ 示例秦始皇：质子爹回国→接班内卷→统一六国→荆轲刺杀→巡游→病倒，每段一个新事件
- ❌ 错误示范：羑里入狱→羑里独坐→羑里捡竹简→羑里推演→羑里出门，五段都在牢里，枯燥
- 同一历史阶段只取**最有戏剧性的一两个瞬间**，用一段讲完，不铺陈过程
- 事件之间要有**跳跃感**，像vlog切片，不是连续叙事
- 段落数控制在6-9段，每段一个新场景，一生用最少的切片串完

### 场景拆分原则（关键）

当一个段落里台词的**语境发生切换**时，必须拆成两段，分别给不同的 `[年龄·状态·动作]` 标注。

- ❌ 错误：同一段里前半句讲"周边人来投奔"（骄傲语境），后半句讲"纣王针对我"（憋屈语境），两个语境挤在一段，台词不接气
- ✅ 正确：拆成两段——
  - 段A：`[中年·岐山山坡·俯瞰来人]` 讲人来投奔，骄傲语气
  - 段B：`[中年·岐山宫室·翻阅竹简苦笑]` 讲纣王针对，憋屈语气
- 语境切换的信号：情绪从正转负、从外景转内景、从自夸转吐槽、对象从"来投奔的人"转"纣王"

### 重要人物出场对话原则（关键）

当历史上有名有姓的重要人物出场时，**适当添加人物之间的对话**，不要让主角一个人闷讲。

- ✅ 示例秦始皇：荆轲刺杀段有"嬴政拿命来 / 老弟有话好好说 / 不要冲动 / 我直播间好几万人看着呢"的对话
- 对话要短，2-4句来回即可，不要写成剧本
- 对方台词也要符合该人物的现代网络人设
- 对话只在重要人物出场时加，路人甲乙不配对话

### 现代热梗点缀原则

在合适节点可点缀**当下流行的网络热梗**（如"道爷我成了""这把高端局""我直接起飞"等），增加趣味性和时代感。
- 梗要和场景情绪匹配，不硬塞
- 全篇1-2处即可，多了变味
- 梗要新，避免过时梗

### 内核串联原则（关键，让全片有"一条线"）

写完整台词前，先想清楚这条视频的**概念内核**——一个能贯穿人物一生的现代身份标签或叙事框架。不是简单贴标签，而是找一个能把这个人物各阶段事件都串起来的"人设钩子"，让全片有统一感，不是散装年表。

**什么是内核**：一个现代观众熟悉的身份/角色/叙事模式，能罩住这个人物一生的多个事件。每个人物都要找一个独属于他的内核，从他的真实经历里长出来，不是套模板。

**内核怎么用**：
- 内核贯穿全片，每段事件都是这个内核的一次"演绎"或"案例"
- 开头引子就点出内核（如"我是XX，也是历史上第一个YY"）
- 主体各段用内核的话术来讲事件（如成功学大师就用"第X课"话术）
- 结尾用内核反转或收束（如"成功学最后一课：别学我晚年"），前后呼应

**优秀范例（齐桓公 · 成功学大师内核）**：
- 内核 = "历史上第一个成功学大师"（从他靠格局、识人、能忍上位的真实经历里长出来）
- 开头：「我是姜小白 / 春秋第一霸主 / 也是历史上 / 第一个成功学大师 / 现在给你们录 / 最后一节课」
- 主体各段用"成功学第X课"话术串联：第一课别怕起点低（流亡）→第二课能忍才能赢（装死）→第三课快就是一切（抢先即位）→第四课格局决定结局（拜仇人为相）→第五课跟对人干对事（九合诸侯）
- 结尾：「成功学最后一课 / 别学我晚年 / 听懂掌声」——前半生五节课教你怎么成功，最后一课教你别学他翻车，反转收束

**内核选择原则**：
- 必须从人物**真实经历和性格**里长出来，不是硬贴（齐桓公靠格局识人上位→成功学大师；秦始皇全年无休操劳→打工皇帝）
- 内核要能**罩住一生多个事件**，不是只对应一个事件
- 内核要有**反转空间**：前半生演绎内核（成功），结尾能反转内核（翻车），形成反差
- 一个人一个内核，不要混搭多个概念
- 如果找不到强内核，再退回普通串联（按时间线讲各事件，靠情绪节奏而非概念统一）

⚠️ 重要原则：示例只用来参考节奏（短句、分段、情绪急转）和结构（引子+当下串联+简短结尾），**不得借用具体句式**。
"家人们直播间别断""身体亮红灯了""咱们史书里见"等秦始皇专属表达，禁止照搬到其他人物。
每个人物的口头语、比喻、网感表达，必须从该人物自己的性格和经历里生长出来。

要求：
- 每句2-8字，独占一行
- 全文控制在80-120行之间（对应60-90秒视频）
- 按段落分组，每段3-6句，段间空行
- **每段开头用方括号标注当前人物状态**，格式：`[年龄·状态·动作]`，例如 `[52岁·羑里狱中·独坐推演八卦]` `[老年·病榻·侧靠望向窗外]`。年龄写具体岁数或"老年/中年/青年"，状态写人物此刻处境，动作写人物说话时正在做什么。这一标注独占一行，与台词分开，方便分镜时直接对应画面。
- **状态标注下方加一句阶段概括**，8个字左右，简短易懂，概括这段台词讲的是什么。格式：`# 概括内容`，例如 `# 羑里囚中推演周易` `# 渭水访贤遇姜太公`。独占一行，用于快速把握全片结构。
- 主体段落的状态标注必须是"那个当下的时刻"，不是临终回望
- 台词写完后，在下方写发布信息与剪辑指引

### 再写发布信息与剪辑指引

台词稿写完后，输出以下三块内容：

#### 一、自媒体发布信息

```
【发布标题】（不超过20个字符，含标点。要有钩子感、反差感或悬念感）
例：坐了7年牢，写出一本神书

【内容简介】（见下方详细规范）

【话题标签】（见下方详细规范）
```

**内容简介详细规范**

简介不是2-3句摘要，而是一篇独立的内容钩子，逻辑完整、情绪收束。根据人物类型选用以下两种结构：

---

**A. 翻案文章式（适用于被历史误解/黑化的人物，如商纣王、曹操、岳飞等）**

六层结构，顺序不可颠倒：

1. **权威引用** — 引用古人或史学家的一句话/考据结论，建立"历史有失真"的可信基础。格式：`XX说过："……"——一句口语化注解。` 或 `XX考证：……`
2. **层累展示** — 1-2行，展示罪状/标签是如何被层层加码的（时间线：XX时代只有→到XX才冒出→到XX直接），揭示历史叙事的人为建构性。
3. **反问转折** — 一行，「那真实的XX是什么样的？」把观众带入"我要知道真相"的好奇心。
4. **真实行为列举** — 2-3行，用顿号列举真实行为，结尾用一句点明为什么被误解（"全是得罪XX的活，全被写成XX"）。
5. **关键事件高潮** — 3-5行短句，铺陈最戏剧性的历史瞬间，每句一个镜头感的信息点，不连续叙述，要有画面感。
6. **情绪收束** — 最后一句，带主观情绪，悲壮、讽刺或愤慨，不解释。

黄金示例（商纣王）：
```
子贡说过："纣之不善，不如是之甚也。"——纣王的坏，没传说中那么夸张。
顾颉刚先生考证：纣王的罪状是层层加码的，周初《牧誓》只列6条，到《史记》才冒出酒池肉林炮烙剖心，到《封神演义》直接神魔化。

那真实的帝辛是什么样的？
征伐东夷开疆到长江、用人不论出身搞改革、削弱神权少搞人祭——
全是得罪贵族的活，全被写成暴政。

牧野之战那天，精锐陷在东夷调不回，
临时拉的奴隶战俘八十万临阵倒戈，
他被自己人卖了，鹿台这把火，他亲自点的。
```

---

**B. 反差收束式（适用于逆袭/成功/翻车类人物，如齐桓公、秦始皇、刘邦等）**

三层结构：

1. **人物定位句** — 一句话点出人物最抓人的现代定位（人物名+第一视角Vlog+核心内核标签）
2. **核心反差展示** — 2-3句，列出人物最反直觉的行为或命运，每句一个反差点，不解释原因，让观众自己产生好奇
3. **情绪收束** — 最后一句，带观点或情绪，不留白

示例（齐桓公）：
```
齐桓公姜小白第一视角Vlog，史上第一个成功学大师亲授五节课。
流亡不抱怨、中箭能装死、拜仇人为相、九合诸侯称霸春秋——
结果晚年信错三个小人，饿死宫中六十七天没人收尸。
听懂掌声。
```

---

**选用原则**：
- 人物有被历史黑化/误解的史学争议 → 翻案文章式
- 人物以逆袭、成功、翻车为主线 → 反差收束式
- 两者都适用时，翻案文章式深度更强，优先用

---

**话题标签详细规范**

5-8个，混合四类：
- **人物类**：人物常用名 + 历史称号或真实名（如 #商纣王 #帝辛）
- **大词类**：触达历史爱好者的泛类词（#历史vlog #历史真相 #历史冷知识）
- **事件/关键词类**：视频涉及的具体史事（#牧野之战 #春秋五霸 #管仲）
- **有立场的标签**：带观点、能精准触达深度历史爱好者的标签（如 #被胜利者写黑的历史 #成功学 #逆袭）。这类标签不要超过2个，太多显得说教。
- 相关人物可单独标出（#顾颉刚 #子贡 #鲍叔牙），有助于触达搜索这些人名的受众

示例（商纣王）：`#商纣王 #历史真相 #牧野之战 #帝辛 #历史vlog #被胜利者写黑的历史 #商朝 #顾颉刚 #子贡`
示例（齐桓公）：`#齐桓公 #姜小白 #春秋五霸 #管仲 #历史vlog #成功学 #历史冷知识 #春秋战国`

#### 二、花字信息（剪辑时叠加在画面上的文字）

按段落列出每个阶段需要叠加的花字，分两类：

- **阶段标签花字**（画面上方，标识当前人生阶段）：格式 `「[阶段名]」`，例如 `「羑里囚中推演周易」` `「渭水访贤遇姜太公」`
- **强调花字**（画面中央或下方，强调关键词或情绪点，大字加粗）：在情绪爆发、热梗、反差金句处使用，每段最多1-2处

示例格式：
```
段1 [老年·病榻] 阶段标签：「姬昌-周国之主」 强调花字：无
段2 [中年·岐山山坡] 阶段标签：「岐山起家口碑爆棚」 强调花字：「寒酸吗你」
段3 [52岁·羑里] 阶段标签：「羑里囚中推演周易」 强调花字：「道爷我成了」
...
```

#### 三、配乐与BGM建议

- **BGM情绪方向**：按段落标注情绪走向，不写歌名，写情绪。例：开场平静内敛→中段低沉压抑→出狱后逐步蓄力→结尾单音留白
- **关键卡点**：标注需要音乐卡点的位置（热梗处、情绪急转处、对话处）
- **音效建议**：在特定动作或转折处建议的音效（如牢门关闭、竹简铺开、钓竿入水等）

#### 四、视频封面设计

封面是决定点击率的核心要素，必须单独设计并输出。

**封面结构（固定两行，不可变）：**
- **主标题**：**永远是人物名称本身**，大字居中或偏上，字号最大。例：「周文王」「秦始皇」「苏轼」「商纣王」。
  - ⚠️ 硬性规则：主标题**只能是人物名称**，不允许替换为任何创意文案、金句、钩子句。
  - ❌ 错误：主标题写成「被自己人卖了三千年」「坐7年牢写出神书」——这是副标题的活，不是主标题。
  - ✅ 正确：主标题写「商纣王」，副标题写「被自己人卖了三千年」。
  - 理由：人物名称是观众识别内容的锚点，固定不变；爆款文案由副标题承担，每条视频可换。
- **副标题**：从**第三视角**对人物这段生平的评判或概括，字号略小于主标题，放在主标题下方。要求：
  - 8-15个字，短而抓人
  - 要有反差感/悬念感/猎奇感，让人想点进来
  - 从人物经历中提炼最抓人的那一个点，不贪多
  - 禁止平铺直叙（❌"周文王的一生"），要有钩子（✅"坐7年牢写出神书"）
  - 副标题是封面唯一的"钩子位"，所有爆款文案只出现在这里
  - ⚠️ **视角规则（关键）**：副标题必须是**第三视角的评判/概括**，不是主角自己的口吻。封面是观众点进来前看到的，应该像"旁人给这个人下的一句判词"，不是人物自己在说话。
    - ❌ 错误（主角口吻）："被自己人卖了三千年"（这是纣王自己在喊冤）、"我亲手点燃了鹿台"（第一人称）
    - ✅ 正确（第三视角评判）："被自己人卖了三千年的暴君"、"一手好牌打稀烂的末代帝王"
    - 区分方法：副标题里出现"我""被自己人卖了"这类第一人称表达就是错的；应该是"他/这位/XX的……"或直接用一个名词性判句
    - 理由：台词稿里已经是主角第一视角在说话，封面副标题如果也用第一视角，就重复了；第三视角判词形成"外人怎么看 vs 本人怎么讲"的反差，更能勾起点击欲
  - ⚠️ **高阶副标题公式（优先使用）**：`[反直觉的真实本质] 而被 [结局] 的"[被解构的旧标签]"`
    - 这个公式让副标题从"概括经历"升级到"重新定义人物"，制造认知落差，比单纯描述更有钩子力。
    - **优秀范例（商纣王）**：`背叛阶级而被推翻的"暴君"`
      - "背叛阶级"= 反直觉的真实本质（他用人不论出身、打破贵族垄断，等于背叛自己所在的贵族阶级）
      - "而被推翻"= 结局（亡国的真实逻辑：不是昏庸，是改革触动了既得利益集团被反噬）
      - "暴君"加引号 = 被解构的旧标签（承认标签存在，但重新定义成因，比直接说"不是暴君"更高级）
    - **公式拆解**：
      - 前半句 `[反直觉的真实本质]`：找到这个人物被误解的真相，用一个反常识的短语点出本质（例：背叛阶级、被自己人背刺、改革触怒既得利益）
      - 中间 `而被 [结局]`：点出这个本质导致的下场，形成因果链条（例：而被推翻、而被写黑、而被灭国）
      - 后半句 `"[被解构的旧标签]"`：用引号包裹大众对这个人物的刻板标签，暗示"这是别人贴的，不是事实"（例："暴君"、"昏君"、"奸臣"）
    - **为什么这个公式更强**：
      - 普通副标题只说"发生了什么"（被自己人卖了三千年）→ 观众只是好奇
      - 公式副标题说"为什么会这样 + 重新定义标签"（背叛阶级而被推翻的"暴君"）→ 观众产生"原来如此"的认知落差，点击欲更强
    - **其他人物套用示例**：
      - 周文王：`坐穿牢底而写出神书的"叛臣"`
      - 秦始皇：`统一六合而累死在工位的"暴君"`
      - 曹操：`挟天子而养出三国乱世的"汉贼"`
    - 写副标题时**优先尝试因果公式**，如果人物经历不适合（没有可解构的旧标签，或因果链不成立），再用重新定义式或普通第三视角判句。
  - ⚠️ **因果准确性规则（关键，最容易翻车）**：副标题里如果用"A而B""A却B"的因果/转折链条，A和B之间必须有**真实因果或逻辑关系**，不能把两个不相关的事件强行绑成因果。这是副标题最严重的硬伤——不是"不够抓人"，而是"事实错误"。
    - ❌ 错误（齐桓公案例）：`拜仇人而饿死宫中的"春秋首霸"`——"拜仇人（管仲）"和"饿死宫中"没有因果关系。饿死的真因是宠信易牙、竖刁、开方三个小人，跟拜管仲无关。把不相关的事件绑成因果，观众一看就觉得不对，是事实硬伤。
    - ✅ 正确（齐桓公案例）：`把仇人拜成相国的春秋第一成功学大师`——不做因果链，而是用"把仇人拜成相国"这个反直觉行为 + "成功学大师"这个重新定义的标签，形成认知落差，且不涉及虚假因果。
    - **自检方法**：写完副标题后自问"A真的导致了B吗？"。如果A和B在史实上是独立事件（哪怕都属于这个人的一生），就**禁止**用"而/却/结果"绑成因果，改用重新定义式。
  - ⚠️ **重新定义式副标题（当因果公式不适用时优先使用）**：当人物的经历无法用单条因果链概括（如前半生巅峰和后半生翻车是两个独立事件，或人物有多个高光点但无单一因果），改用 `[反直觉的真实行为/本质] 的"[重新定义的标签]"` 结构。
    - **结构**：前半句点出一个反直觉的真实行为或本质，后半句用一个全新的现代标签重新定义这个人（不沿用旧标签，也不做因果）。
    - **范例（齐桓公）**：`把仇人拜成相国的春秋第一成功学大师`
      - "把仇人拜成相国" = 反直觉的真实行为（射他一箭的人他不但没杀，还拜为相国）
      - "春秋第一成功学大师" = 重新定义的标签（不用"霸主"旧标签，用"成功学大师"重新定义他靠格局、识人、能忍上位的本质）
    - **适用场景**：人物一生有多个高光点但无法归因为单一因果时；或人物前半生巅峰、后半生翻车，两个阶段独立时（此时强行做因果会变成事实硬伤）。
    - **与因果公式的区别**：因果公式强调"为什么落到这个结局"（A而导致B），重新定义式强调"这个人本质是什么"（用反直觉行为 + 新标签）。两者择优使用，不可强行套用。

**封面画面建议：**
- 建议从台词稿中选一个最有视觉冲击力的场景作为封面底图
- 标注画面类型（AI生成·史诗风 / 真人演绎·第一视角自拍 / 真人演绎·情景再现）
- 一句话描述封面画面内容
- 人物神态/情绪要点

**输出格式：**
```
【封面设计】
主标题：周文王
副标题：坐7年牢写出神书
封面画面：AI生成·史诗风 — 昏暗牢房中竹简铺满，52岁姬昌低头专注推演，光线从高窗落下
人物神态：专注、沉静、带一丝倔强
```

## 写台词的自查清单

每段台词写完过一遍：
- [ ] 每句话是人物自己说的（第一人称）？
- [ ] 没有超过8个字的长句？
- [ ] 每段开头有 `[年龄·状态·动作]` 标注，且与该段台词处境一致？
- [ ] 状态标注下方有 `# 阶段概括`（8字左右）？
- [ ] 主体段落是"那个当下的主观视角"，不是临终回望？
- [ ] 主体段落没有出现"我年轻那会儿""我继位那会儿""结果后来""没想到后来"等回忆口吻标志词？
- [ ] 主体段落没有剧透结局（如"养了个白眼狼"），只有当下预感（如"他儿子在外面磨刀"）？
- [ ] 主体段落用现在时态说话，情绪是那个当下的真实情绪，不是事后平静复盘？
- [ ] 只有开头引子和结尾允许回望，主体各段都待在自己的当下？
- [ ] 开头引子用"大众对ta的认知/标签"切入，有自报家门 + 大众印象点出 + 复盘钩子，不是老年病榻回望？
- [ ] 开头引子的话术从人物自身性格和标签里长出来，不是套用"全网都说我是最XX的XX"固定句式？
- [ ] 每段对应一个独立事件/场景，没有重复踩同一场景？
- [ ] 段落内语境切换时已拆成两段（如外景骄傲→内景憋屈）？
- [ ] 重要人物出场时有2-4句对话，不是主角一个人闷讲？
- [ ] 事件之间有跳跃感，像vlog切片，不是连续叙事铺陈过程？
