# Stage 1：概念期引导策略

学生症状：有一个模糊的"想法"，能说出大概，但说不清楚，或者每次说都不一样，或者说了很多但核心不明。

## 概念提炼的目标

一个可用的概念需要包含：
1. **主角**：具体的人，而不是类型（"一个普通上班族"不够，"一个隐瞒了债务的父亲"更好）
2. **核心欲望**：他强烈想要什么（外部目标）
3. **内心缺失**：他真正需要什么（内部需求，往往他自己不知道）
4. **主要障碍**：什么在阻止他
5. **代价**：追求欲望要付出什么

## 引导工具：五层追问法

对学生的每个"想法"，依次追问：

**第一层：谁的故事？**
> "这个故事，我们主要跟着谁走？这个人现在的生活是什么状态——用一个具体的场景来描述他普通的一天。"

**第二层：他想要什么？**
> "在故事开始的时候，他最迫切想要得到或完成的一件事是什么？这个'想要'要具体到可以拍出来的行动——他会做什么来得到它？"

**第三层：为什么得不到？**
> "什么在阻止他？外部的阻力（环境、对手、规则）是什么？他自身的问题（恐惧、盲点、弱点）是什么？"

**第四层：他会改变吗？**
> "在故事结束时，这个人跟开头相比会有什么不同？他学到了什么，还是学到了错误的东西，还是拒绝改变？"

**第五层：为什么是现在？**
> "为什么故事在这个时间点发生？是什么打破了他原来的平静生活，逼迫他必须行动？"

## 类型与情感承诺

帮助学生明确他们的"情感承诺"——这个故事想让观众感受到什么？

问：> "当你想到这个故事的最后一场戏，你希望观众走出影院时心里是什么感觉？"

这个问题经常能帮学生找到他们真正想说的事。

## 参照作品的使用

一旦了解了概念，可以推荐参照作品，但要说明原因：

- 概念涉及"制度与个人的对抗" → 推荐《我不是药神》，分析程勇的欲望（赚钱）和最终选择（牺牲）之间的弧线
- 概念涉及"家庭秘密" → 推荐《隐秘的角落》，分析如何把"孩子知道了成人的秘密"变成道德困境
- 概念涉及"身份危机" → 推荐《搏击俱乐部》，分析如何用外化的角色具象化内心冲突

## One-Page概念文件

当概念基本清晰后，引导学生写出一页纸的概念，包含：

```
标题（工作标题即可）：
类型：
主角：（一句话描述，包含最重要的内部矛盾）
故事世界：（时间、地点、环境，一句话）
核心冲突：（外部障碍 vs 内部缺失）
情感承诺：（这个故事最终要让观众感受到什么）
一句话概述（logline）：
```

## 阶段结束标准

学生能写出清晰的 logline（一到两句话说清楚主角、目标、障碍和赌注），可以进入 Stage 2。
