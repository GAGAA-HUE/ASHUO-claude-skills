# Stage 0：茫然期引导策略

学生症状：没有任何故事，不知从哪开始，或者说"我什么都想写但什么都写不出来"。

## 根本问题诊断

茫然通常来自以下几种原因：
1. **目标太大**：想写"一部好电影"而不是"一个具体的时刻"
2. **缺乏权限感**：觉得自己"还没资格"写某个题材
3. **创意与执行脱节**：有感受但不知道如何转化为故事
4. **模仿焦虑**：觉得什么都被写过了

## 引导路径

### 第一步：找到"触动时刻"

不要让学生想"故事"，让他们想"一个画面"或"一种感受"：

> "不用想故事。告诉我，最近有没有某个时刻——可能是你亲身经历的，也可能是你看到的或听说的——让你觉得'这个有点意思'或者'这个让我不舒服/感动/愤怒'？哪怕只是一个片段。"

等待他们的回答。这个答案往往包含了他们最真实的素材。

### 第二步：把感受转化为冲突

一旦学生给出一个"触动时刻"，追问：

> "在那个时刻里，有没有两种力量在拉扯？或者有没有一个人，他想要某件事但得不到？"

### 第三步：One-Liner 练习

引导学生完成这个句子：

**"一个 [什么样的人]，想要 [什么]，但是 [什么阻止了他]。"**

示例：
- "一个不敢说出秘密的孩子，想要保护家人，但是沉默正在把他变成同谋。"（→《隐秘的角落》）
- "一个绝症病人，想要尊严地死去，但是他的孩子不允许他放弃。"（→ 无数种可能的故事）

这个练习不是为了得到"完美答案"，而是为了找到**冲突的核心**。

## 常见陷阱与应对

**陷阱：学生给出的是"类型"而非"冲突"**
"我想写一个爱情故事。"
→ 追问："爱情故事里，是什么阻止了两个人在一起？不是外部原因，是内部原因——是他们自己的什么让他们彼此远离？"

**陷阱：学生给出的是"主题"而非"故事"**
"我想写关于孤独的故事。"
→ 追问："孤独的是谁？他做了什么事来逃避或者面对孤独？这件事让他付出了什么代价？"

## 阶段结束标准

当学生能够说出一句清晰的 one-liner，包含主角、欲望、障碍三要素，可以进入 Stage 1。
