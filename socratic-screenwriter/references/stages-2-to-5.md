# Stage 2：大纲发展与结构诊断

## 核心目标

从概念到大纲，需要解决的问题是：**这个故事如何展开？每个转折点是否有内在逻辑？**

## 结构诊断工具

### 基础结构检查（适用于电影/长剧本）

引导学生逐一确认以下关键时刻是否存在且清晰：

1. **普通世界**：主角在事件发生前是什么状态？（这建立对比）
2. **触发事件**：什么打破了普通生活，逼迫主角必须做出反应？
3. **第一个门槛**：主角主动选择进入新世界/新任务的时刻
4. **中点转折**：故事中段，主角以为成功但其实距离真正的问题更近了
5. **最低点**：主角失去一切，或面临最深的失败
6. **最终行动**：主角用改变后的自己去面对最终挑战

追问格式：
> "你的故事里，[具体结构点]是哪一场戏？发生了什么？"

### 因果链检查

对大纲中的每个情节点，问：

> "这件事发生，是因为前面发生了什么？它的发生，又导致了什么必然的结果？"

如果学生说"然后……然后……然后……"而不是"因为……所以……但是……"，说明情节是堆砌而不是生长的。

## 人物弧线与结构的关系

结构不只是情节顺序，更是**人物内心变化的外在形状**。

追问：
> "在大纲里，主角在哪个时刻开始改变？是什么事件迫使他重新认识自己或世界？"

## 推荐参照

- 结构图谱：让学生拆解一部他熟悉的电影，逐场写出每个转折点
- 推荐对照：《唐人街》（宿命感如何通过结构实现）、《心灵捕手》（人物内在弧线如何驱动外部情节）

# Stage 3：执笔卡壳处理

## 场景卡壳

每个场景需要回答：
1. **场景开始时，谁想要什么？**
2. **场景结束时，局面发生了什么变化？**（必须有变化——情绪变化、信息变化、关系变化）
3. **这场戏在更大结构里的功能是什么？**

追问：
> "你在这场戏里，开头的状态和结尾的状态，有什么不同？"

如果没有变化，这场戏通常可以删掉或与其他场戏合并。

## 对话卡壳

坏对话的最常见原因：**人物在说他们真正想说的话**。

好的对话往往是：人物在说别的事，但观众听到了真正的意思。

追问：
> "在这段对话里，两个人物各自真正想要从对方那里得到什么？他们有没有直接说出来？如果直接说出来了，能不能让他们用别的方式表达？"

参照：《社交网络》开场对话，Zuckerberg 和女友的对话表面在聊名校文化，实际是两人关系破裂的全景展示。

## 人物卡壳

如果写着写着感觉人物"不像真人"：

> "这个角色的一个从来没出现在故事里的行为习惯是什么？他私下一个人的时候会做什么？他有什么让人轻微烦恼的小缺点？"

让人物在故事之外有生命，他在故事里就会更真实。

# Stage 4：初稿修改策略

## 首轮阅读原则

不要让学生边写边改。完成初稿后，先整体阅读一遍，只记录**感受**，不做修改。

引导问题：
> "读完之后，哪个地方你觉得'这里有点问题'但说不清楚是什么？我们先从感受出发，再找原因。"

## 常见诊断维度

| 症状 | 可能原因 |
|------|---------|
| 整体读来疲惫 | 节奏单一，缺少张弛 |
| 主角不讨喜也不有趣 | 主角缺乏主动性，只在被动反应 |
| 故事感觉散 | 缺少清晰的中心问题/欲望 |
| 结局不满足 | 结局没有回应开头建立的期待 |
| 人物说话都一样 | 每个人物缺少独特的语言习惯和逻辑 |

## 修改优先级

引导学生按以下顺序修改（不要先从对话层面动手）：

1. 先修**结构**（转折点是否在对的位置）
2. 再修**人物弧线**（变化是否真实且有根据）
3. 再修**场景功能**（每场戏是否必要）
4. 最后修**对话和细节**

# Stage 5：剧本市场流程

## 工业流程概览

```
概念/Pitch → 剧本大纲 → 分集/分幕大纲 → 剧本初稿 
→ 内部修改 → 项目开发 → 制片方介入 → 导演介入 → 拍摄稿
```

## 针对不同市场的格式要求

**院线电影：**
- 标准好莱坞格式（Final Draft / Fade In）
- 90-120页，每页约1分钟
- Logline + Synopsis + 完整剧本

**流媒体/网剧（中国市场）：**
- 通常需要：故事大纲（1-2页）+ 分集大纲（每集约1页）+ 前3集完整剧本
- 更重视"钩子"设计和集末悬念

**微短剧：**
- 每集2-5分钟
- 前3秒必须有强钩子
- 情绪密度极高，几乎每场都需要强冲突

## 投递与开发

引导学生了解：
1. 编剧工会/行业协会的保护机制
2. 如何写一份有效的项目陈述（Pitch Deck）
3. 剧本版权保护的基本方式

这部分内容建议学生配合行业书籍（如《救猫咪》《故事》）和实际业内资源深入了解。
