# 小说改编详细方法论 · Novel Adaptation Guide

> ⚠️ **重要：本文件已根据真实改编迭代中的失败案例修订。**
> 核心教训：改编不是「按短剧套路填充原著人名」，而是「以原著事实为地基，在其上建造短剧结构」。
> **全书必须先读完再动笔。任何设定标注「原著依据」前必须能找到对应原文。**

---

## 第零步：全书通读（不可跳过）

**为什么不能先读几章就开始？**

读取部分章节会产生两类错误：
1. **虚构关键情节**：不知道原著已经发生了什么，用短剧套路填补，导致改编情节与原著矛盾（如某小说县令早在第15章暴毙，但改编大纲写成「主角与县令当面对决」）
2. **错标人物设定**：把后期才揭示的信息误以为前期已有，或把原著明确否定的设定当成隐藏能力写入人物小传

**通读工作流：**
```
① 读取全部章节标题 → 建立故事骨架
② 按阶段分批读取正文 → 每批400-600字/章，覆盖关键转折
③ 建立「原著事件清单」（带章节号）→ 这才是改编的真正原材料
④ 确认主角核心设定（有无修为/特殊能力/身份秘密）→ 必须有原文直接交代
```

---

## 核心理念

小说改短剧不是"翻译"，是**重构**。原著是素材库，短剧才是产品。爽感 > 忠实原著。

**但重构必须建立在原著事实之上。** 任何改编行为都分两类，必须清楚区分：
- **保留并改编**：原著有此情节，改编其呈现方式
- **改编补充**：原著无此情节，为短剧需要新增，必须在输出时显式标注「改编补充」

---

## 人物小传三层标注规范

写人物小传时，每一条信息必须属于且只属于以下三层之一：

```
【原著明确】有原文直接语句支撑，标注章节号
示例：「没有丹海，无法修行」→【原著明确·第30章，阿水检查后告知】

【原著暗示】有行为/细节支撑，但原著未直接说明，注明推断依据
示例：「对闻潮生有不自知的在意」→【原著暗示·依据：第5章劈柴还刀、第8章雪中出手护人】

【改编创作】原著无依据，为短剧节奏/市场需求增加，必须显式标注
示例：「身份揭露时刻提前至第3集」→【改编创作·原著无对应时间节点】
```

**严禁**：把「合理推断」或「套路补充」不加标注地写进人物小传，伪装成原著依据。

---

## 集数大纲章节索引规范

每一集的核心事件必须标注依据：

```
| 集数 | 核心事件 | 原著依据 | 类型 |
|-----|---------|---------|------|
| 第1集 | 风雪夜救阿水，送入破庙 | 第1章 | 保留并改编 |
| 第2集 | 张猎户留被褥，大黑狗首次送粥 | 第2-4章 | 保留并改编 |
| 第8集 | 黑衣杀手夜袭，阿水用雪球配合击杀 | 第8章 | 保留并改编 |
| 第X集 | [某情节] | 无 | 改编补充·为[原因]新增 |
```

无法填写原著依据的情节，必须先回去读原著确认，再决定是否标注「改编补充」。

## 第一步：爽点提炼（改编前必做）

通读原著，建立**爽点清单**：

```
【爽点清单模板】
编号 | 原著章节 | 爽点类型 | 爽感强度（1-10） | 可视化难度 | 保留/删除/改编
-----|---------|---------|--------------|----------|-------------
001  | 第3章   | 主角打脸反派 | 9 | 低 | 保留，提前到第2集
002  | 第8章   | 身份揭露  | 10 | 中 | 改编，分两步揭露制造悬念
...
```

**爽点类型清单：**
- 打脸型：当众羞辱 → 当众反打脸
- 揭秘型：隐藏身份/能力的揭露
- 逆袭型：弱者对强者的压倒性胜利
- 守护型：被人保护/为人牺牲
- 复仇型：精准的因果报应
- 甜宠型：主动被爱/被当全世界珍视
- 虐恋型：相爱不能相守的撕裂感

---

## 第二步：删除清单

以下内容在改编时**默认删除**：

| 删除内容 | 原因 | 替代方案 |
|---------|------|---------|
| 大段内心独白 | 镜头无法直接呈现 | 改为对白或动作外化 |
| 环境铺垫描写 | 浪费时长 | 用分镜画面交代 |
| 次要人物支线 | 分散注意力 | 合并到主线人物 |
| 缓慢的感情升温过程 | 短剧节奏不允许 | 用"甜蜜时刻切片"替代 |
| 过度的历史/世界观解释 | 观众无耐心 | 用角色对话带出，≤30秒 |
| 原著铺垫超过3章无爽点 | 掉流量 | 直接跳至冲突，用闪回补交代 |

## 第三步：时间线压缩法则

```
原著体量 → 短剧对应体量（参考）
10万字小说 → 30-40集短剧
30万字小说 → 60-80集短剧
100万字小说 → 100集短剧（大量删减）
```

**压缩四步法：**

1. **合并场景**：将原著3个场景达到同一目的的情节，压缩成1个场景
2. **角色合并**：原著5个配角功能相似的，合并成1-2个
3. **跳跃式叙事**：用字幕/对话交代"三个月后"，跳过过渡段落
4. **倒叙开场**：从原著高潮点开始，用悬念勾住观众，再慢慢回溯

---

## 第四步：开场重构（最重要一步）

**原著开场 vs 短剧开场的区别：**

| 对比项 | 原著开场 | 短剧开场（改编后）|
|-------|---------|---------------|
| 从何处开始 | 人物介绍/时代背景 | 最大冲突的中间 |
| 前3秒 | 文字描述环境 | 强情绪画面/台词炸点 |
| 节奏 | 缓慢建立 | 立刻入场 |
| 人物介绍方式 | 作者视角叙述 | 通过冲突展示性格 |

**改编开场公式：**
```
第1集开场 = 原著第X章（冲突最激烈处）+ 倒叙"三天前/一年前" + 
            快速用对话交代必要背景 + 回到冲突 + 爽点/悬念
```

---

## 第五步：对白现代化

**原著对白 → 短剧对白转化规则：**

| 原则 | 说明 |
|-----|------|
| 每句≤15字 | 拆分长句，保留核心信息 |
| 书面语→口语 | "吾意已决"→"我决定了" |
| 情绪外显化 | "她心中涌起一股热流"→"你知道吗，这是我第一次觉得有人在乎我" |
| 加强对立感 | 让每句对话都有立场和锋芒 |
| 删除解释性对话 | 观众自己能看出来的不用说 |

**改编示例：**

原著：「萧凌云目光深邃，凝视着面前这个曾让他痛苦不堪的女子，心中百感交集，却只道：'你既已归来，往事便就此揭过。'」

短剧版：
```
萧凌云（冷漠直视）
你回来了。

苏晚晴
......

萧凌云
过去的事，不提了。
（转身，声音突然哽咽）
但你要知道——你走的那三年，我每天都在找你。
```

---

## 第六步：爽点重新分布

将原著爽点均匀"撒"到各集结尾，制造持续追剧动力：

**爽点分布策略：**
- 前15集：爽点密度最高（争取留住新用户）
- 中期：爽点间隔可以拉长，但虐感要补上
- 付费节点前后：必须有S级爽点或S级虐点
- 结局前5集：爽点密集爆发，让付费用户感觉值回票价

---

## 改编红线（不可踩）

1. **不能删掉原著最著名的爽点** → 粉丝会骂，改编为视听版本即可
2. **不能改变CP的HE结局**（如原著是HE）→ 核心情感契约不能违反
3. **不能让主角"弱化"** → 改编可以增加挫折，但主角的核心能力/魅力不能削减
4. **不能无故增加支线** → 改编是做减法，不是加法
