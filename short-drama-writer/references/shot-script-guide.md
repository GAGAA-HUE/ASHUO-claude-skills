# 分镜视听语言指南 · Shot Script Guide

## 短剧视听语言的核心原则

**竖屏第一原则：** 所有构图优先考虑9:16竖屏呈现
- 人物居中/上三分之一，减少横向信息
- 特写优于全景（手机屏幕小，细节才清晰）
- 人脸占屏幕50%以上时情绪传达最佳

**情绪即画面：** 每个镜头都要有情绪立场，没有"中性镜头"

---

## 景别使用指南

| 景别 | 使用场景 | 情绪效果 |
|-----|---------|---------|
| 大特写（眼睛/嘴/手部细节） | 情绪爆发/转折瞬间/秘密揭露 | 极度强调，不可忽视 |
| 特写（脸部） | 情绪高点/对话关键句/内心变化 | 亲密感，情感连接 |
| 近景（胸部以上） | 日常对话/情感交流 | 中等亲密度，最常用 |
| 中景（腰部以上） | 动作+对话/关系展示 | 信息量大，交代清楚 |
| 全景（全身） | 登场亮相/场景建立/肢体语言强调 | 展示力量感或弱势 |
| 大全景（含环境） | 场景交代/身份地位展示 | 建立世界感 |

**竖屏短剧使用比例建议：**
- 特写/近景：60%
- 中景：30%
- 全景/大全景：10%

## 镜头运动指南

| 运动方式 | 情绪含义 | 典型使用场景 |
|---------|---------|------------|
| 固定镜头 | 稳定/对峙/压迫 | 双方对话/审判场面/力量对比 |
| 推镜（zoom in） | 强调/揭露/情绪升级 | 发现秘密/情绪爆发前 |
| 拉镜（zoom out） | 孤独/失落/事件结束 | 主角独自承受/告别场景 |
| 摇镜（pan） | 跟随视线/空间交代 | 主角视线引导/场景建立 |
| 跟镜（tracking） | 动感/主角行动中 | 主角气势登场/追逐戏 |
| 手持抖动 | 紧张/失控/情绪崩溃 | 争吵戏/危机时刻 |
| 斯坦尼康 | 流畅气势/仪式感 | 重要登场/决定性时刻 |

## 光影设计系统

### 按题材调光

| 题材 | 推荐光效 | 色温 | 理由 |
|-----|---------|------|-----|
| 甜宠/霸总 | 高调自然光 + 轮廓光 | 暖白（5600K） | 明亮、美颜、浪漫 |
| 悬疑/惊悚 | 低调光 + 强侧光 | 冷蓝（4000K以下） | 神秘感、不安全感 |
| 战神/逆袭 | 逆光 + 强光比 | 暖金（3200K） | 英雄感、力量感 |
| 穿越/古装 | 自然光 + 烛光质感 | 暖橙（2700K） | 时代感、仪式感 |
| 都市情感 | 窗户自然光 + 柔光 | 中性白（5000K） | 真实感、亲近感 |

### 经典布光法在短剧中的应用

**伦勃朗光（Rembrandt Light）：**
- 适用：反派出场/秘密揭露/角色黑化时刻
- 效果：脸部阴影三角，神秘/力量感强

**逆光/轮廓光：**
- 适用：主角气势登场/英雄时刻/告白场景
- 效果：主体发光感，神圣/浪漫

**顶光：**
- 适用：主角受压迫/处于绝境
- 效果：脸部阴影加深，显憔悴/压迫感

## 构图法则

### 竖屏构图关键规则

**三分法（最常用）：**
- 人物眼睛放在上三分之一线上
- 情绪动作向的一侧留更多空间（面向右则右侧留空）

**居中构图（权力感）：**
- 反派宣示权力时
- 主角最强时刻登场
- 对称场景（审判/对决）

**斜线构图（动感/不稳定）：**
- 追逐戏
- 情绪失控场景
- 重要信息揭露的冲击感

**框架构图（强调/聚焦）：**
- 通过门框/窗框/手臂围成的框框住主体
- 强调人物的被注视感/被困感

## 色调设计系统

### 情绪色调对照表

| 情绪/阶段 | 色调方向 | LUT/滤镜特征 |
|---------|---------|------------|
| 甜蜜/幸福 | 暖橙粉 + 高饱和 | 阴影提亮，高光偏黄 |
| 压迫/绝望 | 冷蓝绿 + 低饱和 | 整体压暗，肤色偏灰 |
| 爽感/逆袭 | 高对比度 + 暖金 | 高光爆亮，阴影深黑 |
| 回忆/过去 | 褪色感 + 暖黄 | 降饱和，阴影提亮 |
| 危险/悬疑 | 深绿/青 + 强阴影 | 中间调压暗，强光比 |
| 权力/霸气 | 冷白 + 高对比 | 纯净感，硬光 |

## 分镜脚本完整示例

**场景：主角第一次当众打脸反派（关键爽点场景）**

```
【第12集 · 第23-27镜 · 打脸高潮段落】

---[镜头23]---
▶ 景别：中景 → 慢慢推至近景
▶ 镜头运动：缓推（强调转折时刻）
▶ 构图：反派居中，周围围观人群虚化背景
▶ 光影：顶光 + 侧光（反派此刻正在宣示权力）
▶ 色调：冷白高对比
▶ 时长：约8秒

画面：反派在众人面前指着主角，嘴角冷笑，正在宣判。
背景：公司大厅，围观同事窃窃私语。

反派（傲慢，声音足够让所有人听到）
「你一个没背景没能力的人，
凭什么跟我谈合作条件？」

人群反应：低声嗤笑，主角孤立无援。

---[镜头24]---
▶ 景别：大特写（主角眼睛）
▶ 镜头运动：固定
▶ 构图：眼睛居中，虹膜清晰可见
▶ 光影：轮廓光 + 眼神光（关键！）
▶ 色调：开始从冷蓝向暖色轻微偏移（转折信号）
▶ 时长：约3秒

画面：主角眼神从低垂→缓缓抬起，瞳孔聚焦，
     眼神里从委屈变为某种平静的锐利。

无对白。
BGM：低沉音效开始

---[镜头25]---
▶ 景别：近景
▶ 镜头运动：固定（主角稳如磐石，形成对比）
▶ 构图：三分法，主角偏左，右侧留给反派
▶ 光影：窗户自然逆光打在主角肩膀（轮廓光/英雄感）
▶ 色调：转为暖调（爽感到来的信号）
▶ 时长：约6秒

主角（平静，甚至带微笑，声音不大但清晰）
「没背景？」

（停顿2秒，掏出手机）

主角
「刚才，晨辉集团的陈董事长给我发了合作意向书。」

---[镜头26]---
▶ 景别：全景（展示整个空间的权力反转）
▶ 镜头运动：快速摇到反派脸部 → 立刻切特写
▶ 构图：先全景交代人群反应，再切反派
▶ 光影：正常曝光（反派失去"光环"）
▶ 时长：约4秒

画面：人群表情变化——惊讶、交头接耳；
     镜头快速推至反派脸——不可置信，嘴角笑意消失。

---[镜头27]---
▶ 景别：特写（主角嘴角微扬）
▶ 镜头运动：固定
▶ 构图：居中，权力感
▶ 光影：顶光去掉，改为正面柔光（主角此刻"发光"）
▶ 色调：暖金，高对比，饱和度提高
▶ 时长：约5秒

主角（声音里有一点点玩味）
「噢，对了——」
「我就是你说的那个'没背景'的人的后台。」

BGM：情绪爆发，强节拍
音效：周围人群倒吸一口气声
```

## 音效与BGM情绪指南

| 情绪时刻 | BGM/音效设计 |
|---------|------------|
| 爽点爆发 | 强节拍+弦乐上扬，突然的音乐cut out再进 |
| 悬念建立 | 低沉持续音+心跳音效 |
| 甜蜜时刻 | 轻钢琴/吉他，温暖+慢节奏 |
| 危机/绝境 | 不和谐音程+快速鼓点 |
| 打脸/反转 | 先静音0.5秒，然后爆发 |
| 集尾钩子 | 音乐在最高点突然cut，留余韵 |
