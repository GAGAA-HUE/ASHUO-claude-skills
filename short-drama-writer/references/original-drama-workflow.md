## 第二步：人物小传设计

### 主角设计模板

```
【主角小传】
姓名：
外在身份：（普通人/弱势群体，制造初始反差）
隐藏身份：（真实背景/能力，是爽感来源）
核心欲望：（驱动全剧行动的一个动机）
核心伤痛：（造成人物动机的过去创伤）
能力觉醒时机：（第X集，以什么事件为触发点）
性格标签：（2-3个关键词，要有张力/矛盾感）
爽点开关：（哪类场景会触发他/她的爆发时刻）
```

### CP设计模板（爱情线）

```
【CP设计】
主CP组合类型：（强强/强弱/敌人→恋人/禁忌之恋）

破冰节点：（第X集，以什么事件打破隔阂）
虐恋高潮：（全剧最大考验，在第X集）
HE/BE/开放结局：（结局方向）
```

### 反派设计模板

```
【反派设计】
姓名与身份：
与主角的关系：（职场竞争/家族矛盾/情敌/仇人）

最终结局：（惩罚方式，要与恶行对等，越戏剧越好）
```

## 第三步：三幕结构设计

### 标准短剧结构（以100集为例）

**第一幕：建立世界（1-15集）**
- 1-3集：主角登场 + 核心冲突建立 + 第一个爽点
- 4-8集：世界观/规则/人物关系全部清楚
- 9-15集：主角遭遇最大初始挫折，反派气焰最嚣张

**第二幕A：蓄力反击（16-45集）**
- 每5集一次爽点爆发
- 每10集一次重大反转
- CP线：误会期→初步破冰→第一次情感升温

**第二幕B：高潮前虐（46-75集）**
- 主角能力/资源到达顶峰
- 最大危机出现（可能是背叛/失去/代价）
- CP线：最大误会/分离/虐恋高潮

**第三幕：封神收线（76-100集）**
- 76-90集：主角全面反击，逐一清算反派
- 91-95集：大BOSS最后挣扎/反扑
- 96-100集：终极打脸/封神时刻 + CP和解/HE

## 第四步：钩子节拍表

每集填写以下表格，确保钩子密度达标：

```
集数 | 核心事件 | 情绪类型 | 集尾钩子 | 钩子等级
-----|---------|---------|---------|--------
第1集 | ...    | 愤怒+期待 | 主角身份线索出现 | A级
第2集 | ...    | 爽感    | 反派设局，主角陷危 | A级
第3集 | ...    | 爽感+悬疑 | 大反转  | S级
...  |         |          |         |
```

## 第五步：首集剧本写作要点

**首集黄金结构（3分钟版）：**

```
0-15秒：视觉炸点开场（不是主角自述/旁白）
         → 直接进入冲突现场

15-45秒：建立身份反差
         → 主角"弱势现状" + 暗示"隐藏实力"

45秒-1分30秒：第一次正面冲突
              → 反派首次出手，主角受委屈

1分30秒-2分30秒：主角第一次局部反击
                → 小爽点，但还没完全逆袭

2分30秒-3分钟：集尾钩子
              → 更大危机/身份揭露线索/情感悬念
```
