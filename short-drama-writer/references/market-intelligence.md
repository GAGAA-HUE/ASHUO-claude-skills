# 市场情报与赛道分析 · Market Intelligence

## 国内短剧市场（2024-2025）

### 平台格局
- **抖音**：最大流量入口，算法分发，首集免费+付费解锁
- **快手**：下沉市场更强，家庭/农村/逆袭题材表现好
- **微信小程序**：付费率最高，用户消费意愿强，霸总/甜宠主战场
- **爱优腾芒**：精品化短剧，制作成本更高，但分发有保障

### 爆款公式解析

**霸总甜宠公式：**
```
平凡/落魄女主 + 误入豪门 + 被误解/虐待 
→ 隐藏身份/靠山揭露 + 霸总悔恨/追妻 
→ 虐恋 + HE
核心情绪：被宠爱的幻想满足
```

**战神赘婿公式：**
```
天才/战神/大佬 + 主动隐藏身份 + 被家人/妻子看不起
→ 一次次被欺辱但暗中报复 + 身份逐渐揭露 
→ 所有人跪下道歉 + 封神时刻
核心情绪：社会压力下的逆袭幻想
```

**穿越重生公式：**
```
现代人/重生者 + 带着记忆/超前知识 
→ 提前布局/避开命运 + 复仇前世仇人 
→ 改变命运/创造新结局
核心情绪：如果能重来的弥补感
```

### 付费节点设计

付费节点通常在15-20集，付费节点前必须：
1. 建立强情感连接（用户已经在乎主角）
2. 悬念累积到顶点（不付钱实在忍不住）
3. 刚好在一个A级或S级钩子之后（爽完了想看更多）

## 出海短剧市场（Reelshort/DramaBox生态）

### 市场规模与用户画像
- 主要用户：北美（35%）、东南亚（25%）、欧洲（20%）
- 核心受众：25-45岁女性，有付费习惯
- 付费方式：按集付费或月订阅
- 平均完播率高于国内（用户更有耐心）

### 头部赛道深度分析

**Alpha/CEO Romance（霸道总裁）：**
- 必要元素：财富象征（豪车/豪宅/公司权力）、支配性格、女主善良但有骨气
- 文化适配：避免封建等级感，用"商业竞争"替代"家族地位"
- 差异化：加入美国文化元素（律师/医生/名校背景）

**Werewolf/Supernatural Romance：**
- 必要元素：Alpha-Beta-Omega体系、命运配对（Fated Mates）、Pack（狼群/家族）
- 规则：Alpha命令力、月圆变形、配对bond（情感链接）
- 女主类型：Rejected Luna（被拒绝的月神/配偶）最受欢迎
- 节奏：第1集必须有超自然元素展示，不能拖

**Revenge Romance：**
- 核心弧线：受伤→离开→成长蜕变→以全新姿态归来→复仇+新爱情
- 关键：复仇不能只是情绪发泄，要有"精准计划"感
- 西方适配：女主复仇后要有"新生"弧线，不能只有仇恨

### 出海剧本写作注意事项

**文化雷区：**
- 避免：磕头/跪拜（被视为贬低）
- 避免：强制安排婚姻+没有女主主动选择权（现代西方读者反感）
- 避免：过度强调家族荣誉压过个人意志

**加分项：**
- 女主有独立职业/技能（律师/医生/侦探/设计师）
- 反转中男主有真诚道歉和改变（不是单纯追妻）
- 配角有各自完整的人物弧线

**对白本地化原则（中→英改编）：**
- 中文含蓄的情感表达，英文要直给
- 肢体接触描写更明确（握手、拥抱、眼神）
- 称呼方式：英文直呼名字，避免"少爷/小姐"等称谓

## 选题评估模型

用这个模型给任何一个选题打分（满分100分）：

| 评估维度 | 满分 | 评分标准 |
|---------|-----|---------|
| 情绪强度 | 25分 | 能激起几种强情绪？愤怒/爽感/哭感/共鸣 |
| 受众清晰度 | 20分 | 目标受众明确且足够大吗？ |
| 差异化 | 15分 | 市场有同类但你的有新意吗？ |
| 视觉化潜力 | 15分 | 场景/角色/冲突好拍吗？ |
| 爽点密度 | 15分 | 每集能保证有钩子吗？ |
| IP改编可行性 | 10分 | 有现成受众基础吗？ |

**80分以上：强烈推荐立项**
**60-79分：可以立项，需要优化弱项**
**60分以下：建议重新选题**
