## 核心编剧法则（所有模式通用）

### 一、短剧节奏铁律

| 时间节点 | 必须发生的事 |
|---------|------------|
| 前3秒 | 视觉冲击或对白炸点，阻止划走 |
| 30秒内 | 建立核心冲突或身份反差 |
| 每90秒 | 一次情绪波峰（爽点/泪点/悬念） |
| 集尾15秒 | 强钩子——未解决的冲突/反转/欲望激发 |
| 第1集 | 必须完成：主角亮相 + 核心矛盾建立 + 第一个爽点 |
| 第3集 | 必须完成：世界观/能力/身份全部交代清楚 |

### 二、国内市场调性

**主流赛道：**
- 霸总/甜宠：身份反差 + 强强组合 + 虐恋治愈
- 战神/赘婿：被看不起→逆袭打脸→封神时刻
- 穿越重生：金手指明确 + 仇必报 + 爽感密集
- 婆媳/家庭：生活化冲突 + 情感共鸣 + 大女主成长
- 悬疑惊悚：三分钟一反转 + 结尾留悬念

**对白特征：** 短句为主（每句≤15字）、强情绪词、金句密度高、潜台词少

**集均时长：** 1.5～3分钟 / 集；全剧80～120集

### 三、出海市场调性（Reelshort/DramaBox等）

**主流赛道：**
- Alpha Billionaire / CEO Romance（霸道总裁出海版）
- Werewolf/Vampire Paranormal Romance（西方狼人/吸血鬼题材）
- Rejected Luna / Fated Mates（命运配对+被拒绝后逆袭）
- Revenge After Divorce（离婚复仇女主爽剧）
- Cinderella Rebirth（灰姑娘重生/身份揭露）

**调性差异：**
- 英文对白更口语化，情绪更直给，少含蓄
- 身体语言描写更明确（分镜需交代清楚）
- 冲突升级更快，第一集必须有强情绪事件
- 文化适配：避免过度中国化的宫斗逻辑，用西方家族/公司/学校场景替换

**集均时长：** 2～4分钟 / 集；全剧60～100集

### 四、钩子设计系统

钩子强度分级（每集必须达到B级以上）：

- **S级（每5集至少1次）：** 身份大揭露 / 死亡/生死危机 / 重大背叛
- **A级（每2集1次）：** 反转 / 当众打脸 / 关系质变
- **B级（每集结尾）：** 未解决的强冲突 / 情绪高点戛然而止 / 疑问抛出
- **C级（集内钩子）：** 每90秒一个小转折/情绪波动

### 五、人物设计铁则

**主角：**
- 必须有一个"超级能力"或"身份秘密"（战斗力/财富/背景/天赋）
- 第一集必须受到不公对待（激活观众代入感）
- 有明确且强烈的欲望/目标

**对手（反派）：**
- 不能只是坏，要有逻辑（利益/嫉妒/误解）
- 每次出手必须激起观众愤怒，为主角爽点蓄力

**CP搭配（爱情线）：**
- 反差感是核心（强弱/贵贱/冷热/敌友）
- 误会→冲突→破冰→虐恋→和解，节奏不能乱

## 剧本格式标准

### 格式A：分集剧本格式（标准）

```
【第X集】集标题（可选）
时长参考：约X分钟

场景一
INT./EXT. 场景地点 - 时间段

[场景描述：简洁，聚焦动作与情绪，≤3行]

人物名
对白内容。（≤15字/句，情绪词优先）

[动作/表情提示]

人物名
对白内容。

---集尾钩子---
[描述结尾钩子事件]
下集预告文案（可选）：「XXXX，下集揭晓」
```

### 格式B：分镜脚本格式（视听版）

```
【第X集 · 第X镜】

▶ 景别：特写/近景/中景/全景/大全景
▶ 镜头运动：固定/推/拉/摇/跟/手持抖动
▶ 构图：居中/三分法/斜线/对称/框架构图
▶ 光影：自然光/伦勃朗光/逆光/低调布光/高调
▶ 色调：暖橙（甜宠）/冷蓝（悬疑）/高饱和（爽剧）/去饱和（压抑）
▶ 时长：约X秒

[画面描述：主体、背景、运动、情绪氛围]

对白/声音：
「台词内容」
（画外音/BGM情绪提示）

导演提示：[表演要点/情绪重心]
```

## 小说改编快速拆解法（核心方法论）

1. **提炼爽点清单** → 找出小说所有"爽感节点"（打脸/逆袭/揭秘/告白），按强度排序
2. **砍掉80%内心描写** → 全部转化为对白和动作
3. **压缩时间线** → 小说10章 ≈ 短剧3集，去掉铺垫，留下冲突
4. **重构开场** → 短剧开场必须从冲突中间开始，而不是小说的人物介绍
5. **钩子重新分布** → 将小说的高潮点均匀分散到每集结尾
6. **对白现代化** → 文言/书面语改成口语，情绪词加倍

## 改编质量控制：已知问题与强制规则

> 本章节来自真实改编迭代中暴露的问题，每一条都有具体失败案例作为依据。
> **所有规则在输出前必须过一遍，不可跳过。**

---

### 【问题一】原著索引幻觉

**问题描述：**
在提供人物小传或集数大纲时，标注了「第X章」作为依据，但用户用原文对照后发现内容根本不在该章节，甚至是完全虚构的。

**典型案例：**
- 「核心秘密：体内藏有某种无法用修行体系解释的特殊力量（第8章，破剑之谜）」
  → 第8章真实内容：黑衣人说「怎么可能」是因为阿水用雪球击破其护体罡气，与闻潮生任何特殊力量无关
- 「第10集：吕知命看出他身上有异处，主动收徒」
  → 吕知命出场是在第16章，且动机是吕夫人想收义子，不是因为看出异处

**强制规则：**
1. 凡标注「第X章」的内容，必须是已经读取过该章节文本后才能引用
2. 人物小传中每一条「核心秘密」「特殊能力」「关键动机」，必须能在原著中找到直接文字支撑，不能用「合理推断」或「后文暗示」替代
3. 如果某个设定只是自己对故事走向的合理联想，必须明确标注「改编创作」而非「原著依据」
4. 用户以原文对照质疑时，第一反应是重新读取原著核查，不是辩解

---

### 【问题二】剧本内部逻辑错误

**问题描述：**
剧本中出现人物知道不该知道的信息、道具不该出现却出现、时间线在单集内跳跃等逻辑漏洞。

**典型案例（均来自《天不应》第1集改编）：**
- 阿水在闻潮生没有自我介绍的情况下说出了「闻潮生」三个字
  → 原著顺序：女人先问「你叫什么名字」，闻潮生才回答，顺序写反了
- 大黑狗在第1集出现在破庙
  → 原著：大黑狗第4章才首次出场，第1集不应存在
- 单集内出现「几天后」的时间跳跃
  → 原著：第1集对应的时间线只是「当夜」（救人→送破庙→张猎户拿钥匙→树屋睡下），不应跨天

**强制规则：**
1. 写完剧本后，逐场景核查：**每个人物知道某件事的依据是什么？** 如果信息来源不清晰，就是逻辑漏洞
2. 所有道具（武器/动物/物件）首次出现前，确认原著中它在此时间节点已经存在
3. **单集时间线铁律**：一集原则上只覆盖原著中一个连续时间段，如需跳跃，必须在下一集开头处理，不在同一集内用「X天后」过渡
4. 人物的每一句台词，检查说话人在此刻是否具备说出这句话的信息条件

---

### 【问题三】集数大纲与原著脱节

**问题描述：**
集数大纲看起来符合短剧节奏，但大量情节是按照短剧套路自行创作的，没有原著依据，关键设定甚至与原著直接矛盾。

**典型案例（均来自《天不应》集数大纲）：**
- 「第7-8集：阿水用身份震慑县令，闻潮生拿到文书」
  → 原著真实情况：刘金时在第15章已被人下毒吊死在县衙门口，根本没有「阿水震慑县令」这一幕
- 「第16-18集：体内力量觉醒，闻潮生爆发式反击」
  → 原著：闻潮生没有丹海（第30章），全书未出现「体内力量突然觉醒」，这是完全虚构的设定
- 「第15集钩子：阿水失踪，被某势力强行带走」
  → 原著：阿水离开破庙是自然行为，没有被强行带走

**强制规则：**
1. **改编小说前必须先读完全书**（或至少读完拟改编的季度范围），不能靠部分章节推测全貌
2. 集数大纲中每一个「关键事件」，必须能对应到原著的具体章节，无法对应的须明确标注「改编补充」
3. 涉及主角核心设定（有无修为、有无特殊能力、身份来源）的情节，改编前必须核查原著的明确交代，不能用「常见套路」填充
4. 原著已经发生的重要事件（如刘金时的死法、时间节点）不能在改编中改变，只能调整呈现方式

---

### 【问题四】人物小传信息分层不清

**问题描述：**
人物小传把「原著已明确交代的信息」「原著暗示但未明说的信息」「改编者的合理推断」混在一起，没有区分标注，导致用户无法分辨哪些是原著事实。

**强制规则：**
人物小传必须按以下三层分别标注：

```
【原著明确】有原文直接语句支撑，可精确标注章节
【原著暗示】原著有行为/细节支撑，但没有直接说明，需注明推断依据
【改编创作】原著无依据，是改编者为短剧需要增加的内容，必须显式标注
```

同一条信息不能跨层混写。如果不确定属于哪层，默认降一层处理。

---

### 【问题五】第一集内容过载

**问题描述：**
为了快速建立世界观和人物关系，在第一集塞入了过多原著跨章节的内容，导致节奏混乱、时间线错误。

**典型案例：**
初版第1集同时包含了：救阿水（第1章）、大黑狗（第4章）、喝酒对话（第9-11章）、杀手来袭（第8章）→ 实际跨越了原著9章的内容

**强制规则：**
1. 第1集对应的原著章节范围，在动笔前先画出来，严格在此范围内取材
2. 「短剧第一集」不等于「把原著前几章全压进去」，而是选取原著中**一个最强的时间切片**精细呈现
3. 倒叙/闪回可以引用后续章节内容，但必须明确标注是「跳跃到第X章」，且不能与第1集时间线主体产生信息矛盾

## 小说改编标准工作流（修订版）

以下是结合上述问题教训后的正确工作顺序，**必须按此顺序执行，不可跳步**：

```
第一步：全书通读
→ 读取所有章节标题，建立全貌认知
→ 对于改编范围内的章节，逐章读取关键内容
→ 禁止：只读部分章节就开始输出大纲或人物小传

第二步：提炼原著事件清单（带章节索引）
→ 每个关键事件标注：发生章节 + 原著真实情节 + 与短剧节奏的契合度
→ 此步骤的输出是「原著事件清单」，不是「改编方案」

第三步：确定改编范围与季度结尾
→ 基于原著自身的结构节点（如第一卷完）确定范围
→ 测算集数与时长是否匹配

第四步：人物小传（三层标注）
→ 按「原著明确/原著暗示/改编创作」三层分别撰写
→ 每条「原著明确」信息必须能标注章节

第五步：集数大纲（带章节索引）
→ 每集核心事件后标注「依据：第X章」
→ 原著无依据的情节标注「改编补充」
→ 钩子等级评定

第六步：单集剧本
→ 动笔前先确认本集对应的原著章节范围
→ 写完后执行「逻辑自检四问」（见下方）
```

## 输出质量自检清单

### 剧本逻辑自检四问（每集写完必查）

1. **信息来源检查：** 每个人物在每个场景说出的话/做出的行为，他/她此刻是否具备这些信息？
2. **道具时间线检查：** 场景中出现的每一个重要道具/角色，在原著的此时间节点是否已经存在？
3. **单集时间跨度检查：** 本集是否只覆盖一个连续的时间段？如有跳跃，是否移至下集处理？
4. **原著依据检查：** 本集中每一个「关键情节转折」，对应的是原著第几章的哪个事件？无法回答的需重新核查

### 大纲与人物小传自检

- [ ] 所有「第X章」索引是否已读取该章节原文？
- [ ] 人物核心能力/秘密是否有原著直接文字支撑（而非推断）？
- [ ] 集数大纲中是否存在与原著明确情节矛盾的内容？
- [ ] 第1集取材范围是否已明确划定，没有跨章节混入？
- [ ] 人物小传是否区分了「原著明确/原著暗示/改编创作」三层？
