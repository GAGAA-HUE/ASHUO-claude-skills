# 抖音 30 秒极速版模板

## 结构节拍

| 段落 | 时长 | 功能 | 技巧 |
|------|------|------|------|
| **黄金 3 秒** | 3s | 反常识提问 / 惊人事实 / 直接冲突 | 禁止铺垫，直接上钩子 |
| **钩子展开** | 7s | 一句话交代背景，建立悬念 | "但没人知道的是……" |
| **主体高潮** | 15s | 1 个核心事件，情绪推到顶点 | 用对比制造冲击 |
| **结尾互动** | 5s | 引导评论 / 点赞 / 关注 | "你觉得呢？评论区见" |

## 分镜表格式

```markdown
| 镜号 | 景别 | 时长 | 画面内容 | 旁白/台词 | 情绪/音乐 | 备注 |
|------|------|------|---------|----------|----------|------|
| 01 | 特写 | 3s | | | 悬疑/紧张 | 黄金 3 秒，必须留住用户 |
| 02 | 中景 | 7s | | | 递进 | 快速铺垫 |
| 03 | 近景 | 15s | | | 高潮 | 核心事件 |
| 04 | 特写 | 5s | | | 互动 | 引导互动 |
```

## 口播字数控制

- **总字数**：90～120 字（按 240 字/分钟语速）
- **每句长度**：不超过 15 字，短句为主
- **禁止长句**：超过 20 字的句子必须拆分

## 标题公式（三选一）

1. **数字冲击**："X 分钟前，他做了 XX"
2. **反常识**："XX 居然不是 XX？真相太离谱"
3. **悬念钩子**："他 XX 了 XX 年，最后发现……"
