# 抖音 120 秒完整版模板

## 结构节拍

| 段落 | 时长 | 功能 | 技巧 |
|------|------|------|------|
| **黄金 3 秒** | 3s | 反常识提问 / 惊人事实 / 直接冲突 | 禁止铺垫，直接上钩子 |
| **钩子展开** | 15s | 快速交代背景，建立悬念 | "但没人知道的是……" |
| **主体递进** | 70s | 4 个核心事件，情绪起伏 | 事件 A → 转折 → 事件 B → 递进 → 事件 C → 转折 → 事件 D |
| **高潮/反转** | 20s | 最大戏剧性时刻 | 可留开放式结尾 |
| **结尾互动** | 12s | 引导评论 / 点赞 / 关注 | "你觉得呢？评论区见" |

## 口播字数控制

- **总字数**：360～480 字（按 240 字/分钟语速）
- **每句长度**：不超过 15 字，短句为主
- **禁止长句**：超过 20 字的句子必须拆分

## 情绪曲线模板

```
好奇（3s）→ 紧张（15s）→ 震惊（15s）→ 反思（5s）→ 紧张（15s）→ 反转（5s）→ 上升（15s）→ 反思（5s）→ 高潮（15s）→ 开放（12s）
```

## 标题公式（三选一）

1. **数字冲击**："X 分钟前，他做了 XX"
2. **反常识**："XX 居然不是 XX？真相太离谱"
3. **悬念钩子**："他 XX 了 XX 年，最后发现……"

## 信息密度检查清单

- [ ] 每 15 秒至少有一个新的信息点或情绪转折
- [ ] 旁白之间使用因果连接词（"但"、"然而"、"更可怕的是"、"讽刺的是"）
- [ ] 没有纯罗列式叙述（"他做了 A，做了 B，做了 C"）
- [ ] 结尾有明确的互动引导
