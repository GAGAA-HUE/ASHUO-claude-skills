# Wan 2.7 提示词结构指南

## 核心框架

```
[主体] + [动作/状态] + [环境/场景] + [光线/天气] + [风格/质感] + [技术参数词]
```

### 各模块详解

#### 1. 主体描述（必须）
描述核心视觉元素：人物特征、物体属性、场景构成。

**人物类：**
- 性别、年龄、外貌特征（发色、发型、眼睛颜色、肤色）
- 服装：材质 + 款式 + 颜色
- 表情与姿态
- 人物数量（1~3人细节描述效果最好）

**物体/产品类：**
- 材质、形状、颜色
- 与场景的关系（摆放位置、角度）

**场景类：**
- 地理位置 + 建筑风格 + 时代背景

#### 2. 动作/状态（推荐）
静态：坐着、站立、凝视远方、微微回眸
动态感：衣角飘动、发丝飞扬、烟雾弥漫、水波荡漾

#### 3. 环境/场景（推荐）
- 室内：木质地板、落地窗、暖色调咖啡馆
- 室外：樱花街道、霓虹雨夜、荒漠公路
- 虚构：赛博空间、魔法森林、星际飞船舱

#### 4. 光线与氛围（强烈推荐）
光线是写实感的关键。

| 光线类型 | 关键词（中） | 关键词（英） |
|----------|------------|------------|
| 黄金时刻 | 黄金时刻，柔和暖光 | golden hour, warm soft light |
| 蓝调时刻 | 蓝调时刻，冷色天空 | blue hour, cool twilight |
| 自然漫射 | 自然漫射光，柔和阴天 | diffused natural light, overcast |
| 工作室灯 | 专业影棚打光，蝴蝶光 | studio lighting, butterfly light |
| 霓虹氛围 | 霓虹灯反光，赛博朋克光 | neon reflections, cyberpunk lighting |
| 烛光/暖光 | 烛光，温暖橙光，氛围感 | candlelight, warm ambient glow |
| 逆光 | 轮廓光，逆光剪影 | rim light, backlit silhouette |

#### 5. 风格/质感（推荐）
见 `style-keywords.md` 各类型区块。

#### 6. 技术参数词（可选，用于提升质量）

**通用质量提升词：**
- 中文：超高细节，超清晰，专业摄影，8K分辨率，RAW格式
- 英文：ultra-detailed, hyper-realistic, professional photography, 8K resolution, RAW photo

**负向描述（避免的元素）：**
Wan 2.7 的文字输入也可以包含"请不要出现XXX"的表述，thinking mode 会理解。

## 文字渲染（Wan 2.7 专属优势）

Wan 2.7 是目前文字渲染最准确的图像模型之一，支持 12 种语言。

### 使用方法
直接在提示词中明确说明文字内容、字体风格、位置：

```
图片中央有一块木制标牌，上面用黑色手写体写着"新鲜草莓 Fresh Strawberries"，
字迹清晰工整，标牌周围点缀着新鲜草莓。
```

```
A wooden signboard in the center reads "Fresh Strawberries" in black handwritten font,
clean and legible text, surrounded by fresh strawberries.
```

### 文字渲染最佳实践
1. **明确指定字体风格**：手写体/印刷体/霓虹灯字体/刻字
2. **说明文字颜色**：白色/金色/黑色墨水
3. **指定位置**：画面中央/左上角/标牌上/T恤上
4. **开启 thinking mode**：复杂文字布局必开

## 多图一致性写法

Wan 2.7 支持"系列图"模式（enable_sequential=true），用同一提示词生成多张保持角色/场景一致的图片。

### 写法示例
```
一组记录同一只流浪橘猫的电影感图集，特征始终一致。
第一张：春天，橘猫在盛开的樱花树间穿行。
第二张：夏天，橘猫在老街树荫下乘凉。
第三张：秋天，橘猫走在金色落叶铺成的地面上。
第四张：冬天，橘猫在雪地上留下爪印。
```

参数设置：`enable_sequential: true`，`n: 4`

## 常见错误与修正

| 问题 | 原因 | 修正方式 |
|------|------|---------|
| 人物脸部失真 | 主体描述太少 | 增加五官、肤色、发型细节 |
| 背景与前景不协调 | 场景描述断裂 | 统一光线来源和色调 |
| 画面过于拥挤 | 元素堆砌 | 减少主体数量，用"构图简洁"约束 |
| 文字出现错误 | 未开启 thinking mode | 开启 thinking_mode: true |
| 风格漂移 | 风格词太泛 | 使用具体参考词，如"新海诚风格"替代"动漫风格" |
