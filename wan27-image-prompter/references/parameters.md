# Wan 2.7 参数配置指南

## 模型选择

| 模型 | 适用场景 | 特点 |
|------|---------|------|
| `wan2.7-image-pro` | 高品质出图、商业用途、复杂构图 | 支持4K、thinking mode，生成稍慢 |
| `wan2.7-image` | 快速迭代、测试提示词效果 | 速度更快，质量略低 |

**建议：** 确定好提示词后用 Pro 版出最终图；调试提示词阶段用普通版。

---

## size 参数（分辨率）

### wan2.7-image-pro

| 规格 | 总像素 | 适用场景 |
|------|--------|---------|
| `1K` | ~100万像素 | 快速预览、社媒小图 |
| `2K`（默认）| ~400万像素 | 日常使用、大多数场景 |
| `4K` | ~1600万像素 | 商业印刷、海报、精品输出（仅限纯文生图） |

**注意：** 4K 仅在纯文生图（无参考图输入）且不生成图集时支持。

### wan2.7-image

| 规格 | 适用场景 |
|------|---------|
| `1K` | 快速迭代 |
| `2K`（默认）| 日常使用 |

### 自定义比例（宽×高）

也可以直接指定像素尺寸，格式：`"宽度*高度"`，例如：
- `"1280*720"` → 16:9 横屏
- `"720*1280"` → 9:16 竖屏（适合手机壁纸、社媒故事）
- `"1024*1024"` → 1:1 正方形（适合头像、产品图）
- `"1536*1024"` → 3:2 横版（适合摄影风格）

**限制：** 宽高必须均在 240~8000 之间，宽高比在 1:8 到 8:1 之间。

## thinking_mode 参数

```json
"thinking_mode": true
```

**何时开启：**
- ✅ 复杂场景（多人物、复杂空间关系）
- ✅ 需要精确位置排列的构图
- ✅ 包含画内文字
- ✅ 多参考图融合
- ✅ 概念艺术/电影感画面（构图要求高）

**何时关闭（节省时间）：**
- 简单的单主体图（如单人写真、单件产品图）
- 快速测试提示词思路

---

## n 参数（生成数量）

```json
"n": 1
```

- `1`：精确控制时使用（配合 thinking mode）
- `2~4`：探索阶段，从多个结果中挑选
- **最大值：** 4

---

## enable_sequential 参数（系列图/图集模式）

```json
"enable_sequential": true,
"n": 4
```

**用途：** 生成多张保持主体/风格一致性的系列图。适合：
- 角色多场景展示（同一人物在不同环境）
- 产品多角度展示
- 故事性连环图
- 四季/时间变化主题

**提示词写法：**
需在提示词中明确描述每张图的内容差异，用"第一张/第二张"或"First image/Second image"区分。

**示例：**
```
一组电商产品图集，展示同一款白色陶瓷马克杯。
第一张：马克杯放在木质桌面上，自然晨光侧打，背景是模糊的绿植。
第二张：马克杯握在一双女性的手中，温暖的室内光，背景是柔焦的书架。
第三张：马克杯旁边摆放着一本书和咖啡豆，俯拍，Lifestyle风格。
第四张：马克杯特写，展示杯口质感和手柄细节，白底，商业摄影风格。
```

## 图像编辑相关参数

### bbox_list（交互式编辑选区）

当需要精确指定编辑区域时使用：

```json
"bbox_list": [
  [],                          // 第1张图：不指定区域（全图参考）
  [[989, 515, 1138, 681]]     // 第2张图：指定编辑区域 [x1, y1, x2, y2]
]
```

坐标格式：绝对像素坐标，左上角为原点 (0,0)。

**使用场景：**
- 精确替换图片中某个区域的内容
- 保留特定区域不变，只修改其他部分

## 参数配置速查表

| 场景 | 推荐配置 |
|------|---------|
| 商业产品主图 | Pro，2K，thinking_mode: true，n: 2 |
| 社媒竖图（9:16）| Pro，720*1280，thinking_mode: false，n: 2 |
| 电影概念艺术 | Pro，2K，thinking_mode: true，n: 1 |
| 角色系列图 | Pro，2K，enable_sequential: true，n: 4 |
| 包含文字的海报 | Pro，2K，thinking_mode: true，n: 1 |
| 快速测试提示词 | 普通版，1K，n: 4 |
| 4K精品出图 | Pro，4K，thinking_mode: true，n: 1（仅限纯文生图）|

## 输入图像规格（用于图生图/图像编辑）

- 格式：JPEG、JPG、PNG（不支持透明通道）、BMP、WEBP
- 尺寸：宽高均在 240~8000 像素之间
- 宽高比：1:8 到 8:1 之间
- 文件大小：不超过 20MB
- 最多可输入：9 张参考图
