# Wan 2.7 高阶提示词技巧详解

> 来源：阿里官方《Wan 2.7-Image 图像生产力指南》第二章·高阶提示词技巧

---

## （一）结构与布局控制
**控制维度：内容 - 总体控制**

支持对构图、画面结构与设计布局的整体性控制，通过自然语言精确约束图像的视觉重心、空间分布、视角角度及光影氛围等。

**参考结构：**
```
「镜头角度」+「构图框架」+「元素内容与分布」+「景深」+「光影氛围」
```

**关键词参考：**

| 维度 | 示例关键词 |
|------|----------|
| 镜头角度 | 俯拍、仰拍、平视、鸟瞰、低机位、特写、远景 |
| 构图框架 | 三分法、居中对称、对角线构图、框中框、引导线 |
| 元素分布 | 左上角放置标题、右下角留白、主体居中偏左 |
| 景深 | 浅景深/背景虚化、深景深/全景清晰、焦外散景 |
| 光影氛围 | 黄金时刻、蓝调时刻、逆光剪影、丁达尔效应、柔和散射光 |

## （二）多模态组合输出（图文混排）
**控制维度：内容 - 结构控制**

具备高精度的原生文本渲染能力，支持将指定文字内容与画面风格完美融合，确保文字位置、风格与整体画面视觉对齐，实现图文的协同表达。

**参考结构：**
```
「图像定位」+「画面风格」+「"文字内容"」+「文字属性」+「图文融合关系」
```

**使用要点：**
- 文字内容用**引号**括起来，明确区分
- 标明文字**位置**（画面顶部/居中/右下角）
- 标明**字体风格**（手写体/印刷体/霓虹灯/刻字）
- 标明**文字颜色和大小**关系
- 复杂版式开启 `thinking_mode: true`

**适用场景与示例：**

```
文字海报：
赛博朋克风城市夜景，画面中央醒目白色粗体大字"未来已来"，
下方小字"THE FUTURE IS NOW"，霓虹光晕效果，文字与背景融合自然

图文适配：
科技感蓝黑色背景，顶部标题区域"WAN API"金属质感大字，
下方三列图文对齐展示功能特性，信息层级清晰

超长图：
电商详情页竖版长图，奶油色系北欧风，床头柜产品为主体，
分四个区域依次展示：产品全貌/细节特写/使用场景/规格参数，
图文混排，文字标注清晰
```

## （三）细粒度与局部控制
**控制维度：内容 - 细节控制**

支持对局部属性（主体、元素、背景）进行细粒度约束（内容、形态、纹理、材质、光影、虚化与颗粒等），保持关键细节的精准稳定呈现。

**参考结构：**
```
「宏观描述」+「主体/元素」+「局部细节」+「空间与交互关系」+「背景及其他属性」+「风格与画质」
```

**千人千面（人脸精细控制）关键词：**

| 维度 | 可控属性 |
|------|---------|
| 五官廓形 | 杏仁眼、圆眼、深邃眼、肿眼泡、欧式大双、瑞凤眼、高鼻梁 |
| 面部比例 | 鹅蛋脸、圆脸、锥子脸、方形脸、高颧骨 |
| 表情神态 | 微笑、严肃、慵懒、惊喜、若有所思、眼神坚定 |
| 妆容 | 裸妆、烟熏妆、眼线、口红颜色（正红/豆沙/橘色）、腮红 |
| 发型 | 波浪卷、直发、丸子头、刘海、发色（金/棕/黑/渐变） |
| 配饰 | 耳环款式、项链、帽子类型、眼镜框型 |

**适用场景：** 人物写真、虚拟形象设计、角色一致性、品牌人设

## （四）动态叙事类（组图）
**控制维度：内容 - 元素控制**

对于包含因果或时间顺序的动态叙事类组图图像，按照**先图片结构，再图像内容**的描述方式，以确保故事线与动作流的逻辑闭环。

**参考结构：**
```
「叙事载体」+「主题风格」+「图像格式」+「流程步骤/分镜描述」+「细节构成」
```

**示例：**
```
流程顺序（多宫格）：
手工蛋挞制作教程，可爱扁平插画风，4格宫格竖版布局，
步骤1.准备材料 2.混合原料 3.过滤蛋液 4.倒入蛋挞皮烤制，
每格标注步骤名称，暖色系，卡通风格

时间线（单图）：
人类航天里程碑，深蓝星空科技风，横向时间轴布局，
标注1957年/1969年/1986年/2003年/2021年/2024年关键节点，
配对应图标，简洁信息图风格
```

## （五）静态展示类（组图）
**控制维度：内容 - 元素控制**

对于无时序要求的静态展示类图像，是对同一个（或同一类）对象的全方位展示。为保持主体的一致性，采用**总分结构叙事**比单独强调叙事效果相对更好。

**参考结构：**
```
「叙事载体」+「特殊构图（如有）」+「主题风格」/「主体」+「按构成描述+细节」
```

**变体类型：**

| 类型 | 说明 | 适用 |
|------|------|------|
| 同主体 不同视角 | 同一角色/产品，多角度展示 | 人物写真、产品图 |
| 同主体 不同角度 | 正面/侧面/背面/特写 | 角色设定、服装展示 |
| 同风格 不同内容 | 统一美学下的不同元素 | 系列海报、表情包 |
| 同内容 不同载体 | 同一场景的多视角 | 绘本、漫画 |

## （六）反事实与创意探索
**控制维度：内容 - 特殊控制**

**抽象概念构建：** 将抽象用词与具象内容进行有意识组合跨语义生成，以获取意想不到的画面结果。

| 情绪 → 画面 | 示例提示词 |
|------------|----------|
| 愤怒 | 扭曲的红色线条人形，爆炸感构图 |
| 悲伤 | 一个人站在巨浪前的海边，背影渺小 |
| 欢乐 | 少女在花海中奔跑，满画面蝴蝶与花瓣 |
| 恐惧 | 深海中孤独的光点，四周无边黑暗 |
| 迷茫 | 雾中裸树，远处模糊光源 |

**抽象内容构建：** 使用反常规概念或边界条件探索，生成趣味性组合结构图像。

| 非常规类型 | 示例 |
|-----------|------|
| 非常规尺寸 | 巨型猫咪坐在城市中央，体量与高楼相当 |
| 非常规材质 | 鲸鱼尾巴由黑色塑料袋构成（环保主题） |
| 非常规组合 | 穿西装的猫咪坐在老式火车上看风景 |
| 非常规状态 | 一块透明冰块燃烧着蓝色火焰 |
| 非常规结构 | 悬浮倒置的山峰，下方是镜面湖泊 |

## （七）风格与美学控制
**控制维度：风格 - 混合控制**

混合多风格生成具有合理关系和美感的图片。可以进行分离内容风格、风格迁移、混合艺术家风格、精细控制等操作。

**设计前先思考：**
> 需要融合的风格有哪些？是按什么比例如何融合的？内容和风格的关系是什么？

**参考结构：**
```
「混合风格描述」+「风格融合形式」+「内容构成」+「画面要求」
```

**风格混合类型：**

| 类型 | 示例 |
|------|------|
| 非冲突风格混合 | 梵高星空笔触 + 写实山景 → 油画感自然风光 |
| 冲突风格混合 | 线描白猫 + 真实草地场景 → 2D与3D融合 |
| 材质混合 | 3D卡通造型 + 游戏像素风场景 |
| 艺术家风格迁移 | 浮世绘配色 + 现代街拍人物 |
| 复杂风格混合 | 传统工笔画人物 + 赛博朋克霓虹环境 |

**调色盘（色彩风格迁移）参考词：**

| 色调名 | 适用场景 |
|--------|---------|
| 电影感 | 青橙色调，高对比，好莱坞风 |
| 冷色调 | 蓝灰系，清冷，都市感 |
| 马卡龙色 | 粉嫩低饱和，甜美，女性向 |
| 复古胶片感 | 褪色颗粒，黄绿色偏移，70-90年代 |
| 暖色调 | 橙黄系，温暖，生活气息 |
| 莫兰迪 | 灰色系，高级感，去饱和 |
| 黑白灰 | 极简，艺术，纪实风 |
| 多巴胺 | 高饱和撞色，活力，年轻感 |
| 赛博霓虹 | 紫蓝粉，发光感，未来感 |
| 敦煌美学 | 土红金棕，古典，东方美学 |
| 忧郁蓝调 | 深蓝紫，沉郁，情绪化 |
| 春日氛围 | 嫩绿粉白，清新，自然感 |
