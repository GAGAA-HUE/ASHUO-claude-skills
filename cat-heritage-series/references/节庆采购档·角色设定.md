## 陈列道具卡 1:猫咪塑料模特

```xml
<prop id="CatMannequin">

  <name>猫咪塑料模特</name>

姿态:双手自然下垂或微抬,作"展示"姿势;

  </form>
  <costume_themes>
按节庆切换(每个模特穿不同主题):
1. 春节款:红色唐装+金色盘扣+小鞭炮挂件;
2. 端午款:汉服(青绿)+艾草香囊+五彩绳;
3. 中秋款:玉兔造型(白绒+长耳)+月饼盒;
4. 圣诞款:麋鹿造型(棕绒+鹿角+红鼻)+铃铛;
5. 日常和风款:和服(蓝染)+木质发簪+小团扇;
6. 生日款:小皇冠+彩带+气球;
7. 七夕款:牛郎织女小款(偶发);
8. 元旦款:红色围巾+雪花图案(偶发);
默认款:全裸塑料猫身(店主可换衣)。
  </costume_themes>
  <budget_rule>
- 不计入动物角色预算(同 v6.3 的 A008/A019 等"陈列道具"归类);
- 不参与叙事主线(不与三猫互动,不"被摸头"/"被逗");
- 不发出任何声音(纯视觉);
- 同屏可出现 2-4 只(橱窗陈列);
- 必须静止站立(无任何动作/表情变化);
- 出场时间计入"场景道具"时长,不计"角色"时长;
- 不出现在院落/家中——仅在萌宠服装店橱窗或超市陈列区。
  </budget_rule>
  <forbidden_list>

- ❌ 被任何人类店长"调整姿势"——道具在出场前已摆好;
- ❌ 与三猫同框对话/眼神交流;
- ❌ 进入院落或家中布置段;
- ❌ 出现在无节庆的 TYPE A 主线工艺片(本道具专属于 TYPE B)。

  </asset_ids>

- 静态站立(无任何动作);
- 不同模特穿不同主题服饰(同店内 2-4 只混搭);

- 不与三猫同框特写(避免观众误认)。
  </visual_reference>
</prop>
```

## 角色调用规则(LLM 视角)

### 角色出现优先级

| 场景 | 源姐姐 | 朔哥哥 | 猫咪塑料模特 | 三猫 |
|---|---|---|---|---|
| 院落/家 | ❌ | ❌ | ❌ | ✅ |
| 城市商业街 | ❌ | ❌ | ❌ | ✅ |
| 萌宠服装店 | ✅(POV·只露手/道具) | ❌ | ✅ | ✅ |
| 好萌超市 | ❌ | ✅(POV·只露手/道具) | ✅ | ✅ |
| 节庆采购返程 | ❌ | ❌ | ❌ | ✅ |

### 角色预算汇总(每期 TYPE B)

- **源姐姐** POV 互动时长 ≤40s（只露手/道具）
- **朔哥哥** POV 互动时长 ≤35s（只露手/道具）
- **猫咪塑料模特** 同屏 2-4 只,出场时长不限(纯道具)
- **人类顾客** ≤2 人 / ≤20s,远景
- **三猫** 全程主视角

### 角色违反约束的判定

| 违反类型 | 输出判定 |
|---|---|
| 源姐姐 POV 互动时长 >40s | 输出失败 |
| 朔哥哥 POV 互动时长 >35s | 输出失败 |
| 源姐姐面部 / 全身 / 静态站位形象出现在画面中 | 输出失败(POV 红线) |
| 朔哥哥面部 / 全身 / 静态站位形象出现在画面中 | 输出失败(POV 红线) |
| 朔哥哥出现在萌宠服装店 | 输出失败(双店间隔原则) |
| 源姐姐/朔哥哥抱猫 | 输出失败 |
| 猫咪塑料模特与三猫互动 | 输出失败(道具不响应) |
| 猫咪塑料模特被摸头 | 输出失败 |
| 猫咪塑料模特出现在院落 | 输出失败(道具只属于店铺) |
| 朔哥哥 / 源姐姐台词 >3 句/期 | 输出失败 |
| 单句台词 >8 字 | 输出失败 |
| 人类顾客特写 | 输出失败(只能远景) |

## 维护说明

1. 每生成一期 TYPE B 脚本,核对角色 POV 互动时长,确保不超预算
2. 角色详细设定有调整时,同步更新本文件 + 节庆采购档·设计宪法.md + 主资·物质资产表.md
3. 猫咪塑料模特新增款式时,在 `<costume_themes>` 末尾添加,不修改已有款式
4. 人类店长新增成员时(如未来加助理),需先在 节庆采购档·设计宪法.md 升级"允许人类"约束
5. POV 视角规则有调整时,同步更新本文件 `<on_screen_rule>` + 节庆采购档·设计宪法.md 约束 9
