### v1.3 修正

- 字幕卡位置：从"招牌结尾"前移到"每个工艺流程的开头"
- 招牌结尾不放字幕卡，让情绪钩子独占 2–3 秒

### v4 增强（基于第 1 期实战）

- 招牌动作库扩展：**挠**加入（与扑咬 / 拍头 / 推 / 抽尾巴 / 骑 并列）
- 招牌互动升级：
  - 扑蝴蝶用力过猛扑倒师傅 → 师傅翻身挠橘猫（升级版招牌互动）
  - 师傅用爪子推开橘猫的脸（动机：担心橘猫烫到，含情感内核）
- 情感内核：**"严厉的爱"双钩子**——教训背后是关心
- 画面约束：绝对不出现人类、不出现集市、所有原料获取由角色直接完成

### v5 修订（基于家庭设定调整）

- **角色数**：从 2 只猫扩展为 3 只猫（优雅姐 + 黄毛弟 + 呆萌妹），见"三猫家庭完整设定 v2.0"
- **能量分配**：权威源从"体型反差（师傅 vs 学徒）"回到"靠谱度反差（大姐姐 vs 弟弟/妹妹）"
- **招牌情感线扩展**：除原有"严厉的爱"外，新增两条情感主线：
  - **D 姐替妹出头**：黄毛弟欺负呆萌妹 → 优雅姐抽黄毛弟尾巴教训
  - **E 弟关键时刻护家人**（非强制每期都拍）：姐或妹被外物/他者欺负 → 黄毛弟挺身而出
- **COLD OPEN 规则改写**（见改动 3）：黄毛弟出场取材 + 姐与妹在旁指挥等候（打太阳伞 / 冰阔乐 / 认真摆材料）
- **SOURCING 段分工固定化**：取材体力活 = 黄毛弟；现场指挥 = 优雅姐 + 呆萌妹
- **招牌结尾改为三人镜头**：优雅姐教训黄毛弟 + 黄毛弟装无辜 + 呆萌妹瞪大眼睛在旁当气氛组
- **meta 彩蛋扩展**：成品上同时体现三只猫形象（姐款异瞳三花轮廓 / 弟款橘色爪印 / 妹款小白猫脚印；三猫同款 = 终极彩蛋）
- **画面约束增加项**：呆萌妹不被惩罚；只能瞪大眼睛 + 歪头 + 被姐宠溺挪开

## 二、三猫家庭完整设定 v2.0（原"双猫完整设定 v1.3"改写）

### 别名表（贯穿所有脚本）

| 代号 | 品种 | 家庭身份 | 性格内核 | 核心职能 |
|---|---|---|---|---|
| **优雅姐** | 异瞳三花 | 老大 | 认真干活靠谱 + 被弟弟妹妹弄破防 + 兜底者 | 工艺主讲 + 教训者 + 替妹出头 |
| **黄毛弟** | 橘猫 | 老二 | 调皮捣蛋憨傻机灵 + 贱兮兮 | 取材主力 + 弄砸者 + 关键时护家人 |
| **呆萌妹** | 小白猫 | 老妹 | 可可爱爱认真办砸 + 团宠 | 气氛组 + 帮倒忙 / 递东西 |

### 外形 + 角色反差（v5 修订）

| 维度 | 优雅姐（姐） | 黄毛弟（弟） | 呆萌妹（妹） |
|---|---|---|---|
| 体型 | **小体型**（弱势外形，但工艺主讲 = 权威实际来源） | **大体型**（强势外形 + 体力担当） | **小体型**（团宠 + 紧贴姐姐） |
| 角色 | 权威方（靠谱度反差） | 调皮方 | 团宠方（不进入权威对比） |
| 工艺参与度 | 主讲（≥50%） | 取材 + 灵机一动搞砸 | 气氛组 + 帮倒忙 |

> v1.3 体型反差权威（小 = 师傅 vs 大 = 学徒）保留为"姐弟小妹"的体型底色，但权威的实际来源不再靠体型，而是靠"靠谱度"——优雅姐是真讲工艺者，黄毛弟打架 / 搬东西厉害但工艺上仍被姐按住。

### 性格内核（v5 扩展）

**优雅姐（姐）**：
- 沉浸态、偷瞄、忍无可忍
- 与弟的互动：教训（推 / 挠 / 拍 / 抽尾 / 扑咬 / 骑）
- 与妹的互动：宠溺保护（推开妹帮倒忙的爪子时力度极轻 / 把妹挪到安全位置）

**黄毛弟（弟）**：
- **机智偷懒 + 掩护 + 装无辜**——沿用原 8 类行为库
- **撺掇呆萌妹**：拉着妹一起干坏事
- **欺负呆萌妹**：拍妹头 / 抢妹手里的材料 / 推倒妹的东西 → 招致姐的打
- **关键时护家人**：姐或妹被外物 / 他者欺负时挺身而出（情感落点）
- **灵机一动搞砸**：在制作段中出其不意的举动把事情搞砸（不限于偷懒，还包括"自以为聪明的主动行为"反而把工艺破坏）

**呆萌妹（妹）·v5 新增**：
- **可可爱爱认真干活**：整整齐齐摆材料、认真递工具、站在姐姐身旁当背景气氛组
- **招牌办砸动作**（两种并行，由当期选取）：
  - **帮倒忙型**：递给姐姐错误的工具 / 把水打翻浸湿材料 / 把粘好的半成品弄歪 / 把颜料盘打翻
  - **气氛组型**：在旁打太阳伞 / 递冰阔乐 / 用爪子拍节奏 / 给姐姐扇扇子
- **被欺负时的反应**：瞪大眼睛 + 歪头 + 缩成一团 → 触发优雅姐出手教训黄毛弟
- **姐或哥护着妹时**：妹安静地贴在姐身旁

### 招牌动作库（v5 三猫版）

**优雅姐（姐）**：
- 沉浸演示工艺，**面向镜头背对弟妹**（观众同视角偷窥弟妹在身后搞事）
- 偷瞄时**尾巴尖微微摆动**（猫"管不了你但是在意"的标志）
- **忍无可忍"教训"动作库**（v5 沿用 v4）：扑咬 / 拍头 / 推 / 抽尾巴 / 骑 / 挠
- 物理反差爆点：推黄毛弟发现自己推不动
- 情感内核（v5 升级）：推开脸 / 挠 等动作背后是**担心学徒受伤**（"严厉的爱"），以及**替妹妹出头**（"姐姐保护"）
- **新招牌动作**（v5）：推开呆萌妹帮倒忙伸过来的爪子（温柔版 + 力度极轻，与推开黄毛弟完全不同）

**黄毛弟（弟）· v5 扩展**：
- **招牌偷懒方式"假装在做"**——整整齐齐摆材料、空中划拉假装工艺、自以为天衣无缝
- **偷懒行为库（8 类典型行为）· 沿用 v1.3**：
  1. 打瞌睡（在不该睡的地方睡着）
  2. 神游（眼睛盯着窗外、虫子、飞鸟）—— **v4 升级：用力过猛型神游（如扑蝴蝶扑倒姐）**
  3. 被其他东西吸引注意力（追光点 / 蝴蝶 / 自己的尾巴）
  4. **不小心打翻东西 → 试图掩盖**（用爪子把碎片推到角落、用身体挡住）—— 机智感真正来源
  5. 偷吃东西（米、糖、颜料、竹笋）
  6. 假装在做（升级版——整整齐齐摆材料、空中划拉假装工艺）
  7. 装无辜（被发现时瞪大眼睛 + 歪头）
  8. 偷偷把半成品叼走藏起来
- **新属性动作库**（v5）：
  - 撺掇妹（凑过去咬耳朵 / 用爪子推妹一下示意）/ 欺负妹（拍妹头 / 抢妹材料 / 推倒妹东西）/ 灵机一动搞砸（自以为聪明的主动行为反向破坏工艺）/ 护家人（挺身而出）

**呆萌妹（妹）· v5 新增**：
- 帮倒忙动作库（5 类）：
  1. 递错工具
  2. 打翻水 / 颜料
  3. 把粘好的半成品弄歪
  4. 踩到关键材料上
  5. 把工具藏起来忘了
- 气氛组动作库（4 类）：
  1. 打太阳伞
  2. 递冰阔乐（用爪子举杯）
  3. 用爪子拍节奏（应援）
  4. 给姐姐扇扇子
- 不参与工艺主流程，不被惩罚——只能瞪大眼睛 + 歪头 + 被姐宠溺挪开

### 每集开场（**v5 修订：决策 20 调整**）

**旧 v1.3 / v4**：开场不固定——师傅已沉浸演示 + 橘猫根据非遗主题自然延伸行为。

**v5 新规则**（硬约束）：
- **黄毛弟先出场取材**为 COLD OPEN 的主体
- **姐与妹在家 / 场边指挥等候**——打太阳伞 + 冰阔乐 + 认真摆材料 + 用爪子指挥方向
- COLD OPEN 不再是"姐已沉浸演示"，而是 **"弟在取材 + 姐妹在旁指挥 + 妹妹递冰阔乐"**
- 三猫空间分配默认（具体由主题决定）：
  - **黄毛弟**：场上场下跑，干体力活
  - **优雅姐**：C 位附近，叉腰指挥 / 用爪子指方向 / 偶尔亲自上手
  - **呆萌妹**：紧贴姐身侧或伞下，递冰阔乐 / 打太阳伞
- 题材相关动作自然延伸到当下主题（米塑 → 弟背米穗 / 陶艺 → 弟背陶土 / 糖画 → 弟扛甘蔗），姐的指挥和妹的氛围组动作也由主题延伸

### 招牌结尾（v5 修订为三人镜头）

**工艺快完成时** → 黄毛弟在画面外"自以为天衣无缝地偷懒" → **优雅姐终于抬头忍无可忍教训它** → 黄毛弟装无辜 → **呆萌妹在旁瞪大眼睛 + 歪头当气氛组** → **结束**（不放字幕卡，让情绪钩子独占 2-3 秒，三人镜头构图）

### 互动节奏双轨制（设计宪法 v1.2 + v5 扩展）

- **主线节拍 70%**：四种招牌互动模板（A 扑倒+挠 / B 推开脸+担心 / C 推不动+反差 / **D 姐替妹出头· v5 新增**）
- **辅线节拍 30%**：三猫齐心做事的沉浸过渡段（姐主讲，妹递工具/气氛组，弟穿插"灵机一动"）
- **不是每段开头都有捣乱**——捣乱出现在工艺流程的中段或收尾段
- 每集 1-2 次"黄毛弟自以为天衣无缝的偷懒 / 捣乱"，不堆砌
- **v5 新增**：每集至少 1 次 D（姐替妹出头）；E（弟护家人）由当期主题决定是否落地

### 行为推导工作流（决策 20 + v5 扩展）

```
先定主题与知识点
→ 推导三猫在该工艺下的各自天性动作
  · 优雅姐的主讲动作
  · 黄毛弟的取材动作 + 灵机一动搞砸动作 + 撺掇/欺负妹动作
  · 呆萌妹的帮倒忙动作或气氛组动作
→ 推导"姐替妹出头 D"的触发情境（弟欺负妹的合理化形式）
→ 推导"弟关键时刻护家人 E"的可选情境（由当期主题决定是否落地）
→ 推导招牌结尾（姐教训弟 + 弟装无辜 + 妹瞪大眼睛当气氛组）
```

招式（A/B/C/D/E）全部后置推导，不预设剧本。

## 三、整体节奏结构（三段式分层 + v5 强化）

```
[0-10%]      COLD OPEN —— v5：黄毛弟取材 + 优雅姐指挥 + 呆萌妹气氛组（COLD OPEN 不再是"姐已沉浸演示"）
[10-30%]     SOURCING —— v5：弟继续取材 / 姐与妹在家继续摆材料准备 / 必要时省略常规步骤
             - 段 0-A：原料采集（弟背/扛/捞/砍，姐或妹可参与关键采集）
             - 段 0-B：时间跳转（晾晒 / 催芽 / 浸泡等）
             - 段 0-C（可选）：常规准备（堆柴火等）—— v4/v5 强化：必要时省略以保证节奏紧凑
[30-X%]      PROCESS —— 工艺段 1-N（每段开头各 1 张字幕卡；姐主讲 + 妹递工具 + 弟穿插灵机一动）
[最后]       招牌结尾 —— 三人镜头：优雅姐忍无可忍教训 + 黄毛弟装无辜 + 呆萌妹瞪大眼睛（不放字幕卡，2-3 秒）
```

**v5 分层原则**：
- 字幕卡（认知任务）= SOURCING 段 / PROCESS 段开头
- 情绪钩子 = 招牌结尾（三人镜头）
- 招牌互动升级 = PROCESS 段中（A 扑倒 / B 推开脸 / C 推不动 / D 姐替妹出头）
- 弟护家人 E（可选）= 取材段 / 工艺意外段
- 几者不抢同一时间窗
