## 二、双猫完整设定 v1.3 终稿

### 外形 + 角色反差

| 维度 | 三花（师傅） | 橘猫（学徒） |
|---|---|---|
| 体型 | **小体型**（弱势外形） | **大体型**（强势外形） |
| 角色 | **权威方**（反差爆点） | 调皮方 |

### 性格内核

| 维度 | 三花 | 橘猫 |
|---|---|---|
| 性格 | 沉浸态、偷瞄、忍无可忍 | **机智偷懒、以为自己天衣无缝** |
| 与对方的互动方式 | 偷瞄 + 间歇性忍无可忍教训 | 偷懒 + 捣乱 + 掩盖 + 装无辜 |

### 招牌动作

**三花（师傅）**：
- 沉浸演示工艺，**面向镜头背对橘猫**（观众同视角偷窥学徒在身后搞事）
- 偷瞄橘猫一眼时**尾巴尖微微摆动**（猫"管不了你但是在意"的标志）
- **忍无可忍"教训"动作库**（v4 扩展）：扑咬 / 拍头 / 推 / 抽尾巴 / 骑 / **挠**（新增）
- **物理反差爆点**：三花推橘猫 → **发现自己推不动**（小体型推大体型）
- **情感内核**（v4 新增）：推开脸 / 挠 等动作背后是**担心学徒受伤**（"严厉的爱"）

**橘猫（学徒）**：
- **招牌偷懒方式"假装在做"**——整整齐齐摆材料、空中划拉假装工艺、**自以为天衣无缝**
- **偷懒行为库（8 类典型行为）**：
 1. 打瞌睡（在不该睡的地方睡着）
 2. 神游（眼睛盯着窗外、虫子、飞鸟，明显走神）—— **v4 升级：用力过猛型神游（如扑蝴蝶扑倒师傅）**
 3. 被其他东西吸引注意力（追光点 / 蝴蝶 / 自己的尾巴）
 4. **不小心打翻东西 → 试图掩盖**（用爪子把碎片推到角落、用身体挡住）—— 这是"机智感"的真正来源
 5. 偷吃东西（米、糖、颜料、竹笋）
 6. 假装在做（升级版——整整齐齐摆材料、空中划拉假装工艺）
 7. 装无辜（被发现时瞪大眼睛 + 歪头）
 8. 偷偷把半成品叼走藏起来

### 每集开场（**不固定**，根据主题调整）

- 师傅已开始演示（沉浸态）
- 橘猫根据非遗主题自然延伸行为：
 - 做米塑 → 橘猫可能在偷吃米团
 - 做蜡染 → 橘猫可能在染缸边打瞌睡
 - 做竹编 → 橘猫可能在追竹叶
 - 做陶艺 → 橘猫可能在玩陶土
- **不要千篇一律**——开场是主题延伸，不是固定模板

### 招牌结尾（每集固定 2-3 秒）

工艺快完成时 → 橘猫在画面外"自以为天衣无缝地偷懒" → 三花终于抬头**忍无可忍**教训它 → 橘猫装无辜 → **结束**（不放字幕卡，让情绪钩子独占 2-3 秒）

### 互动节奏双轨制（设计宪法 v1.2）

- **主线节拍（占每集 70%）**：L1 三花偷瞄 + 橘猫继续捣乱 → 反复升级 → 三花**终于**忍无可忍教训对方
- **辅线节拍（占每集 30%）**：师徒齐心做事的沉浸过渡段（用于工艺的关键步骤镜头，保护 ASMR 沉浸感）
- **不是每段开头都有捣乱**——捣乱出现在工艺流程的中段或收尾段，给观众"原来前面看着认真的橘猫其实在偷懒"的反转
- 每集只有 1–2 次"橘猫自以为天衣无缝的偷懒 / 捣乱"，不堆砌

### 行为推导工作流（决策 20）

**先定主题与知识点 → 再推导猫咪在该工艺场景下的天性动作 → 最后设计双猫互动**
- **不要预设破坏招式库**——招式是后置推导出来的，不是预设剧本
- 8 类偷懒行为库是"素材池"，不是"必演清单"，每集从中抽取适合主题的 1–2 个

## 三、整体节奏结构（三段式分层 + v4 强化）

```
[0-10%]      COLD OPEN —— 师傅已沉浸演示 + 橘猫根据主题自然延伸（开场不固定）
[10-30%]     SOURCING —— 前期材料准备（v4 新增，无集市 / 角色自给自足）
             - 段 0-A：原料采集（采麦穗 / 采泥料 / 采竹子等）
             - 段 0-B：时间跳转（晾晒 / 催芽 / 浸泡等）
             - 段 0-C（可选）：常规准备（堆柴火等）—— v4 强化：必要时省略以保证节奏紧凑
[30-X%]      PROCESS —— 工艺段 1-N（每段开头各 1 张字幕卡）
[最后]       招牌结尾 —— 三花忍无可忍教训 + 橘猫装无辜（不放字幕卡，情绪独占 2-3 秒）
```

**v4 关键分层原则**：
- 字幕卡（认知任务）= SOURCING 段 / PROCESS 段开头
- 情绪钩子 = 招牌结尾
- 招牌互动升级 = PROCESS 段中（扑倒 / 推开脸等含情感内核的动作）
- 两者不抢同一时间窗
