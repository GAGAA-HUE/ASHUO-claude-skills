## 节气锚定使用规则

1. **每期必填节气名 + 物候符号**（如"白露·露凝白·桂花初绽"）
2. **每期 ≥2 个画面元素**呼应节气物候（在背景出现，不是主要动作）
3. **主题对应可选**——可与节气强相关（桂花酒+白露），也可不相关（做陶杯+白露）
4. **节气链优先**：相邻两期建议物候连续（如白露→秋分，避免突然跳到立冬）
5. **空档期填空**：当节气之间有空档时，物候元素可重叠使用（如白露后期延续到秋分初期）

## 写实动作亮点设计原则（v6.3 · 替代表情包）

v6.3 起,弟闯祸本身仍是连续动态物理动作（闯祸类型 A-G 见 主工艺档·设计宪法.md principle_12）,不再强制 ≥3s 逗留的表情包节拍。

**v6.3 推荐写实动作亮点清单**：

| 类型 | 例子 | 适用节气 |
|---|---|---|
| **物理困境** | 弟头卡陶罐拔不出 / 弟掉进染缸爬出来全身湿 / 弟卡在窗框 / 弟被竹筐罩住 | 任意（陶罐/染缸/窗/竹） |
| **环境暴露** | 弟被柴火烟呛到喷嚏连天 / 弟满头面粉白成雪猫 / 弟被雨水淋透炸毛 | 寒露 / 霜降 / 立冬 |
| **姿势爆笑** | 弟四脚朝天躺泥地 / 弟趴在柿子树下啃一半 / 三猫叠罗汉摔成一团 | 秋分 / 寒露 |
| **表情写实** | 弟瞳孔地震看自己爪子 / 弟打喷嚏打到自己翻白眼 / 妹瞪大眼睛 | 任意 |

**v6.3 禁止清单**（写实风格底线）：
- 河豚脸（嘴脸被打变形）
- 绿毛猫（颜色变异）
- 头顶西瓜皮（无厘头道具）
- 任何不符合写实动物行为的拟人化变形

**v6.3 关键变化**：原"表情包铁律"的"≥3s 逗留"+"表情价值截图传播点"+"表情包画面"等字段全部下线。弟闯祸连续发生,镜头持续跟随,不停格。

## 选题示例（v6 第 15-20 期草案）

### 第 15 期·处暑·做陶杯（建议首期）
- **节气锚定**：处暑·凉风至·橘子转色
- **物候呼应元素**：院中橘树 / 蒲扇 / 凉风 / 蝉声渐弱（≥2）
- **主题**：做陶杯（与处暑非强相关，但物候到位）
- **宇宙资产**：新建 A008（陶土陶罐 × 3）+ 复用 A007（品茗杯 × 3·来自 ep-14）
- **动作亮点**：弟头卡陶罐拔不出 / 弟满头面粉白成雪猫

### 第 16 期·白露·桂花酒（建议第二期）
- **节气锚定**：白露·露凝白·桂花初绽
- **物候呼应元素**：叶尖露珠 / 桂花初绽 / 傍晚斜阳
- **主题**：酿桂花酒（强相关）
- **宇宙资产**：新建 A009（桂花酒坛 × 2）+ 复用 A008（陶土陶罐 × 3·来自 ep-15·装桂花酒用）
- **动作亮点**：弟被桂花瓣呛到喷嚏连天 / 弟偷喝酒醉躺泥地

### 第 17 期·秋分·收高粱
- **节气锚定**：秋分·昼夜均·高粱红
- **物候呼应元素**：高粱红 / 落叶飘 / 月圆
- **主题**：收高粱 + 酿酒
- **宇宙资产**：新建 A010（高粱酒坛 × 2）+ 复用 A009（桂花酒坛 · 同院酒窖布局）

### 第 18 期·寒露·糖葫芦
- **节气锚定**：寒露·露水寒·柿子红
- **物候呼应元素**：柿子红 / 露水寒 / 早霜迹象
- **主题**：做糖葫芦（强相关）
- **宇宙资产**：新建 A011（糖葫芦签子 × 10）
- **动作亮点**：弟偷吃糖葫芦粘牙张嘴 / 弟被柴火烟呛到喷嚏连天

### 第 19 期·霜降·菊花茶
- **节气锚定**：霜降·初霜·菊花黄
- **物候呼应元素**：初霜 / 菊花盛黄 / 早晚温差极大
- **主题**：采菊 + 泡菊花茶
- **宇宙资产**：新建 A012（菊花干 × 一罐）+ 复用 A007（品茗杯 × 3）

### 第 20 期·立冬·包饺子
- **节气锚定**：立冬·北风起·草木黄落
- **物候呼应元素**：北风起 / 室内炊烟 / 储冬

- **宇宙资产**：新建 A013（饺子帘 × 1）+ 复用 A008（陶土陶罐 · 装饺子用）

## v7.0 节庆锚轨道（新增·独立于节气锚）

> **v7.0 TYPE B 节日采购片**专用节庆锚定系统。**与 v6.3 节气锚完全独立**——节庆片不必填节气,但节庆必须填。

### 核心原则

1. **节庆锚(必填·TYPE B)**——具体节庆名(春节/端午/中秋/圣诞/元旦/七夕/生日等)+ 节庆类型 + 视觉符号 ≥2 项
2. **节气锚(可选·TYPE B)**——仅当用户明确要求同时挂节气时才填
3. **节庆锚优先级 > 节气锚**——若两者并存,节庆场景为主,节气物候作背景点缀
4. **TYPE B 不适用 v6.2 脆冲**——节庆场景本身已自带"非当季"特征(圣诞=冬季气氛在春节片中也允许)

### 节庆锚轨道使用规则

1. **每期 TYPE B 必填节庆名 + 节庆类型 + 视觉符号 ≥2 项**(写在脚本表字段 7「节庆锚定说明」)
2. **节庆视觉符号必须在画面中真实出现**(红灯笼/圣诞树/月饼桌/粽子摊),不能只写字幕卡
3. **节庆锚优先级 > 节气锚**——若两者并存,节气物候作背景点缀(如白露背景的桂花瓣可叠加在春节氛围中)
4. **风格脆冲**(替代 v6.2 脆冲)——若用户在非当季节庆(如夏日拍圣诞片),通过**室内装饰+暖色灯光+雪落簌簌音效**脆冲

### 节庆锚轨道 vs 节气锚轨道

| 维度 | 节气锚轨道(TYPE A) | 节庆锚轨道(TYPE B) |
|---|---|---|
| **适用类型** | TYPE A 主线工艺片 | TYPE B 节日采购片 |
| **必填项** | 节气名 + 物候符号 | 节庆名 + 节庆类型 + 视觉符号 ≥2 |
| **优先级** | 氛围锚,非主题锁 | 主题锁·优先级最高 |
| **脆冲机制** | v6.2 脆冲(玻璃温室/进口木箱/光线脆冲) | 不适用·节庆自带非当季特征 |
| **对应文档** | `主工艺档·设计宪法.md` (节气锚引擎) | `节庆采购档·设计宪法.md` (节庆锚引擎) |
