# 物质资产表（Asset Ledger）

> v6 宇宙构建的核心档案。每期脚本表的"字段 7 宇宙资产联动"必须引用本表中的 asset_id。
>
> **v6 规则**：
> - v6 起从 0 累计；前 14 期资产保留为"可选复用"（标记"可选"），不强制
> - 复用时复用方不需在脚本里写"上期回顾"——以"自然道具"出现在画面即可
> - 消耗性资产（食物 / 酒 / 糖等）标记"已消耗"，不可复用
> - 复用时必须写"出现段落"——让 LLM 知道在哪段画面里放

---

## 字段说明

| 字段 | 含义 |
|---|---|
| asset_id | 唯一编号（A00X，从 A001 起） |
| 名称 | 资产名（如"陶土陶罐 × 3"） |
| 创建期 | 在哪一期创建（如"ep-15"） |
| 类别 | 器具 / 染织 / 工具 / 雕塑 / 食物（消耗）/ 饮品（消耗）/ 家具 |
| 当前状态 | 在架 / 已消耗 |
| 复用期列表 | 哪些期复用了这个资产（可空） |

## 复用机制规则

1. **每期至少填一个 asset_id**（新建或复用），写入脚本表字段 7
2. **复用时必须写出现段落**（让 LLM 知道在哪段画面里放）
3. **新建时自动分配下一个 A 编号**（A008、A009...），写入本表
4. **v6 起从 0 累计**；前 14 期资产保留为"可选复用"，**不强制**
5. **消耗性资产**（食物/酒/糖）标记"已消耗"，不可复用
6. **剧透策略 A**：复用资产在画面里以"自然道具"出现，新观众不依赖上期记忆；老观众通过 asset_id 关联识别为彩蛋；不在脚本里写"上期回顾"

## 维护说明

- 每生成一期 v6 脚本，**立即更新本表**（新建填行 + 复用填"复用期列表"列）
- 消耗性资产（如某期做了米酒并喝完）状态改为"已消耗"
- 累计到 20+ 个资产时，考虑建立"资产分类索引"（如器具类 / 工具类 / 染织类）
