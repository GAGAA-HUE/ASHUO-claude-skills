# 节气链 + 选题池（Solar Terms Calendar）

> v6 节气物候锚定引擎的核心档案。每期脚本表的"字段 8 节气锚定说明"必须引用本表。
>
> **v6 关键原则**：
> - **节气是氛围锚，不是主题锁**——两天一更的发布节奏下节气之间有空档期（每节气约 15 天，可发 7-8 期）
> - 主题可与节气强相关（桂花酒 / 糖葫芦），也可不相关（陶杯 / 凉席）——只要物候呼应做到位
> - 每期 ≥2 个画面元素呼应节气物候（叶尖露珠 / 桂花初绽 / 傍晚斜阳 / 柿子红等）

## 节气锚定使用规则

1. **每期必填节气名 + 物候符号**（如"白露·露凝白·桂花初绽"）
2. **每期 ≥2 个画面元素**呼应节气物候（在背景出现，不是主要动作）
3. **主题对应可选**——可与节气强相关（桂花酒+白露），也可不相关（做陶杯+白露）
4. **节气链优先**：相邻两期建议物候连续（如白露→秋分，避免突然跳到立冬）
5. **空档期填空**：当节气之间有空档时，物候元素可重叠使用（如白露后期延续到秋分初期）

## 写实表情包设计原则（v6 铁律）

表情包必须从**物理动作的夸张瞬间**里找，**禁止**变形卡通 / 颜色变异 / 拟人化变形。

**v6 推荐写实表情包清单**：

| 类型 | 例子 | 适用节气 |
|---|---|---|
| **物理困境** | 弟头卡陶罐拔不出 / 弟掉进染缸爬出来全身湿 / 弟卡在窗框 / 弟被竹筐罩住 | 任意（陶罐/染缸/窗/竹） |
| **环境暴露** | 弟被柴火烟呛到喷嚏连天 / 弟满头面粉白成雪猫 / 弟被雨水淋透炸毛 | 寒露 / 霜降 / 立冬 |
| **姿势爆笑** | 弟四脚朝天躺泥地 / 弟趴在柿子树下啃一半 / 三猫叠罗汉摔成一团 | 秋分 / 寒露 |
| **表情写实** | 弟瞳孔地震看自己爪子 / 弟打喷嚏打到自己翻白眼 / 妹瞪大眼睛定格 | 任意 |

**v6 禁止清单**：
- 河豚脸（嘴脸被打变形）
- 绿毛猫（颜色变异）
- 头顶西瓜皮（无厘头道具）
- 任何不符合写实动物行为的拟人化变形

## 选题示例（v6 第 15-20 期草案）

### 第 15 期·处暑·做陶杯（建议首期）
- **节气锚定**：处暑·凉风至·橘子转色
- **物候呼应元素**：院中橘树 / 蒲扇 / 凉风 / 蝉声渐弱（≥2）
- **主题**：做陶杯（与处暑非强相关，但物候到位）
- **宇宙资产**：新建 A008（陶土陶罐 × 3）+ 复用 A007（品茗杯 × 3·来自 ep-14）
- **写实表情包**：弟头卡陶罐拔不出 / 弟满头面粉白成雪猫

### 第 16 期·白露·桂花酒（建议第二期）
- **节气锚定**：白露·露凝白·桂花初绽
- **物候呼应元素**：叶尖露珠 / 桂花初绽 / 傍晚斜阳
- **主题**：酿桂花酒（强相关）
- **宇宙资产**：新建 A009（桂花酒坛 × 2）+ 复用 A008（陶土陶罐 × 3·来自 ep-15·装桂花酒用）
- **写实表情包**：弟被桂花瓣呛到喷嚏连天 / 弟偷喝酒醉躺泥地

### 第 17 期·秋分·收高粱
- **节气锚定**：秋分·昼夜均·高粱红
- **物候呼应元素**：高粱红 / 落叶飘 / 月圆
- **主题**：收高粱 + 酿酒
- **宇宙资产**：新建 A010（高粱酒坛 × 2）+ 复用 A009（桂花酒坛 · 同院酒窖布局）

### 第 18 期·寒露·糖葫芦
- **节气锚定**：寒露·露水寒·柿子红
- **物候呼应元素**：柿子红 / 露水寒 / 早霜迹象
- **主题**：做糖葫芦（强相关）
- **宇宙资产**：新建 A011（糖葫芦签子 × 10）
- **写实表情包**：弟偷吃糖葫芦粘牙张嘴 / 弟被柴火烟呛到喷嚏连天

### 第 19 期·霜降·菊花茶
- **节气锚定**：霜降·初霜·菊花黄
- **物候呼应元素**：初霜 / 菊花盛黄 / 早晚温差极大
- **主题**：采菊 + 泡菊花茶
- **宇宙资产**：新建 A012（菊花干 × 一罐）+ 复用 A007（品茗杯 × 3）

### 第 20 期·立冬·包饺子
- **节气锚定**：立冬·北风起·草木黄落
- **物候呼应元素**：北风起 / 室内炊烟 / 储冬
- **主题**：包饺子（强相关）
- **宇宙资产**：新建 A013（饺子帘 × 1）+ 复用 A008（陶土陶罐 · 装饺子用）
- **写实表情包**：弟被面粉糊一脸 / 弟趴在饺子堆里啃
