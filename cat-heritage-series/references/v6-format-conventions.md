# v6.3 输出格式约定（v6-format-conventions）

> 本文件是 `cat-heritage-series` 技能的脚本表输出规范。v6.3 替代 v6。
>
> **v6.3 vs v6 关键差异**：
> - 删除「沙雕表情包定格」必填字段（用户反馈"画面里不要有任何的定格,所有内容全部都是动态的"）
> - 段 5「冲突定格（3-5s）」改为「冲突瞬间（动态推进 2-3s）」
> - 时长仍为 **75-85 秒**,5 节拍压缩版不变
> - 节气锚定 / 宇宙资产联动 仍为必填
> - 节气是氛围锚,主题可不与节气直接相关

---

## 整体结构（8 个固定字段）

```
# 第 N 期 — [主题]

## 1. 基本信息                    ← 表格形式
## 2. 工艺段                      ← SOURCING + PROCESS + 招牌结尾 + meta
## 3. 三猫互动节拍                ← v6 强化妹的隐性功能
## 4. 黄毛弟行为推导              ← v6 强化"捧哏"属性
## 5. 整体节奏结构                ← 含完整脚本叙事（v6.3 无表情包定格）
## 6. 字幕卡文案汇总              ← ≤25 字 / 张
## 7. 宇宙资产联动（v6 必填）    ← 新建 / 复用 asset_id
## 8. 节气锚定说明（v6 必填）    ← 氛围锚 + 物候呼应元素
```

## 字段 1：基本信息

**格式**：表格，每行必填

| 项 | 内容 | v6 判定 |
|---|---|---|
| 非遗名称 | （含所属类别、级别，如"陶器拉坯技艺（景德镇·国家级）"） | 必填 |
| 节气锚定（v6 必填·v6.2 可脆冲） | （节气名 + 物候符号，例："白露·露凝白·桂花初绽"；脆冲期标注 ★） | **任一为空 = 输出失败** |
| 物候呼应元素 | （≥2 项，从"节气物候 OR 场景道具脆冲"二选一；脆冲期填脆冲道具） | **任一为空 = 输出失败** |
| 脆冲机制（v6.2 新增·可选） | （脆冲期填：A 场景脆冲/B 光线脆冲/C 环境音脆冲 + 道具具体） | 非脆冲期留空 |
| **动作亮点（v6.3 替代表情包预览）** | （一句话预览本期最爆笑的写实物理动作亮点，例："弟偷吃莲蓉糊一脸"） | 推荐填写（不强制） |
| 一句话知识点 | （≤25 字，硬知识点） | 必填 |
| 工艺戏份占比 | （推荐 35-45%；猫家庭戏份 55-65%） | 必填 |
| 猫咪戏份占比 | （推荐 55-65%；姐 ≥50% / 弟 ≤30% / 妹 10-20%） | 必填 |
| 时长 | （75-85 秒） | 必填 |
| 动物配角预算 | （无 / 驴（≤5s 远景）/ 鹅（≤5s 田边）/ 鸟（≤5s 晒架）） | **任一为空 = 输出失败** |

**v6 三猫戏份分布**（沿用 v5）：
- 优雅姐（工艺主讲 + 指挥 + 替妹出头）：≥50%
- 黄毛弟（取材 + 灵机一动搞砸 + 撺掇 / 欺负妹 + **捧哏**）：≤30%
- 呆萌妹（气氛组 + 帮倒忙 + **隐性任务锚点 / 反应代理**）：10-20%

**v6.3 变更说明**：原"沙雕表情包画面（写实·一句话预览）"字段已下线。改为推荐填写"动作亮点"——一句话预览本期最爆笑的连续动态物理动作（如"弟偷吃莲蓉糊一脸"），不再作为必填字段、不再有 ≥3s 逗留要求。

## 字段 2：工艺段

**结构**：先列 SOURCING 段（如有），再列 PROCESS 段（5 节拍压缩），最后招牌结尾 + meta。

**每段必须包含 5 个元素**：

1. **段名**（如"段 0-A·弟上山采陶土"）
2. **节气物候提示**（v6 新增·标注该段画面出现的物候元素）
3. **字幕卡文案**（≤25 字 / 后期叠加）
4. **姐演示动作**（沉浸态，**v6 必须有慢镜头 + ASMR 加持**）
5. **弟捧哏动作**（v6 强化·每段必有 1 次捧哏动作补节奏）
6. **妹的隐性功能呈现**（v6 新增：姐公布任务时妹的反应 / 主爆点时妹的反应代理）
7. **时长**（秒）
8. **画面要点**（含三猫位置 + 招牌互动节点）
9. **制作知识文本**（详细但有条理）

**v6 段落格式宪法**（详见 `drama-engine-v6.md` 的 `<paragraph_constitution_v6>`）：
- **叙事段**写氛围 + 感觉（散文化，不列要点）
- **节拍列表**写具体动作 + 时间 + 位置 + ASMR（3-4 个节拍，蒙太奇段 4-5 个）
- **弧线总结**写情绪走向（任务推进 / 弟搞怪被训 / 协作回归 / 收尾 四选一）

**5 节拍时间锚点**：

| 节拍 | 时间 | 时长 | 内容 |
|---|---|---|---|
| Hook | 0-3s | ≤3s | 黄金三秒强力钩子 |
| 推进 | 3-15s | ≤12s | 主线 + SOURCING |
| 主爆点 | 25-40s | 5-8s | ≥5s 逗留 |
| 唯美段 | 40-55s | ≤15s | 慢镜头 + ASMR |
| 反转结尾 + meta | 55-75s | ≤15s | 余波彩蛋 ≤5s |

## 字段 3：三猫互动节拍（v6 升级）

**结构**：按时间轴列出节拍节点，每节点包含"动作描述 + 招牌互动类型 + 行为库编号"。

**v6 新增的妹隐性功能标注**：
- **任务锚点节拍**：姐用眼神/手势公布任务 → 妹跟着看/鼓掌/歪头（在节拍描述里加一句"妹在背景跟着看 / 鼓掌"）
- **反应代理节拍**：主爆点发生时妹的反应**与观众同步**（"妹惊呆捂嘴" / "妹瞳孔地震"）

**v6 招牌互动模板**：

### 模板 A：扑倒 + 挠（神游型偷懒）
```
黄毛弟扑蝴蝶用力过猛扑倒姐 → 姐翻身挠弟 → 弟装无辜 → 妹瞪大眼睛
```

### 模板 B：推开脸 + 担心（危险动作）
```
弟想偷舔锅边 → 姐用木勺柄推开弟的脸 → 弟缩回舌头装无辜 → 姐尾巴尖轻摆
```

### 模板 C：推不动 + 反差（物理爆点）
```
姐发现布被染成全蓝 → 忍无可忍推弟 → 发现自己推不动 → 弟一脸"怎么挠痒痒呢"
```

### 模板 D：姐替妹出头（v6 强制·每期至少 1 次）
```
弟拍妹的头抢材料 → 妹瞪大眼睛 + 缩成一团 → 姐立刻抽弟尾巴教训 → 弟装无辜 → 姐用爪子把妹挪到安全位置
```

### 模板 E：弟护家人（v6 可选·由当期主题决定）
```
姐或妹被外物欺负 → 弟挺身而出（勇敢挡 / 龇牙 / 拍走威胁）→ 姐轻轻拍弟一下
```

**双轨制原则（v6 沿用 v5）**：
- 主线节拍 70%（反转 + 招牌互动，每期强制 ≥1 次 A/B/C/D 任一 + ≥1 次 D）
- 辅线节拍 30%（沉浸过渡段，三猫齐心做事）

## 字段 4：黄毛弟行为推导（v6 强化"捧哏"属性）

**v6 仍保留"橘猫行为推导"标题**（向后兼容），但行为池已扩展。

**每期弟必须包含的两类行为**：
1. **闯祸 / 捣乱行为**（从 8 类行为库抽取）
2. **v6 强化·捧哏行为**（每段 1 次，节奏补位）：
   - 接住姐的梗（姐摆好材料 → 弟立刻搬错地方）
   - 填补节奏空白（姐沉浸演示 → 弟在旁小声嘀咕）
   - 反向配合（姐要安静 → 弟故意制造声响）

**8 类偷懒行为库**（沿用 v5）：
1. 打瞌睡 2. 神游 3. 被其他东西吸引 4. 不小心打翻→试图掩盖 5. 偷吃 6. 假装在做 7. 装无辜 8. 偷偷把半成品叼走

**呆萌妹行为推导**：见字段 4 扩展或合并到字段 4 末尾。

## 字段 5：整体节奏结构（含完整脚本叙事）

**结构**：先列 5 节拍时间轴，再按时间轴逐秒描述画面内容。**v6.3 新增要求**：每段剧本描述结尾必须包含「衔接说明」（详见 `drama-engine-v6.md` `principle_15_v6_3_new`）。

**段间衔接说明格式（v6.3 强制）**：

```
[段 X → 段 X+1]
- 衔接逻辑: [搬家逻辑(场景/时间切换) / 走路逻辑(同场景连续动作)]
- 具体手法: [声音带路 / 缓冲垫空镜 / 缓慢叠化 / 动作匹配 / 视线匹配 / 同方向运动]
- 路标: [具体的视觉/听觉线索,如「桂花瓣飘过空荡牛栏 → 桂花瓣飘过院墙」]
```

**5 节拍时间轴格式（v6.3 修订·无定格）**：

```
[0-3s]      Hook —— 黄金三秒强力钩子
[3-15s]     推进 —— 主线 + SOURCING
[15-25s]    起因（草蛇灰线·意外制造）
[25-40s]    主爆点（≥5s 逗留·动态推进）
[30-45s]    变装 / 战损（弟因意外产生视觉化变装）
[40-55s]    唯美工艺展示（慢镜头 + ASMR）
[55-75s]    段 5 反转结尾 —— **v6.3 强制三段式**：
              ├ [55-60s] 冲突瞬间（强度 ★★★★★·动态推进 2-3s）
              ├ [60-70s] 克制惩罚（强度 ★★★★ ↓·不是暴打·精准对位）
              └ [70-75s] 平静收束（强度 ★★ ↓·三猫回归日常）
[75-80s]    meta 彩蛋 + 宇宙资产露出（5s 长镜头）
[80-83s]    情绪留白（字幕淡出 / 纯画面 / 无新动作·2-3s）
```

**v6.3 段 5 三段式收尾 + 情绪留白（v6.3 动态版·替代 v6 表情包定格）**：

段 5 是全视频的情绪落点。v3 "冲突堆到最后"会让结尾"还没完"——**v6.3 强制段 5 遵循三段式（冲突瞬间+克制惩罚+平静收束）**，并在 meta 彩蛋后再留 **2-3s 情绪留白**，让情绪真正落地。**v6.3 关键变化**：原"冲突定格（3-5s 表情包定格）"改为"冲突瞬间（动态推进 2-3s）"——镜头持续跟随动作,不停帧。

| 阶段 | 时长 | 强度 | 内容 | 判定 |
|---|---|---|---|---|
| **冲突瞬间** | 2-3s（动态推进） | ★★★★★（最高） | 段 5 最高冲突事件——镜头持续跟随动作,不停格 | 必须 2-3s 动态推进 |
| **克制惩罚** | 5-7s | ★★★★ ↓（必须低于冲突） | 姐的惩罚**不是暴打**·精准对位弟的过错·克制冷静 | 段 4 vs 段 5 必须不同 |
| **平静收束** | 5-10s | ★★ ↓（必须低于惩罚） | 三猫回归日常·静坐看成品·微风 | 必须有 5s 长镜头三猫静坐 |
| **meta 彩蛋** | 5s | — | 宇宙资产露出 + 字幕卡 + 微风 + 蝉鸣渐弱 | 视频明确结束信号 |
| **情绪留白** | 2-3s | ★ ↓ | 字幕卡淡出后纯画面·三猫静坐或空镜·无新动作 | 避免在字幕最满时戛然而止 |

**惩罚设计 4 条原则**（v6 招牌动作库新增）：
1. **不是暴打**：段 5 惩罚必须克制（按住·敲头·推开·瞪眼），不能再用"扑倒+挠"这种激烈动作
2. **精准对位**：惩罚必须直接对应弟"具体做错了什么"——弟差点毁杯 → 姐按住弟尾巴（动态 2 秒）；弟偷吃糖 → 姐冷眼盯弟；弟砸杯 → 姐敲弟头象征性
3. **段 4 vs 段 5 惩罚必须不同**：段 4 动态猛烈（夹后颈提起）·段 5 静态克制（按住·敲头）——**避免惩罚重复**
4. **惩罚强度 < 冲突强度**：惩罚必须比冲突 4 弱（★★↓），不然情绪下不来

**v6.3 段 5 三段式收尾·禁止清单**：
- ❌ 段 5 最后一个画面还在激烈冲突（弟瘫地/被暴打/被夹）→ 观众感觉"还没完"
- ❌ 段 5 惩罚用暴打（扑倒+挠）/夹后颈（与段 4 重复）
- ❌ 段 5 惩罚强度 > 冲突强度（情绪下不来）
- ❌ 段 5 跳过平静收束直接进 meta 彩蛋（视频感觉戛然而止）
- ❌ meta 彩蛋前没有 5-10s 的三猫静坐（"猫家庭的情感落点"缺失）
- ❌ **v6.3 新增**：段 5 任何画面使用"定格/停帧"手法（镜头必须持续动态跟随）

**v6 招牌动作库新增两个收尾动作**（v6.3 去除"定格"措辞）：
- **按住**（姐按住弟尾巴·动态 2 秒）——克制惩罚符号
- **敲头**（用木勺柄敲弟头象征性）——收束信号,不是打,是"我们回家吃饭"的隐喻

**完整脚本叙事格式**：

```
**[时间区间] · [阶段名] · [环境氛围]**

字幕卡（如有）：
> **[≤25 字字幕卡文案]**

画面：[逐镜头描述画面内容,含三猫互动节点——v6.3 起所有画面均为连续动态]
[招牌互动（如有）]：[完整描述招牌互动,包含动作、动机、镜头特写]
```

**v6.3 变更说明**：原"[表情包定格（如有）]：[**v6 必填**·描述沙雕表情包画面 + ≥3s 逗留 + 表情价值]"模板已删除。弟闯祸本身仍是连续动态事件（闯祸类型 A-G 见 drama-engine-v6.md principle_12），不再有"表情包节拍"必填字段、不再有 ≥3s 逗留要求、不再有"表情价值"截图传播点字段。

**v6.3 段 5 三段式收尾·字段 5 输出模板（必填）**：

```
### [55-60s] · 冲突瞬间（强度 ★★★★★ · 动态推进）

画面：[描述段 5 最高冲突事件——弟的物理动作 + 姐的反应 + 妹的旁观,**镜头持续动态跟随**,不停格]

### [60-70s] · 克制惩罚（强度 ★★★★ ↓）

画面：[姐的惩罚动作——**不是暴打**·精准对位弟"具体做错了什么"——动态推进]

**v6 招牌动作库（v6.3 措辞更新）：
- 按住：[姐按住弟尾巴·动态 2 秒]
- 敲头：[姐用木勺柄敲弟头象征性]
- 推开：[姐用爪推开弟]
- 瞪眼：[姐冷眼盯弟]

**判定**：
- [ ] 段 4 vs 段 5 惩罚是否不同（动态猛烈 vs 静态克制）
- [ ] 惩罚强度 < 冲突强度（★★★★↓）

### [70-75s] · 平静收束（强度 ★★ ↓）

画面：[三猫回归日常——三猫静坐看成品 / 蹭脸 / 安静看着对方——连续动态推进]
- 前景·中线 = [成品特写（如陶杯/陶罐/染布）+ 斜阳光斑]
- 中景 = [姐/弟/妹静坐成品后方——5s 长镜头]

**判定**：
- [ ] 平静收束强度 < 惩罚强度（★★↓）
- [ ] 视频真正结局是三猫回归平静（不是激烈冲突场景）
- [ ] meta 彩蛋前有 ≥5s 三猫静坐（情感落点）

### [75-80s] · meta 彩蛋 + 宇宙资产露出

画面：[宇宙资产同框特写 + 字幕卡 + 微风 + 蝉鸣渐弱——连续动态]
字幕卡：[例："猫家·处暑陶杯"]
宇宙资产：[asset_id + 三猫印记清晰可见]

### [80-83s] · 情绪留白（强度 ★ ↓）

画面：[字幕卡淡出后纯画面·三猫仍静坐或空镜·无新动作·情绪自然落地]
- 前景 = [成品/宇宙资产虚化处理或完全淡出]
- 中景 = [三猫静坐或空镜·无动作]
- 背景 = [微风/落叶/斜阳渐弱]

**判定**：
- [ ] meta 彩蛋后是否保留 2-3s 纯画面
- [ ] 留白段无新动作 / 无新字幕 / 无冲突
- [ ] 情绪真正落地，观众感到"结束了"

```

## 字段 7：宇宙资产联动（v6 必填）

**格式**：表格

| 类型 | asset_id | 名称 | 类别 | 出现段落 |
|---|---|---|---|---|
| 本期新建 | A00X | （如"陶土陶罐 × 3"） | 器具 | 段 3 / 段 5 |
| 本期复用 | A00Y | （如"品茗杯 × 3"） | 器具 | meta 彩蛋 |

**判定**：两栏至少一栏非空 = 输出合规；两栏皆空 = 输出失败

**复用机制规则**：
1. 每期必须填至少一个 asset_id（新建或复用）
2. 复用时必须写**出现段落**（让 LLM 知道在哪段画面里放）
3. 新建时自动分配下一个 A 编号，写入 `asset-ledger.md`
