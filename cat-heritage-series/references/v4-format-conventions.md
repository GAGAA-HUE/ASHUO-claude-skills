# v4 输出格式约定（v5 三猫修订）

> 本文件是 `cat-heritage-series` 技能的输出格式规范，源自第 1 期（龙须糖）实战迭代。后续所有生成的脚本表必须严格遵循本格式。
>
> **v5 修订要点**：
> - 字段 3 标题由"双猫互动节拍"改为"三猫互动节拍"
> - 主线节拍模板新增 **D 姐替妹出头**
> - 招牌结尾改为**三人镜头样板**（姐教训弟 + 弟装无辜 + 妹瞪大眼睛当气氛组）
> - meta 彩蛋扩展至三猫款
> - 招牌互动 5 类节拍密度（v5 强制）—— 每集至少一次 D，可选 E

---

## 整体结构（6 个固定字段）

```
# 第 N 期 — [主题]

## 1. 基本信息                ← 表格形式，固定 5 行
## 2. 工艺段                  ← 含制作知识文本（每段独立成块）
## 3. 三猫互动节拍            ← v5 由"双猫"改；招牌互动升级要点
## 4. 橘猫（黄毛弟）行为推导  ← 决策 20 后置推导
## 5. 整体节奏结构            ← 含完整脚本叙事（按时间轴逐秒描述）
## 6. 字幕卡文案汇总          ← 表格形式，便于后期剪辑复用
```

## 字段 1：基本信息

**格式**：表格，固定 5 行

| 项 | 内容 |
|---|---|
| 非遗名称 | （含所属类别、级别，如"龙须糖制作技艺（北京·国家级）"） |
| 一句话知识点 | （≤25 字，硬知识点） |
| 工艺戏份占比 | （推荐 30-40%；猫家庭戏份 60-70%） |
| 猫咪戏份占比 | （推荐 60-70%；内含三猫分布：姐 ≥50% / 弟 ≤30% / 妹 10-20%） |
| 时长 | （推荐 50-95 秒） |

**v5 三猫戏份分布建议**：
- 优雅姐（含工艺主讲 + 指挥 + 替妹出头）：≥50%
- 黄毛弟（取材 + 灵机一动搞砸 + 撺掇 / 欺负妹）：≤30%
- 呆萌妹（气氛组 + 帮倒忙）：10-20%

## 字段 2：工艺段（含制作知识文本）

**结构**：先列 SOURCING 前期准备段（如有），再列 PROCESS 工艺段。

**每段必须包含的 5 个元素**：
1. **段名**（如"段 0-A·弟上山采麦穗"）
2. **字幕卡文案**（≤25 字 / 后期叠加）
3. **师傅演示动作**（沉浸态，面向镜头背对弟妹）
4. **时长**（秒）
5. **画面要点**（含招牌互动节点 + SOURCING 段需明确弟是体力担当）
6. **制作知识文本**（详细但有条理，包含：原料 / 原理 / 操作细节 / 镜头建议）

**SOURCING 段设计原则（v5 强化）**：
- 避开集市 / 人类
- 所有原料获取由角色直接完成
- **v5 强制**：体力活由黄毛弟承担（背 / 扛 / 捞 / 砍 / 搬）
- 优雅姐可参与关键采集或指挥
- 呆萌妹不参与 SOURCING 体力活，仅在旁打太阳伞 / 递冰阔乐 / 认真摆材料
- 必要时省略常规步骤（如备火柴）以保证节奏紧凑

**SOURCING 段三猫分工样板**（以采麦穗为例）：

```
段 0-A·黄毛弟上山采麦穗
- 字幕卡：「秋分过后麦穗饱满，黄毛弟背筐上山」
- 弟动作：黄毛弟大体型背着竹筐上坡，跃过石头，用爪子割下麦穗
- 姐动作：优雅姐在坡下用爪子指挥方向（"这块地的穗最满"）
- 妹动作：呆萌妹在伞下举着冰阔乐看着，偶尔用爪子给姐扇扇子
- 时长：6-8s
```

## 字段 3：三猫互动节拍（v5 修订）

**结构**：按时间轴列出节拍节点，每节点包含"动作描述 + 招牌互动类型 + 行为库编号"。

**招牌互动升级模板（v5 共四种主线 + 一种可选 + 一种辅线）**：

### 模板 A：扑倒 + 挠（采原料 / 神游型偷懒）

```
黄毛弟扑蝴蝶用力过猛直接扑倒了优雅姐
→ 优雅姐生气的翻身挠黄毛弟
→ 黄毛弟装无辜瞪眼歪头
→ 呆萌妹在旁瞪大眼睛 + 缩成一团
```

### 模板 B：推开脸 + 担心（危险动作 / 偷吃东西）

```
黄毛弟想偷舔锅边的糖渣
→ 优雅姐用爪子推开黄毛弟的脸
→ 优雅姐的爪部动作轻但坚定——担心黄毛弟烫到（蒸汽+高温糖浆）
→ 黄毛弟缩回舌头装无辜
→ 优雅姐尾巴尖轻轻摆一下（猫"管不了你但是在意"的标志）
→ 呆萌妹在旁学着姐的样子用小爪推开（结果扑空）
```

### 模板 C：推不动 + 反差（招牌物理爆点）

```
优雅姐发现布被染成全蓝 → 忍无可忍推黄毛弟
→ 发现自己推不动（小体型推大体型）
→ 黄毛弟一脸"怎么挠痒痒呢"
→ 呆萌妹被推到一边，"嘭"地坐在地上瞪大眼睛
```

### 模板 D：姐替妹出头（v5 新增·强制每期至少 1 次）

```
黄毛弟拍呆萌妹的头抢走她摆好的材料
→ 呆萌妹瞪大眼睛 + 歪头 + 缩成一团（被欺负标志反应）
→ 优雅姐立刻抽黄毛弟尾巴教训（姐妹保护本能）
→ 黄毛弟装无辜瞪眼歪头
→ 优雅姐用爪子把呆萌妹挪到安全位置（温柔宠溺）
```

### 模板 E：弟护家人（v5 新增·可选·由当期主题决定是否落地）

```
姐或妹被外物/他者欺负（如遇蛇 / 野狗 / 滚落的材料 / 飞来的树枝）
→ 黄毛弟立刻挺身而出（勇敢挡在身前 / 龇牙 / 拍走威胁）
→ 姐与妹同时受到保护
→ 后续：姐轻轻拍黄毛弟一下（少见的"弟弟你长大了"式肯定）
```

**双轨制原则**：
- 主线节拍 70%（反转 + 招牌互动，每期强制 ≥1 次 A/B/C/D 任一 + ≥1 次 D）
- 辅线节拍 30%（沉浸过渡段，三猫齐心做事）
- 可选 E（弟护家人）由当期主题决定是否落地

**5 类节拍密度清单（v5 强制）**：

| 项 | 是否每期必有 | 备注 |
|---|---|---|
| A 扑倒+挠 | 至少 0-1 次 | 可省略；本期如出现神游型偷懒则必有 |
| B 推开脸+担心 | 至少 0-1 次 | 可省略；本期如出现危险动作则必有 |
| C 推不动+反差 | 至少 1 次 | 招牌物理爆点，每期强制 |
| D 姐替妹出头 | **至少 1 次** | v5 强制项 |
| E 弟护家人 | 0-1 次 | 非强制，由当期主题决定 |
| 招牌结尾（三人镜头） | 必有 | 2-3 秒，无字幕卡 |

## 字段 4：黄毛弟（橘猫）行为推导

> v5 仍保留"橘猫行为推导"作为字段标题（不强行改名以保持向后兼容），但行为池已扩展为黄毛弟 + 呆萌妹双份。

**结构**：列出本期出现的 1-2 个最自然的"偷懒 / 捣乱 / 撺掇 / 护家人"行为。

**每个行为必须包含**：
1. 行为类型（从 8 类行为库抽取 + 行为库编号）
2. 行为具体描述
3. 为什么"自然"（基于该工艺场景的合理性）

**8 类偷懒行为库**（v5 沿用 v1.3）：
1. 打瞌睡（在不该睡的地方睡着）
2. 神游（眼睛盯着窗外、虫子、飞鸟）—— **v4 升级：用力过猛型神游（如扑蝴蝶扑倒姐）**
3. 被其他东西吸引注意力（追光点 / 蝴蝶 / 自己的尾巴）
4. **不小心打翻东西 → 试图掩盖**（机智感核心来源）
5. 偷吃东西（米、糖、颜料、竹笋）
6. 假装在做（整整齐齐摆材料、空中划拉假装工艺）
7. 装无辜（被发现时瞪大眼睛 + 歪头）
8. 偷偷把半成品叼走藏起来

**v5 新增属性动作库**（黄毛弟专属）：
- 撺掇妹（凑过去咬耳朵 / 用爪子推妹一下示意"一起干"）
- 欺负妹（拍妹头 / 抢妹材料 / 推倒妹东西 → 招致姐打）
- 灵机一动搞砸（自以为聪明的主动行为反向破坏工艺）
- 护家人（姐或妹被外物 / 他者欺负时挺身而出）

**呆萌妹（v5 新增）行为推导**：见字段 4 扩展或合并到字段 4 末尾。

## 字段 5：整体节奏结构（含完整脚本叙事）

**结构**：先列时间轴结构，再按时间轴逐秒描述画面内容。

**时间轴结构格式（v5 修订）**：

```
[0-8s]     COLD OPEN —— 弟取材 + 姐指挥 + 妹气氛组
[8-18s]    SOURCING·[段名]（[段编号]）+ 字幕卡
[18-24s]   SOURCING·[段名]（[段编号]）+ 时间跳转
[24-36s]   PROCESS·[段名]（[段编号]）+ 字幕卡
...
[70-78s]   招牌结尾（三人镜头，不放字幕卡）
```

**完整脚本叙事格式**：
每段时间块用以下模板：
```
**[时间区间] · [阶段名] · [环境氛围]**

字幕卡（如有，弹出格式）：
> **[≤25 字字幕卡文案]**

画面：[逐镜头描述画面内容，含镜头调度 / 字幕卡时机 / 三猫互动节点]
[招牌互动（如有）]：[完整描述招牌互动，包含动作、动机、镜头特写]
[镜头特写（如有）]：[特写镜头描述]
```

**v5 三人镜头空间分配（招牌互动镜头）**：
- 黄毛弟：左 / 右 / 中央活动
- 优雅姐：C 位（动作中心）
- 呆萌妹：紧贴姐身侧或伞下
