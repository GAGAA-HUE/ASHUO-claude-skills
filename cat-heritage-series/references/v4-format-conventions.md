# v4 输出格式约定

> 本文件是 `cat-heritage-series` 技能的输出格式规范，源自第 1 期（龙须糖）实战迭代。后续所有生成的脚本表必须严格遵循本格式。

---

## 整体结构（6 个固定字段）

```
# 第 N 期 — [主题]

## 1. 基本信息                ← 表格形式，固定 5 行
## 2. 工艺段                  ← 含制作知识文本（每段独立成块）
## 3. 双猫互动节拍            ← 招牌互动升级要点
## 4. 橘猫行为推导            ← 决策 20 后置推导
## 5. 整体节奏结构            ← 含完整脚本叙事（按时间轴逐秒描述）
## 6. 字幕卡文案汇总          ← 表格形式，便于后期剪辑复用
```

---

## 字段 1：基本信息

**格式**：表格，固定 5 行

| 项 | 内容 |
|---|---|
| 非遗名称 | （含所属类别、级别，如"龙须糖制作技艺（北京·国家级）"） |
| 一句话知识点 | （≤25 字，硬知识点） |
| 工艺戏份占比 | （推荐 30-40%） |
| 猫咪戏份占比 | （推荐 60-70%） |
| 时长 | （推荐 50-95 秒） |

---

## 字段 2：工艺段（含制作知识文本）

**结构**：先列 SOURCING 前期准备段（如有），再列 PROCESS 工艺段。

**每段必须包含的 5 个元素**：
1. **段名**（如"段 0-A·采麦穗"）
2. **字幕卡文案**（≤25 字 / 后期叠加）
3. **师傅演示动作**（沉浸态，面向镜头背对橘猫）
4. **时长**（秒）
5. **画面要点**（含招牌互动节点）
6. **制作知识文本**（详细但有条理，包含：原料 / 原理 / 操作细节 / 镜头建议）

**SOURCING 段设计原则**：
- 避开集市 / 人类
- 所有原料获取由角色直接完成
- 必要时省略常规步骤（如备火柴）以保证节奏紧凑

---

## 字段 3：双猫互动节拍

**结构**：按时间轴列出节拍节点，每节点包含"动作描述 + 招牌互动类型 + 行为库编号"。

**招牌互动升级模板（v4 新增）**：

### 模板 A：扑倒 + 挠（采原料 / 神游型偷懒）
```
橘猫扑蝴蝶用力过猛直接扑倒了三花
→ 三花生气的翻身挠橘猫
→ 橘猫装无辜瞪眼歪头
```

### 模板 B：推开脸 + 担心（危险动作 / 偷吃东西）
```
橘猫想偷舔锅边的糖渣
→ 三花用爪子推开橘猫的脸
→ 三花的爪部动作轻但坚定——担心橘猫烫到（蒸汽+高温糖浆）
→ 橘猫缩回舌头装无辜
→ 三花尾巴尖轻轻摆一下（猫"管不了你但是在意"的标志）
```

### 模板 C：推不动 + 反差（招牌物理爆点）
```
三花发现布被染成全蓝 → 忍无可忍推橘猫
→ 发现自己推不动（小体型推大体型）
```

**双轨制原则**：
- 主线节拍 70%（反转 + 招牌互动）
- 辅线节拍 30%（沉浸过渡段）

---

## 字段 4：橘猫行为推导

**结构**：列出本期出现的 1-2 个最自然的"偷懒 / 捣乱"行为。

**每个行为必须包含**：
1. 行为类型（从 8 类行为库抽取 + 行为库编号）
2. 行为具体描述
3. 为什么"自然"（基于该工艺场景的合理性）

**8 类偷懒行为库**（v4 扩展）：
1. 打瞌睡（在不该睡的地方睡着）
2. 神游（眼睛盯着窗外、虫子、飞鸟）—— **v4 升级：用力过猛型神游（如扑蝴蝶扑倒师傅）**
3. 被其他东西吸引注意力（追光点 / 蝴蝶 / 自己的尾巴）
4. **不小心打翻东西 → 试图掩盖**（机智感核心来源）
5. 偷吃东西（米、糖、颜料、竹笋）
6. 假装在做（整整齐齐摆材料、空中划拉假装工艺）
7. 装无辜（被发现时瞪大眼睛 + 歪头）
8. 偷偷把半成品叼走藏起来

---

## 字段 5：整体节奏结构（含完整脚本叙事）

**结构**：先列时间轴结构，再按时间轴逐秒描述画面内容。

**时间轴结构格式**：
```
[0-8s]     COLD OPEN —— [简述]
[8-18s]    SOURCING·[段名]（[段编号]）+ 字幕卡
[18-24s]   SOURCING·[段名]（[段编号]）+ 时间跳转
[24-36s]   PROCESS·[段名]（[段编号]）+ 字幕卡
...
[70-78s]   招牌结尾（不放字幕卡）
```

**完整脚本叙事格式**：
每段时间块用以下模板：
```
**[时间区间] · [阶段名] · [环境氛围]**

字幕卡（如有，弹出格式）：
> **[≤25 字字幕卡文案]**

画面：[逐镜头描述画面内容，含镜头调度 / 字幕卡时机 / 猫咪互动节点]
[招牌互动（如有）]：[完整描述招牌互动，包含动作、动机、镜头特写]
[镜头特写（如有）]：[特写镜头描述]
```
