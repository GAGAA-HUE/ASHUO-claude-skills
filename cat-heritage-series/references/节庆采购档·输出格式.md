> **适用范围**:仅 TYPE B 节日采购片。TYPE A 主线工艺片继续使用 `references/主工艺档·输出格式.md`。
>
> **先判 TYPE 再读对应格式**:接到"采购/萌宠饰品店/超市/节日/新衣"等 TYPE B 关键词 → 读本文件;接到"做一期 X/非遗/工艺"等 TYPE A 关键词 → 读 主工艺档·输出格式.md。

## 整体结构（8 个固定字段）

```
# 第 N 期 — [节日名·主题]

## 1. 基本信息（9 列·含节庆锚定 + 人类角色预算）
## 2. 角色分配表（三猫 + 2 位人类店长 + 猫咪塑料模特）
## 3. 采购清单（≥3 件 / 采购动机 / 采购场所）
## 4. 整体节奏结构（按 30/60/15 分段·含段 5 收尾）
## 5. 字幕卡文案汇总（≤25 字 / 张）
## 6. 宇宙资产联动（必填·A020-A025 预分配）
## 7. 节庆锚定说明（节庆名 + 视觉符号 + 氛围优先级）
## 8. 段 5 收尾规范（享成果段三段式·采购专属冲突）
```

## 字段 1：基本信息表（9 列）

| 项 | 内容 | v7 判定 |
|---|---|---|
| 期数 | （第 N 期·TYPE B 首期从 ep-24 起,实际编号按归档序） | 必填 |
| 主题 | （节日 + 采购内容,例:"春节·萌宠饰品店换新衣"） | 必填 |
| 节庆锚定 | （节庆名 + 节庆类型,例:"春节·传统节日"） | **为空 = 输出失败** |
| 节庆类型 | （传统节日 / 现代节日 / 家庭纪念日 / 节气节日 四选一） | 必填 |
| 采购目的地 | （萌宠饰品店 / 好萌超市 / 双店,例:"萌宠饰品店 + 超市"） | 必填 |
| 动作亮点 | （一句话预览本期最爆笑的连续动态物理动作,例:"弟试穿唐装卡住头"） | 推荐填写 |
| 一句话知识点 | （≤25 字,硬知识点,例:"腊八粥由八种谷物熬制"） | 必填 |
| 时长 | （75-110 秒,默认按 30/60/15 分配） | 必填 |
| 人类角色预算 | （源姐姐 POV ≤40s / 朔哥哥 POV ≤35s / 顾客 ≤2 人 ≤20s） | **为空 = 输出失败** |

**v7 三猫戏份分布（沿用 v6.3）**:
- 优雅姐（工艺主讲 + 指挥 + 替妹出头）:≥50%
- 黄毛弟（取材 + 灵机一动搞砸 + 撺掇 / 欺负妹 + 捧哏）:≤30%
- 呆萌妹（气氛组 + 帮倒忙 + 隐性任务锚点 / 反应代理）:10-20%

## 字段 2：角色分配表

**格式**:表格,4 列

| 角色 | 姓名 | 身份 | 出场时长上限 |
|---|---|---|---|
| 主角·姐 | 三花姐 | 三猫家庭·工艺担当 | 主线全程(≥50% 戏份) |
| 主角·弟 | 橘猫弟 | 三猫家庭·闯祸/捧哏 | 主线全程(≤30% 戏份) |
| 主角·妹 | 小白妹 | 三猫家庭·气氛组/隐性功能 | 主线全程(10-20% 戏份) |
| 人类店长 | 源姐姐 | 萌宠饰品店店长 | POV 互动时长 ≤40s（只露手/道具,不露脸/全身） |
| 人类店长 | 朔哥哥 | 好萌超市店长 | POV 互动时长 ≤35s（只露手/道具,不露脸/全身） |
| 陈列道具 | 猫咪塑料模特 | 非角色·陈列道具 | 不计入角色预算(同屏 2-4 只) |
| 人类顾客 | （偶发·远景） | 商业街/店内背景 | ≤2 人 · ≤20s |

**v7 角色分配判定**:
- 源姐姐 / 朔哥哥 **不能同屏**(双店间隔出现)
- 人类顾客 **不列姓名**(纯背景,不推动剧情)
- 猫咪塑料模特 **不计入角色数**(道具类)

> **POV 备注**:源姐姐 / 朔哥哥的主形象（脸 / 身体 / 全身）通常不直接出现在画面中；与三猫互动时采用 POV（第一人称）视角。「出场时长」=「POV 互动时长」（含双手动作 / 道具出现在镜头前的总时长）。允许出现：双手（递交商品 / 量尺寸 / 接购物袋 / 扫码 / 敲计算器 / 竖大拇指等具体动作）、道具（软尺 / 衣架 / 扫码枪 / 计算器 / 购物车把手 / 购物袋 / 工牌局部等）。禁止出现：面部特写 / 全身轮廓 / 静态站位形象。

## 字段 3：采购清单

**格式**:结构化列表(≥3 件),每件包含 4 项

```
采购物品:（商品名,例:"红色唐装 ×3"）
采购动机:（为什么要买,例:"春节穿新衣讨吉利"）
采购场所:（萌宠饰品店 / 好萌超市）
备注:（可选,例:"弟挑最大码,但肩宽不合"）
```

**采购清单规则**:
- 每期 ≥3 件(至少 1 件来自萌宠饰品店,至少 1 件来自好萌超市)
- 采购动机必须贴近节日(不能只写"想要")
- 至少 1 件物品在"装饰大餐段"被使用(形成闭环)
- 采购物品可作为后续宇宙资产(写入 主资·物质资产表.md)

## 字段 4：整体节奏结构（按 30/60/15 分段）

**TYPE B 时间轴格式（默认 30/60/15·用户可覆盖）**:

```
[ 0-30% ]  采购段(22-33s)
            ├ [进城] 三猫出门 → 城市商业街 → 第一家店
            ├ [引导] 源姐姐/朔哥哥 POV 出现(第 1 节点·只露手/道具)
            ├ [选购] 三猫对比 → 决策
            └ [结账] 付账 → 拿购物袋 → 离店
[30-90%]  装饰大餐段(45-66s)  ← 主爆点所在段
            ├ [返程] 商业街 → 院中
            ├ [拆袋] 三猫分工拆袋 → 挂装饰品
            ├ [换装] 三猫换新衣
            ├ [大餐] 三猫做节日食物
            └ [摆盘] 成品摆上节日桌
[90-100%] 享成果段(11-17s)
            ├ [试穿/试吃] 三猫并排展示
            ├ [互动] 三猫温和互动
            ├ [meta] 宇宙资产 + 字幕卡
            └ [留白] 情绪留白(2-3s)
```

**节奏判定**:
- 采购段 ≤33s / 装饰大餐段 ≥45s / 享成果段 ≤17s
- 用户 prompt 写「这句按 X/Y/Z」→ 完全遵从用户分配
- 装饰大餐段**必须包含回家 + 布置 + 换装三个子节点**(缺一 = 输出失败)

## 字段 5：字幕卡文案汇总

**格式**:表格,≤25 字 / 张

| # | 出现时机 | 文案 |
|---|---|---|
| 1 | 采购段·进城 | [≤25 字] |
| 2 | 采购段·选购 | [≤25 字] |
| 3 | 装饰大餐段·换装 | [≤25 字] |
| 4 | 装饰大餐段·大餐 | [≤25 字] |
| 5 | 享成果段·meta | [≤25 字] |

**v7 字幕卡规则**:
- ≤25 字 / 张(同 v6.3)
- 字幕卡**不写猫的台词**(猫仍不会说话)
- 字幕卡**不写人类店长的台词**(店长台词由"说话"表达,字幕卡只写硬知识点)
- 字幕卡位置 = 采购段开头 / 换装段开头 / meta

## 字段 6：宇宙资产联动（必填·A020-A025 预分配）

**格式**:表格

| 类型 | asset_id | 名称 | 类别 | 出现段落 |
|---|---|---|---|---|
| 本期新建 | A02X | （如"三猫节日新衣 ×3"） | 服饰 | 换装段 / 享成果段 |
| 本期复用 | A020 | （源姐姐围裙） | 服饰 | 萌宠饰品店 |
| 本期复用 | A021 | （朔哥哥工牌） | 服饰 | 好萌超市 |

**A020-A025 预分配表(节庆资产·详见 主资·物质资产表.md)**:

| asset_id | 名称 | 类别 | 备注 |
|---|---|---|---|
| A020 | 源姐姐围裙（米白棉麻·胸前绣「喵」） | 服饰 | 详细设定已写入 节庆采购档·角色设定.md |
| A021 | 朔哥哥工牌（深蓝·左胸口「朔·店长」） | 服饰 | 详细设定已写入 节庆采购档·角色设定.md |
| A022 | 猫咪塑料模特·春季款（汉服/和风） | 陈列道具 | 不入角色预算,同屏可 2-4 只 |
| A023 | 猫咪塑料模特·节庆款（红唐装/圣诞） | 陈列道具 | 按节切换,不单独编号 |
| A024 | 萌宠饰品店招牌（木质·猫耳轮廓） | 场景道具 | 节庆专属资产 |
| A025 | 好萌超市招牌（现代简约·猫爪图标） | 场景道具 | 节庆专属资产 |

**判定**:每期 TYPE B 必须复用 A020-A025 中 ≥1 项(建议复用 A020/A021 或按节日复用 A022/A023)

**复用机制规则**(沿用 v6.3):
1. 每期必须填至少一个 asset_id(新建或复用)
2. 复用时必须写**出现段落**
3. 新建时自动分配下一个 A 编号(从 A026 起),写入 主资·物质资产表.md
4. 消耗性资产(食物/酒/糖)标记"已消耗",不可复用
5. **猫咪塑料模特为陈列道具·非角色**:A022/A023 复用不触发"动物配角预算"

## 字段 7：节庆锚定说明（独立表格·不与节气锚混用）

**格式**:表格

| 节庆名 | 节庆类型 | 视觉符号(≥2) | 氛围优先级 | 节气锚(可选) |
|---|---|---|---|---|
| 春节 | 传统节日 | 红灯笼 / 对联 / 鞭炮 / 唐装 | 节庆氛围优先 | （留空或白露等可选背景） |

**判定**:节庆名 + 类型 + 视觉符号 ≥2 项齐 = 输出合规

**v7 节庆锚 vs 节气锚规则**:
- TYPE B **必填节庆锚**,节气锚**可选**
- 若两者并存:**节庆锚优先级 > 节气锚**(节庆场景为主,节气物候作背景点缀)
- 节庆视觉符号必须在画面中真实出现(红灯笼/圣诞树/月饼桌/粽子摊),不能只写字幕卡

**节庆类型分类**(详见 节庆采购档·设计宪法.md):
- 传统节日:春节 / 元宵 / 端午 / 七夕 / 中秋 / 重阳 / 冬至 / 腊八
- 现代节日:元旦 / 圣诞 / 情人节 / 母亲节 / 父亲节 / 万圣节
- 家庭纪念日:生日 / 周年 / 三猫家庭纪念日
- 节气节日:小年 / 寒食 / 中元 / 下元

## 字段 8：段 5 收尾规范（享成果段·采购专属冲突）

**TYPE B 段 5 = 享成果段**:不再用 v6.3 的"冲突瞬间 + 克制惩罚 + 平静收束"三段式,改为**采购专属收尾**——保留温和冲突(采购后遗症),但整体是"穿新衣吃美食"的温馨收束。

| 阶段 | 时长 | 强度 | 内容 |
|---|---|---|---|
| **试穿/试吃展示** | 5-7s | ★★★ | 三猫并排站/坐,展示新衣 + 节日美食 |
| **三猫互动** | 2-4s | ★★ ↓ | 蹭脸 / 碰杯 / 碰爪等温和互动 |
| **meta 彩蛋** | 3-5s | — | 宇宙资产露出 + 字幕卡 + 微风/蝉鸣/雪落 |
| **情绪留白** | 2-3s | ★ ↓ | 字幕卡淡出 → 纯画面 → 无新动作 → 视频结束 |

**采购专属冲突(替代 v6.3 段 5 冲突瞬间)**——段 5 可选温和冲突(不强制,但推荐保留一个采购后遗症):
- 拎购物袋冲出店门(袋口没扎紧,东西掉出来)
- 结账算错账(弟多拿了商品被朔哥哥发现)
- 穿新衣绊倒(弟试穿唐装被下摆绊倒,妹偷笑)
- 装饰挂错位置(弟把红灯笼挂成歪的,被姐扶正)

**v7 段 5 禁止清单**:
- ❌ 段 5 最后画面还在激烈冲突(弟瘫地/被暴打/被夹)→ 观众感觉"还没完"
- ❌ meta 彩蛋用字幕卡硬切(v6.3 同款禁忌)
- ❌ 跳过情绪留白直接黑屏
- ❌ 在享成果段引入新人类店长(采购已结束,店长不再出场)
- ❌ 在享成果段让塑料模特"活过来"(道具必须保持静止)
