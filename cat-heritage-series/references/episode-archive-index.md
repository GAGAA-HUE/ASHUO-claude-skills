# 归档索引（Episode Archive Index）

> 本文件记录 `cat-heritage-series` 技能已生成的所有脚本表。每当生成一期新脚本表，必须在本文件添加索引条目，避免重复生成。
>
> **技能底层规则**：详见 [三猫家庭设定手册 v3](../三猫家庭设定手册_v3.md)。本索引仅记录生成历史，不重复底层规则。
>
> **使用规则**：
> - 调用本技能时，**先读取本索引**检查是否已存在目标期数
> - 如已存在 → 直接告知用户该期编号 + 文件路径，询问是否需要调整
> - 如不存在 → 按 v3 手册生成 + 写入归档文件 + 在本索引添加条目
>
> **主题范围**：必拍三类——① 非遗手作 ② 传统美食 ③ 网红美食；可选调味剂——生活小剧场（≤20%，必须包含手作或美食元素）。
>
> **画面硬约束**（详见 v3 手册的 `<absolute_constraints>`）：
> - 画面中无任何人类角色
> - 除三只猫外无其他动物
> - 无拟人台词
> - 脚本表内无机位 / 景别 / 角度词汇
> - 猫必须用工具而非爪子干活
