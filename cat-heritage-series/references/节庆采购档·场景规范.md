## 场地 1:萌宠服装店(源姐姐の店)

### 基础信息

| 项 | 内容 |
|---|---|
| 店铺名 | 萌宠服装店(源姐姐の店) |
| 店长 | 源姐姐(YuanJieJie) |
| 类别 | 传统手作衣帽店 |
| 风格 | 江南水乡风格木楼 |
| 位置 | 城市商业街中段,临近河畔 |
| asset_id | A024(招牌) |

### 外观设计

- **建筑**:江南水乡风格木楼,2 层,青砖墙+木质窗框
- **门头**:木质招牌(猫耳轮廓)+暖黄灯笼 2 盏
- **门窗**:木门推拉式,门口石阶 2 级
- **橱窗**:落地玻璃橱窗,陈列 2-4 只**猫咪塑料模特**(穿当季服饰)
- **招牌挂饰**:木牌「猫耳轮廓」+ 春联(春节期)/ 艾草束(端午期)/ 桂花枝(中秋期)等

### 区域划分

```
┌─────────────────────────────────────┐
│  入口橱窗(2-4 只猫咪塑料模特展示)   │
├─────────────────────────────────────┤
│  中岛区(衣架墙·悬挂各类服饰)         │
├─────────────────────────────────────┤
│  试衣角(布帘后·猫专用低镜)           │
├─────────────────────────────────────┤
│  结账台(源姐姐位·木质算盘+钱箱)       │
└─────────────────────────────────────┘
```

#### 区域 1:入口橱窗
- 落地玻璃,内侧陈列 2-4 只猫咪塑料模特
- 不同模特穿不同主题服饰(春节红唐装/端午汉服/中秋玉兔/圣诞麋鹿/日常和风)
- 模特**静止站立**,不作任何动作
- 模特脚下铺米色棉麻布

#### 区域 2:中岛区(衣架墙)
- 木质衣架 ×20+,分款式悬挂
  - 节日款:唐装 / 汉服 / 和服 / 西装 / 圣诞装
  - 日常款:围裙 / 棉麻衣 / 短袖 / 披风
  - 配饰款:领结 / 蝴蝶结 / 小围巾 / 木质发簪
- 三层木架(底层给小猫可触及)

#### 区域 3:试衣角
- 布帘(蓝印花布,可作 A001 复用彩蛋)隔出
- 猫咪专用低镜(高度 30cm)
- 矮凳(给猫站上去用)
- 软尺挂墙面

#### 区域 4:结账台
- 木质柜台(高 70cm)
- 木质算盘 + 钱箱
- 购物袋(纸袋印猫爪印,堆在柜台旁)
- 小本子(手写记账)

### 道具清单

| 道具 | 数量 | 用途 | 备注 |
|---|---|---|---|
| 全身镜(猫专用低镜) | 1 | 试衣时猫看自己 | 高度 30cm |
| 软尺 | 1 | 量猫身围 | 木质卷尺 |
| 购物袋(纸袋印猫爪) | 5+ | 结账时装商品 | 米黄底+蓝爪印 |
| 木质衣架 | 20+ | 挂各类服饰 | 不同款式 |
| 木质算盘 | 1 | 结账 | 收银道具 |
| 猫咪塑料模特 | 2-4 | 橱窗陈列 | A022/A023 复用 |
| 木质小猫轮廓发簪 | 1 | 源姐姐发间佩戴(POV 下仅局部) | 角色配饰 |

### 三猫动线(萌宠服装店段·强制顺序)

```
进门 → 被模特吸引 → 源姐姐 POV 引导 → 量尺寸 → 试衣 → 结账 → 离店
 ↑                                                                      ↓
 入口橱窗 ← 离店后由朔哥哥店引导 ←←←←←←←←←←←←←←←←←←←←←←←←←←←←┘
```

#### 动线 1:进门(2-3s)
- 三猫推开木门进入
- 门口风铃响(「叮铃」ASMR)
- 门内木地板吱呀声

#### 动线 2:被模特吸引(3-5s)
- 三猫在橱窗前驻足
- 弟跳起来想摸模特(被姐推开)
- 妹歪头看模特(慢动作 1s)
- 模特**静止**,不响应

#### 动线 3:源姐姐 POV 引导(5-8s)
- 一只手从柜台后伸出(POV 视角·不露源姐姐面部/全身)
- 手指轻弹中岛区衣架布面(「啪嗒」声)
- 单手指向中岛区衣架
- 简短台词:"试试这件?"

#### 动线 4:量尺寸(8-10s)
- 一只手(源姐姐)取下软尺
- 三猫轮流站到矮凳上
- POV 视角下:蹲身量(对姐 / 弟 / 妹)——画面只见手与软尺
- 弟在量的时候扭来扭去(一只手按住弟肩 1 次)

#### 动线 5:试衣(8-12s)
- 三猫在试衣角
- 布帘放下(蓝印花布)
- 姐选姐款 / 弟选弟款 / 妹选妹款
- 弟试穿唐装被下摆绊倒(可选冲突)
- 布帘外一只手轻轻掀帘:"很合身呢"

#### 动线 6:结账(5-8s)
- 三猫抱新衣到柜台
- 一只手敲算盘(「噼啪」)
- 三猫递钱(以物易物 / 摆小贝壳等)
- 双手撑开购物袋递出
- 简短台词:"节日快乐。"
- 三猫推门离店(风铃再响)

## 场地 2:好萌超市(朔哥哥の店)

### 基础信息

| 项 | 内容 |
|---|---|
| 店铺名 | 好萌超市(朔哥哥の店) |
| 店长 | 朔哥哥(ShuoGeGe) |
| 类别 | 现代便利店+自助超市 |
| 风格 | 现代简约·猫主题包装 |
| 位置 | 城市商业街尾段,临近街口 |
| asset_id | A025(招牌) |

### 外观设计

- **建筑**:现代便利店风格,1 层,玻璃幕墙+自动门帘
- **门头**:简约招牌(猫爪图标)+暖白灯箱
- **门窗**:玻璃推拉门(自动感应),门口地垫(猫爪印)
- **橱窗**:海报窗(当季促销+三猫款商品图)
- **招牌挂饰**:气球拱门(节庆期)/ 圣诞彩灯(圣诞期)等

### 区域划分

```
┌─────────────────────────────────────┐
│  入口区(感应门帘+猫爪地垫)            │
├─────────────────────────────────────┤
│  生鲜冷藏区(冷柜·水果/酸奶/月饼)      │
```

#### 区域 1:入口区
- 玻璃推拉门(自动感应)
- 入口地垫(蓝底猫爪印)
- 一只手从柜台后伸出迎宾(POV·不露朔哥哥面部/全身)

#### 区域 2:生鲜冷藏区
- 玻璃冷柜(高度 50cm)
- 内放:水果(苹果/橙子/石榴/草莓)/ 酸奶 / 月饼 / 粽子(节庆)等
- 冷柜有塑料猫爪贴(细节装饰)

#### 区域 3:零食饮料区
- 木质货架 5 层
- 内放:罐头(猫款鱼罐头·各种口味)/ 饼干 / 酒水 / 饮料
- 货架端头放猫咪塑料模特 1-2 只(穿日常和风款,A022 复用)

#### 区域 4:日用品区
- 木质货架 3 层
- 内放:餐具 / 纸品 / 装饰品(节日挂饰/灯笼/彩带)
- 装饰品按节庆切换(春节红灯笼/圣诞彩灯/端午艾草)

#### 区域 5:自助结账台
- 现代金属柜台(高 70cm)
- 扫码枪 + 计算器
- 购物袋(可降解塑料袋)堆在柜台旁
- 收银机屏幕(显示当季促销)

|---|---|---|---|
| 购物车 | 2 | 猫可坐 | 高度 40cm |
| 购物篮 | 3 | 猫可拎 | 编织塑料 |

| 玻璃冷柜 | 2 | 生鲜冷藏 | 高度 50cm |
| 木质货架 | 5 | 商品陈列 | 多层 |
| 猫咪塑料模特 | 1-2 | 货架端头装饰 | A022/A023 |

### 三猫动线(超市段·强制顺序)

```
进门 → 被货架吸引 → 朔哥哥 POV 引导 → 选品 → 结账 → 离店
 ↑                                              ↓
 入口区 ← 离店后由姐带领回家布置 ←←←←←←←←←←←←←←┘
```

#### 动线 1:进门(2-3s)
- 玻璃门自动感应打开
- 三猫排队进门(姐在前,妹在后,弟乱跑)
- 门口「欢迎光临」电子音(可选)

#### 动线 2:被货架吸引(3-5s)
- 三猫冲向货架
- 弟想爬货架(一只手按住弟肩示意)
- 妹踮脚看最高层(一只手帮她拿下)
- 罐头区的鱼罐头(塑料模特穿日常和风款端坐,装饰作用)

#### 动线 3:朔哥哥 POV 引导(5-8s)
- 一只手从柜台后伸出(POV 视角·不露朔哥哥面部/全身)
- 弯腰平视三猫(画面只见手/衣袖局部)
- 单手指向生鲜冷藏区
- 简短台词:"这边选。"

#### 动线 4:选品(10-15s)
- 三猫在生鲜冷藏区挑水果
- 弟想拿最高层(一只手帮他拿下)
- 妹拿小苹果(一只手竖大拇指)
- 罐头区选鱼罐头(手指"这款很新鲜")

#### 动线 5:购物车段(可选,8-10s)
- 一只手推出小购物车
- 弟跳进购物车坐好
- 一只手扶车把,弯腰推车
- 妹坐在购物车篮沿(示意妹下来——不,允许妹坐)
- **注意**:一只手扶车让猫自己跳

#### 动线 6:结账(8-10s)
- 三猫在结账台
- 一只手逐件扫码(扫码枪「嘀」)
- 一只手敲计算器
- 三猫递钱
- 双手撑开购物袋递出
- 简短台词:"节日快乐。"
- 三猫推门离店

## 场地 3:城市商业街(过渡段)

### 基础信息

| 项 | 内容 |
|---|---|
| 场地名 | 城市商业街(过渡空间) |
| 用途 | 连接院落与双店的过渡空间 |
| 出现时长 | ≤15s 累计 |
| 出现次数 | ≤2 次/期 |

### 外观设计

- **地面**:青石板路(踩上去「咯噔咯噔」)
- **两旁**:店铺招牌林立,各家店铺门口有装饰
- **行人人影**:远景不露脸(可作背景,不推动剧情)
- **节日装饰**:红灯笼/圣诞彩灯/端午龙舟旗/中秋月饼摊/圣诞橱窗
- **行道树**:绿树成荫 / 节庆挂饰

### 出现规则(强制)

1. **仅作过渡**:从院落/家 → 第一家店,或 第一家店 → 第二家店,或 第二家店 → 回院落
2. **时长上限**:≤15s 累计(可分散在 1-2 段)
3. **次数上限**:≤2 次/期
4. **人物限制**:仅远景行人(不露脸),人类顾客可出现在此背景(不推动剧情)
5. **摄影限制**:不能出现机位/景别/角度词汇;允许前景/中景/背景

### 三猫商业街动线

#### 段 1:出门 → 商业街 → 萌宠服装店(5-8s)
- 院门推开,三猫走出
- 商业街青石板路(踏步声)
- 街道两旁灯笼/橱窗闪过
- 三猫走进萌宠服装店

#### 段 2:萌宠服装店 → 商业街 → 好萌超市(3-5s)
- 三猫拎购物袋出萌宠服装店
- 商业街走过一段
- 好萌超市在街尾,猫看见招牌

#### 段 3:好萌超市 → 商业街 → 回家(5-8s)
- 三猫拎购物袋出好萌超市
- 商业街走过一段(夕阳/夜灯渐亮)
- 转入小巷/小桥/河畔,回家

## 场地决策树(TYPE B 必读)

### 用户输入与场地推荐

```
用户说「采购」但未指定地点
├ 推荐:萌宠服装店 → 好萌超市(双店齐全)
├ 单店备选:仅好萌超市(如"换新衣"非必要)
└ 单店备选:仅萌宠服装店(如"采购食物"非必要)

用户说「换新衣」
├ 必须:萌宠服装店
└ 可选:好萌超市(若需配饰/装饰)

用户说「采购食物 / 采购装饰品」
├ 必须:好萌超市
└ 可选:萌宠服装店(若需节日新衣)

用户指定节日
├ 春节 → 萌宠服装店(主·唐装)+ 好萌超市(配·春联/灯笼/饺皮)
├ 端午 → 萌宠服装店(主·汉服)+ 好萌超市(配·粽子/艾草/五彩绳)
├ 中秋 → 萌宠服装店(主·玉兔装)+ 好萌超市(配·月饼/桂花酒)
├ 圣诞 → 萌宠服装店(主·麋鹿装)+ 好萌超市(配·圣诞树/彩灯)
├ 元旦 → 萌宠服装店(主·新年装)+ 好萌超市(配·烟花/彩带)
├ 七夕 → 萌宠服装店(主·情侣装)+ 好萌超市(配·巧克力)
└ 生日 → 好萌超市(主·蛋糕)+ 萌宠服装店(配·生日帽)
```

### 双店同屏判定

**强制原则**:源姐姐与朔哥哥**不在同一画面**出现
- ✅ 允许:源姐姐 POV 在萌宠服装店 → 三猫出萌宠服装店 → 商业街 → 朔哥哥 POV 在好萌超市(间隔出现)
- ❌ 禁止:萌宠服装店和好萌超市在同一画面(双店不在同一建筑)
- ❌ 禁止:源姐姐和朔哥哥同框对话(他们互不认识)

### 院落衔接判定

- 院落 = TYPE A 主线场地,**不在 TYPE B 中改动**
- 装饰大餐段回到院落时,**沿用 TYPE A 场地设定**(详见 design-spec.md)
- TYPE B 院落的"装扮"为**节庆专属**(灯笼/对联/圣诞树),与 TYPE A 的工艺场景融合

## 场地预算汇总(每期 TYPE B)

| 场地 | 出现时长 | 出现次数 | 备注 |
|---|---|---|---|
| 院落(家中布置) | 30-50s | 1 次 | 装饰大餐段 |
| 城市商业街 | ≤15s 累计 | ≤2 次 | 仅过渡 |
| 萌宠服装店 | 22-33s | 1 次 | 采购段 |
| 好萌超市 | 22-33s | 1 次 | 采购段(可与萌宠服装店二选一) |
| 院落(享成果) | 11-17s | 1 次 | 享成果段 |

### 双店同时段判定

- 用户明确说"先去萌宠服装店再去好萌超市" → 双店都拍,装饰大餐段可有好萌超市采购的食材
- 用户说"采购"未指定 → 推荐双店都拍
- 用户说"只去好萌超市" → 跳过萌宠服装店,朔哥哥 POV 互动时长 35s 仍有效
- 用户说"只去萌宠服装店" → 跳好萌超市,源姐姐 POV 互动时长 40s 仍有效

## 场地冲突判定

| 冲突类型 | 输出判定 |
|---|---|
| 朔哥哥出现在萌宠服装店 | 输出失败(双店间隔原则) |
| 源姐姐出现在好萌超市 | 输出失败 |
| 源姐姐/朔哥哥出现在院落 | 输出失败(只属于店铺) |
| 源姐姐/朔哥哥面部 / 全身出现在画面中 | 输出失败(POV 红线) |
| 商业街出现 >2 次 | 输出失败 |
| 商业街累计 >15s | 输出失败 |
