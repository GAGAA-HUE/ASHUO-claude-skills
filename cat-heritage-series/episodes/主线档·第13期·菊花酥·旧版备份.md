## 二、工艺段（COLD OPEN + SOURCING + PROCESS + 招牌结尾）
### 段 0 — COLD OPEN（趴在油锅边）：10s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。下午的厨房里，三花猫蹲在灶台边专心盯着油锅里翻滚的菊花酥生坯。橘猫悄悄溜进厨房趴到灶台边眼巴巴盯菊花酥下油锅，被三花猫发现后用爪子推了一把他的后腿。弟蹲到地上装无辜。妹妹抱着铃铛从画面右侧入画蹲在旁边瞪大眼睛看油锅。三花猫继续专心守油锅，弟不甘心又趴回灶台边，三花猫这次直接用爪子推了弟的脸。

**叙事节拍**：

- **节拍 0-1·姐守油锅·弟趴灶台边**（3s）：三花猫端坐灶台边，目不转睛盯油锅里菊花酥生坯。橘猫悄悄溜进厨房趴到灶台边眼巴巴盯菊花酥下油锅。
  - **三猫位置**：前景·中线 = 三花猫 + 灶台 + 油锅；中景偏右 = 橘猫趴灶台边；背景偏左 = 空（妹未到）。
  - **ASMR**「热油·嗞嗞」+「菊花酥生坯在油锅里翻滚·嗞啦」
- **节拍 0-2·姐推弟后腿·弟蹲地装无辜**（3s）：三花猫用爪子推了一把橘猫的后腿。橘猫蹲到地上装无辜瞪眼歪头。
  - **三猫位置**：前景·中线三花猫推弟；中景偏右橘猫蹲地装无辜；背景偏左空。
  - **ASMR**「姐推弟后腿·啪」+ 弟装无辜「喵」
- **节拍 0-3·妹抱铃铛入画·蹲旁边瞪眼**（2s）：妹妹抱着铃铛从画面右侧入画，蹲在旁边瞪大眼睛看油锅。铃铛「叮」一声轻响。
  - **三猫位置**：前景·中线三花猫守油锅；中景偏右橘猫蹲地装无辜；背景偏左白猫抱铃铛蹲坐。
  - **ASMR**「妹铃铛·叮」+「油锅·嗞嗞」
- **节拍 0-4·弟不甘心再趴灶台边·姐推弟脸**（2s）：弟不甘心又趴回灶台边。三花猫这次直接用爪子推了弟的脸。弟缩回爪装无辜。
  - **三猫位置**：前景·中线三花猫推弟脸；中景偏右橘猫再次被推；背景偏左白猫抱铃铛笑。
  - **ASMR**「姐推弟脸·啪」+ 弟心虚「喵呜」+ 妹笑「嘻」+ 铃铛「叮」

**叙事弧总结**：本段是「**弟趴油锅边·姐推开·弟装无辜·妹入画·弟再趴·姐再推**」的 COLD OPEN 经典四拍。弟趴油锅边是本期「草蛇灰线」的**起因**——弟的姿势会让油锅里的热油在段 5-3 溅出，落在妹白毛上形成「油花猫」变装。本段的核心戏剧反差是「**菊花酥在油锅里绽放的唯美工艺 + 弟趴在油锅边的危险动作**」。

### 段 1 — SOURCING 备料：18s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫用爪子把面粉倒在石桌上挖出火山形小窝，准备打入鸡蛋。橘猫背着小竹筐从画面右侧入画，把黄油块搬到石桌旁，又小跑出画去搬第二块。白猫抱着一捧刚采的菊花瓣轻轻踮脚走到石桌旁，把花瓣递给姐姐。期间橘猫第二次背筐回来时偷咬了一口黄油，被三花猫发现后用爪子精准推开弟弟的脸并摇头示意，妹妹在旁边捂住嘴偷笑。三花猫继续在前景揉面，橘猫只好委屈地把黄油放回桌角，背着竹筐又小跑出画去搬第三块黄油。

**叙事节拍**：

- **节拍 1-1·姐挖火山窝·弟搬黄油·妹采菊花**（5s）：三花猫在石桌前用爪子把面粉堆成火山形小窝，准备打入鸡蛋。橘猫背着小竹筐从画面右侧入画，把第一块黄油搬到石桌旁。白猫抱着一捧刚采的菊花瓣从画面左侧踮脚入画。
  - **三猫位置**：前景·中线 = 三花猫 + 石桌；中景偏右 = 橘猫背筐入画；背景偏左 = 白猫抱菊花瓣踮脚（铃铛晃动）。
  - **ASMR**「面粉入堆·沙」+「黄油落地·咚」+ 弟气喘「呼·呼」+ 铃铛「叮」
- **节拍 1-2·妹踮脚递菊花瓣**（3s）：白猫踮起后脚把菊花瓣一片一片递给三花猫，铃铛随动作「叮叮」轻响。三花猫接过花瓣叠在桌角。
  - **三猫位置**：前景·中线 = 姐接菊花瓣；中景偏右 = 橘猫背第二块入画；背景偏左 = 妹踮脚递花（铃铛晃动）。
  - **ASMR**「花瓣相叠·簌簌」+ 铃铛「叮·叮」
- **节拍 1-3·弟偷咬黄油·姐推开脸·妹偷笑**（4s）：橘猫背第二筐回来时偷偷咬了一口黄油。三花猫头也没抬伸出爪子精准推开弟弟的脸，摇爪示意「放下」。妹妹在一旁捂住嘴偷笑。
  - **三猫位置**：前景·中线 = 姐伸手推弟；中景偏右 = 橘猫叼黄油被推开；背景偏左 = 妹捂嘴笑。
  - **ASMR**「姐推弟·啪」+ 弟委屈「呜」+ 妹笑「嘻」
- **节拍 1-4·姐揉面·弟继续搬·妹继续递**（6s）：三花猫继续在前景专注揉面，把面粉和菊花瓣揉成黄色面团。橘猫背着空竹筐小跑出画去搬第三块黄油。白猫继续踮脚递菊花瓣。
  - **三猫位置**：前景·中线 = 三花猫揉面（沉浸式）；中景 = 橘猫出画；背景偏左 = 妹继续递花。
  - **ASMR**「面团揉捏·咂咂」+「竹筐远去·沙沙」+ 铃铛「叮」

**叙事弧总结**：本段是「**姐沉浸式备料 + 弟妹各司其职 + 弟偶尔闯祸**」的协作型段落。三猫纵深清晰——姐前景揉面、弟中景搬运、妹背景递花瓣，全程 ≥2 只猫同框。

### 段 2 — 起酥（水油皮+油酥叠被子）：22s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把揉好的水油皮面团用擀面杖擀成薄片，把冷藏好的油酥面团放在中间，然后像叠被子一样把水油皮的四边折起来包住油酥。擀面杖「咕噜咕噜」滚动，三花猫神情专注。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐姐擀面（其实在玩）。白猫抱着一罐白芝麻在旁边安静等待姐姐需要撒芝麻。三花猫把包好油酥的面团擀成长条再卷起来，重复「四折叠」四次。橘猫玩着玩着把擀面杖滚到地上，自己蹲坐地上瞪着擀面杖装无辜。三花猫叹了口气继续擀面。

**叙事节拍**：

- **节拍 2-1·姐擀水油皮·弟玩小擀面杖·妹等芝麻**（6s）：三花猫端坐石桌前，爪持擀面杖擀水油皮。擀面杖「咕噜咕噜」滚动。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐擀面（其实是玩）。白猫抱着一罐白芝麻蹲旁边。
  - **三猫位置**：前景·中线 = 三花猫 + 擀面杖；中景偏右 = 橘猫玩小擀面杖；背景偏左 = 白猫抱芝麻罐蹲坐。
  - **ASMR**「擀面杖·咕噜·咕噜」+「小擀面杖·咚咚」（弟玩）
- **节拍 2-2·姐包油酥·叠被子**（5s）：三花猫把油酥面团放在擀好的水油皮中间，把水油皮四边折起来包住油酥。动作如同叠被子般严谨——这是本期「四折叠」的核心工艺步骤。
  - **三猫位置**：前景·中线 = 三花猫 + 折叠面团；中景偏右 = 橘猫继续玩；背景偏左 = 白猫安静等。
  - **ASMR**「面团折叠·扑」+ 姐轻喵「喵」（方向示意）
- **节拍 2-3·弟玩掉擀面杖·装无辜**（4s）：橘猫玩着玩着把擀面杖滚到地上，自己蹲坐地上瞪着擀面杖装无辜。三花猫头也不抬继续擀面。
  - **三猫位置**：前景·中线三花猫继续擀面；中景偏右橘猫蹲在地上瞪擀面杖；背景偏左白猫探头看。
  - **ASMR**「擀面杖落地·咚」+ 弟心虚「喵呜」+ 妹笑「嘻」
- **节拍 2-4·姐卷起+重复「四折叠」四次·弟妹围观**（7s）：三花猫把包好油酥的面团擀成长条卷起来，再擀再卷，重复「四折叠」四次。橘猫和白猫蹲在桌旁围观，面团层次越来越多。
  - **三猫位置**：前景·中线 = 三花猫擀卷；中景偏右 = 橘猫围观；背景偏左 = 白猫围观。
  - **ASMR**「擀面杖·咕噜」+「卷起·扑」+ 远处菊花风「沙沙」

**叙事弧总结**：本段是「**姐沉浸式起酥 + 弟假装帮忙变玩 + 弟闯祸小插曲 + 三猫围观**」的平静推进型段落。起酥工序是本期唯美段的核心伏笔——「四折叠」四次是本期菊花酥层次分明的关键。

### 段 3 — 包馅+切 16 瓣蒙太奇段：24s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把起酥好的面团擀成 1 厘米厚的薄片，用圆形模具压出面皮，包入豆沙馅搓圆压扁，用小刀在表面切出 16 瓣花形，每瓣都用刀背轻轻压一下让花瓣层次分明。橘猫和白猫蹲旁边认真看，橘猫伸手想按面皮想帮忙，被三花猫用爪子推开手背。妹妹递上一小撮白芝麻，三花猫用白芝麻在菊花酥生坯中央装饰成花蕊。橘猫耐不住性子趁姐递芝麻时偷偷伸手按了一下旁边的面皮，结果压出一个扁扁的「弟款扁生坯」。三花猫看了叹了口气把「弟款扁生坯」也放在烤盘边角。三花猫继续在前景专注切瓣。

**叙事节拍**：

- **节拍 3-1·姐擀薄片·压圆模·包馅搓圆**（5s）：三花猫把起酥好的面团擀成 1 厘米厚的薄片，用圆形模具轻轻压下，「咯噔」一声面皮出现。三花猫包入豆沙馅搓圆压扁。橘猫和白猫蹲旁边认真看。
  - **三猫位置**：前景·中线 = 三花猫 + 圆模；中景偏右 = 橘猫蹲坐看；背景偏左 = 白猫蹲坐看。
  - **ASMR**「擀面杖·咕噜」+「圆模压下·咯噔」+ 微风「呼呼」
- **节拍 3-2·姐切 16 瓣·弟伸手按面皮被推开**（5s）：三花猫用小刀在面皮表面切出 16 瓣花形，每瓣都用刀背轻轻压一下让花瓣层次分明。橘猫忍不住伸手想帮忙按面皮，三花猫用爪子轻轻推开弟弟的手背。
  - **三猫位置**：前景·中线三花猫切瓣；中景偏右橘猫伸手被推开；背景偏左白猫安静看。
  - **ASMR**「小刀切瓣·沙沙·沙沙」+「姐推弟手·啪」+ 弟委屈「呜」
- **节拍 3-3·妹递白芝麻装饰**（3s）：妹妹轻轻把一小撮白芝麻递给姐姐。姐姐用白芝麻在菊花酥生坯中央装饰成花蕊。
  - **三猫位置**：前景·中线 = 三花猫 + 菊花酥生坯；中景偏右 = 橘猫围观；背景偏左 = 白猫递芝麻（铃铛晃动）。
  - **ASMR**「芝麻点缀·簌簌」+ 铃铛「叮」+ 远处菊花风「沙沙」
- **节拍 3-4·弟偷偷按面皮→压出「弟款扁生坯」**（6s）：橘猫趁姐姐递芝麻时偷偷伸手按了一下旁边的面皮。结果压出一个扁扁的「弟款扁生坯」（不是 16 瓣的）。三花猫回头看见，叹了口气。
  - **三猫位置**：前景·中线三花猫回头；中景偏右橘猫蹲坐装无辜（身后是扁生坯）；背景偏左白猫捂嘴笑。
  - **ASMR**「面皮被按·噗」+ 弟心虚「喵」+ 姐叹气「呼」+ 妹笑「嘻」
- **节拍 3-5·姐把弟款扁生坯放边角·继续切瓣**（5s）：三花猫叹了口气把「弟款扁生坯」放在烤盘边角。重新开始切下一个标准的 16 瓣菊花酥。
  - **三猫位置**：前景·中线三花猫继续切瓣（沉浸式）；画面一角弟款扁生坯静静躺在烤盘边角。
  - **ASMR**「小刀连续切·沙沙·沙沙」+ 远处菊花风

**叙事弧总结**：本段的情绪线是「**任务推进→弟越界→弟闯小祸→姐宽容接纳→姐继续干活**」的「协作回归型」变体。弟的「扁生坯」是本期最重要的「草蛇灰线」伏笔——这块扁生坯将在段 5 油炸时变成「**意外开花**」的惊喜彩蛋。
### 段 4 — 入油锅前准备：12s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把切好瓣的菊花酥生坯整齐排在案板上。橘猫和白猫帮忙用爪子轻轻托着托盘两边。三花猫用刷子在每个生坯底部刷上一点蛋清，让橘猫把生坯底在白芝麻里蘸一下。三花猫和白猫把所有蘸好芝麻的生坯排到漏勺里准备下油锅。三花猫蹲在灶台前开始烧油，油温慢慢上升。橘猫又趴到灶台边眼巴巴盯油锅，被三花猫用爪子推开脸担心他被热油烫到。

**叙事节拍**：

- **节拍 4-1·三猫共搬生坯入托盘**（4s）：三花猫用刷子在每个生坯底部刷上一点蛋清。橘猫和白猫分别用爪子轻轻托着托盘两边。
