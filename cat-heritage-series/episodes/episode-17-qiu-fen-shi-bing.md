## 2. 工艺段

### 段 0+1（0-15s）· Hook + 推进 · 摘柿 + 削皮

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。秋分午后，院中柿子树挂满橙红灯笼，几片落叶被秋风卷过石阶。弟自告奋勇爬上树摘柿，结果压断一根细枝，连猫带柿滚进树下的干草堆，怀里还紧紧抱着一颗大柿子。姐端着一只旧陶盆走过来，把弟从草堆里拎出来，妹坐在竹篮边，尾巴尖轻点篮沿等任务信号。

- **节拍 1-1·弟压枝摔下**（0-3s）：弟在柿子树枝上伸手够最红的柿子，细枝断裂，弟抱着柿子滚落干草堆，柿子滚到姐脚边。
  - **三猫位置**：前景 = 弟+干草+落柿；中景 = 姐+陶盆；背景 = 妹+竹篮。
  - **ASMR**「树枝断裂脆响」+「干草窸窣」+ 猫叫「嗷呜」
- **节拍 1-2·姐眼神公布任务**（3-8s）：姐把柿子拨进陶盆，抬眼看向妹，妹立刻把竹篮往前推了推，歪头看向柿子。
  - **三猫位置**：前景 = 姐爪+柿子；中景 = 妹+竹篮；背景 = 柿子树+落叶。
  - **ASMR**「陶盆轻响」+「落叶擦地」+ 猫叫「咪」
- **节拍 1-3·姐削皮弟偷啃**（8-15s）：姐用一把小陶刀给柿子旋皮，弟假装递柿子却低头偷啃半颗，嘴角淌出橙黄果肉，姐用陶刀背轻敲弟额头。
  - **三猫位置**：前景 = 姐+陶刀+去皮柿子；中景 = 弟嘴里含柿子；背景 = 妹抱竹篮看。
  - **ASMR**「陶刀削皮沙沙」+「弟咀嚼声」+ 猫叫「嗷」

**叙事弧总结**：本段是『弟搞怪被训型』段落。🔥 严厉 → 🎭 搞笑

### 段 2（15-25s）· 起因 · 穿绳挂晒

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。姐把削好皮的柿子蒂朝上摆成一排，旁边放着一个竹晒架。弟嘴里还嚼着半块柿子，围着晒架转来转去，尾巴把晒架上的棉线扫得乱晃。妹小心翼翼地用爪子捧起一团棉线，递给姐。

- **节拍 2-1·姐穿绳打结**（15-20s）：姐用前爪捏住棉线，在柿子蒂上绕两圈、一抽，把柿子倒挂在晒架横杆上。

  - **三猫位置**：前景 = 弟+晃动的柿子；中景 = 姐爪按弟头；背景 = 妹+棉线团。
  - **ASMR**「柿子摇晃」+「肉垫按头闷响」+ 猫叫「哈」
- **节拍 2-3·三柿挂好**（23-25s）：姐把三颗去皮柿子整齐挂在晒架上，弟被按住不敢动，妹歪头看成品。
  - **三猫位置**：前景 = 三颗挂好的柿子；中景 = 姐；背景 = 弟+妹。
  - **ASMR**「棉线收紧」+「秋风叶落」+ 猫叫「呼噜」

### 段 3（25-40s）· 主爆点 · 弟偷啃柿饼满嘴橙黄

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。晒架刚挂好，弟趁姐转身整理棉线，猛地跃起咬住中间那颗柿子，柿子肉被啃出一个大缺口，橙黄果肉糊了弟满嘴。妹惊得捂住嘴，眼睛瞪圆。姐回头，尾巴竖起，一个箭步冲过来。

- **节拍 3-1·弟跃起偷啃**（25-30s）：弟后腿蹬地跃起，前爪抱住柿子，张嘴啃下一大口，果肉喷溅到脸上。
  - **三猫位置**：前景 = 弟+被啃的柿子；中景 = 晒架；背景 = 姐转身。
  - **ASMR**「果肉挤压」+「弟咀嚼」+ 猫叫「嗷呜」
- **节拍 3-2·表情包定格**（30-33s）：弟定格在抱柿姿势，满嘴橙黄果肉，鼻尖沾着柿子霜，眼神无辜又得意。
  - **三猫位置**：前景 = 弟（单猫特写）；中景 = 无；背景 = 模糊晒架。
  - **ASMR**「果肉滴落」+「弟粗喘」+ 猫叫「喵？」
- **节拍 3-3·姐替妹出头教训弟**（33-37s）：姐冲过来一爪拍在弟后脑勺，弟抱着柿子趴地；姐把妹拨到晒架另一侧，防止弟再撞。
  - **三猫位置**：前景 = 姐+弟；中景 = 妹被拨到安全位；背景 = 晒架。
  - **ASMR**「肉垫拍头闷响」+「弟委屈呜咽」+ 猫叫「咪呜」
- **节拍 3-4·姐没收残柿**（37-40s）：姐从弟怀里叼走被啃的残柿，重新挂在晒架上，弟舔嘴装无辜，妹歪头看缺口柿子。
  - **三猫位置**：前景 = 姐+残柿；中景 = 晒架缺口；背景 = 弟+妹。
  - **ASMR**「柿子蒂轻响」+「弟舔嘴」+ 猫叫「呼噜」

### 段 4（40-55s）· 唯美工艺展示 · 晾晒捏饼

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。秋分斜阳把晒架上的柿子照成半透明琥珀色，秋风卷起院角落叶。姐立起身，用前爪轻轻捏压一颗半干的柿饼，帮助回软整形。弟小心翼翼地用嘴叼来一根棉线，放在姐手边。妹仰头看着晃动的柿子，小脑袋跟着风摆。

- **节拍 4-1·姐捏饼整形**（40-45s）：姐前爪按住柿饼两侧，轻轻挤压，柿饼从硬圆变扁，糖汁微微渗出表面。
  - **三猫位置**：前景 = 姐爪+柿饼；中景 = 晒架；背景 = 弟叼棉线。
  - **ASMR**「柿饼挤压黏响」+「秋风落叶」+ 猫叫「嗯」
- **节拍 4-2·三柿并排成景**（45-50s）：三颗去皮柿子在晒架上并排，弟捧哏式递上棉线，姐把最后一颗挂好。
  - **三猫位置**：前景 = 晒架+三颗柿子；中景 = 姐；背景 = 弟+棉线。
  - **ASMR**「竹架轻响」+「棉线摩擦」+ 猫叫「喵」
- **节拍 4-3·妹追落叶**（50-55s）：一片落叶飘过妹眼前，妹伸爪去拍，落叶粘在爪垫上，妹举爪看，歪头困惑。
  - **三猫位置**：前景 = 妹+粘爪落叶；中景 = 晒架；背景 = 姐+弟。
  - **ASMR**「落叶擦毛」+「妹轻哼」+ 猫叫「咪？」

### 段 5（55-75s）· 反转结尾 · 三段式

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。弟不死心，又绕到晒架下想再偷吃，结果后腿被垂下来的棉线缠住，倒吊在晒架下晃悠，四爪乱蹬。姐走过来，没有暴打，只是用前爪按住弟尾巴根定格两秒。弟立刻老实。最后三猫并排坐在晒架下，秋风把一片柿子叶吹到妹头顶。

- **节拍 5-1·冲突定格**（55-60s）：弟被棉线缠住后腿倒吊在晒架下，身体晃悠，四爪乱蹬，嘴里还叼着一小块柿子皮。
  - **三猫位置**：前景 = 弟+倒挂棉线+晒架；中景 = 姐转身；背景 = 妹后退。
  - **ASMR**「棉线绷紧」+「弟闷哼」+ 猫叫「嗷——」
- **节拍 5-2·克制惩罚**（60-68s）：姐走到倒吊的弟身下，前爪按住弟尾巴根定格两秒，眼神冷冷瞪着弟。
  - **三猫位置**：前景 = 姐爪+弟尾巴；中景 = 弟倒挂；背景 = 妹安静坐。
  - **ASMR**「尾巴被按住轻响」+「弟低声呜咽」+ 猫叫「呜」
- **节拍 5-3·平静收束**（68-75s）：姐帮弟解开棉线放下，弟乖乖蹲好，三猫并排坐在晒架下，秋风带一片柿子叶落在妹头顶。
  - **三猫位置**：前景 = 晒架+三颗柿子；中景 = 三猫并排静坐；背景 = 柿子树+斜阳。
  - **ASMR**「秋风叶落」+「蝉鸣渐弱」+ 猫叫「呼噜」

**叙事弧总结**：本段是『收尾型』段落。🎭 搞笑 → 🌸 温柔
