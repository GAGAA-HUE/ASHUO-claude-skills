## 2. 工艺段（含 SOURCING / PROCESS / 5 节拍压缩）

### 段 0-A · 院中摘桂花（0-3s · Hook · SOURCING）

**节气物候提示**：桂花瓣飘落 + 清晨薄雾

**字幕卡**：白露·露凝白·桂花初绽

**姐演示**：姐执长竹竿（A014）轻敲桂枝，金瓣雨落蓝印花布（慢镜头 + ASMR「笃笃」+「簌簌」）

**弟捧哏**：弟先于姐在树下打滚蹭桂花，橘毛沾满金瓣（闯祸前置）

**妹的隐性功能**：妹蹲石阶抱大落叶，歪头看姐 = 任务锚点（观众跟着妹意识到"今天要做桂花"）

**时长**：3s

**画面要点**：弟四脚朝天蹭花 → 姐敲枝 → 花瓣纷纷扬扬

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。清晨院中薄雾未散，桂花树金黄细碎的花瓣沾着露珠。姐站在树下仰头观望，三花毛色与金桂交映；弟已经在树下打滚，橘色背脊滚了一身碎花瓣；妹蹲在石阶上抱着一片大落叶，歪头看姐。风过，桂花瓣纷纷扬扬落下，前景是沾着晨露的金瓣和石板上的露珠，中景是姐举竹竿的身影，背景是薄雾中的灰瓦白墙。整个场景约 3 秒钟，镜头随竹竿抬起慢慢上扬到桂枝顶端。

**叙事弧总结**：本段是任务推进型段落。情绪从平和（薄雾清晨）走向柔和（金瓣雨落）。

**[段 0-A → 段 0-B]**：搬家逻辑（场景从院中树下到厨房）。具体手法：声音带路——段 0-A 末尾「猫叫咪——」+「竹竿敲枝声余音」→ 段 0-B 开头「厨房里木勺碰陶罐的『咝咝』声先到 0.5 秒」，声音路标提前引导观众「我们要去厨房了」。路标：竹竿敲枝声余音。

### 段 0-B · 三花布收桂花（3-8s · 推进 · SOURCING）

**节气物候提示**：叶尖露珠 + 晨光斜照

**字幕卡**：晨露未干·三花布轻兜金桂

**姐演示**：姐用两只前爪轻提 A001 蓝印花布四角，步态缓慢优雅

**弟捧哏**：弟挤到前头把脸埋进桂花堆猛嗅 → 立刻打喷嚏把花瓣吹飞（闯祸类型 G·连续动态）

**妹的隐性功能**：妹缩脖子捂嘴偷笑（反应代理——与观众同步觉得好笑）

**时长**：5s

**画面要点**：姐捧布前行 → 弟抢嗅喷嚏 → 姐夺回 → 弟装无辜

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。姐小心翼翼把蓝印花布四角提起，兜着一兜新鲜桂花，前景是布兜里沾着露珠的金瓣堆，中景是姐捧着布前行，背景是弟凑过来鼻子猛嗅、妹也好奇踮脚看。晨光从竹篱笆缝隙斜照进来，露珠在叶尖折射。镜头跟着姐的步伐平稳移动，约 2 秒后弟挤过来把脸埋进桂花堆，连续猛嗅后突然打喷嚏，花瓣被吹得四散飞扬，镜头跟着吹飞的花瓣略略上抬；姐立刻一爪按住弟后脑勺推开，把桂花拢回布中，弟装无辜瞪眼歪头。中景里妹缩脖子捂嘴偷笑（5s）。

**叙事弧总结**：本段是弟搞怪被训型段落。情绪从平和走向严厉（姐夺回桂花）再回落到柔和（弟装无辜）。

**[段 0-B → 段 1]**：走路逻辑（同场景连续动作·仍在厨房）。具体手法：动作匹配——段 0-B 末尾「姐把桂花布兜放到灶台边」→ 段 1 开头「姐伸手从布兜里捧起桂花倒入陶罐」，「放布→倒入」动作连贯。路标：灶台边的陶罐（A008）。

### 段 1 · 厨房糖渍桂花（8-15s · 推进 · PROCESS）

**节气物候提示**：薄雾散尽·阳光透过窗棂

**字幕卡**：白砂糖慢熬·金桂入糖自成蜜

**姐演示**：姐执木勺在 A008 陶土陶罐中慢搅糖渍桂花（慢镜头 + ASMR「咝咝」+「啵」）

**弟捧哏**：弟偷舔糖渍桂花蜜（闯祸类型 G·动态连贯）

**妹的隐性功能**：妹站在灶台边看姐搅糖 → 鼓掌 = 任务锚点

**时长**：7s

**画面要点**：姐慢搅糖渍 → 弟探头凑近闻蜜 → 闻太猛打喷嚏糊一脸糖渍桂花蜜 → 妹鼓掌

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。厨房里光线柔和，姐把新鲜桂花倒入 A008 陶罐，加白砂糖，用木勺慢搅。镜头跟着木勺的圆弧运动在陶罐内壁缓缓转动，前景是罐内金黄糖渍桂花蜜（macro 特写·糖浆冒泡·桂花瓣在蜜中半透），中景是姐执木勺专注的表情，背景是阳光透过窗棂的斜光斑。约 3 秒后弟踮脚凑近罐边缘，鼻子凑到糖渍桂花蜜上猛嗅——闻得太急，连打三个喷嚏，糖渍桂花蜜喷到弟鼻头和胡须上，弟歪头甩脸（动态连贯·镜头持续跟随甩动）；妹在灶台边鼓掌蹦蹦跳跳（任务锚点·糖渍完成·7s）。

**叙事弧总结**：本段是任务推进型段落。情绪从平和（厨房晨光）走向柔和（糖渍完成·妹鼓掌庆祝）。

**[段 1 → 段 2]**：走路逻辑（同场景·仍在厨房案板前）。具体手法：视线匹配——段 1 末尾「姐回头看妹」→ 段 2 开头「姐视线落到案板上提前摆好的糯米粉与粘米粉」，视线引导观众看到下一动作的目标。路标：案板上糯米粉袋。

### 段 2 · 糖渍桂花蜜倒入糯米粉 + 揉粉 + 压花模（15-30s · 起因 · PROCESS）

**节气物候提示**：薄雾散尽·午间暖阳

**字幕卡**：蜜入粉中揉·秋日甜意成形

**姐演示**：姐把糖渍桂花蜜倒入糯米粉 + 粘米粉混合粉中 → 用木勺拌匀 → 双爪反复揉压 → 糖桂花均匀嵌入粉团 → 揪小剂子塞入**花形木模具**（梅花/桂花纹·带三猫爪印刻痕）→ 倒扣脱模 → 一块块**花形粉团生坯**整齐排列在案板上（**未蒸前是糯米粉混合面粉的乳白色质地·不是透明**）

**弟捧哏**：弟趁姐不注意伸舌头偷舔花形模具内壁残留糖渍 → 舌尖糊一层糯米粉 + 糖渍混合物（闯祸类型 A 食物粘嘴型变体·糊面粉·连贯动态）

**妹的隐性功能**：妹抱着花形小木模具哒哒跑过来递给姐（任务锚点·动作辅助）

**时长**：15s

**画面要点**：姐倒蜜入粉 → 揉粉 → 压花模 → 弟偷舔模具糊面粉 → 妹递模具

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。午间暖阳斜照厨房案板，姐把糖渍桂花蜜缓缓倒入糯米粉与粘米粉的混合粉堆中（macro 特写·金黄糖蜜拉丝坠入白粉堆·留下一个小坑·粉粒慢慢吸收蜜液变成乳黄），中景是姐用木勺搅拌，背景是阳光透过窗棂。然后姐用双爪反复揉压粉团（ASMR「噗噗」+「沙」），镜头跟着爪子的节奏平稳移动；糖渍桂花碎均匀嵌入粉团，粉团从干涩变得润泽。约 5 秒后姐揪出一小块粉团剂子，按入花形木模具（梅花/桂花纹·带三猫爪印刻痕），用木锤轻敲边缘，倒扣脱模——一块**乳白色的花形粉团生坯**落在案板上（**注意·未蒸前是糯米粉混合面粉的质地·乳白不透明·不是透光如玉**·那是蒸后的事）。镜头跟着脱模动作平移到案板上整齐排列的花形生坯，前景是花形生坯的乳白表面（macro·能看清花瓣纹路和爪印刻痕），中景是姐继续压模，背景是弟趁姐转身伸舌头偷舔花形模具内壁残留的糖渍混合物，舌尖瞬间糊一层白色糯米粉 + 金黄糖渍，弟瞪眼装无辜（动态连贯·镜头持续跟随弟的舌头运动·不停格）；妹抱着另一个花形小木模具哒哒跑过来递给姐（任务锚点·15s）。

**叙事弧总结**：本段是弟搞怪被训型段落。情绪从柔和（姐揉粉压模）走向严厉（姐回头瞪眼）再回落到柔和（妹递模具化解）。弟进入战损状态——舌糊面粉 = 段 3 钩子。

**[段 2 → 段 3]**：走路逻辑（同场景·仍在厨房案板前）。具体手法：动作匹配——段 2 末尾「姐把花形生坯码到案板边」→ 段 3 开头「姐把生坯一块块摆进蒸笼」，「码生坯→摆入蒸笼」动作连贯。路标：蒸笼。

### 段 3 · 上蒸笼 + 等蒸过程中弟妹抖音魔性舞蹈（30-45s · 主爆点 · PROCESS）

**节气物候提示**：午间阳光·桂花瓣飘入窗

**字幕卡**：蒸笼落灶·猫家等待时·才艺开演

**姐演示**：姐把花形生坯一块块摆入蒸笼 → 上灶蒸（动态连续·不停格）

**弟捧哏**：等待蒸的过程中，弟与妹开始抖音魔性舞蹈表演（闯祸类型 F·物理反转型·弟搞怪反转为才艺展示）

**妹的隐性功能**：妹与弟一起舞蹈（任务锚点 + 反应代理·观众同步觉得好玩·**D 类妹变体·首次妹主动参与协作才艺**）

**时长**：15s（含主爆点 5s 逗留）

**画面要点**：姐上灶 → 弟妹等蒸无聊 → 弟先开始扭屁股 → 妹跟上一起跳魔性舞 → 姐瞥一眼又转回去专心蒸 → 蒸气从笼缝冒出

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。午间阳光从窗棂斜照进厨房，姐把花形生坯一块块摆入蒸笼（前景是生坯入笼·能看清花形与爪印），上灶点火。约 5 秒后灶上蒸气开始从笼缝冒出，弟蹲在灶边打哈欠觉得无聊，妹也蹲在一旁抱着膝盖发呆。突然弟像是来了灵感，开始扭屁股扭腰，橘色尾巴甩来甩去——是抖音上很火的那种魔性舞蹈。妹先瞪大眼睛看，犹豫了 2 秒后也加入，兄妹俩在灶边并排扭屁股扭腰，弟的尾巴甩到妹的耳朵，妹甩耳朵躲避动作更夸张了，弟看到妹的躲避动作跳得更起劲（**v6.3 主爆点·动态连贯·镜头持续跟着舞蹈动作移动·不停格·5s 逗留**）。姐在灶台边瞥了一眼，耳朵抖了抖，又转回去专心看火，嘴角微不可察地翘了一下。中景是兄妹魔性舞蹈的连贯动作（前景是蒸笼缝隙冒出的蒸气形成的白雾），背景是灶火跳动。整个舞蹈过程持续约 5 秒，镜头随着弟的甩尾和妹的甩耳运动平移跟拍（15s）。

**叙事弧总结**：本段是协作回归型 + 弟搞怪反转才艺型段落。情绪从柔和（姐上灶）走向搞笑（弟妹魔性舞蹈）走向柔和（姐淡定看火）。v6 招牌互动 F·弟妹反向协作展示才艺——这是本期主爆点。

**[段 3 → 段 4]**：走路逻辑（同场景·仍在厨房灶台边）。具体手法：动作匹配——段 3 末尾「姐伸手揭笼盖」→ 段 4 开头「姐把笼盖掀到一边」，「揭盖→掀开」动作连贯。路标：笼盖掀起的蒸气。

### 段 4 · 揭盖唯美段（45-60s · 唯美段 · PROCESS）

**节气物候提示**：傍晚斜阳·炊烟袅袅

**字幕卡**：炊烟起时·花形桂花糕透光如玉

**姐演示**：姐揭笼盖 → 蒸汽腾起 → 花形桂花糕表面凝露 → **蒸后透光如玉**（从乳白生坯 → 蒸后变半透如玉·质地对比·慢镜头 + ASMR「咝——」+「叮」+ 呼吸点）

**弟捧哏**：弟伸爪想揭盖 → 姐用木勺柄轻敲弟手背 → 弟缩爪（v6 招牌动作·推开·动态 2 秒）

**妹的隐性功能**：妹递给姐蒸笼盖（任务锚点）

**时长**：15s

**画面要点**：弟想揭盖被敲 → 姐揭盖 → 蒸气腾起 → 花形桂花糕表面凝露透光如玉 → 弟想伸手摸 → 姐推开
