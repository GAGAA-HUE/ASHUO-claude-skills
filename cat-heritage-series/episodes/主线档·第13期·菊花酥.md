## 二、工艺段（COLD OPEN + SOURCING + PROCESS + 招牌结尾）

### 段 0 — COLD OPEN（踢门起床）：12s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。清晨卧室里，橘猫四仰八叉地躺在床上呼呼大睡，肚皮一起一伏。三花猫和小白猫站在床上，三三花猫抬起右前爪干脆利落地指向橘猫方向，发出短促"喵"指令声。小白猫立刻压低身体进入狩猎姿态，肚皮贴地尾巴僵直向橘猫鬼鬼祟祟移动。白猫猛地「噗」地跳到橘猫肚皮上，把橘猫瞬间压醒，进入子弹时间，橘猫双眼猛然睁开瞳孔瞬间收缩成细线眼白清晰可见面部进入惊醒态；第 3 秒面部肌肉开始扭曲嘴角向两侧咧开露出牙齿舌头微伸整张脸呈现被砸醒到痛苦的夸张表情，小帽失去支撑被面部肌肉震得微微弹起，第 4 秒下巴收紧颈部后侧肌肉隆起头部以慢动作开始向后仰起；第 4.5 秒头部完全仰起到极限角度嘴巴张开呈 O 形整张脸定格在难以置信表情上；第 5 秒帽子以慢动作飞出在空中翻转半圈；橘猫瞪大眼睛「喵！」一声弹起。妹妹骑在橘猫肚皮上开心地笑。三花猫看着妹骑弟的闹剧忍不住「喵」笑了一声（这是让弟弟起床开始干活的意思），用爪子点点门外示意弟弟起床。橘猫揉揉眼睛委屈地重新戴上小帽子从床上爬下来，背起小竹筐准备出门。

**叙事节拍**：

- **节拍 0-1·弟睡觉·姐妹门外**（3s）：橘猫四仰八叉躺在床上呼呼大睡，肚皮一起一伏。三花猫和小白猫站在卧室门外，三花猫用爪子比划「一二三」。
  - **三猫位置**：前景·中线 = 床 + 弟睡觉；中景偏右 = 姐在门外；中景偏左 = 妹在门外。
  - **ASMR**「弟打呼·呼噜·呼噜」+「三花姐数数·喵·喵·喵」
- **节拍 0-2·姐妹踢门·妹跳弟身压醒**（4s）：姐妹俩一起用后腿把门「砰」一声踢开。白猫蹿到床上「噗」跳到橘猫肚皮上。橘猫瞬间被压醒「喵！」一声弹起。
  - **三猫位置**：前景·中线床+弟被压；中景偏左妹骑弟；中景偏右姐站在床头柜上。
  - **ASMR**「踢门·砰」+「妹跳·噗」+ 弟惊叫「喵！」
- **节拍 0-3·妹骑弟摇铃铛·姐笑喵一声**（3s）：妹妹骑在橘猫肚皮上开心摇铃铛「叮叮」响。橘猫揉揉眼睛委屈。三花猫站在床头柜上看着这一幕忍不住「喵」笑了一声——这是让弟弟起床干活的意思。
  - **三猫位置**：前景·中线床+弟妹叠在一起；中景偏右姐在床头柜上。
  - **ASMR**「妹笑·嘻」+ 铃铛「叮·叮」+ 姐笑「喵」
- **节拍 0-4·姐指门外·弟爬下床背筐**（2s）：姐用爪子点点门外示意弟弟起床干活。橘猫委屈爬下床，背起小竹筐准备出门。
  - **三猫位置**：前景·中线床；中景偏右姐指门；前景·中线弟爬下床。
  - **ASMR**「姐指门·嗒」+「弟爬下床·沙」+「背筐·窸窣」

**叙事弧总结**：本段是「**弟懒睡→姐妹合力闹醒→妹主动参与→姐权威号令→全家出发**」的起床号令型 COLD OPEN。**姐笑喵一声**是本期「权威方温柔登场」的标志动作——姐不用打不用骂，笑着喵一声弟就知道该干活了。这是本期「错位」的起始——姐温柔权威 vs 弟体力担当 vs 妹气氛组。

### 段 1 — SOURCING 备料 + 三色染色：20s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。院子里，三花猫把面粉倒在石桌上挖出火山形小窝准备和面。橘猫背着小竹筐从画面右侧入画搬黄油块、面粉袋进进出出。小白猫抱着一颗刚采的菊花踮脚走到石桌旁把花递给姐姐。三花猫摸了摸小白猫的头然后把揉好的基础白色面团分成三块——第一块加南瓜粉染成橘色（弟款）、第二块保持原有的白色（妹款）、第三块加可可粉+南瓜粉染成三花色（黑白橘）（姐款）。三只染色面团排成一行。期间橘猫第二次背筐回来时偷咬了一口黄油，被三花猫发现后用爪子精准推开弟弟的脸。橘猫死猪不怕开水烫的小表情，脸扭曲着咀嚼黄油

**叙事节拍**：

- **节拍 1-1·姐和面·弟搬黄油·妹采菊花**（6s）：三花猫在石桌前用爪子把面粉堆成火山形小窝，准备打入鸡蛋和油。橘猫背着小竹筐从画面右侧入画，把黄油块搬到石桌旁。白猫抱着一捧刚采的菊花瓣从画面左侧踮脚入画。
  - **三猫位置**：前景·中线 = 三花猫 + 石桌；中景偏右 = 橘猫背筐入画；背景偏左 = 白猫抱菊花瓣踮脚（铃铛晃动）。
  - **ASMR**「面粉入堆·沙」+「黄油落地·咚」+ 弟气喘「呼·呼」+ 铃铛「叮」
- **节拍 1-2·姐分三块面团+三色染色**（6s）：三花猫把揉好的基础面团切成均等三块。第一块加可可粉揉成橘色（弟款·象征橘猫）。第二块保持原色（妹款·象征小白猫原本的白色——染色后会保持浅色）。第三块加紫薯粉+南瓜粉分两次揉染成三花色（姐款·异瞳三花纹）。三只染色面团排成一行晾着。
  - **三猫位置**：前景·中线 = 三花猫 + 三块面团（三色并排）；中景偏右 = 橘猫背第二筐入画围观；背景偏左 = 妹踮脚递花（铃铛晃动）。
  - **ASMR**「分面团·扑」+「可可粉揉入·沙沙」+「紫薯粉揉入·沙沙」+ 铃铛「叮」
- **节拍 1-3·弟偷咬黄油·姐推开脸·妹偷笑**（4s）：橘猫背第二筐回来时偷偷咬了一口黄油。三花猫头也没抬伸出爪子精准推开弟弟的脸，摇爪示意「放下」。妹妹在一旁捂住嘴偷笑。
  - **三猫位置**：前景·中线 = 姐伸手推弟；中景偏右 = 橘猫叼黄油被推开；背景偏左 = 妹捂嘴笑。
  - **ASMR**「姐推弟·啪」+ 弟委屈「呜」+ 妹笑「嘻」
- **节拍 1-4·姐盖布醒发·弟继续搬·妹继续递**（4s）：三花猫用湿布把三色面团盖好醒发。橘猫背着空竹筐小跑出画去搬第三块黄油。白猫继续踮脚递菊花瓣给姐（三色面团用菊花瓣继续装饰）。
  - **三猫位置**：前景·中线 = 三花猫盖布（沉浸式）+ 三色面团；中景 = 橘猫出画；背景偏左 = 妹继续递花。
  - **ASMR**「湿布盖面·扑」+「竹筐远去·沙沙」+ 铃铛「叮」

**叙事弧总结**：本段是「**姐和面→分三块→染色→弟妹协作**」的核心备料段。**染色工序**是本期最大特色——弟款橘色（可可粉）、妹款原色（保持白色）、姐款三花色（紫薯+南瓜双粉）三色面团为后续成品展示埋下视觉伏笔。弟款染色用可可粉是因为可可色最接近橘猫橘色——三花色用紫薯+南瓜是为了呈现异瞳三花的渐变效果。

### 段 2 — 起酥（水油皮+油酥叠被子）：18s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把三色染色后的水油皮面团用擀面杖擀成薄片，把冷藏好的原色油酥面团放在中间，然后像叠被子一样把水油皮的四边折起来包住油酥。擀面杖「咕噜咕噜」滚动，三花猫神情专注。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐姐擀面（其实在玩）。白猫抱着一罐白芝麻在旁边安静等待姐姐需要撒芝麻。三花猫把包好油酥的面团擀成长条再卷起来，重复「四折叠」四次。橘猫玩着玩着把擀面杖滚到地上，扑过去四脚朝天把擀面杖举起来不停的拍打（像是耍杂技）。三花猫叹了口气继续擀面。

**叙事节拍**：

- **节拍 2-1·姐擀三色水油皮·弟玩小擀面杖·妹等芝麻**（6s）：三花猫端坐石桌前，爪持擀面杖擀三色水油皮（橘色+白色+三花色）。擀面杖「咕噜咕噜」滚动。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐擀面（其实是玩）。白猫抱着一罐白芝麻蹲旁边。
  - **三猫位置**：前景·中线 = 三花猫 + 擀面杖 + 三色面皮；中景偏右 = 橘猫玩小擀面杖；背景偏左 = 白猫抱芝麻罐蹲坐。
  - **ASMR**「擀面杖·咕噜·咕噜」+「小擀面杖·咚咚」（弟玩）
- **节拍 2-2·姐包油酥·叠被子**（5s）：三花猫把原色油酥面团放在擀好的水油皮中间，把水油皮四边折起来包住油酥。动作如同叠被子般严谨——这是本期「四折叠」的核心工艺步骤。
  - **三猫位置**：前景·中线 = 三花猫 + 折叠面团；中景偏右 = 橘猫继续玩；背景偏左 = 白猫安静等。
  - **ASMR**「面团折叠·扑」+ 姐轻喵「喵」（方向示意）
- **节拍 2-3·弟玩掉擀面杖·装无辜**（3s）：橘猫玩着玩着把擀面杖滚到地上，自己蹲坐地上瞪着擀面杖装无辜。三花猫头也不抬继续擀面。
  - **三猫位置**：前景·中线三花猫继续擀面；中景偏右橘猫蹲在地上瞪擀面杖；背景偏左白猫探头看。
  - **ASMR**「擀面杖落地·咚」+ 弟心虚「喵呜」+ 妹笑「嘻」
- **节拍 2-4·姐卷起+重复「四折叠」四次·弟妹围观**（4s）：三花猫把包好油酥的面团擀成长条卷起来，再擀再卷，重复「四折叠」四次。橘猫和白猫蹲在桌旁围观，面团层次越来越多。
  - **三猫位置**：前景·中线 = 三花猫擀卷；中景偏右 = 橘猫围观；背景偏左 = 白猫围观。
  - **ASMR**「擀面杖·咕噜」+「卷起·扑」+ 远处菊花风「沙沙」

**叙事弧总结**：本段是「**姐沉浸式起酥 + 弟假装帮忙变玩 + 弟闯祸小插曲 + 三猫围观**」的平静推进型段落。起酥工序是本期唯美段的核心伏笔——「四折叠」四次是本期菊花酥层次分明的关键。
### 段 3 — 姐舞段（长固定镜头·治愈系拉伸舞）：22s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。这是一段**长固定镜头**：相机位置不变，背景是金黄稻田 + 远处的桂花树。前景·中线 = 三花猫戴着橙色腰带在跳一段治愈系拉伸舞——动作舒展缓慢（参考视频我会直接提供给seedance-director模型，。中景偏左 = 白猫铃铛开心地看着姐姐跳舞，身体跟着节拍轻轻摇晃。中景偏右（虚化背景）= 橘猫不停地进出画面——从右侧入画背着黄油块 / 面粉袋 / 南瓜粉袋 / 莲蓉盆 / 菊花瓣篮进进出出到左侧厨房里干活。这段最后，橘猫最后一次入画把一袋面粉放在地上，自己直接疲惫地躺在地上气喘吁吁「呼·呼·呼」，肚皮一起一伏。

**叙事节拍**：

- **节拍 3-1·长固定镜头建立·姐起舞**（6s）：固定镜头建立——背景金黄稻田 + 桂花树。前景·中线三花猫开始治愈系拉伸舞（动作一：双臂画圆缓缓向上伸展），橙色腰带飘起。中景偏左白猫抱铃铛开心摇晃。
  - **三猫位置**：前景·中线 = 三花猫跳舞；中景偏左 = 白猫抱铃铛看；中景偏右 = 背景虚化（弟尚未出现）。
  - **ASMR**「晨风·呼呼」+「姐脚步·嗒·嗒」+ 铃铛「叮·叮」+ 远处桂花风
- **节拍 3-2·姐转圈·弟第一次入画背黄油**（5s）：姐缓缓原地转圈一圈（动作二），橙腰带飘起来。弟从画面右侧入画背着黄油块小跑穿过虚化背景到左侧厨房方向。
  - **三猫位置**：前景·中线 = 三花猫转圈；中景偏左 = 白猫抱铃铛；中景偏右 = 弟背着黄油块跑过（虚化）。
  - **ASMR**「姐脚步·嗒·嗒」+「弟气喘·呼·呼」+「黄油块晃·咚·咚」+ 铃铛「叮」
- **节拍 3-3·姐侧身下腰·弟多次进出背南瓜粉/剥莲蓉**（6s）：姐侧身下腰再缓缓起身（动作三）。弟继续在虚化背景里进进出出——这次背着南瓜粉袋从右入画到左出画，下次抱着莲蓉盆从左入画到右出画（往返多次）。白猫继续跟着节拍摇铃铛。
  - **三猫位置**：前景·中线 = 三花猫下腰起身；中景偏左 = 白猫摇铃铛；中景偏右 = 弟多次进出（虚化）。
