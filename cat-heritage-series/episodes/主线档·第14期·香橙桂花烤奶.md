## 二、工艺段（COLD OPEN + SOURCING + PROCESS + 招牌结尾）
### 段 0 — COLD OPEN（弟扑蝶砸姐）：10s

李子柒式治愈系动物短片+周星驰无厘头喜剧桥段，主角为参考图中的三只猫猫。午后院子里，橘树结满了金黄的橙子。三花猫蹲在树荫下端着一杯冰可乐优哉游哉地喝，小白猫靠着三花猫也抱着一杯冰可乐，姐妹俩乘凉享受惬意午后。橘猫已经爬上树干，前爪正够到一颗橙子。突然一只凤尾蝶从眼前飞过，橘猫的眼睛瞬间被蝴蝶吸引——瞳孔放大、身子一晃、忘记自己在树上，前爪松开橙子伸出去扑蝶。结果扑了个空，重心一失，整只橘猫「哇啊——」惨叫着从树上直坠而下，一头栽在三花猫身上。三花猫「嗷！」一声惨叫被砸翻在地，冰可乐「哗啦」浇了她一身。三花猫猛地扑向橘猫在他身上打他，小白猫在旁边偷笑

**叙事节拍**：

- **节拍 0-1·姐树下喝可乐·妹靠姐乘凉·弟树上够橙**（3s）：午后院子橘树结满金黄橙子。三花猫蹲在树荫下端着冰可乐惬意喝，小白猫靠着三花猫也抱着一杯冰可乐。橘猫已经爬上树干，前爪正够到一颗橙子。
  - **三猫位置**：前景·中线 = 橘树 + 弟在树上；中景偏左 = 姐树下喝可乐；中景偏右 = 妹靠姐喝可乐（铃铛轻晃）。
  - **ASMR**「冰可乐气泡·嘶嘶」+「树叶·沙沙」+「弟爬树·沙沙」
- **节拍 0-2·蝴蝶飞过·弟忘记在树上·扑蝶失足**（2s）：凤尾蝶飞过橘猫眼前。橘猫瞳孔瞬间放大，伸爪扑蝶——前爪离开橙子，身子重心一失，整只橘猫从树上直坠而下「哇啊——」惨叫。
  - **三猫位置**：前景·中线 = 弟从树上坠下；中景偏左 = 姐树下抬头惊愕；中景偏右 = 妹抱可乐抬头看。
  - **ASMR**「弟惊叫·哇啊」+「树叶掉落·沙沙」+「蝴蝶翅膀·扑棱」
- **节拍 0-3·弟砸姐身上·可乐浇姐一身·姐被砸翻**（2s）：橘猫一头栽在三花猫身上。三花猫「嗷！」惨叫被砸翻在地，冰可乐「哗啦」浇了她一身。
  - **三猫位置**：前景·中线 = 姐被砸翻在地；中景偏右 = 弟趴在姐身上；背景偏左 = 妹抱可乐瞪大眼睛。
  - **ASMR**「弟砸姐·砰」+「可乐浇身·哗啦」+ 姐惨叫「嗷！」+ 妹惊叫「喵！」
- **节拍 0-4·姐翻身挠弟+啪啪两耳光·弟脸成河豚状**（2s）：三花猫翻身起来双爪抓起橘猫的脸「啪啪」两个耳光。橘猫整张脸被拍成河豚状——眼歪嘴斜舌头外吐一脸懵「喵呜？」，头上立刻肿起两个大包。
  - **三猫位置**：前景·中线 = 姐双爪抓弟脸拍；中景偏右 = 弟脸成河豚状；背景偏左 = 妹抱可乐偷笑。
  - **ASMR**「姐拍弟脸·啪啪」+「弟脑袋肿包·duang」+ 弟懵「喵呜？」+ 妹笑「嘻」
- **节拍 0-5·弟蹲地揉包·姐一身可乐气鼓鼓·妹继续偷笑**（1s）：橘猫蹲在地上揉着头上两个还在「duang duang」颤的大包。三花猫气鼓鼓低头看自己一身可乐水渍，尾巴炸成松鼠尾巴。小白猫抱着可乐一边偷笑一边摇铃铛。
  - **三猫位置**：前景·中线 = 弟蹲地揉包；中景偏左 = 姐一身可乐气鼓鼓；中景偏右 = 妹偷笑摇铃铛。
  - **ASMR**「弟揉包·沙」+「姐尾巴炸毛·呼」+ 妹铃铛「叮·叮」+ 微风「呼呼」

**叙事弧总结**：本段是「**姐妹树下乘凉·弟树上抓橙·蝴蝶飞来·弟扑蝶失足·砸姐一身可乐·姐拍脸挠头暴揍·妹偷笑**」的周星驰无厘头型 COLD OPEN。**反差核心**：姐妹的惬意午后（冰可乐+树荫+铃铛）vs 弟的天降灾星（扑蝶失忆·砸姐·可乐浇身·脑袋肿包）——悠闲与闯祸在同一画面里形成强反差。**关键设计**：弟的「**忘记自己在树上**」是典型无厘头设计——观众明知猫在树上，他自己却忘，扑蝶=本能战胜理智的瞬间，戏剧张力极强；姐被砸+可乐浇身是物理合理的双重暴击（砸+湿），所以姐的暴揍理由充分；**河豚脸**+**脑袋肿包**+**尾巴炸成松鼠**是猫的夸张表情三连，让整段视觉密度极高。**B 模板（姐护妹+担心弟）**：本段被「姐担心自己的可乐被浪费」这一新变体替代——姐既要揍弟又要护可乐（最后没护住），是设计宪法要求「B 模板变体灵活应用」的体现。

### 段 1 — SOURCING（采橙子·背牛奶·摘桂花）：18s

李子柒式治愈系动物短片+周星驰无厘头喜剧桥段设计，主角为参考图中的三只猫猫。院子里，橘猫用爪子抱着牛奶罐从画面右侧入画（背着小竹筐·弟标志物）。小白猫踩着小木凳用爪子够高处的桂花枝，把金黄的干桂花抖落在竹匾里晾着。三花猫在前景，从旁边的竹筐里挑出两颗最饱满的橙子切薄片。橘猫搬牛奶罐时橙子在竹筐里滚出来，橘猫赶紧用爪按住滚动的橙子不让它跑（机智感），接着嗷的一口把橙子塞进嘴巴里面，脸撑得鼓鼓的咀嚼，汁水从嘴角流出。

**叙事节拍**：

- **节拍 1-1·姐捡橙子堆筐·弟搬牛奶·妹踩凳够桂花**（5s）：三花猫蹲在地上用爪子把掉下来的橙子一个个捡起堆在竹筐里。橘猫用爪子抱着牛奶罐从画面右侧入画。白猫踩着小木凳用爪子够高处的桂花枝。
  - **三猫位置**：前景·中线 = 三花猫 + 地上橙子；中景偏右 = 橘猫抱牛奶罐入画；背景偏左 = 白猫踩凳够桂花（铃铛晃动）。
  - **ASMR**「橙子入筐·咚咚」+「牛奶罐·咚咚」+「桂花抖落·簌簌」+ 铃铛「叮」
- **节拍 1-2·姐挑橙·弟挡滚橙·妹够不到桂花求助**（6s）：三花猫挑出两颗最饱满的橙子准备切薄片。橘猫搬牛奶罐时橙子在竹筐里滚出来，橘猫赶紧用爪按住滚动的橙子不让它跑（机智感）。白猫在凳子上伸爪够高处的桂花枝够不到，「喵」一声求助姐姐。
  - **三猫位置**：前景·中线 = 三花猫挑橙；中景偏右 = 橘猫按橙不让滚；背景偏左 = 白猫踩凳够桂花求助（铃铛晃动）。
  - **ASMR**「橙子滚·咕噜」+「弟按橙·啪」+ 妹求助「喵」+ 铃铛「叮·叮」
- **节拍 1-3·姐帮妹压下桂花枝**（3s）：三花猫用木勺柄帮白猫把高处的桂花枝压下来。白猫开心地「喵」一声摇铃铛。
  - **三猫位置**：前景·中线 = 三花猫持木勺柄压枝；中景偏左 = 白猫接桂花（铃铛晃动）；背景偏右 = 橘猫继续按橙。
  - **ASMR**「姐压桂花枝·沙」+ 妹开心「喵」+ 桂花抖落「簌簌」+ 铃铛「叮」
- **节拍 1-4·三猫备料完成·姐姐开始切橙**（4s）：三花猫把挑好的两颗橙子放在案板上准备切片（一片煮一片放杯底）。橘猫继续按住竹筐里剩余的橙子不让滚。白猫抱着竹匾里收集的干桂花递给姐姐。
  - **三猫位置**：前景·中线 = 三花猫切橙；中景偏右 = 橘猫按橙；背景偏左 = 白猫递桂花（铃铛晃动）。
  - **ASMR**「切橙·沙沙」+ 弟按橙「啪」+「桂花入匾·簌簌」+ 铃铛「叮」

**叙事弧总结**：本段是「**三猫备料 + 弟机智按滚橙 + 妹求助被姐帮 + 三猫协作**」的协作型段落。**弟的机智感**：按住滚动的橙子不让它跑——这是设计宪法要求的「弟偷懒要有策略不能笨拙」的体现。**妹的主动参与**：踩凳够桂花 + 求助姐姐 + 接桂花 = 妹的主动习性体现。
### 段 2 — 干炒焙茶：14s

李子柒式治愈系动物短片+周星驰无厘头喜剧桥段设计，主角为参考图中的三只猫猫。厨房里，三花猫端坐在陶锅前，爪持木勺。陶锅微微加热，三花猫把 5 克乌龙茶倒进锅里，用木勺不断翻炒。茶叶在锅里「沙沙」作响，慢慢炒出浓郁的茶香味——这是本期唯美工艺的「干炒焙茶」高光时刻。橘猫蹲在灶台旁边探头偷闻茶香，结果脸凑太近被茶烟呛到「咳」了一声，三花猫用木勺柄推开弟的脸让他退后。白猫抱着一只空茶杯蹲在旁边眼巴巴看着锅里的茶叶。

**叙事节拍**：

- **节拍 2-1·姐微火热锅·弟妹围观**（3s）：陶锅微微加热。三花猫端坐灶台前爪持木勺。橘猫和白猫蹲在两侧围观。
  - **三猫位置**：前景·中线 = 三花猫 + 陶锅 + 木勺；中景偏右 = 橘猫围观；背景偏左 = 白猫抱空茶杯蹲坐。
  - **ASMR**「火焰·呼呼」+「木勺放锅·嗒」
- **节拍 2-2·姐倒乌龙茶·干炒出香**（5s）：三花猫把 5 克乌龙茶倒进锅里，用木勺不断翻炒。茶叶在锅里「沙沙」作响，慢慢炒出浓郁的茶香味。
  - **三猫位置**：前景·中线 = 三花猫干炒；中景偏右 = 橘猫凑近闻；背景偏左 = 白猫抱杯围观（铃铛轻晃）。
  - **ASMR**「茶叶入锅·沙」+「木勺翻炒·沙沙·沙沙」+「茶香升起·嗞」（茶香=嗅觉 ASMR）
- **节拍 2-3·弟凑太近被呛·姐推开脸**（3s）：橘猫蹲在灶台旁边探头偷闻茶香，结果脸凑太近被茶烟呛到「咳」了一声，三花猫用木勺柄推开弟的脸让他退后。弟缩回爪装无辜。
  - **三猫位置**：前景·中线三花猫推弟；中景偏右橘猫被呛缩回；背景偏左白猫捂嘴笑。
  - **ASMR**「弟呛·咳」+「姐推弟脸·啪」+ 弟装无辜「喵」+ 妹笑「嘻」+ 铃铛「叮」
- **节拍 2-4·姐继续干炒·弟妹围观等待**（3s）：三花猫继续用木勺干炒茶叶至茶香浓郁。橘猫和白猫蹲在旁边继续围观（弟这次乖乖保持距离）。
  - **三猫位置**：前景·中线三花猫继续干炒（沉浸式）；中景偏右橘猫围观；背景偏左白猫抱杯围观。
  - **ASMR**「木勺翻炒·沙沙」+「远处桂花风·沙沙」

**叙事弧总结**：本段是「**姐干炒乌龙茶·弟凑近被呛·姐推开·姐继续炒**」的协作回归型段落。**弟被茶烟呛**是 B 模板（推开脸+担心）的本期变体——姐用木勺柄推开弟的脸保护他不被呛到。**干炒焙茶**是本期「唯美段」的第一个高光——茶香升起的嗅觉 ASMR。

### 段 3 — 熬制焦糖：16s

李子柒式治愈系动物短片+周星驰无厘头喜剧桥段设计，主角为参考图中的三只猫猫。三花猫在炒香的茶底中小心倒入 5 克白砂糖，用木勺不断搅拌让糖融化。全程保持小火，白糖慢慢从白色颗粒融化成金黄透明的焦糖色——这是本期唯美工艺的「焦糖熬制」高光时刻。橘猫蹲在灶台旁边眼巴巴盯着锅里融化的焦糖，馋得「喵」叫了一声想伸出舌头偷舔，被三花猫用木勺柄精准推开弟的嘴脸担心他被烫到。白猫抱着一杯温水在旁边安静等待姐姐需要时加水。三花猫继续小火熬糖至焦糖色均匀无颗粒。

**叙事节拍**：

- **节拍 3-1·姐加白砂糖·小火熬制**（4s）：三花猫在炒香的茶底中小心倒入 5 克白砂糖，用木勺不断搅拌让糖融化。全程保持小火。
  - **三猫位置**：前景·中线 = 三花猫 + 陶锅 + 白砂糖；中景偏右 = 橘猫围观；背景偏左 = 白猫抱温水杯蹲坐。
  - **ASMR**「砂糖入锅·沙」+「木勺搅拌·沙沙·沙沙」+「火焰·呼呼」
- **节拍 3-2·姐熬至焦糖色·唯美高光**（4s）：白糖慢慢从白色颗粒融化成金黄透明的焦糖色——这是本期唯美工艺的「焦糖熬制」高光。三花猫神情专注用木勺看着。

## 七、本期关键设计要点

**1. 工艺特色（用户指定·反推流程）**：六道工序——干炒焙茶（5g 乌龙茶）→ 熬制焦糖（5g 白砂糖）→ 焦糖煎橙片 → 注奶煮奶茶（500ml 牛奶）→ 撒花增香（干桂花）→ 出锅装杯（杯底放橙片+撒桂花点缀）。**新中式调饮**的唯美工艺流程，每个工序都有对应的高光时刻。

**2. 开场设计**：姐妹树下喝可乐乘凉 → 弟树上够橙 → 蝴蝶飞过 → 弟扑蝶失足坠下 → 砸姐一身可乐 → 姐啪啪两耳光+挠头暴揍 → 弟脸成河豚+脑袋两肿包 → 妹偷笑 = 「**扑蝶的代价**」开场既符合工艺流程（要橙子做烤奶·橙子还在树上），又给戏剧冲突留空间（弟扑蝶失足=钩子）。**无厘头设计**：弟**忘记自己在树上**扑蝶，本能战胜理智的喜剧瞬间；姐被砸+可乐浇身的双重暴击物理合理；河豚脸+脑袋肿包+尾巴炸毛=猫的夸张表情三连。

**3. 三猫分工**：姐（工艺主讲·权威方）+ 弟（闯祸+体力担当·按橙+搬牛奶+递杯）+ 妹（主动参与·踩凳摘桂花+放杯底橙+接杯+蹭姐脸）。

**4. 弟的机智感**：段 1-2 弟机智按住滚动的橙子不让它跑（设计宪法要求「弟偷懒要有策略不能笨拙」的体现）。

**5. 妹设计升级**：踩凳够桂花 + 求助姐姐 + 接桂花 + 放杯底橙片 + 主动接杯 + 蹭姐脸 = 妹从「递东西+捂嘴笑」升级到「**主动参与工艺流程多个环节**」。

**6. B 模板高频应用**：因为烤奶工艺有多个高温危险点（茶烟/焦糖/焦糖溅/烤奶烫），所以 B 模板（推开脸+担心）在段 2/3/4/6 多次应用，每次形态不同——段 2 姐用木勺柄推开；段 3 姐用木勺柄推开嘴脸；段 4 姐未注意到（弟自己被溅）；段 6 姐吹奶递弟。**段 0 的 B 模板变体**：姐护可乐被毁（被砸+被浇身的双重暴击）→ 姐用啪啪两耳光+挠头暴揍弟（不是关心型而是报仇型 B 模板的合法变体）。

**7. 三款茶具视觉**：姐款（异瞳三花托着）+ 弟款（橘色猫爪印茶杯）+ 妹款（小白猫款白瓷杯）= 错位原理的视觉收尾。

**8. 不强调强闭环（用户反馈）**：本期按用户反馈**不要求强草蛇灰线**——弟款爪印茶杯只是「三款茶具」之一的视觉符号。弟被焦糖溅爪是轻量级后遗症（段 4-3 → 段 6-5 端杯时爪微缩）。
