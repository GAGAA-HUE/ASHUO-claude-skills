## 二、工艺段（COLD OPEN + SOURCING + PROCESS + 招牌结尾）

### 段 0 — COLD OPEN（扑蝴蝶）：10s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。午后的院子里，三花猫正在石桌上擀面，橘猫蹲在石桌旁被一只凤尾蝶吸引，悄悄伸出爪子扑过去，凤尾蝶轻巧地飞起，橘猫用力过猛直接扑倒三花猫。三花猫一身面粉翻身用爪子挠橘猫，橘猫蹲在地上装无辜。白猫蹲在旁边瞪大眼睛缩成一团。三花猫身上的面粉洒在刚擀好的水油皮上。

**叙事节拍**：

- **节拍 0-1·姐擀面·弟瞄蝴蝶**（3s）：三花猫端坐石桌前，爪持擀面杖擀水油皮。擀面杖在面皮上「咕噜咕噜」滚动。橘猫蹲在石桌另一侧，目光被一只凤尾蝶吸引。
  - **三猫位置**：前景·中线 = 三花猫 + 石桌 + 水油皮；中景偏右 = 橘猫蹲坐盯蝴蝶；背景偏左 = 白猫抱铃铛蹲坐。
  - **ASMR**「擀面杖·咕噜」+「凤尾蝶翅膀·扑棱」
- **节拍 0-2·弟扑蝶→扑倒姐**（3s）：凤尾蝶轻巧飞起，橘猫伸出爪子用力扑过去，结果扑到三花猫身上。三花猫被扑倒，爪里还攥着擀面杖。面粉撒了一桌。
  - **三猫位置**：前景·中线三花猫被扑倒；中景偏右橘猫趴在姐身上；背景偏左白猫瞪大眼睛缩成一团。
  - **ASMR**「弟扑·咚」+「面粉飞扬·扑」+ 姐惊叫「喵！」
- **节拍 0-3·姐翻身挠弟·弟装无辜**（3s）：三花猫翻身用爪子挠橘猫的脸，橘猫立刻蹲坐装无辜瞪眼歪头。三花猫身上和桌上全是面粉。
  - **三猫位置**：前景·中线三花猫翻身；中景偏右橘猫蹲坐装无辜；背景偏左白猫抱铃铛瞪眼。
  - **ASMR**「姐挠弟·沙沙」+ 弟装无辜「喵」+ 铃铛「叮」
- **节拍 0-4·面粉落在水油皮上**（1s）：桌上的面粉均匀洒在刚擀好的水油皮上。三花猫低头看着这块「意外装饰」的水油皮，叹了口气。
  - **三猫位置**：前景·中线石桌 + 撒了面粉的水油皮；三猫分别在画面周围。
  - **ASMR**「姐叹气·呼」+ 微风「呼呼」

**叙事弧总结**：本段是「**弟闯祸+姐反抗+弟装无辜+意外结果出现**」的 COLD OPEN 经典四拍。弟扑蝶扑倒姐撒一身面粉——这是本期「草蛇灰线」的**起因**，面粉将参与后续茶花酥的「白霜装饰」形成逻辑闭环。

### 段 1 — SOURCING 备料：22s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫用爪子把面粉倒在石桌上挖出火山形小窝，准备打入鸡蛋。橘猫背着小竹筐从画面右侧入画，把黄油块搬到石桌旁，又小跑出画去搬第二块。白猫抱着一捧刚采的茶花瓣轻轻踮脚走到石桌旁，把花瓣递给姐姐。期间橘猫第二次背筐回来时偷咬了一口黄油，被三花猫发现后用爪子精准推开弟弟的脸并摇头示意，妹妹在旁边捂住嘴偷笑。三花猫继续在前景揉面，橘猫只好委屈地把黄油放回桌角，背着竹筐又小跑出画去搬第三块黄油。

**叙事节拍**：

- **节拍 1-1·姐挖火山窝·弟搬黄油**（6s）：三花猫在石桌前用爪子把面粉堆成火山形小窝，准备打入鸡蛋。橘猫背着小竹筐从画面右侧入画，把第一块黄油搬到石桌旁。
  - **三猫位置**：前景·中线 = 三花猫 + 石桌；中景偏右 = 橘猫背筐入画；背景偏左 = 白猫蹲坐抱茶花。
  - **ASMR**「面粉入堆·沙」+「黄油落地·咚」+ 弟气喘「呼·呼」
- **节拍 1-2·妹踮脚递茶花瓣**（4s）：白猫踮起后脚把茶花瓣一片一片递给三花猫，铃铛随动作「叮叮」轻响。三花猫接过花瓣叠在桌角。
  - **三猫位置**：前景·中线 = 姐接茶花瓣；中景偏右 = 橘猫背第二块入画；背景偏左 = 妹踮脚递花（铃铛晃动）。
  - **ASMR**「花瓣相叠·簌簌」+ 铃铛「叮·叮」
- **节拍 1-3·弟偷咬黄油·姐推开脸·妹偷笑**（5s）：橘猫背第二筐回来时偷偷咬了一口黄油。三花猫头也没抬伸出爪子精准推开弟弟的脸，摇爪示意「放下」。妹妹在一旁捂住嘴偷笑。
  - **三猫位置**：前景·中线 = 姐伸手推弟；中景偏右 = 橘猫叼黄油被推开；背景偏左 = 妹捂嘴笑。
  - **ASMR**「姐推弟·啪」+ 弟委屈「呜」+ 妹笑「嘻」
- **节拍 1-4·姐揉面·弟继续搬·妹继续递**（7s）：三花猫继续在前景专注揉面，把面粉和茶花瓣揉成彩色面团。橘猫背着空竹筐小跑出画去搬第三块黄油。白猫继续踮脚递茶花瓣。
  - **三猫位置**：前景·中线 = 三花猫揉面（沉浸式）；中景 = 橘猫出画；背景偏左 = 妹继续递花。
  - **ASMR**「面团揉捏·咂咂」+「竹筐远去·沙沙」+ 铃铛「叮」

**叙事弧总结**：本段是「**姐沉浸式备料 + 弟妹各司其职 + 弟偶尔闯祸**」的协作型段落。三猫纵深清晰——姐前景揉面、弟中景搬运、妹背景递花瓣，全程 ≥2 只猫同框。

### 段 2 — 起酥（水油皮+油酥）：18s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把揉好的水油皮面团用擀面杖擀成薄片，把冷藏好的油酥面团放在中间，然后像叠被子一样把水油皮的四边折起来包住油酥。擀面杖「咕噜咕噜」滚动，三花猫神情专注。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐姐擀面（其实在玩）。白猫抱着一杯温水在旁边安静等待姐姐需要加水。三花猫把包好油酥的面团擀成长条再卷起来，重复三次。橘猫玩着玩着把擀面杖滚到地上，自己蹲坐地上瞪着擀面杖装无辜。三花猫叹了口气继续擀面。

**叙事节拍**：

- **节拍 2-1·姐擀水油皮·弟玩小擀面杖·妹等温水**（6s）：三花猫端坐石桌前，爪持擀面杖擀水油皮。擀面杖「咕噜咕噜」滚动。橘猫蹲在画面一角用爪子抱着一根小擀面杖假装帮姐擀面（其实是玩）。
  - **三猫位置**：前景·中线 = 三花猫 + 擀面杖；中景偏右 = 橘猫玩小擀面杖；背景偏左 = 白猫抱温水杯蹲坐。
  - **ASMR**「擀面杖·咕噜·咕噜」+「小擀面杖·咚咚」（弟玩）
- **节拍 2-2·姐包油酥·折叠**（4s）：三花猫把油酥面团放在擀好的水油皮中间，把水油皮四边折起来包住油酥。动作如同叠被子般严谨。
  - **三猫位置**：前景·中线 = 三花猫 + 折叠面团；中景偏右 = 橘猫继续玩；背景偏左 = 白猫安静等。
  - **ASMR**「面团折叠·扑」+ 姐轻喵「喵」（方向示意）
- **节拍 2-3·弟玩掉擀面杖·装无辜**（4s）：橘猫玩着玩着把擀面杖滚到地上，自己蹲坐地上瞪着擀面杖装无辜。三花猫头也不抬继续擀面。
  - **三猫位置**：前景·中线三花猫继续擀面；中景偏右橘猫蹲在地上瞪擀面杖；背景偏左白猫探头看。
  - **ASMR**「擀面杖落地·咚」+ 弟心虚「喵呜」+ 妹笑「嘻」
- **节拍 2-4·姐卷起+重复三次·弟妹围观**（4s）：三花猫把包好油酥的面团擀成长条卷起来，再擀再卷，重复三次。橘猫和白猫蹲在桌旁围观，面团层次越来越多。
  - **三猫位置**：前景·中线 = 三花猫擀卷；中景偏右 = 橘猫围观；背景偏左 = 白猫围观。
  - **ASMR**「擀面杖·咕噜」+「卷起·扑」+ 远处桂花风「沙沙」

**叙事弧总结**：本段是「**姐沉浸式起酥 + 弟假装帮忙变玩 + 弟闯祸小插曲 + 三猫围观**」的平静推进型段落。起酥工序是本期唯美段的核心伏笔——弟妹围观正是为段 3 压模蒙太奇做铺垫。
### 段 3 — 压模蒙太奇段：24s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把起酥好的面团擀成 1 厘米厚的薄片，用茶花形状的木模压出花形，再用小刀修整边缘，把压好的茶花酥生坯整齐排在烤盘里。橘猫和白猫蹲旁边认真看，橘猫伸手想按模子想帮忙，被三花猫用爪子推开手背。妹妹递上一小撮茶花瓣，三花猫用花瓣装饰茶花酥的中央。橘猫耐不住性子趁姐递花瓣时偷偷按了一下模子，结果压出一个小小的橘猫爪印形状的「茶花酥」。三花猫看了叹了口气把「弟款茶花酥」也放在烤盘边角。三花猫继续在前景专注压模。

**叙事节拍**：

- **节拍 3-1·姐擀薄片·压茶花模**（5s）：三花猫把起酥好的面团擀成 1 厘米厚的薄片，用茶花形状的木模轻轻压下，「咯噔」一声花形出现。橘猫和白猫蹲旁边认真看。
  - **三猫位置**：前景·中线 = 三花猫 + 木模；中景偏右 = 橘猫蹲坐看；背景偏左 = 白猫蹲坐看。
  - **ASMR**「擀面杖·咕噜」+「木模压下·咯噔」+ 微风「呼呼」
- **节拍 3-2·姐修边·弟伸手按模被推开**（4s）：三花猫用小刀修整茶花酥边缘。橘猫忍不住伸手想帮忙按模子，三花猫用爪子轻轻推开弟弟的手背。
  - **三猫位置**：前景·中线三花猫修边；中景偏右橘猫伸手被推开；背景偏左白猫安静看。
  - **ASMR**「小刀修边·沙沙」+「姐推弟手·啪」+ 弟委屈「呜」
- **节拍 3-3·妹递茶花瓣装饰**（4s）：妹妹轻轻把一小撮茶花瓣递给姐姐。姐姐用花瓣在茶花酥中央装饰成花蕊。
  - **三猫位置**：前景·中线 = 三花猫 + 茶花酥；中景偏右 = 橘猫围观；背景偏左 = 白猫递花瓣（铃铛晃动）。
  - **ASMR**「花瓣点缀·簌簌」+ 铃铛「叮」+ 远处桂花风「沙沙」
- **节拍 3-4·弟偷偷按模→压出「弟款爪印」**（6s）：橘猫趁姐姐递花瓣时偷偷伸手按了一下模子。结果压出一个小小的橘猫爪印形状的茶花酥。三花猫回头看见，叹了口气。
  - **三猫位置**：前景·中线三花猫回头；中景偏右橘猫蹲坐装无辜（身后是爪印茶花酥）；背景偏左白猫捂嘴笑。
  - **ASMR**「木模压下·咯噔」+ 弟心虚「喵」+ 姐叹气「呼」+ 妹笑「嘻」
- **节拍 3-5·姐把弟款茶花酥放边角·继续压模**（5s）：三花猫叹了口气把「弟款爪印茶花酥」放在烤盘边角。重新开始压下一个标准的茶花酥。
  - **三猫位置**：前景·中线三花猫继续压模（沉浸式）；画面一角弟款茶花酥静静躺在烤盘边角。
  - **ASMR**「木模连续压·咯噔·咯噔」+ 远处桂花风

**叙事弧总结**：本段的情绪线是「**任务推进→弟越界→弟闯小祸→姐宽容接纳→姐继续干活**」的「协作回归型」变体。弟的「爪印茶花酥」是本期最重要的「草蛇灰线」伏笔——这块茶花酥将在段 5 出炉时承担重要闭环作用。

### 段 4 — 入炉烤制：14s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把摆满茶花酥生坯的烤盘端到石桌上。橘猫和白猫帮忙用爪子轻轻托着烤盘两边。三花猫打开烤箱门（烤箱门自动向下翻开），把烤盘送进烤箱，关上烤箱门。三花猫蹲在烤箱前看火候，橘猫和白猫也蹲在旁边盯着烤箱。三花猫用蒲扇轻轻扇风。橘猫趁姐扇风时偷偷伸手想摸烤箱门，被三花猫用蒲扇轻轻拍了一下爪子。三花猫继续蹲在烤箱前用蒲扇扇风，神情专注。

**叙事节拍**：

- **节拍 4-1·三猫共搬烤盘入炉**（4s）：三花猫用爪子端起烤盘，橘猫和白猫分别用爪子轻轻托着烤盘两边。三猫一起把烤盘送进烤箱。
  - **三猫位置**：前景·中线 = 三花猫 + 烤盘；中景偏右 = 橘猫托盘；背景偏左 = 白猫托盘（铃铛晃动）。
  - **ASMR**「烤盘落地·咚」+「烤箱门·咔嗒」+ 远处桂花风
- **节拍 4-2·姐蹲烤箱看火候·弟妹围观**（4s）：三花猫蹲在烤箱前，爪持蒲扇轻轻扇风，神情专注。橘猫和白猫也蹲在两侧盯着烤箱门看。
