### 段 0+1（0-15s）· Hook + 推进 · 穿串

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。寒露清晨，院中柿子树挂了几颗早红，草叶尖还凝着露水。姐蹲在石灶边的竹筐前，筐里盛着刚从后院摘来的红山楂。弟趁姐不注意，叼起一颗山楂就想往篱笆外跑，姐头也不回，尾巴一扫把弟拍了个趔趄。妹坐在竹筐另一侧，怀里抱着一小把竹签，歪头看着姐，像是等任务信号。

- **节拍 1-1·弟偷山楂被姐拍**（0-3s）：弟叼起一颗红山楂转身要跑，姐尾巴从侧面扫中弟脸颊，山楂落地滚到妹脚边。
  - **三猫位置**：前景 = 弟+落地方的山楂；中景 = 姐+竹筐；背景 = 妹+小竹签堆。
  - **ASMR**「竹筐轻响」+「山楂落地咕噜」+ 猫叫「喵呜」
- **节拍 1-2·姐眼神公布任务**（3-8s）：姐用爪子把山楂拨回筐中，抬头看向妹，妹立刻把怀里竹签往前推了推，尾巴尖轻摆。
  - **三猫位置**：前景 = 姐爪子+山楂；中景 = 妹+竹签；背景 = 石灶+糖锅。
  - **ASMR**「竹签碰撞」+「草叶露水滴落」+ 猫叫「咪」
- **节拍 1-3·姐弟穿串弟偷吃**（8-15s）：姐用嘴叼起竹签穿山楂，弟假装递山楂却偷偷把一颗塞进嘴里，腮帮子鼓起，姐用竹签头轻敲弟额头。
  - **三猫位置**：前景 = 姐+竹签+山楂串；中景 = 弟嘴里含山楂；背景 = 妹抱着竹签看。
  - **ASMR**「竹签穿果脆响」+「弟咀嚼声」+ 猫叫「嗷」

- **节拍 2-1·姐熬糖搅拌**（15-20s）：姐立在灶边，用前爪按住一根木棍在糖锅里匀速画圈，糖液由白转黄再泛起琥珀光。

### 段 3（25-40s）· 主爆点 · 冰糖舌 + 姐解围

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。弟的舌头粘着一块晶莹琥珀糖，甩头甩不掉，越甩糖丝拉得越长。妹惊得捂住嘴，眼睛瞪得溜圆。姐急忙放下木棍，用爪子按住弟下巴，另一只爪子捏住糖块边缘轻轻一掰，糖块脱落，弟的舌头重获自由，却还回味地咂咂嘴。

- **节拍 3-1·弟甩头糖丝拉长**（25-30s）：弟原地转圈甩头，舌头上的琥珀糖块甩出一道晶莹糖丝，在晨光里闪闪发亮。

  - **ASMR**「糖丝轻颤」+「弟甩头喘息」+ 猫叫「嗷呜嗷呜」
- **节拍 3-2·表情包定格**（30-33s）：弟定格在歪头张嘴姿势，舌头尖还粘着一小块糖，眼神无辜又惊慌。
  - **三猫位置**：前景 = 弟（单猫特写）；中景 = 无；背景 = 模糊糖锅。
  - **ASMR**「糖块反光」+「弟粗喘」+ 猫叫「喵？」
- **节拍 3-3·姐替妹出头教训弟**（33-37s）：姐从弟身后跃起，一爪拍在弟后脑勺上，弟趴地装无辜；姐把妹往自己身侧拨了拨，防止弟乱撞。
  - **三猫位置**：前景 = 姐+弟；中景 = 妹被姐拨到安全位；背景 = 糖锅。

  - **三猫位置**：前景 = 姐爪+糖块；中景 = 弟；背景 = 妹歪头。
  - **ASMR**「糖块脆裂」+「弟咂嘴」+ 猫叫「呼噜」

### 段 4（40-55s）· 唯美工艺展示 · 蘸糖拉丝

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。寒露斜阳穿过柿子树，在石灶上投下斑驳光斑。姐优雅地拎起一串山楂，在琥珀色糖液表面轻轻一蘸、一提，糖液瞬间在果面挂出一层晶莹脆壳，拉出细长糖丝。弟蹲在一边，小心翼翼地把空竹签递到姐手边，不敢再捣乱。妹仰头看糖丝，小脑袋跟着糖丝移动。

- **节拍 4-1·姐蘸糖提丝**（40-45s）：姐前爪捏住竹签尾端，将山楂串斜插入糖锅，一提一转，糖液均匀裹上果面，拉出透明糖丝。
  - **三猫位置**：前景 = 糖锅+姐前爪+山楂串；中景 = 姐；背景 = 弟递竹签。
  - **ASMR**「糖液流淌」+「糖丝轻断」+ 猫叫「嗯」
- **节拍 4-2·三串糖葫芦成型**（45-50s）：姐把蘸好糖的山楂串架在竹签架上，三串并排，糖壳在斜阳下泛着琥珀光，弟捧哏式递上第三根竹签。
  - **三猫位置**：前景 = 糖葫芦+竹签架（A011）；中景 = 姐；背景 = 弟+竹签。
  - **ASMR**「竹签架轻响」+「糖壳微裂」+ 猫叫「喵」

  - **三猫位置**：前景 = 妹+粘糖丝的爪垫；中景 = 糖葫芦；背景 = 姐+弟。
  - **ASMR**「糖丝粘爪轻响」+「妹轻哼」+ 猫叫「咪？」

- **节拍 5-1·冲突定格**（55-60s）：弟扑向竹签架咬住糖葫芦，冰糖壳粘牙，弟张嘴想拔却拔不出，前爪悬空乱蹬。
  - **三猫位置**：前景 = 弟+糖葫芦+竹签架；中景 = 姐转身；背景 = 妹后退。
  - **ASMR**「糖壳脆响」+「弟闷哼」+ 猫叫「嗷——」
- **节拍 5-2·克制惩罚**（60-68s）：姐走到弟身后，前爪按住弟尾巴根定格两秒，弟不敢再蹬，眼神从得意变委屈。
  - **三猫位置**：前景 = 姐爪+弟尾巴；中景 = 弟+粘牙糖葫芦；背景 = 妹安静坐。
  - **ASMR**「尾巴被按住轻响」+「弟低声呜咽」+ 猫叫「呜」
- **节拍 5-3·平静收束**（68-75s）：姐松开尾巴，弟乖乖蹲好，三猫并排坐在竹签架前，微风带下一片柿子叶落在妹头顶。
  - **三猫位置**：前景 = 三串糖葫芦；中景 = 三猫并排静坐；背景 = 柿子树+斜阳。
  - **ASMR**「微风叶落」+「蝉鸣渐弱」+ 猫叫「呼噜」
