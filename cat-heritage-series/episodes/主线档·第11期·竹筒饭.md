## 二、工艺段（COLD OPEN + SOURCING + PROCESS + 招牌结尾）

### 段 0 — COLD OPEN（已经在做）：12s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。橘猫在吭哧吭哧的砍竹子，夏天，姐姐妹妹在旁边撑着伞喝着冰可乐十分悠闲，白猫可可爱爱的挥拳鼓励黄毛弟，终于竹子被砍倒，但是落下的竹叶洒了三花猫一身，白猫在旁边笑了起来，三花猫有些生气的给了橘猫一巴掌，橘猫委屈巴巴。

**叙事节拍**：

- **节拍 0-1·三猫各忙各**（4s）：夏日午后竹林边，橘猫挥柴刀砍竹（中景偏前·主操作位），三花猫与白猫并排撑伞喝冰可乐（背景偏左），白猫时不时挥拳给橘猫加油。橘猫挥刀「咚·咔」，冰可乐气泡「嘶」。
  - **三猫位置**：中景偏前 = 橘猫挥刀；背景偏左 = 姐+妹撑伞（围裙+铃铛可见）。
  - **ASMR**「柴刀砍竹·咚·咔」+「冰可乐·嘶」
- **节拍 0-2·竹倒竹叶洒姐**（3s）：竹子终于被砍倒，向画面左侧倾倒时竹叶纷纷扬扬飘落，洒了三花猫一身。三花猫伞下一脸米色竹叶。橘猫举着柴刀愣住。白猫忍不住「嘻」地笑了一声。
  - **三猫位置**：前景·中线 = 倒下竹子 + 竹叶飞散；中景偏右 = 橘猫举刀愣；背景偏左 = 姐身上沾竹叶 + 妹笑。
  - **ASMR**「竹倒·喀啦」+「竹叶飘落·沙沙」+ 妹笑「嘻」
- **节拍 0-3·姐打弟·弟委屈**（3s）：三花猫放下可乐碗，伸出爪子朝橘猫后脑勺轻轻拍了一下。橘猫立刻蹲坐在地上眼巴巴地「喵呜」一声，露出委屈巴巴的表情。妹妹在一旁摇铃铛笑得前仰后合。
  - **三猫位置**：前景·中线 = 姐伸爪打弟；中景偏右 = 橘猫蹲坐委屈；背景偏左 = 妹笑。
  - **ASMR**「爪子拍脑门·啪」+ 弟委屈「喵呜」+ 铃铛「叮叮」+ 远处知了「知了·知了」

**叙事弧总结**：本段是「**任务进展 + 弟闯祸 + 姐制止 + 弟装委屈**」的 COLD OPEN 经典四拍。画面信息密度高（一段里塞进三个三猫位置变化），同时三猫各有戏份。

### 段 1 — SOURCING 备料：22s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫在院子石桌前泡糯米，面前摆着木盆、粽叶和小竹篓，三花猫专注地用手把糯米淘洗干净倒进木盆里。橘猫背着家里的竹筐（弟标志物）从画面右侧入画把糯米袋搬到石桌旁，又从左侧出画去搬第二袋，来回跑得气喘吁吁。白猫摇着铃铛踮起脚把粽叶一片一片递给姐姐，铃铛声「叮叮」轻响。期间橘猫第二次背筐回来时嘴馋偷偷叼起一片粽叶想啃，被三花猫发现后用爪子推开弟弟的脸并摇头示意，妹妹在旁边捂住嘴偷笑。橘猫只好委屈地把粽叶放回去，背着竹筐又小跑出画去搬第三袋糯米。三花猫继续在前景泡米。

**叙事节拍**：

- **节拍 1-1·姐泡米·弟妹搬运准备**（8s）：三花猫端坐石桌前，双手（爪）捧米放入木盆，加井水淘洗。橘猫背着竹筐第一次从画面右侧入画把糯米袋放下，转身从左侧出画去搬第二袋。白猫蹲在石桌左侧举着一叠粽叶等待。
  - **三猫位置**：前景·中线 = 三花猫 + 木盆；中景 = 橘猫背筐往返；背景偏左 = 白猫举粽叶。
  - **ASMR**「糯米入水·哗啦」+「竹筐落地·咚」+ 弟气喘「呼·呼」
- **节拍 1-2·妹踮脚递粽叶·铃铛响**（4s）：白猫踮起后脚把粽叶一片一片递给三花猫，铃铛随动作「叮叮」轻响。三花猫接过粽叶叠在桌角。
  - **三猫位置**：前景·中线 = 姐接粽叶；中景偏右 = 橘猫背第二袋入画；背景偏左 = 妹踮脚递粽叶（铃铛晃动）。
  - **ASMR**「粽叶相叠·簌簌」+ 铃铛「叮·叮」
- **节拍 1-3·弟偷叼粽叶·姐推开·妹偷笑**（5s）：橘猫背第二袋回来放下时，偷偷叼起桌角一片粽叶想啃。三花猫头也没抬伸出爪子精准推开弟弟的脸，摇爪示意「放下」。妹妹在一旁捂住嘴偷笑。橘猫把粽叶放回桌角。
  - **三猫位置**：前景·中线 = 姐伸手推弟；中景偏右 = 橘猫叼粽叶被推开；背景偏左 = 妹捂嘴笑。
  - **ASMR**「姐推弟·啪」+ 妹笑「嘻」+ 弟委屈「呜」
- **节拍 1-4·弟继续搬·姐继续泡米·妹继续递**（5s）：橘猫背着空竹筐小跑出画去搬第三袋。三花猫继续在前景专注泡米，加井水再次淘洗。白猫继续踮脚递粽叶，铃铛轻响。
  - **三猫位置**：前景·中线 = 三花猫泡米（沉浸式）；中景 = 橘猫出画；背景偏左 = 妹继续递粽叶。
  - **ASMR**「竹筐远去·沙沙」+「井水·哗啦」+ 铃铛「叮」

**叙事弧总结**：本段是「**姐沉浸式干活 + 弟妹各司其职 + 弟偶尔闯祸**」的协作型段落。三猫纵深清晰——姐前景泡米、弟中景搬运、妹背景递粽叶，全程 ≥2 只猫同框。

### 段 2 — 砍竹去青：18s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三只猫回到竹林边，橘猫持柴刀把砍好的竹子一节节锯开去掉青皮，每锯一节就用力甩一下柴刀甩掉竹屑。三花猫蹲在弟弟身侧用木勺接住流下的竹沥，木勺满一勺就倒进旁边的小木桶。白猫抱着小刀安静地修整竹节边缘的毛刺。橘猫用力过猛一片竹屑飞起迷了自己的眼，连打两个喷嚏差点把刀甩飞，三花猫放下木勺用爪子按住弟弟的肩膀让他别动，妹妹立刻递上干净的粽叶帮弟弟擦眼睛。三花猫继续在前景用木勺接竹沥，橘猫眯着眼继续锯竹，白猫继续修毛刺。

**叙事节拍**：

- **节拍 2-1·弟锯竹·姐接竹沥·妹修毛刺**（8s）：橘猫（中景偏右）持柴刀锯开竹节青皮，每锯一节用力甩刀甩掉竹屑。三花猫（前景偏左）蹲弟弟身侧用木勺接住流下的竹沥，每满一勺倒进小木桶。白猫（背景偏右）安静地持小刀修整竹节边缘毛刺，坐姿静态。
  - **三猫位置**：前景偏左 = 三花猫蹲接竹沥；中景偏右 = 橘猫锯竹；背景偏右 = 白猫修毛刺（铃铛静止）。
  - **ASMR**「柴刀锯竹·嘶·嘶·咔」+「竹沥入勺·滴答」+「小刀修毛刺·沙沙」
- **节拍 2-2·弟被竹屑迷眼·连打喷嚏**（3s）：橘猫用力过猛一片竹屑飞起钻进自己的眼，连打两个喷嚏差点把刀甩飞。他眯着眼用爪子揉眼。
  - **三猫位置**：中景偏右的橘猫突然停手揉眼；前景偏左的三花猫抬头。
  - **ASMR**「哈啾·哈啾」+ 弟惊叫「喵呜」
- **节拍 2-3·姐按住弟肩·妹递粽叶擦眼**（4s）：三花猫放下木勺，伸出爪子按住弟弟的肩膀让他别动，妹立刻从竹筒旁抽出一片干净的粽叶递到姐姐爪边。三花猫接过粽叶轻轻帮弟弟擦眼。橘猫眯着眼乖乖不动。
  - **三猫位置**：前景·中线 = 三花猫按住弟肩+接过粽叶；中景偏右 = 橘猫眯眼被擦；背景偏右 = 妹递粽叶（铃铛晃动）。
  - **ASMR**「姐按弟肩·嗒」+「粽叶擦眼·沙沙」+ 铃铛「叮」
- **节拍 2-4·姐继续接竹沥·弟继续锯·妹继续修**（3s）：擦完眼后三花猫回到木勺边继续接竹沥，橘猫眯着眼继续锯竹（小心一些了），白猫继续安静修毛刺。三猫各归各位。
  - **三猫位置**：前景·中线 = 三花猫接竹沥；中景偏右 = 橘猫锯竹；背景偏右 = 白猫修毛刺。
  - **ASMR**「柴刀锯竹·嘶·咔」+「竹沥入勺·滴答」

**叙事弧总结**：本段是「**三猫协作 + 弟小失误 + 姐替弟解围 + 回归协作**」的平静推进型段落。借段 3「弟面壁扭舞」前的过渡节拍，让段 3 的爆发有铺垫。三猫在前景/中景/背景形成清晰的纵深。

### 段 3 — 装米封口（蒙太奇段）：24s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫在堂屋木桌前，爪持木勺把泡好的米装入竹筒，第一层米沙沙滑入，木勺柄轻轻压实，第二层米继续装入压实。橘猫和白猫一开始蹲旁边认真看，然后橘猫开始犯馋，将脑袋伸了过去想吃，但是够不到，伸出爪子拨动，结果将竹筒打翻。米从竹筒口溢出洒在木桌上。白猫幸灾乐祸的喵了一声，三花猫瞬间转头盯橘猫，橘猫立刻蹲角落面壁，但耐不住性子开始站起来扭腰跳舞（魔性的抖音舞蹈），旁边的小白猫被吸引了过去也开始跳舞。三花猫沉浸式的在前景干活。

**画面细化（叙事节拍）**：

- **节拍 3-1·专注装米**（6s）：三花猫端坐木桌前，爪持木勺舀米入竹筒。第一层米沙沙滑入，木勺柄轻压；第二层米同样压实。木勺与竹筒口碰撞「咚咚」。三花猫围裙整洁（姐标志物），专注神情。橘猫与白猫蹲在木桌另一侧歪头认真看。
  - **三猫位置**：前景·中线 = 三花猫 + 竹筒；中景偏右 = 橘猫蹲坐看；背景偏左 = 白猫蹲坐看。
  - **ASMR**「米粒沙沙」+「木勺压米·咚」
- **节拍 3-2·弟犯馋打翻竹筒**（4s）：橘猫馋相毕露，脑袋探过去想吃米，嘴够不到，伸出爪子拨竹筒，竹筒倾倒，米从筒口溢出洒满木桌。橘猫爪上还粘着几粒米。
  - **三猫位置**：中景偏右的橘猫突然伸爪越过桌沿；前景·中线的三花猫仍在装第二筒最后一勺。
  - **ASMR**「竹筒倾倒·哐当」+「米洒桌面·沙啦」+ 橘猫心虚「喵呜」
- **节拍 3-3·姐盯弟→弟面壁**（3s）：三花猫缓缓转头，眼神锁定橘猫。橘猫立刻溜到画面角落蹲下面对墙壁。妹在背景幸灾乐祸的「喵」了一声。
  - **三猫位置**：前景·中线三花猫转头；画面角落橘猫蹲坐面对墙（背对画面）；背景偏左白猫捂嘴笑。
  - **ASMR**「妹幸灾乐祸·喵」+ 姐呼气「呼」
- **节拍 3-4·弟扭腰跳舞→妹被吸引也开始跳**（7s）：弟面壁没几秒就耐不住性子，回头偷瞄姐姐一眼，发现姐姐已经埋头继续装米，便站起身扭动腰臀开始跳魔性的抖音舞蹈（夸张的左右摆胯+伸爪动作）。妹在一旁被吸引过去也开始模仿扭动。两只猫在画面一角对着扭，三花猫不为所动继续在前景装米。
  - **三猫位置**：前景·中线 = 三花猫埋头继续装米（沉浸式）；画面角落偏右 = 橘猫扭腰跳舞；背景偏右 = 白猫被吸引也开始扭。
  - **ASMR**「弟甩胯·啪嗒啪嗒」+ 妹铃铛「叮叮」+ 远处知了「知了·知了」（夏季氛围）
- **节拍 3-5·姐继续干活·腊肉香菇豌豆**（4s）：三花猫不受干扰，按顺序在第一只竹筒里码上腊肉丁、香菇块和嫩豌豆，再覆最后一层糯米压实。三花猫抖了抖围裙上的米粒，重新端起木勺。
  - **三猫位置**：前景·中线三花猫继续操作；画面一角弟妹仍在扭。
  - **ASMR**「肉落竹筒·咚咚」+「豌豆滚动·沙啦」+「覆米·扑」

**叙事弧总结**：本段的情绪线不再是「任务推进」，而是「**任务被打断→肇事者受罚→肇事者自娱→姐依然专注**」的轻喜剧结构。弟妹的扭腰跳舞成为本段的「破坏性插曲」，让 24s 的蒙太奇段保持节奏起伏（装米→打断→面壁→跳舞→姐继续装米），避免单调。

### 段 4 — 烤制等待：16s

李子柒式治愈系动物短片，主角为参考图中的三只猫猫。三花猫把三只封好口的竹筒搬到院子里的火塘边一字排开，开始蹲火塘边看火候，橘猫主动请缨守火但是守不到三分钟就被炭火烟熏得眯起眼睛连连后退，三花猫用蒲扇轻轻扇走弟弟面前的烟并指了指旁边的竹凳示意他坐下，橘猫不服气又凑近火堆结果被烟呛得打喷嚏，三花猫用蒲扇朝弟弟扇了两下，妹妹在背景里笑得铃铛直晃。三花猫继续在前景扇扇看火候，橘猫只好蹲坐在旁边眼巴巴看火苗。
