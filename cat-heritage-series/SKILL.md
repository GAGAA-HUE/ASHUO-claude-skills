# 猫咪非遗系列 — 多期选题大纲生成器（v6.3 + v7.0）

为"猫咪为主角的非遗科普短视频系列"生成多期结构化选题大纲。基于 **v6.3 戏剧引擎** + **三猫家庭完整设定 v6.3** + **设计宪法 v6.3**。

## ⚠️ 重要：调用前必须先读 references/

为避免与已归档内容重复，**每次被调用时必须先读取**：

**v6.3 主线工艺片（TYPE A）必读**：
1. `references/主工艺档·设计宪法.md` — **v6.3 核心宪法**（戏剧引擎 5 原理 + 节气引擎 + **v6.3 删除表情包定格** + 宇宙联动 + 段落宪法 + 自查清单）
2. `references/主工艺档·输出格式.md` — v6.3 输出格式约定（8 字段）
3. `references/主资·物质资产表.md` — 物质资产表（宇宙联动查询）
4. `references/主资·节气档案.md` — 节气链 + 选题池 + 物候元素库
5. `references/剧集归档总索引.md` — 已有归档索引（避免重复生成）

**v7.0 节日采购片（TYPE B）必读**（接到"采购/萌宠饰品店/超市/节日/新衣"等关键词时额外读取）：
6. `references/节庆采购档·设计宪法.md` — **v7.0 TYPE B 核心宪法**（9 条绝对约束(含 POV 视角规则 #9) + 30/60/15 时间预算 + 节庆锚引擎）
7. `references/节庆采购档·输出格式.md` — v7.0 TYPE B 输出格式约定（8 字段·节庆锚替代节气锚）
8. `references/节庆采购档·角色设定.md` — 源姐姐 / 朔哥哥 / 猫咪塑料模特 角色卡库（含 POV 视角规则）
9. `references/节庆采购档·场景规范.md` — 萌宠饰品店 / 好萌超市 / 城市商业街 场地规范

## 适用场景

触发本技能：
- 用户说"做一期 X"、"下一集拍 X"、"规划 N 期"、"列选题"
- 用户希望基于一个非遗主题展开成完整一集的内容设计
- 用户询问"这个非遗适不适合做"
- 用户说某个节气名（"处暑做 X"、"白露拍 Y"）
- **v7.0 新增（TYPE B 节日采购片触发词）**：用户说"采购/换新衣/逛店/超市/萌宠饰品店/节日/春节买新衣/端午包粽子/中秋买月饼/圣诞采购/生日蛋糕/源姐姐/朔哥哥"等关键词 → 切换到 TYPE B 节日采购片系统（详见 `references/节庆采购档·设计宪法.md`）

不适用：
- 单条 Seedance 视频提示词生成 → 直接调用 `seedance-director` 或 `seedance-2.5-scene-director`
- 不是猫 / 不是非遗的内容 → 不要硬套本技能
- 用户已经给出完整剧本只想校验 → 直接读 v6.3 文档对照

**v7.0 类型判定流程**：收到输入后，**先判定 TYPE 类型**：
1. 关键词包含"采购/换新衣/萌宠饰品店/超市/源姐姐/朔哥哥/节庆名" → **TYPE B**（节日采购片）
2. 关键词包含"做一期 X/工艺/非遗/节气名" → **TYPE A**（主线工艺片）
3. 关键词包含"梦境/番外/平行宇宙" → **TYPE C**（番外篇）

## 输入约定

最小输入是一个**高层主题词**，例如：
- "做一期米塑"
- "plan 10 episodes covering 蜡染 / 扎染 / 蜡缬 / 夹缬 / 灰缬"
- "下一集拍陶器"
- "处暑做一期陶杯"

可选补充输入（推荐）：
- 期望期数（默认 10 期）
- 主题类别（食品 / 器具 / 染织 / 雕塑 等）
- 是否限定某个非遗级别
- 节气锚定（如"白露期"）

## 输出约定（v6.3 格式·8 个固定字段）

**每期一份结构化脚本表**，中文输出：

```
# 第 N 期 — [主题]

## 1. 基本信息（表格·含节气锚定+动作亮点+动物预算）
## 2. 工艺段（含 SOURCING / PROCESS / v6.3 5 节拍压缩）
## 3. 三猫互动节拍（v6 强化妹隐性功能 + 弟捧哏属性）
## 4. 黄毛弟行为推导（v6 强化"捧哏"属性）
## 5. 整体节奏结构（5 节拍时间轴 + v6.3 段5冲突瞬间）
## 6. 字幕卡文案汇总（≤25 字/张）
## 7. 宇宙资产联动（v6 必填·新建/复用 asset_id）
## 8. 节气锚定说明（v6 必填·氛围锚+物候呼应）
```

详细格式规范见 `references/主工艺档·输出格式.md`。

## v6.3 关键约束（3 条铁律）

1. **节气锚定（氛围锚·非主题锁）**——每期必挂载到具体节气，主题可与节气无强相关，但画面必须 ≥2 个元素呼应节气物候
2. **宇宙资产联动**——每期新建 / 复用 ≥1 个 asset_id，写入 `references/主资·物质资产表.md`
3. **动物配角放宽**——每期最多 1 只配角（驴/鹅/鸟/猪），仅背景或辅料位 ≤5s，不参与主线

**v6.3 关键变更**：v6 原"沙雕表情包铁律"已删除（用户反馈"画面里不要有任何的定格,所有内容全部都是动态的"）。所有画面必须连续动态推进,段 5 的"冲突定格"改为"冲突瞬间"(动态推进 2-3s)。弟闯祸本身仍是连续动态事件(闯祸类型 A-G 见 principle_12),不再有 ≥3s 逗留的表情包节拍。

## v7.0 关键约束（4 条新铁律·TYPE B）

1. **节庆锚定（主题锁·优先级最高）**——每期必填节庆名 + 节庆类型 + 视觉符号 ≥2 项；节庆锚优先级 > 节气锚
2. **30/60/15 时间预算**——TYPE B 默认按 30%（采购）/ 60%（装饰大餐）/ 15%（享成果）分段，总时长 75-110 秒；用户可在 prompt 中以「这句按 X/Y/Z」完全覆盖
3. **允许 2 位人类店长（严控范围·POV 视角）**——仅源姐姐（萌宠饰品店）POV ≤40s + 朔哥哥（好萌超市）POV ≤35s；双店间隔出现，不在同一画面同框；台词 ≤3 句/人/期，单句 ≤8 字；**POV 视角规则**：源姐姐/朔哥哥的主形象（脸/身体/全身）通常不直接出现在画面中，画面只见「手」与「道具」
4. **POV 视角规则（v7.0 约束 #9）**——源姐姐 / 朔哥哥与三猫互动时采用第一人称视角；允许出现：双手（递交商品/量尺寸/接购物袋/扫码/敲计算器/竖大拇指等具体动作）、道具（软尺/衣架/扫码枪/计算器/购物车把手/购物袋/工牌局部等）；禁止出现：面部特写/全身轮廓/静态站位形象

**v7.0 关键变更**：在 v6.3 TYPE A 主线工艺片之外，新增 TYPE B 节日采购片系统——允许 2 位人类店长（源姐姐 / 朔哥哥）作为辅助角色，**主形象不直接出现在画面（POV 视角）**；猫咪塑料模特为陈列道具（非角色，不入预算）。两条线并行，9 期已归档主线工艺片（ep-13.5 / 15-23）保持 v6.3 冻结。

## 工作流

收到输入后，**先判断输入属于哪种模式**，按对应模式执行：

### 模式 A：直接给出主题词（例："做一期米塑"）

**先检查归档索引** → 如已归档 → 直接告知用户该期编号并询问是否调整 → 否则进入 Step 1-6。

#### Step 1：验证主题是否符合 v6.3 判据
非遗题材判据 = **T1.2 可操作为主 + 半操作为辅**——师傅猫的爪子至少完成一个工艺的小闭环或半闭环动作。

#### Step 2：推导一句话知识点（≤25 字硬知识点）

#### Step 3：节气锚定（v6 必填）
- 查 `references/主资·节气档案.md` 找当前/临近节气的物候符号
- 推导 ≥2 个物候呼应画面元素（露珠 / 桂花 / 落叶 / 斜阳 / 柿子等）

#### Step 4：拆解工艺段（5 节拍压缩版）
- SOURCING 段（如有）：无集市 / 无人类 / 角色自给自足
- PROCESS 段：按 Hook / 推进 / 主爆点 / 唯美段 / 反转结尾 5 节拍压缩
- 每段以"字幕卡 + 师傅演示 + 弟捧哏 + 妹隐性反应"为单位

#### Step 5：推导三猫互动 + 动作亮点
- 招牌动作库：扑咬 / 拍头 / 推 / 抽尾巴 / 骑 / 挠
- 招牌互动升级：A 扑倒+挠 / B 推开脸+担心 / C 推不动+反差 / **D 姐替妹出头（每期强制）**
- **动作亮点（v6.3 替代表情包）**：一句话预览本期最爆笑的连续动态物理动作（如"弟偷吃莲蓉糊一脸"），不再有 ≥3s 逗留要求

#### Step 6：宇宙资产联动
- 查 `references/主资·物质资产表.md` 是否有可复用资产
- 本期新建资产 → 自动分配 A00X 编号 → 写入 `主资·物质资产表.md`
- 复用资产 → 标注"出现段落"

#### Step 7：输出结构化脚本表（v6.3 8 字段）

**v6.3 新增要求**：每段描述结尾必须附「衔接说明」（搬家逻辑/走路逻辑 + 具体手法 + 路标元素），详见 `references/主工艺档·设计宪法.md` 的 `principle_15_v6_3_new`。

#### Step 8：归档
每生成一期完整脚本，立即写入 `episodes/episode-NN-[slug].md`，并在 `references/剧集归档总索引.md` 添加索引条目 + 更新 `references/主资·物质资产表.md`。

### 模式 B：要求生成选题（例："plan 10 episodes"）

**先进入"选题生成阶段"**，输出候选列表 + 理由，等用户挑选后再进入 Step 1-8。

#### 模式 B 工作流

**B-Step 1**：确定选题边界（期数 / 节气范围 / 主题类别）
**B-Step 2**：从 `references/主资·节气档案.md` 候选池 + WebSearch 国家级非遗名录扩展
**B-Step 3**：按四维判据筛选（节气锚定 / 写实动作亮点 / 宇宙资产可建 / 工艺可操作）
**B-Step 4**：输出候选列表 + 理由
**B-Step 5**：等待用户挑选
**B-Step 6**：批量归档 → 用户确认后批量写入 episodes/ + 更新索引 + 更新 asset-ledger

## 关键约束（v6.3 强化版）

1. **节气锚定（氛围锚非主题锁）**：每期 ≥2 个物候呼应元素
2. **宇宙资产联动**：每期新建/复用 ≥1 个 asset_id
3. **动物配角放宽**：≤1 只 / ≤5s / 仅背景
4. **时长**：75-85 秒（v3/v5 是 110-130s）
5. **段落宪法**：叙事段写氛围，节拍列表写具体动作，两者互补不复读
6. **妹的隐性功能**：任务锚点 + 反应代理，**妹不主动发起**
7. **弟的捧哏属性**：每段 1 次捧哏动作补节奏
8. **招牌互动 D**：每期 ≥1 次姐替妹出头
9. **v6.3 全部画面动态推进**：无表情包定格/停帧,镜头持续跟随动作移动
10. **段 5 三段式（v6.3 动态版）**：冲突瞬间(动态 2-3s) + 克制惩罚 + 平静收束 + meta 彩蛋
11. **不要直接调用 Seedance 提示词生成**——本技能只产出结构化脚本表

**v7.0 TYPE B 专属**（详见 `references/节庆采购档·设计宪法.md`）：
- 时长 75-110 秒
- 30/60/15 时间预算（采购/装饰大餐/享成果）
- 2 位人类店长 POV 视角（源姐姐 POV ≤40s / 朔哥哥 POV ≤35s）
- POV 视角规则：主形象（脸/身体/全身）不出现；只见「手」与「道具」
- 人类台词 ≤3 句/人/期，单句 ≤8 字
- 猫咪塑料模特 = 陈列道具（同屏 2-4 只）
- 人类顾客 ≤2 人/期,≤20s,远景
- 节庆锚定（节庆名 + 类型 + 视觉符号 ≥2）
- macro/close-up 节拍 ≥3 个
