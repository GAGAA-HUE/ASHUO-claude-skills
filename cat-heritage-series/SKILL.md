# 猫咪非遗系列 — 多期选题大纲生成器（v4 格式）

为"猫咪为主角的非遗科普短视频系列"生成多期结构化选题大纲。基于共享理解 v1.3 + 双猫完整设定 v1.3 + 设计宪法 v1.2。

## ⚠️ 重要：调用前必须先读 references/

为避免与已归档内容重复，**每次被调用时必须先读取**：
1. `references/design-spec.md` — v1.3 决策清单 + 双猫设定 + 设计宪法
2. `references/v4-format-conventions.md` — v4 输出格式约定
3. `references/episode-archive-index.md` — 已有归档索引（避免重复生成）

## 适用场景

触发本技能：
- 用户说"做一期 X"、"下一集拍 X"、"规划 N 期"、"列选题"
- 用户希望基于一个非遗主题展开成完整一集的内容设计
- 用户询问"这个非遗适不适合做"（题材判据决策 9）

不适用：
- 单条 Seedance 视频提示词生成 → 直接调用 `seedance-director` 或 `seedance-2.5-scene-director`
- 不是猫 / 不是非遗的内容 → 不要硬套本技能
- 用户已经给出完整剧本只想校验 → 直接读 v1.3 文档对照

## 输入约定

最小输入是一个**高层主题词**，例如：
- "做一期米塑"
- "plan 10 episodes covering 蜡染 / 扎染 / 蜡缬 / 夹缬 / 灰缬"
- "下一集拍陶器"

可选补充输入（推荐）：
- 期望期数（默认 10 期）
- 主题类别（食品 / 器具 / 染织 / 雕塑 等）
- 是否限定某个非遗级别
- 是否复用某只主推猫（默认两只都用）

## 输出约定（v4 格式）

**每期一份结构化脚本表**，中文输出，包含以下字段：

```
# 第 N 期 — [主题]

## 1. 基本信息
## 2. 工艺段（含制作知识文本）
   - 段名 / 字幕卡文案 / 师傅演示动作 / 时长 / 画面要点 / 制作知识文本
   - 工艺段前可加 SOURCING 前期准备段（无集市 / 角色自给自足）
## 3. 双猫互动节拍（设计宪法 v1.2）
   - COLD OPEN → SOURCING → PROCESS → 招牌结尾
   - 主线节拍 70%（含招牌互动升级：扑倒/挠/推开脸带情感内核）
   - 辅线节拍 30%（沉浸过渡段）
   - 招牌结尾 2-3 秒
## 4. 橘猫行为推导（决策 20 后置推导）
## 5. 整体节奏结构（含完整脚本叙事）
   - 时间轴结构 + 完整脚本叙事（按时间轴逐秒描述画面）
## 6. 字幕卡文案汇总（≤25 字/张）
```

详细格式规范见 `references/v4-format-conventions.md`。

## 工作流

收到输入后，**先判断输入属于哪种模式**，按对应模式执行：

### 模式 A：直接给出主题词（例："做一期米塑"）

**先检查归档索引** → 如已归档 → 直接告知用户该期编号并询问是否调整 → 否则进入 Step 1-5。

### Step 1：验证主题是否符合决策 9 判据
非遗题材判据 = **T1.2 可操作为主 + 半操作为辅**——师傅猫的爪子至少完成一个工艺的小闭环或半闭环动作。

### Step 2：推导一句话知识点
- ≤25 字
- 硬知识点（决策 1）
- 观众看完能记住 / 复述的
- 不能是情感金句

### Step 3：拆解工艺段（含 SOURCING 前期准备）
- SOURCING 段（如有）：无集市 / 无人类 / 角色自给自足
- PROCESS 段：2-4 段
- 每段以"字幕卡 + 师傅演示 + 橘猫行为"为单位
- 字幕卡放在每段开头（v1.3 修正）

### Step 4：推导双猫互动（含招牌互动升级）
- 招牌动作库：**扑咬 / 拍头 / 推 / 抽尾巴 / 骑 / 挠**（v4 新增"挠"）
- 招牌互动升级要点：
  - 扑蝴蝶用力过猛扑倒师傅 → 师傅翻身挠橘猫
  - 师傅用爪子推开橘猫的脸（担心烫到）→ 橘猫缩回舌头装无辜
- **情感内核**：教训背后是关心（"严厉的爱"双钩子）
- 招牌结尾固定 2-3 秒（三花忍无可忍 + 橘猫装无辜）

### Step 5：输出结构化脚本表（v4 格式）
按"输出约定"格式输出。

### Step 6：归档到 episodes/ 文件夹
每生成一期完整脚本，立即写入 `episodes/episode-NN-[slug].md`，并在 `references/episode-archive-index.md` 添加索引条目。

### 模式 B：要求生成选题（例："plan 10 episodes"）

**先进入"选题生成阶段"**，输出候选列表 + 理由，等用户挑选后再进入 Step 1-5 + Step 6 归档。

#### 模式 B 工作流

**B-Step 1：确定选题边界**
**B-Step 2：搜索候选选题**（WebSearch 国家级非遗名录）
**B-Step 3：按四维判据筛选**
**B-Step 4：输出候选列表 + 理由**
**B-Step 5：等待用户挑选**
**B-Step 6：批量归档** → 用户确认后批量写入 episodes/ + 更新索引

## 关键约束（v4 强化版）

1. **字幕卡位置固定在工艺段开头**（v1.3 修正），招牌结尾不放字幕卡
2. **招牌互动 70% 反转 + 30% 沉浸过渡**（设计宪法 v1.2）
3. **开场不固定化**（决策 20）—— 根据主题延伸，不要千篇一律
4. **体型反差**（双猫设定 v1.3）：三花小体型 = 师傅 = 权威方；橘猫大体型 = 学徒 = 调皮方
5. **招牌动作库**（v4 扩展）：扑咬 / 拍头 / 推 / 抽尾巴 / 骑 / **挠**（新增）
6. **招牌互动升级**（v4 新增）：扑倒 / 推开脸含情感内核（担心 / 关心）
7. **机智感**（设计宪法 v1.2）：橘猫的偷懒要"有策略"，不能笨拙
8. **ASMR 分段音效**（决策 12）
9. **画面约束（v4 新增）**：
   - 绝对不出现人类
   - 不出现集市场景
   - 所有原料获取由角色直接完成（采麦穗 / 晾麦芽 / 堆柴火等）
   - 必要时可省略常规步骤以保证节奏紧凑
10. **不要直接调用 Seedance 提示词生成**——本技能只产出结构化脚本表

## 与其他技能的关系

- **上游**：`seedance-director` / `seedance-2.5-scene-director` — 接收本技能产出的脚本表，生成 Seedance 可用提示词
- **上游（可选）**：`hailuo-h3-director` — 当需要文字精准还原（如品牌植入场景）时切换
- **平行**：`edu-video-creator` — 不调用，是另一类科普视频技能
