# AE 片头与 MG 动画知识库

本文档为 H3 生成 AE 片头、MG 动画（Motion Graphics）类视频提示词提供专业知识支持。

---

## 1. 图形运动规律（Easing Functions）

### 1.1 基础缓动类型

运动曲线决定元素的运动感和节奏感，必须在提示词中明确标注。

| 缓动类型 | 英文标注 | 运动特征 | 适用场景 |
|---------|---------|---------|---------|
| **线性** | linear | 匀速运动，无加减速 | 机械感、循环动画、背景元素 |
| **缓入** | ease-in | 慢速启动，逐渐加速 | 元素进入、消失前的蓄力 |
| **缓出** | ease-out | 快速启动，逐渐减速 | 元素登场、落地动画 |
| **缓入缓出** | ease-in-out | 两端慢，中间快 | 自然流畅的过渡、UI 切换 |
| **弹性** | bounce | 落地后弹跳 | 活泼感、趣味性强调 |
| **回弹** | elastic | 超出目标后回弹 | 游戏感、卡通风格 |
| **预备** | anticipate | 反向蓄力后弹出 | 爆发感、戏剧性登场 |

### 1.2 提示词标注示例

```
[0-1秒] 标题从画面上方快速落下（ease-out），在中央位置轻微弹跳两次（bounce）后稳定
[1-2秒] 副标题从左侧滑入（ease-in-out），运动流畅无顿挫
[2-3秒] 装饰图形匀速旋转（linear），作为背景持续动画
```

## 2. 文字动效类型

### 2.1 经典文字动效

| 动效类型 | 实现方式 | 视觉效果 | 适用风格 |
|---------|---------|---------|---------|
| **打字机** | 逐字符显现 | 文字从左到右逐个出现，类似打字 | 科技、编程、复古 |
| **擦除/涂抹** | 遮罩扫过 | 像橡皮擦或笔刷擦出文字 | 手绘、创意、教育 |
| **拆分重组** | 字符分散再聚合 | 字母四散后飞回正确位置 | 动感、科幻、游戏 |
| **描边生长** | 路径动画 | 文字轮廓线从无到有描绘出来 | 高端、精致、品牌片 |
| **像素化** | 方格溶解 | 文字以像素方块形式出现/消失 | 复古游戏、科技、数字 |
| **翻转** | 3D 旋转 | 文字沿轴线翻转显现 | 现代、简洁、品牌 |
| **路径跟随** | 沿曲线运动 | 文字沿指定路径移动出现 | 流畅、优雅、叙事性 |
| **故障效果** | RGB 分离/闪烁 | 文字带有信号干扰感 | 赛博朋克、科技、实验性 |

### 2.2 文字动效提示词模板

**打字机效果**：
```
片头标题"创新科技"以打字机效果从左到右逐字显现（0.1秒/字），伴随轻微的字符抖动，白色等宽字体，黑色背景
```

**描边生长**：
```
品牌名称"LUXE"的金色轮廓线从中心点向外描绘生长（ease-out），线条粗细 3px，2 秒内完成，内部填充随后淡入
```

**拆分重组**：
```
标题"GAME START"的字母从画面四周飞入（elastic），每个字母旋转 720 度，在中央位置精准组合成完整文字
```

## 3. 形状变换（Shape Morphing）

### 3.1 基础形状转换

| 起始形状 | 目标形状 | 转换逻辑 | 典型应用 |
|---------|---------|---------|---------|
| **圆 → 方** | 圆角逐渐变直角 | 边缘流动变形 | 品牌标志演变、概念过渡 |
| **线条 → 图标** | 线段重组 | 路径节点移动 | Logo 展示、产品介绍 |
| **文字 → 图形** | 笔画解构重组 | 字符轮廓变形 | 创意片头、品牌故事 |
| **几何 → 有机** | 规则变为不规则 | 添加噪波扰动 | 自然感、流体效果 |
| **2D → 3D** | 平面挤出 | Z 轴空间拓展 | 空间感、层次感 |

### 3.2 形状变换提示词示例

```
[0-2秒] 圆形从画面中心扩散（ease-out），边缘逐渐变形为正方形（ease-in-out），转换过程中保持面积恒定
[2-4秒] 正方形的四条边分离，重新组合为品牌 Logo 的轮廓（anticipate），线条带有轻微弹性感
```

## 4. 转场方式

### 4.1 常用转场类型

| 转场名称 | 视觉特征 | 技术描述 | 适用节奏 |
|---------|---------|---------|---------|
| **擦除** | 线条扫过 | 直线/曲线遮罩移动 | 快速、利落 |
| **溶解** | 淡入淡出 | 透明度渐变 | 柔和、优雅 |
| **缩放** | 画面放大/缩小 | Scale 变换 | 聚焦、空间切换 |
| **旋转** | 画面转动 | Rotation 变换 | 动感、连续性 |
| **分裂** | 画面撕裂 | 多方向位移 | 冲击力、戏剧性 |
| **液态** | 流体融合 | 有机形状过渡 | 自然、高端 |
| **像素化** | 方格溶解 | 网格分解重组 | 科技、游戏 |
| **故障** | 信号干扰 | RGB 错位/扫描线 | 赛博朋克、实验 |

### 4.2 转场提示词模板

**擦除转场**：
```
[3-4秒] 垂直白色线条从左向右扫过（ease-in-out），线条经过处画面内容从场景 A 切换到场景 B，扫描线宽度 5px
```

**液态转场**：
```
[5-6秒] 场景 A 的画面从底部如液体般向上流动消失（ease-out），同时场景 B 从顶部流入，两者在中部形成自然融合
```

## 5. 粒子效果

### 5.1 粒子类型与特征

| 粒子类型 | 形态 | 运动特征 | 应用场景 |
|---------|------|---------|---------|
| **尘埃** | 小圆点 | 缓慢漂浮、布朗运动 | 环境氛围、柔和背景 |
| **火花** | 发光点/轨迹 | 快速飞溅、向外辐射 | 能量感、爆发效果 |
| **数据流** | 数字/字符 | 竖向/横向流动 | 科技、信息、编程 |
| **光点** | 光晕球体 | 缓慢上升、随机闪烁 | 梦幻、魔法、庆典 |
| **几何碎片** | 三角形/方块 | 爆炸离散、重力下落 | 冲击、解构、转场 |
| **流体** | 有机形态 | 波动、融合 | 高端、自然、品牌 |

### 5.2 粒子效果提示词示例

**火花粒子**：
```
Logo 定格瞬间，从 Logo 边缘向外辐射金色火花粒子（200+ 颗），粒子带有拖尾轨迹（motion blur），以 ease-out 曲线向四周扩散后逐渐消失
```

**数据流粒子**：
```
背景中垂直向下流动的绿色数字流（0-9 和字母随机组合），数字以 linear 匀速下落，速度不一，营造黑客帝国风格的科技氛围
```

## 6. 图层层级与空间设计

### 6.1 2.5D 空间构建

虽然 MG 动画主要在 2D 平面，但可通过视差和缩放营造空间感：

| 层级 | 元素类型 | 运动速度 | Z 轴位置感 |
|------|---------|---------|-----------|
| **前景层** | 大型装饰图形 | 快速移动 | 距离观众最近 |
| **主体层** | 核心文字/Logo | 中速/静止 | 焦点位置 |
| **中景层** | 辅助图形 | 慢速移动 | 主体后方 |
| **背景层** | 纹理/渐变 | 极慢/静止 | 最深处 |

### 6.2 视差效果提示词

```
镜头从左向右平移（tracking shot）：
- 前景层：白色大圆形以 3 倍速度向右移出画面（ease-in-out）
- 主体层：品牌名称保持画面中央，轻微左右浮动
- 中景层：灰色小圆形以 0.5 倍速度向右移动
- 背景层：深蓝色渐变静止不动
通过速度差营造空间层次感
```

## 7. 配色与风格

### 7.1 MG 动画常见配色方案

| 风格 | 主色调 | 辅助色 | 背景色 | 典型应用 |
|------|--------|--------|--------|---------|
| **扁平简约** | 饱和纯色 | 同色系深浅变化 | 纯白/纯色 | 品牌介绍、信息图 |
| **渐变质感** | 渐变过渡色 | 金属光泽 | 深色/渐变 | 科技、高端品牌 |
| **霓虹赛博** | 荧光粉/蓝 | 紫/青 | 纯黑 | 游戏、科技、夜店 |
| **复古蒸汽波** | 粉/紫/青 | 金色点缀 | 渐变背景 | 潮流、艺术、怀旧 |
| **玻璃拟态** | 半透明白 | 柔和彩色 | 模糊背景 | 现代 UI、简洁品牌 |

### 7.2 风格提示词示例

**扁平简约**：
```
风格：扁平设计（flat design），纯色填充无渐变，主色为品牌蓝（#0066FF），辅助色为浅灰（#F5F5F5），白色背景，阴影使用色块而非模糊
```

**霓虹赛博**：
```
风格：赛博朋克（cyberpunk），荧光粉色（#FF00FF）和霓虹蓝（#00FFFF）文字带外发光效果（glow），纯黑背景，文字边缘有轻微 RGB 色散（chromatic aberration）
```

## 8. 节奏与时间设计

### 8.1 时间节点规划

**6 秒片头标准结构**：
- **0-1秒**：开场/引入（元素登场）
- **1-4秒**：核心展示（Logo/标题呈现）
- **4-6秒**：收尾/定格（最终画面稳定）

**节奏类型**：
- **急促节奏**：每 0.5-1 秒一个动作变化，适合动感、科技风格
- **舒缓节奏**：每 2-3 秒一个关键变化，适合高端、品牌片
- **混合节奏**：前半快速吸引注意，后半慢速展示细节

### 8.2 时间节点提示词示例

```
[0-0.5秒] 黑屏，突然闪现白色（flash）
[0.5-1.5秒] Logo 从小到大快速放大（ease-out），旋转 360 度
[1.5-3秒] Logo 稳定在画面中央，轻微呼吸式缩放（scale 0.98-1.02 循环）
[3-5秒] 品牌名称从下方滑入（ease-in-out），定格在 Logo 下方
[5-6秒] 整体画面保持静止，强化品牌记忆
```
