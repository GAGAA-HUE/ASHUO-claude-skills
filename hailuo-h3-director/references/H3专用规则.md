# H3 专用规则参考文档

本文档记录 Hailuo H3（MiniMax 多模态视频生成模型）的提示词格式规范、素材标记语法、时间轴标注、音频控制关键词和硬约束。

---

## 1. H3 提示词格式规范

### 1.1 标准结构顺序

H3 提示词必须按以下顺序组织：

```
[镜头类型 + 时长 + 宽高比]  ← 第一行，模型优先读取
主体
动作
环境
镜头
风格
[@素材标记]
[音频控制]
```

**示例**：
```
Wide shot, 6s, 16:9

主体：25岁左右的女性，黑色短发，白色衬衫配深蓝色西装外套，表情专注

动作：
[0-2秒] 从画面左侧走进办公室，右手提着咖啡杯，步伐稳健
[2-4秒] 在办公桌前停下，放下咖啡杯，拉开椅子
[4-6秒] 坐下并打开笔记本电脑，双手放在键盘上准备输入

环境：现代简约办公室，白色墙面，木质办公桌，窗外自然光透过百叶窗洒入，形成条纹光影

镜头：
起始为侧面跟拍（tracking shot），与人物保持平行移动
[2-4秒] 镜头逐渐静止（static shot）
[4-6秒] 缓慢推近至中景（slow dolly-in to medium shot）

风格：ARRI Alexa Mini LF，Cooke S4 35mm 定焦，自然光为主，暖色调，低对比度，现代商业片质感

音频：轻微的脚步声，咖啡杯放置在桌面的声音，键盘敲击声，办公室环境音（空调、远处交谈）
```

### 1.2 关键规则

1. **镜头信息前置**：镜头类型、时长、宽高比必须在第一行，因为模型优先读取第一行内容
2. **固定顺序不可打乱**：主体 → 动作 → 环境 → 镜头 → 风格 → 音频
3. **每个片段仅一个核心焦点**：避免在一个时间段内堆叠多个平行动作或多次运镜切换
4. **专业术语优先**：使用电影摄影术语（slow dolly-in、rack focus、golden hour lighting）而非口语化描述
5. **具体动作 > 情绪渲染**：写"眉头紧皱，嘴角下压，视线低垂"而非"看起来很悲伤"
6. **镜头参数通常无需特别指定**：分辨率、帧率等技术参数由 H3 平台 UI 设置，不写进文本提示词

## 2. 素材标记语法

### 2.1 标记类型

H3 支持三种素材标记：

| 标记 | 用途 | 位置 |
|------|------|------|
| `@image1` | 参考图片（角色/场景/道具） | 主体或环境描述后 |
| `@video1` | 参考视频（运动风格/场景基础） | 动作或镜头描述后 |
| `@audio1` | 参考音频（配乐/对话/音效） | 音频控制段落 |

多个同类素材按序号递增：`@image1`、`@image2`、`@image3`

### 2.2 使用规范

**图片素材标记示例**：
```
主体：@image1（短发干练女性，灰色西装，手持平板电脑）

环境：@image2（现代科技公司大堂，玻璃幕墙，白色简约设计）
```

**视频素材标记示例**：
```
动作：@video1 中人物的行走节奏与姿态，但将场景从室内改为户外公园

镜头：参考 @video1 的运镜方式，保持平稳跟拍
```

**音频素材标记示例**：
```
音频：@audio1（用户提供的背景音乐），画面节奏与音乐鼓点同步
```

### 2.3 输出时的素材绑定说明

每当提示词中出现素材标记时，输出末尾必须附上：

```
**素材绑定说明**
- @image1：请上传 [具体描述，如"短发女性肖像照"]
- @video1：请上传 [具体描述，如"产品旋转展示视频"]
- @audio1：请上传 [具体描述，如"轻快的电子音乐"]
```

## 3. 时间轴标注规范

### 3.1 基本格式

H3 支持在一条提示词内描述多个动作阶段和镜头变化，关键是**按时间顺序明确标注**：

```
[起始秒数-结束秒数] 动作描述 + 镜头状态
```

### 3.2 正确示例

```
动作：
[0-3秒] 人物从门外走进房间，右脚先跨入，身体前倾，右手推开木门，门缓慢打开
[3-5秒] 人物在椅子前停下，转身面向桌子，视线落在桌上的笔记本上
[5-8秒] 人物坐下，腰背挺直，右手拿起桌上的咖啡杯，左手翻开笔记本第一页

镜头：
[0-3秒] 侧面跟拍（tracking shot），镜头与人物平行移动，保持中景
[3-5秒] 镜头逐渐静止（static shot），固定在人物侧后方
[5-8秒] 缓慢推近（slow dolly-in），从中景过渡到特写手部动作
```

### 3.3 错误示例（禁止）

❌ **堆叠式表达**（无时间轴逻辑）：
```
人物走进房间、坐下、拿起杯子、喝水，镜头跟随、静止、推近、特写
```

❌ **时间段重叠或跳跃**：
```
[0-3秒] 人物走进房间
[2-5秒] 人物坐下  ← 与前一段时间重叠
[7-10秒] 人物喝水  ← 5-7秒缺失
```

### 3.4 时间段划分原则

- **每个时间段对应一个明确的动作核心 + 一个明确的镜头状态**
- 时间段之间应有逻辑衔接（动作的因果、空间的连续）
- 时间段长度根据动作复杂度灵活调整（快速动作 1-2 秒，缓慢情绪推进 3-5 秒）
- 总时长不超过 H3 单次生成上限（6s 或 10s）

## 4. 音频控制关键词

### 4.1 音频描述方式

H3 支持通过自然语言描述音频，并通过特定关键词精确控制：

#### 4.1.1 环境音与音效

直接描述，不需特殊标记：

```
音频：咖啡店环境音（低声交谈、杯碟碰撞、咖啡机蒸汽声），人物脚步声清晰，坐下时椅子轻微摩擦
```

#### 4.1.2 对话内容

对话必须加引号，并说明语气、语速：

```
音频：角色A说"欢迎来到我们的店铺"，语速适中，语气热情；背景有轻微的商场环境音
```

多段对话：
```
音频：
[0-3秒] 角色A说"你好，请问需要什么帮助？"，语气友善
[3-6秒] 角色B回答"我想了解一下这款产品"，语气好奇
```

#### 4.1.3 纯净音效（无配乐）

当需要后期自行添加配乐时，使用：

```
No music
```

完整示例：
```
音频：No music，仅保留环境音（风声、鸟鸣）和人物动作音效（脚步、翻页）
```

#### 4.1.4 无字幕

避免 H3 在画面中生成硬压字幕：

```
no subtitles
```

### 4.2 音频与画面同步

音频描述应与动作时间轴对应：

```
动作：
[0-3秒] 人物从门外走进房间
[3-6秒] 人物坐下并打开电脑
[6-8秒] 人物开始打字

音频：
[0-3秒] 脚步声，木门开启的吱呀声
[3-6秒] 椅子拉动声，电脑开机提示音
[6-8秒] 键盘敲击声，节奏稳定
```

## 5. H3 硬约束（技术限制）

以下约束来自 H3 官方平台调研和实测，违反会导致生成失败或画面扭曲：

### 5.1 分辨率与时长约束

| 约束 | 说明 |
|------|------|
| **最长时长 15s** | H3 支持最长 15 秒的单次视频生成 |
| **1080p 支持 15s** | 1080p 分辨率可支持 15 秒时长 |
| **512p 不支持末帧** | 512p 分辨率不支持设置 last frame（末帧图片参考） |
| **提示词上限 ~2000 字符** | 单条提示词超过约 2000 字符会被截断或拒绝 |

**推荐配置**：
- 常规场景：1080p + 6s-15s（根据内容复杂度选择）
- 快速预览：512p + 6s（成本低、速度快，但无法用末帧）
- 复杂叙事：1080p + 10s-15s（适合完整故事片段）

### 5.2 模型功能约束

| 功能 | 可用模型 | 说明 |
|------|---------|------|
| **精细运镜编排** | Hailuo 1.0-Director, 3.0 | 需要插入多个运镜关键帧时，使用 Director 模型 |
| **2D 插画动效** | Hailuo 1.0-Live | 专为 2D 插画/卡通角色优化 |
| **首帧+末帧控制** | Hailuo 2.0 及以上（非 512p） | 同时提供起始和结束画面参考 |
| **音频输入** | 部分模型支持 | 并非所有版本都支持音频输入，需查看平台标注 |

### 5.3 提示词优化功能

H3 平台有"Prompt Optimize"（提示词优化）功能，会自动改写用户输入。

**特殊情况**：当使用**人脸参考图**（Subject-to-Video / S2V 模式）时：
- **必须关闭"Prompt Optimize"**
- 原因：自动优化可能偏离参考图特征，导致生成的人物与参考不符
- 在 H3 平台设置中手动关闭该选项

### 5.4 其他已知约束

- **镜头信息必须前置**：H3 优先读取第一行，如果镜头类型、时长、宽高比不在开头，可能被忽略
- **避免平铺多动作**：一次性堆叠 5+ 个动作会导致画面扭曲，应按时间轴分段
- **商业文案必须逐字复述**：H3 对文字生成的准确性依赖提示词中的原文，改写或简化会导致文案错误

## 6. H3 与其他模型的差异

### 6.1 H3 vs Seedance 2.0

| 维度 | H3 | Seedance 2.0 |
|------|----|----|
| **核心定位** | 多模态商业内容生成 | 电影级叙事镜头 |
| **输入类型** | 文字/图片/视频/音频 | 主要为文字 |
| **强项** | 文案准确性、素材融合、产品展示 | 时间理解、复杂运镜、叙事蒙太奇 |
| **提示词结构** | 镜头前置 + 固定顺序（主体→动作→环境→镜头→风格） | 灵活叙事结构 + 分镜表 |
| **典型场景** | 广告、电商、UI 演示、品牌内容 | 电影片段、MV、预告片、概念短片 |

### 6.2 H3 vs Kling / Sora

- **Kling**：未在同一平台，无直接对比数据
- **Sora 2**（同平台）：4s/8s/12s，720p，侧重自然物理模拟和长镜头连续性
- **Veo 3.1**（同平台）：8s，720p/1080p，支持音频，Google 出品

H3 的差异化在于**多模态输入能力**和**商业文案准确性**，而非纯粹的物理真实感或艺术风格化。

## 7. 实战注意事项

### 7.1 商业场景必做检查

- ✓ 包装上的文字是否逐字复述？
- ✓ 品牌 logo 位置是否明确？
- ✓ UI 界面文案是否完整写入？
- ✓ 产品尺寸是否有相对参照物？
- ✓ 是否标注了 No music（便于后期配乐）？

### 7.2 素材场景必做检查

- ✓ 是否为每个素材标注了 @image1 / @video1 / @audio1？
- ✓ 是否在输出末尾附上了"素材绑定说明"？
- ✓ 素材描述是否足够具体，让用户知道上传什么？
- ✓ 如为人脸参考，是否提示用户关闭 Prompt Optimize？

### 7.3 复杂动作场景必做检查

- ✓ 是否按时间轴拆分了每个动作阶段？
- ✓ 每个时间段是否只有一个核心动作 + 一个明确镜头状态？
- ✓ 时间段之间是否有逻辑衔接？
- ✓ 总时长是否符合 H3 的 6s/10s 限制？

### 7.4 字数超限时的压缩策略

优先保留（不可压缩）：
1. 镜头+时长+宽高比（第一行）
2. 动作时间轴
3. 文案逐字复述（商业场景）
4. 主体核心特征
5. 镜头核心设计

可压缩（精简但保留关键信息）：
1. 环境次要陈设
2. 风格补充说明
3. 音频次要材质反馈

## 8. 快速参考速查表

### 8.1 第一行格式

```
[镜头类型], [时长], [宽高比]
```

示例：
- `Wide shot, 6s, 16:9`
- `Close-up, 10s, 9:16`
- `Medium shot, 8s, 1:1`

### 8.2 常用镜头类型（英文术语）

- Wide shot（广角远景）
- Medium shot（中景）
- Close-up（特写）
- Extreme close-up（大特写）
- Over-the-shoulder shot（过肩镜头）
- Bird's eye view（鸟瞰）
- Low angle（低角度）

### 8.3 常用运镜（英文术语）

- Static shot（静止）
- Tracking shot（跟拍）
- Dolly-in / Dolly-out（推轨/拉轨）
- Slow dolly-in（缓慢推进）
- Pan left / Pan right（左摇/右摇）
- Tilt up / Tilt down（上仰/下俯）
- Zoom in / Zoom out（变焦推进/拉远）
- Rack focus（焦点转移）
- Handheld（手持）

### 8.4 常用光线术语（英文）

- Golden hour lighting（黄金时刻光线）
- Backlit / Backlight（逆光）
- Soft light（柔光）
- Hard light（硬光）
- Volumetric lighting（体积光）
- Rim light（轮廓光）
- Three-point lighting（三点布光）

### 8.5 音频控制关键词

- `No music` — 无配乐，仅保留音效
- `no subtitles` — 无字幕
- `"对话内容"` — 对话必须加引号
