# 游戏界面与 UI 动效知识库

本文档为 H3 生成游戏界面、UI 动效、HUD 元素、交互反馈类视频提示词提供专业知识支持。

---

## 1. UI 元素动画类型

### 1.1 基础 UI 动画

| 动画类型 | 动作描述 | 缓动建议 | 适用元素 |
|---------|---------|---------|---------|
| **淡入淡出** | 透明度 0-100% 变化 | ease-in-out | 所有 UI 元素通用 |
| **滑入滑出** | 从屏幕边缘移入/移出 | ease-out（入）/ ease-in（出） | 菜单、通知、面板 |
| **缩放** | 从小放大或从大缩小 | ease-out（放大）/ ease-in（缩小） | 按钮点击、弹窗 |
| **弹出** | 快速放大 + 轻微回弹 | bounce / elastic | 奖励提示、成就解锁 |
| **旋转翻转** | 沿轴线旋转显现 | ease-in-out | 卡片翻面、切换效果 |
| **描边扫过** | 边框发光扫过 | linear | 选中高亮、充能条 |

### 1.2 UI 动画提示词示例

**按钮点击反馈**：
```
[0-0.2秒] 按钮从正常状态（scale 1.0）快速缩小至 0.9（ease-in）
[0.2-0.4秒] 按钮弹回至 1.05（bounce），轻微超过原始大小
[0.4-0.6秒] 按钮回到 1.0（ease-out），同时按钮边缘发出白色光晕（glow，持续 0.3 秒后淡出）
```

**卡片翻转**：
```
[0-1秒] 卡片背面朝上，沿 Y 轴旋转 180 度（ease-in-out），旋转至 90 度时卡片正面开始显现
[1-2秒] 卡片完全翻转至正面，轻微回弹（elastic），定格展示卡片内容
```

**滑入菜单**：
```
[0-0.5秒] 菜单面板从屏幕右侧滑入（ease-out），初始位置在屏幕右侧外 100%，最终停在屏幕右侧 20% 处
[0.5-0.8秒] 菜单项逐个淡入（每项间隔 0.1 秒，ease-out），从上到下依次显现
```

## 2. 游戏 HUD 元素

### 2.1 常见 HUD 元素类型

| HUD 元素 | 显示内容 | 动态特征 | 交互反馈 |
|---------|---------|---------|---------|
| **血条/生命值** | 当前血量/最大血量 | 扣血时条减少 + 抖动 | 低血量时红色闪烁 |
| **能量条** | 当前能量/最大能量 | 充能时发光 + 流动效果 | 满能量时光效强化 |
| **技能冷却** | 冷却时间倒计时 | 圆形进度条 + 数字 | 冷却完成时闪光提示 |
| **弹药计数** | 当前弹药/备用弹药 | 射击时数字减少 | 弹药耗尽时红色警告 |
| **小地图** | 地图 + 标记 | 玩家位置脉冲 | 敌人出现时红点闪烁 |
| **得分/金币** | 数值增减 | 数字滚动 + 上升 | 获得时金色光效 |

### 2.2 HUD 动效提示词示例

**血条扣血反馈**：
```
[0-0.2秒] 角色受到伤害，血条从 80% 快速减少至 50%（ease-out），红色填充部分向左收缩
[0.2-0.5秒] 血条边框白色闪烁 2 次（每次 0.15 秒），整个血条轻微抖动（shake，振幅 ±2px）
[0.5-1秒] 血条后方出现暗红色"损失血量"指示条（0.5 秒后淡出），显示本次受伤量
```

**技能冷却完成**：
```
[0-3秒] 技能图标呈灰色半透明状态，上方覆盖顺时针旋转的黑色扇形遮罩（表示冷却中），遮罩从 360 度缩减至 0 度
[3-3.5秒] 冷却完成瞬间，技能图标恢复全彩，边缘发出金色光芒向外扩散（ease-out），伴随"叮"的音效提示
[3.5-4秒] 图标轻微放大至 1.1 倍后回弹至 1.0（bounce），强调可用状态
```

**金币获得动画**：
```
[0-0.5秒] 金币图标从屏幕中央飞向右上角金币计数器位置（ease-in），飞行轨迹带有抛物线弧度
[0.5-0.8秒] 金币数字从 150 滚动增加至 200（数字滚动效果，每帧 +10），金色光效从数字中心向外扩散
[0.8-1秒] 金币图标轻微放大缩小（scale 1.0 → 1.2 → 1.0，bounce），强化获得感
```

## 3. 按钮与交互反馈

### 3.1 按钮状态与反馈

| 按钮状态 | 视觉表现 | 动画反馈 | 典型场景 |
|---------|---------|---------|---------|
| **正常（Normal）** | 默认颜色和大小 | 无动画 | 未交互状态 |
| **悬停（Hover）** | 颜色变亮，边框发光 | 缓慢放大至 1.05（ease-out） | 鼠标悬停 |
| **按下（Press）** | 颜色变暗，缩小 | 快速缩小至 0.95（ease-in） | 点击瞬间 |
| **禁用（Disabled）** | 灰色半透明 | 无交互反馈 | 不可用状态 |
| **选中（Selected）** | 特殊颜色，持续发光 | 边框光效循环 | 当前选中项 |

### 3.2 按钮交互提示词示例

**悬停反馈**：
```
[0-0.2秒] 鼠标移入按钮，按钮背景色从蓝色（#0066FF）过渡到亮蓝（#3399FF，ease-out）
[同时] 按钮边框出现白色外发光（glow，2px 模糊，透明度 0 → 80%）
[同时] 按钮缩放从 1.0 放大至 1.05（ease-out）
```

**点击反馈（完整周期）**：
```
[0-0.1秒] 鼠标点击，按钮快速缩小至 0.95（ease-in）
[0.1-0.3秒] 按钮弹回至 1.05（elastic），边缘发出向外扩散的波纹效果（ripple，圆形光圈从中心向外扩散）
[0.3-0.5秒] 按钮回到 1.0（ease-out），波纹淡出
```

## 4. 弹窗与面板动画

### 4.1 弹窗登场方式

| 登场方式 | 动作描述 | 情绪传达 | 适用场景 |
|---------|---------|---------|---------|
| **中心缩放** | 从屏幕中心放大 | 聚焦、重要 | 确认对话框、警告 |
| **顶部下拉** | 从顶部滑下 | 通知、提示 | 系统消息、成就 |
| **底部上推** | 从底部滑上 | 展开、详情 | 详情面板、选项 |
| **左右滑入** | 从侧边滑入 | 导航、切换 | 侧边栏、菜单 |
| **淡入 + 缩放** | 透明度和大小同时变化 | 柔和、自然 | 普通弹窗 |
| **爆炸登场** | 从粒子/碎片聚合 | 冲击、奖励 | 宝箱开启、大奖 |

### 4.2 弹窗动画提示词示例

**中心缩放弹窗**：
```
[0-0.3秒] 弹窗从屏幕中心点快速放大（scale 0 → 1.1，ease-out），同时透明度从 0 提升至 100%
[0.3-0.5秒] 弹窗轻微回弹至 1.0（elastic），背景遮罩层（黑色半透明，透明度 60%）同步淡入
[0.5秒后] 弹窗内的按钮和文字逐个淡入（每个元素间隔 0.1 秒）
```

**奖励爆炸登场**：
```
[0-0.5秒] 屏幕中央出现金色光点闪烁（scale 0.5 → 1.5 循环 3 次）
[0.5-1秒] 光点爆炸，向外辐射 100+ 颗金色粒子（ease-out），粒子带有拖尾轨迹
[1-1.5秒] 奖励面板从爆炸中心快速放大显现（scale 0 → 1.2，ease-out），带有旋转效果（rotate 360 度）
[1.5-2秒] 面板回弹至 1.0（bounce），粒子在面板周围缓慢环绕漂浮
```

## 5. 加载与进度动画

### 5.1 加载动画类型

| 加载类型 | 视觉形式 | 运动方式 | 适用场景 |
|---------|---------|---------|---------|
| **旋转圈** | 圆形或弧形旋转 | 匀速顺时针旋转（linear） | 通用加载 |
| **进度条** | 横条填充 | 从左到右填充（ease-out） | 文件下载、关卡加载 |
| **脉冲圆** | 圆形扩散 | 从中心向外扩散后消失 | 等待状态 |
| **点阵跳动** | 3-5 个点依次跳动 | 波浪式上下跳动（ease-in-out） | 简约风格加载 |
| **骨架屏** | 灰色占位块闪烁 | 从左到右扫过光效 | 内容加载预览 |

### 5.2 加载动画提示词示例

**旋转加载圈**：
```
加载图标为圆环，圆环 3/4 部分为白色，1/4 部分透明（形成缺口），圆环以屏幕中心为轴匀速顺时针旋转（linear，1 秒完成一圈），旋转过程中圆环粗细保持 4px，旋转不停顿
```

**进度条加载**：
```
[0-5秒] 进度条从 0% 填充至 100%（ease-out），填充部分为蓝色渐变（#0066FF → #00AAFF），未填充部分为灰色（#CCCCCC）
[同时] 进度条内部有从左到右移动的白色光效扫过（linear，0.5 秒一次，循环）
[同时] 进度条上方显示百分比数字（0% → 100%），数字每 0.1 秒更新一次
```

## 6. 游戏场景特定 UI

### 6.1 RPG 游戏 UI

| UI 元素 | 视觉风格 | 动画特征 |
|---------|---------|---------|
| **背包格子** | 网格布局，格子带边框 | 新物品掉落时闪光 |
| **装备栏** | 人形轮廓 + 装备槽 | 装备拖拽时发光路径 |
| **任务追踪** | 列表形式，左侧图标 | 任务完成时打勾动画 |
| **对话框** | 底部横幅，头像 + 文本 | 文字逐字显现（打字机效果） |

### 6.2 射击游戏 HUD

| UI 元素 | 视觉风格 | 动画特征 |
|---------|---------|---------|
| **准星** | 十字或圆点 | 射击时扩散后收缩 |
| **弹药显示** | 大号数字 + 图标 | 换弹时旋转动画 |
| **击杀提示** | 屏幕中上方横幅 | 从右侧滑入停留 2 秒后淡出 |
| **受伤指示** | 屏幕边缘红色光晕 | 受击方向发光 + 脉冲 |

### 6.3 游戏 UI 提示词示例

**背包物品拾取**：
```
[0-0.5秒] 物品图标从屏幕中央飞向背包格子位置（ease-in），飞行轨迹为抛物线
[0.5-0.8秒] 物品落入背包格子，格子边框金色闪光（glow，持续 0.3 秒）
[0.8-1秒] 物品图标在格子内轻微弹跳（bounce，scale 0.9 → 1.1 → 1.0）
```

**对话框打字机效果**：
```
[0-3秒] 对话框底部横幅从下方滑入（ease-out，0.3 秒），左侧圆形头像同时淡入
[0.3秒起] 对话文字以打字机效果逐字显现（每个字符间隔 0.05 秒），白色文字，黑色描边（1px）
[同时] 每显现一个字符时播放轻微"哒"的音效
```

## 7. UI 设计风格

### 7.1 常见游戏 UI 风格

| 风格名称 | 视觉特征 | 配色 | 典型游戏类型 |
|---------|---------|------|-------------|
| **扁平现代** | 纯色，无渐变，简洁 | 高饱和度纯色 | 休闲游戏、移动游戏 |
| **新拟态** | 柔和阴影，内凹/外凸 | 浅灰、柔和色 | 现代 UI、工具应用 |
| **科幻赛博** | 荧光边框，故障效果 | 蓝/紫/荧光色 | 科幻射击、赛博朋克 |
| **奇幻魔法** | 华丽边框，粒子光效 | 金/紫/宝石色 | RPG、奇幻游戏 |
| **军事硬核** | 棱角分明，网格纹理 | 军绿/灰/橙 | 战术射击、军事策略 |
| **赛璃拟态** | 半透明，模糊背景 | 白色半透明 | 现代游戏、简约风 |

### 7.2 风格提示词示例

**科幻赛博风格**：
```
风格：赛博朋克（cyberpunk）UI，深色背景（#0A0E27），UI 元素边框为荧光蓝（#00FFFF），所有边框带外发光效果（glow，2px 模糊），按钮和面板边缘有轻微 RGB 色散（chromatic aberration），背景有扫描线纹理（scan lines，透明度 10%）
```

**奇幻魔法风格**：
```
风格：奇幻魔法（fantasy magic）UI，UI 边框为金色华丽雕花（ornate golden frame），边框带有细微的浮雕效果，背景为深紫色渐变（#2D1B3D → #1A0F29），UI 周围环绕缓慢漂浮的金色光点粒子（20-30 颗），文字为暖金色（#FFD700），带有轻微发光
```

## 8. 快速参考速查

### 常用 UI 动画英文术语
- fade in/out（淡入/淡出）
- slide in/out（滑入/滑出）
- scale up/down（放大/缩小）
- bounce（弹跳）
- elastic（弹性）
- ripple effect（波纹效果）
- glow（发光）
- shake（抖动）

### 常用交互状态
- normal（正常）
- hover（悬停）
- press（按下）
- disabled（禁用）
- selected（选中）
- active（激活）

### 常用 HUD 元素
- health bar（血条）
- energy bar（能量条）
- cooldown timer（冷却计时器）
- ammo count（弹药计数）
- mini-map（小地图）
- score display（得分显示）
