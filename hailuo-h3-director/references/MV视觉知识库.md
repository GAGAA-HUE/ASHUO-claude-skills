# MV 视觉知识库

本文档为 H3 生成 MV（音乐视频）视觉内容提供专业知识支持，重点在于音画同步、视觉风格和特效叠加。

---

## 0. 歌词贴字 MV 与多镜头拼接补充规则（来自官方特化工作流）

当用户明确要 **歌词贴字 / Lyric typography / Trap MV / Dark-pop / Cyber-grunge / 30 秒以上 MV**，优先建议切换到 `music-video-subtitle-generator`；若用户决定留在本 skill，则遵守以下规则：

### 0.1 歌词所有权与排版

- 用户提供的歌词为锁定文本：不得生成、补写、改写、翻译、释义或替换，演唱与可见文字都须逐字匹配。
- 若用户想要完整音乐 MV 但未提供歌词，先生成并让用户锁定原创歌词，再写分镜。
- 字幕文字是空间化图形主体，不是底部字幕条；可置于前/中/后景，也可被肩膀或手遮挡。
- 每个 Shot 只有一个主文字事件；文字不可遮挡眼睛、关键面部表情、口型同步中的嘴部。

### 0.2 超过 15 秒的 Master Audio 拼接

- 先锁定一条连续的 Master Audio，所有短片生成与剪辑均以它为唯一音频基线。
- 将 30 秒拆为 4-8 个 2-5 秒镜头，并把歌词、人声、鼓点、snare、808、drop 映射到精确时间段。
- 剪辑点落在歌词停顿、呼吸、snare 或 drop；不得在活跃元音中硬切，除非下一镜头能延续口型。
- 所有镜头复用相同全局美术锚（颗粒级别、LUT、主光方向、角色身份、画幅）。
- 长镜头续接：上一段尾帧作为下一段首帧；硬切场景：用同向 pan、手部遮挡、动作 match cut 或重拍实现动势连续。
- 前段文字在 bass hit 处碎裂/扫出/砸屏，下一段文字在重拍处砸入/展开，继承视觉动量。

### 0.3 Dark-pop / Trap 编辑约束

- 使用 hard cuts，不使用 fade、dissolve 或软转场。
- hi-hat roll 驱动微抖/跳帧；snare 驱动放大、硬切、肩部下沉；808 驱动低频压缩、拉伸或错位。
- 可加入胶片颗粒、轻微抖动、半色调点、粗糙印刷边缘、扫描偏移；避免将这些效果变成无节奏的噪声。

## 1. 音画同步标记

### 1.1 音乐节奏点类型

| 节奏点类型 | 音乐特征 | 画面对应 | 标注方式 |
|-----------|---------|---------|---------|
| **鼓点（Beat）** | 低频鼓声 | 镜头切换、闪白、抖动 | 标注具体秒数 |
| **重拍（Downbeat）** | 小节第一拍 | 场景转换、大动作 | 每 4 拍标注一次 |
| **高潮（Drop）** | 音乐能量爆发点 | 视觉高峰、特效爆发 | 明确标注时间点 |
| **人声入（Vocal）** | 歌手开始演唱 | 人物特写、口型同步 | 标注歌词开始时间 |
| **过渡（Bridge）** | 音乐桥段 | 慢镜头、氛围营造 | 标注段落时间范围 |
| **尾奏（Outro）** | 音乐渐弱结束 | 画面淡出、余韵 | 标注结束时间 |

### 1.2 音画同步提示词示例

**鼓点切镜**：
```
音频：@audio1（用户提供的音乐）

动作与镜头（按鼓点同步）：
[0-1秒] 前奏，镜头静止，人物站在舞台中央
[1.2秒] 第一个鼓点，镜头闪白 0.1 秒后切换至侧面特写
[1.8秒] 第二个鼓点，镜头快速推进至人物面部（快速 dolly-in）
[2.4秒] 第三个鼓点，镜头切换至俯视角度
[3.0秒] 第四个鼓点（重拍），画面闪白后场景切换至夜景街道
```

**高潮 Drop 爆发**：
```
[8-10秒] 音乐进入 Bridge 段落，画面为黑白慢镜头（slow motion，50% 速度），人物缓慢转身
[10秒] Drop 瞬间，画面从黑白瞬间切换为全彩（0.1 秒），同时爆发金色粒子从人物身后向外辐射（ease-out），镜头快速旋转 360 度（1 秒完成）
[10-15秒] 高潮段落，每 0.5 秒快速切镜一次，画面闪烁频率与音乐节奏完全同步
```

**人声口型同步**：
```
[5-10秒] 歌手演唱段落，镜头为正面中景（medium shot），焦点在面部
[5.2秒] 歌词"Hello"，嘴唇动作与发音同步（嘴型张开-闭合）
[5.8秒] 歌词"World"，嘴型变化与音节对应
[6.5秒] 歌词高音部分，头部微微后仰，表情用力
```

## 2. 视觉风格分类

### 2.1 常见 MV 视觉风格

| 风格名称 | 视觉特征 | 色调 | 典型情绪 | 适用音乐类型 |
|---------|---------|------|---------|-------------|
| **复古 VHS** | 扫描线、色彩溢出、画面抖动 | 褪色、偏暖 | 怀旧、复古 | 复古流行、Lo-Fi |
| **赛博朋克** | 霓虹灯、雨夜、反光湿地 | 荧光粉/蓝/紫 | 科技、未来、冷酷 | 电子、合成器音乐 |
| **Y2K 美学** | 金属质感、反光、镜像、泡泡 | 银色、荧光色 | 千禧年、科技感 | 流行、电子流行 |
| **黑白胶片** | 高对比度、颗粒感、划痕 | 纯黑白 | 经典、忧郁、艺术 | 爵士、独立音乐 |
| **梦幻柔焦** | 柔光、光晕、过曝边缘 | 柔和粉彩 | 浪漫、梦幻、温柔 | 抒情、民谣 |
| **故障艺术** | RGB 分离、像素错位、闪烁 | 高对比、错位色 | 实验、混乱、叛逆 | 电子、实验音乐 |
| **超现实** | 不合理空间、漂浮物体、变形 | 鲜艳或诡异 | 奇幻、超脱现实 | 艺术流行、indie |

### 2.2 风格提示词示例

**复古 VHS 风格**：
```
风格：80 年代 VHS 录像带质感（VHS aesthetic），画面带有水平扫描线（scan lines，透明度 30%），色彩轻微溢出（chromatic aberration，RGB 通道错位 2px），画面边缘有黑色暗角（vignette），整体色调偏暖黄（warm tone，+15% yellow），画面带有轻微抖动（jitter，每 0.5 秒随机位移 ±3px）
```

**赛博朋克风格**：
```
风格：赛博朋克（cyberpunk），夜景雨后街道，地面有霓虹灯反光（荧光粉 #FF00FF 和蓝 #00FFFF），背景有日文霓虹招牌模糊虚化，人物身上有蓝紫色边缘光（rim light），画面色调偏冷（cool tone），高对比度，雨滴在镜头前缓慢滑落
```

**故障艺术风格**：
```
风格：故障艺术（glitch art），画面随机出现 RGB 色彩分离（red/green/blue 通道错位 5-10px，每 0.3 秒触发一次），局部像素化扭曲（pixel displacement，每 0.5 秒随机区域），画面偶尔出现水平条纹错位（horizontal shift，持续 0.1 秒），黑白与全彩快速闪烁（每 1 秒闪烁 1 次）
```

## 3. 特效叠加

### 3.1 常用视觉特效

| 特效名称 | 视觉效果 | 技术描述 | 适用场景 |
|---------|---------|---------|---------|
| **色散** | RGB 通道分离 | 红绿蓝三色边缘错位 | 故障风格、冲击时刻 |
| **光晕/光斑** | 镜头光晕 | 光源产生六边形/圆形光斑 | 逆光、梦幻场景 |
| **颗粒** | 胶片颗粒感 | 随机噪点 | 复古、胶片质感 |
| **运动模糊** | 高速移动拖影 | 运动方向的模糊 | 动感、速度感 |
| **光线泄漏** | 胶片漏光效果 | 画面边缘彩色光带 | 复古、艺术感 |
| **镜像/万花筒** | 画面对称复制 | 中心对称或多重镜像 | 迷幻、实验风格 |
| **粒子** | 漂浮光点/尘埃 | 缓慢漂浮的发光粒子 | 梦幻、魔法感 |

### 3.2 特效叠加提示词示例

**光晕特效**：
```
特效：镜头对准舞台灯光（逆光），产生六边形光晕效果（lens flare），光晕中心为强烈白光，向外辐射 6 条光芒，边缘带有彩色光圈（蓝-紫-粉渐变），光晕随镜头移动而移动，当灯光退出画面时光晕逐渐消失
```

**颗粒 + 光线泄漏**：
```
特效：画面叠加胶片颗粒（film grain，透明度 20%，颗粒大小 1px），画面右侧边缘有橙色光线泄漏（light leak），从右上角向中心渐变扩散，透明度 40%，营造复古胶片感
```

**镜像万花筒**：
```
[高潮段落 10-15秒] 画面以中心点为轴进行 4 象限镜像（kaleidoscope effect），上下左右对称复制，形成万花筒图案，每个象限内的画面同步运动，镜像边界处有轻微发光效果，营造迷幻视觉
```

## 4. 镜头语言与运动

### 4.1 MV 常用镜头运动

| 镜头运动 | 运动方式 | 情绪传达 | 音乐匹配 |
|---------|---------|---------|---------|
| **静止镜头** | 固定不动 | 稳定、聚焦、严肃 | 安静段落、叙事 |
| **推拉镜头** | 向前推进或向后拉远 | 推进=紧张/聚焦，拉远=疏离/全貌 | 情绪变化、高潮前 |
| **跟随镜头** | 跟随人物移动 | 沉浸感、第一视角 | 动态段落、舞蹈 |
| **环绕镜头** | 绕主体旋转 | 展示、炫耀、动感 | 高潮、solo 段落 |
| **甩镜头** | 快速水平甩动 | 转场、时空切换 | 快速切换、Drop |
| **手持晃动** | 模拟手持抖动 | 真实感、纪实感 | 现场感、街头风 |
| **无人机航拍** | 高空俯瞰或上升 | 宏大、自由、开阔 | 开场、结尾、副歌 |

### 4.2 镜头运动提示词示例

**环绕镜头配合节奏**：
```
[副歌段落 15-25秒] 镜头以歌手为中心顺时针环绕 360 度（10 秒完成一圈），环绕速度与音乐节奏同步：
- 前 5 秒（15-20秒）：镜头匀速环绕（linear），背景为夜景城市灯光虚化
- 20秒：重拍瞬间，镜头速度突然加快 2 倍（1 秒内完成 90 度旋转）
- 21-25秒：镜头恢复正常速度，继续环绕至初始位置
```

**甩镜头转场**：
```
[8秒] 镜头在场景 A（室内）快速向右甩动（0.2 秒内水平移动 180 度，运动模糊强烈）
[8.2秒] 镜头甩动至场景 B（户外），甩动过程中画面模糊，甩动结束后画面清晰，配合鼓点瞬间完成场景切换
```

## 5. 色彩与色调

### 5.1 MV 色调类型

| 色调名称 | 颜色特征 | 情绪氛围 | 适用音乐 |
|---------|---------|---------|---------|
| **暖色调** | 橙黄红为主 | 温暖、激情、怀旧 | 抒情、流行 |
| **冷色调** | 蓝青紫为主 | 冷酷、忧郁、科技 | 电子、R&B |
| **高饱和** | 纯色鲜艳 | 活力、青春、张扬 | 流行、嘻哈 |
| **低饱和/褪色** | 色彩灰蒙蒙 | 复古、怀旧、柔和 | 独立、民谣 |
| **黑白** | 纯黑白无彩色 | 经典、艺术、忧郁 | 爵士、艺术流行 |
| **双色调** | 仅保留 1-2 种颜色 | 强烈、风格化 | 实验、艺术 |
| **霓虹荧光** | 荧光色彩 | 夜店、派对、未来 | 电子、舞曲 |

### 5.2 色调提示词示例

**暖色怀旧**：
```
色调：暖色调（warm tone），整体偏橙黄色（+20% orange, +10% yellow），高光部分带金色（golden highlights），阴影部分呈深褐色（deep brown shadows），营造日落黄昏的温暖怀旧氛围，色彩饱和度降低 20%（desaturated）
```

**双色调（青橙对比）**：
```
色调：双色调（duotone），阴影和暗部为深青色（#003D4C），高光和亮部为暖橙色（#FF8C42），中间调过渡自然，去除其他色彩信息，营造强烈视觉对比和风格化效果
```

## 6. 剪辑节奏

### 6.1 剪辑节奏类型

| 节奏类型 | 切换频率 | 情绪传达 | 适用段落 |
|---------|---------|---------|---------|
| **慢节奏** | 5-10 秒一镜 | 舒缓、叙事、沉浸 | 前奏、过渡段 |
| **中节奏** | 2-4 秒一镜 | 常规、稳定、流畅 | 主歌段落 |
| **快节奏** | 0.5-1 秒一镜 | 动感、激烈、刺激 | 副歌、高潮 |
| **闪切** | 0.1-0.3 秒一镜 | 爆发、冲击、混乱 | Drop 瞬间 |

### 6.2 剪辑节奏提示词示例

**主歌中节奏 + 副歌快节奏**：
```
剪辑节奏规划：

主歌段落（0-20秒）：中节奏剪辑
[0-3秒] 镜头 1：歌手正面中景
[3-6秒] 镜头 2：侧面特写
[6-9秒] 镜头 3：全景展示环境
[9-12秒] 镜头 4：手部特写
...每 3 秒切换一次镜头

副歌段落（20-30秒）：快节奏剪辑
[20-21秒] 镜头 1：歌手正面
[21-22秒] 镜头 2：舞者群舞
[22-23秒] 镜头 3：灯光特写
[23-24秒] 镜头 4：歌手侧面
...每 1 秒切换一次镜头，配合鼓点
```

## 7. 场景与布景

### 7.1 常见 MV 场景类型

| 场景类型 | 环境特征 | 光线氛围 | 适用风格 |
|---------|---------|---------|---------|
| **室内棚拍** | 纯色背景墙、极简布景 | 可控光源、均匀照明 | 所有类型通用 |
| **街头夜景** | 城市街道、霓虹灯、车流 | 霓虹灯、路灯、昏暗 | 嘻哈、R&B、电子 |
| **自然户外** | 森林、海滩、山野 | 自然光、黄昏/日出 | 民谣、独立、清新 |
| **废墟工业** | 废弃工厂、仓库、涂鸦墙 | 硬光、强对比 | 摇滚、嘻哈、实验 |
| **豪华室内** | 宫殿、别墅、酒店 | 华丽吊灯、暖黄光 | 流行、R&B、奢华风 |
| **超现实空间** | 无限延伸、镜面、悬浮 | 戏剧性用光 | 艺术、实验、概念 |

### 7.2 场景提示词示例

**街头夜景**：
```
环境：城市夜景街道，湿润的柏油路面反射霓虹灯光（粉色和蓝色），背景有模糊的车流光轨，街边商铺的日文霓虹招牌，轻微雾气弥漫，地面有浅水坑反射灯光

光线：主要光源为霓虹灯（侧面照射），人物脸部有荧光粉色边缘光（rim light），背景昏暗但霓虹区域明亮，营造赛博朋克氛围
```

**超现实空间**：
```
环境：无限延伸的白色空间，地面为镜面材质（完美反射人物倒影），远处有漂浮的几何形体（立方体、球体）缓慢旋转，空间无明确边界，营造超脱现实感

光线：顶部柔光均匀照射，无明显阴影，人物周围有轻微光晕，远处几何体边缘有荧光蓝描边
```
