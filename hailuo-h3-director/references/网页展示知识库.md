# 网页展示知识库

本文档为 H3 生成网页展示、数字内容演示、品牌网站动态呈现类视频提示词提供专业知识支持。

---

## 1. 网页交互演示

### 1.1 常见网页交互类型

| 交互类型 | 触发方式 | 视觉反馈 | 适用场景 |
|---------|---------|---------|---------|
| **鼠标悬停** | 光标移到元素上 | 元素变色、放大、下划线出现 | 导航栏、按钮、卡片 |
| **点击** | 鼠标点击 | 按钮按下、波纹扩散、页面跳转 | 按钮、链接、提交 |
| **滚动触发** | 页面向下滚动 | 元素淡入、视差移动、数字递增 | 长页面、产品展示 |
| **拖拽** | 鼠标拖动元素 | 元素跟随光标、拖拽轨迹 | 可排序列表、滑块 |
| **表单输入** | 文字输入 | 光标闪烁、输入框高亮、实时验证 | 登录、注册、搜索 |
| **下拉展开** | 点击展开菜单 | 菜单下拉滑出、选项淡入 | 下拉菜单、折叠面板 |

### 1.2 交互演示提示词示例

**鼠标悬停导航栏**：
```
[0-2秒] 光标从屏幕左侧移动至导航栏"产品"按钮（ease-in-out）
[2-2.5秒] 光标悬停在"产品"按钮上，按钮背景色从透明过渡到半透明白色（ease-out，透明度 0 → 30%），按钮文字下方出现蓝色下划线从左到右扫过（0.3 秒，ease-out）
[2.5-3秒] 光标继续向右移动至"服务"按钮，"产品"按钮恢复原状（背景透明，下划线消失）
```

**按钮点击波纹效果**：
```
[0-1秒] 光标移动至"立即购买"按钮（蓝色矩形按钮，圆角 8px）
[1-1.2秒] 光标点击按钮，按钮快速缩小至 0.95（ease-in）
[1.2-1.5秒] 从点击位置向外扩散白色半透明波纹（ripple effect，圆形从 0 → 按钮宽度，透明度从 50% → 0%，ease-out）
[1.5-1.8秒] 按钮弹回至 1.0（elastic），页面淡出准备跳转
```

**滚动触发元素淡入**：
```
[0-2秒] 页面初始显示顶部 banner，下方内容区域在视口外（不可见）
[2-4秒] 页面向下滚动（smooth scroll），滚动条向下移动
[4-5秒] 当"产品特点"标题滚动到视口中央时，标题从下方滑入并淡入（slide up + fade in，位移 50px，透明度 0 → 100%，ease-out）
[5-6秒] 标题下方的 3 个特点卡片依次淡入（每张间隔 0.2 秒，ease-out）
```

## 2. 滚动视差效果

### 2.1 视差滚动类型

| 视差类型 | 运动关系 | 视觉效果 | 适用场景 |
|---------|---------|---------|---------|
| **多层视差** | 不同层以不同速度滚动 | 营造空间深度感 | 首页 hero 区、产品展示 |
| **背景固定** | 背景不动，前景滚动 | 背景图钉住效果 | 品牌故事、大图展示 |
| **元素横向移动** | 滚动时元素左右移动 | 动态流动感 | 装饰元素、品牌 Logo 墙 |
| **缩放视差** | 滚动时元素放大/缩小 | 聚焦或空间扩展感 | 产品特写、图片画廊 |
| **旋转视差** | 滚动时元素旋转 | 立体感、活力 | 装饰图形、产品 3D 展示 |

### 2.2 视差效果提示词示例

**多层视差（三层）**：
```
[0-5秒] 页面向下滚动（滚动距离 800px）

- 前景层（文字内容）：以 1.0 倍速度向上滚动（正常滚动速度）
- 中景层（产品图片）：以 0.6 倍速度向上滚动（比前景慢）
- 背景层（渐变背景）：以 0.3 倍速度向上滚动（最慢）

通过速度差营造空间层次感，产品图片像"悬浮"在前景和背景之间
```

**背景固定（Parallax Fixed）**：
```
[0-5秒] 页面向下滚动
- 背景图（城市天际线照片）：固定不动（position: fixed），始终停留在视口中央
- 前景内容（文字段落、按钮）：正常向上滚动，内容从背景图上方移过
- 背景图上方有半透明深色遮罩（透明度 40%），确保前景文字清晰可读
```

## 3. 页面加载与转场

### 3.1 页面加载动画

| 加载类型 | 视觉形式 | 动画描述 | 适用场景 |
|---------|---------|---------|---------|
| **骨架屏** | 灰色占位块 | 从左到右扫过光效 | 内容加载预览 |
| **品牌 Logo** | Logo 动画 | Logo 描边生长或淡入 | 首次访问、品牌强化 |
| **进度条** | 横条填充 | 0-100% 填充 | 资源加载、大文件 |
| **遮罩揭开** | 幕布拉开 | 从上/下/侧边滑出 | 页面初始展示 |
| **元素依次淡入** | 元素逐个显现 | 从上到下依次淡入 | 首屏内容加载 |

### 3.2 页面转场动画

| 转场类型 | 动作描述 | 视觉效果 | 适用场景 |
|---------|---------|---------|---------|
| **淡入淡出** | 当前页淡出，新页淡入 | 柔和平滑 | 通用转场 |
| **滑动切换** | 页面左右或上下滑动 | 流畅连贯 | 多页应用、幻灯片 |
| **缩放** | 当前页缩小消失，新页放大 | 聚焦感 | 详情页进入 |
| **翻页** | 像书页一样翻转 | 纸质感、优雅 | 作品集、电子书 |
| **液态变形** | 页面像液体融合 | 高端、流动 | 品牌网站、创意展示 |

### 3.3 加载与转场提示词示例

**骨架屏加载**：
```
[0-2秒] 页面显示骨架屏（skeleton screen）：
- 顶部导航栏：灰色矩形占位（#E0E0E0）
- 主内容区域：3 个灰色圆角矩形卡片占位，排列成网格
- 从左到右扫过白色半透明光效（linear，每 1.5 秒循环一次，光效宽度 100px，透明度 30%）

[2-3秒] 骨架屏淡出（fade out，0.5 秒），真实内容淡入（fade in，0.5 秒）：
- 导航栏显示真实 Logo 和菜单项
- 卡片显示产品图片、标题、描述
```

**页面滑动转场**：
```
[0-1秒] 用户点击导航栏"关于我们"，当前页（首页）向左滑出画面（ease-in-out，1 秒内完全移出）
[同时] 新页面（关于页）从右侧滑入（ease-in-out，1 秒内到达正常位置）
[1-2秒] 关于页内容依次淡入：标题（0.3 秒）→ 段落（0.5 秒）→ 图片（0.7 秒）
```

## 4. 品牌动态呈现

### 4.1 品牌元素展示方式

| 展示元素 | 呈现方式 | 动画特点 | 适用时机 |
|---------|---------|---------|---------|
| **Logo** | 描边生长、淡入、组装 | 优雅、精致 | 页面开场、首屏 |
| **标语/口号** | 打字机效果、逐字淡入 | 叙事感、强调 | Logo 后、品牌介绍 |
| **品牌色** | 色块扩散、渐变流动 | 视觉冲击、品牌识别 | 背景、转场 |
| **产品阵列** | 依次展示、旋转登场 | 丰富感、专业 | 产品页、品类展示 |
| **数据可视化** | 数字递增、图表生长 | 可信度、成就感 | 关于页、成绩展示 |

### 4.2 品牌呈现提示词示例

**Logo 描边生长**：
```
[0-3秒] 品牌 Logo 以白色描边路径动画方式显现（stroke animation）：
- Logo 轮廓线从左上角起点开始描绘，沿路径生长（ease-out），线条粗细 2px
- 3 秒内完成整个 Logo 的轮廓描绘
[3-4秒] Logo 内部填充品牌蓝色（#0066FF）从上到下填充（ease-out）
[4-5秒] Logo 下方品牌名称"TechBrand"以淡入方式显现（fade in，ease-out）
```

**数据递增动画**：
```
[滚动到"成就"区域] 触发数据递增动画：
- "10000+ 用户"：数字从 0 快速递增至 10000（2 秒内完成，ease-out），每 0.05 秒更新一次数字
- "98% 满意度"：数字从 0 递增至 98（1.5 秒内完成，ease-out）
- "50+ 国家"：数字从 0 递增至 50（1 秒内完成，ease-out）
- 数字递增的同时，对应图标从下方弹出（bounce）
```

## 5. 响应式与设备展示

### 5.1 多设备展示方式

| 设备类型 | 展示方式 | 动画特点 | 适用场景 |
|---------|---------|---------|---------|
| **桌面浏览器** | 浏览器窗口 + 地址栏 | 窗口整体展示 | 网站 UI 展示 |
| **手机竖屏** | 手机外框 + 屏幕内容 | 手持感、滚动演示 | 移动端适配展示 |
| **平板横屏** | 平板外框 + 屏幕内容 | 中等尺寸展示 | 跨设备适配 |
| **多屏组合** | 桌面+手机+平板同框 | 响应式强调 | 全平台展示 |

### 5.2 设备展示提示词示例

**手机滚动演示**：
```
[0-1秒] iPhone 手机（黑色外框，圆角屏幕）从右侧滑入画面（ease-out），竖屏放置，屏幕亮起显示 App 首页
[1-4秒] 手机屏幕内容向上滚动（smooth scroll），展示 App 不同模块：
  - 1-2秒：顶部 banner 区域
  - 2-3秒：中部产品卡片网格
  - 3-4秒：底部导航栏
[4-5秒] 手指图标从屏幕底部向上滑动（模拟触摸手势），屏幕随手势向上滚动
```

**多设备响应式展示**：
```
[0-2秒] 画面中央出现桌面浏览器窗口（1920x1080），显示网站首页，窗口带有地址栏和浏览器控件
[2-3秒] 浏览器窗口向左移动并缩小至 40% 大小（ease-in-out）
[3-4秒] 右侧出现平板设备（横屏，768x1024），显示同一网站的平板适配版本，布局调整为双列
[4-5秒] 平板下方出现手机设备（竖屏，375x812），显示移动端适配版本，布局为单列堆叠
[5-6秒] 三设备同时轻微上下浮动（float，ease-in-out），强调响应式设计
```

## 6. 动态图表与数据可视化

### 6.1 图表类型与动画

| 图表类型 | 动画方式 | 视觉效果 | 适用数据 |
|---------|---------|---------|---------|
| **柱状图** | 柱子从下向上生长 | 清晰直观 | 对比数据、时间序列 |
| **折线图** | 线条从左到右描绘 | 流畅连贯 | 趋势变化、时间序列 |
| **饼图** | 扇形逐个展开 | 旋转展示 | 占比、构成 |
| **环形进度** | 圆环顺时针填充 | 聚焦单一指标 | 百分比、完成度 |
| **雷达图** | 从中心向外扩散 | 多维展示 | 多维度评估 |

### 6.2 图表动画提示词示例

**柱状图生长**：
```
[0-2秒] 图表坐标轴淡入（X 轴和 Y 轴，灰色线条）
[2-4秒] 5 根柱子依次从底部向上生长（每根间隔 0.3 秒，ease-out）：
  - 第 1 根柱子：0 → 60% 高度，蓝色（#0066FF）
  - 第 2 根柱子：0 → 80% 高度，蓝色
  - 第 3 根柱子：0 → 45% 高度，蓝色
  - 第 4 根柱子：0 → 95% 高度，橙色高亮（#FF6600）
  - 第 5 根柱子：0 → 70% 高度，蓝色
[4-5秒] 柱子顶部数值标签淡入（fade in），显示具体数据
```

**环形进度填充**：
```
[0-2秒] 灰色圆环背景淡入（线条粗细 8px，透明度 20%）
[2-4秒] 蓝色进度圆环从 12 点位置顺时针填充至 75%（ease-out），填充部分为渐变蓝色（#0066FF → #00AAFF）
[4-5秒] 圆环中央数字从 0 递增至 75（ease-out），显示"75%"，数字为大号粗体
```

## 7. 微交互与细节动画

### 7.1 微交互类型

| 微交互 | 触发时机 | 动画效果 | 用户反馈 |
|--------|---------|---------|---------|
| **表单验证** | 输入完成 | 输入框边框变绿/红，图标出现 | 即时反馈正确/错误 |
| **收藏/点赞** | 点击图标 | 图标放大缩小，颜色变化 | 操作已确认 |
| **通知提示** | 新消息到达 | 从顶部滑下，停留 3 秒后滑出 | 不打断但提醒用户 |
| **加载占位** | 内容加载中 | 骨架屏或旋转圈 | 告知用户等待 |
| **工具提示** | 悬停在图标上 | 小气泡淡入显示说明文字 | 帮助理解功能 |

### 7.2 微交互提示词示例

**点赞动画**：
```
[0-0.2秒] 用户点击"点赞"图标（空心心形，灰色），图标快速缩小至 0.8（ease-in）
[0.2-0.5秒] 图标变为实心红色，快速放大至 1.3（elastic），周围迸发 8 个小红心粒子向外飞散（ease-out）
[0.5-0.7秒] 图标回弹至 1.0（ease-out），粒子淡出消失
[0.7秒后] 点赞数字从 128 变为 129，数字轻微跳动（scale 1.0 → 1.2 → 1.0，bounce）
```

**表单验证反馈**：
```
[用户输入邮箱完成] 
[0-0.3秒] 输入框失去焦点，系统验证邮箱格式
[0.3-0.5秒] 验证通过：输入框边框从灰色变为绿色（ease-out），右侧出现绿色对勾图标（✓）淡入
[0.5-0.8秒] 对勾图标轻微放大缩小（scale 0.8 → 1.2 → 1.0，bounce）

若验证失败：
[0.3-0.5秒] 输入框边框变为红色，右侧出现红色叉号图标（✗），输入框左右抖动（shake，振幅 ±5px，持续 0.3 秒）
[0.5秒后] 输入框下方显示红色错误提示文字"请输入有效的邮箱地址"（淡入）
```

## 8. 快速参考速查

### 常用网页交互术语
- hover（悬停）
- click（点击）
- scroll（滚动）
- drag（拖拽）
- swipe（滑动）
- smooth scroll（平滑滚动）
- ripple effect（波纹效果）

### 常用页面转场术语
- fade in/out（淡入/淡出）
- slide transition（滑动转场）
- zoom transition（缩放转场）
- page flip（翻页）
- liquid transition（液态转场）

### 常用加载动画术语
- skeleton screen（骨架屏）
- loading spinner（加载旋转圈）
- progress bar（进度条）
- shimmer effect（闪烁光效）

### 常用滚动效果术语
- parallax scrolling（视差滚动）
- scroll-triggered animation（滚动触发动画）
- sticky header（固定头部）
- infinite scroll（无限滚动）
