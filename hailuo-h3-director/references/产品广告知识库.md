本文档为 H3 生成产品广告、电商展示、品牌内容类视频提示词提供专业知识支持。

## 1. 产品展示运镜

### 1.1 经典展示运镜类型

| 运镜名称 | 运动轨迹 | 展示重点 | 适用产品 |
|---------|---------|---------|---------|
| **360度旋转** | 镜头绕产品水平旋转一圈 | 完整外观、全方位细节 | 手机、手表、瓶装产品、小型电子产品 |
| **垂直扫描** | 镜头从下到上/从上到下移动 | 产品高度、纵向设计 | 高瓶装产品、立式家电、包装盒 |
| **特写扫描** | 镜头沿产品表面缓慢移动 | 材质细节、工艺质感 | 奢侈品、珠宝、高端电子产品 |
| **爆炸图** | 产品部件分解展示 | 内部结构、组装逻辑 | 电子产品、机械装置、复杂产品 |
| **推进特写** | 镜头从远景推进到特写 | 从整体到细节的引导 | 所有产品通用 |
| **环绕上升** | 镜头螺旋上升环绕产品 | 立体感、高级感 | 高端产品、艺术品、豪华品 |

### 1.2 运镜提示词模板

**360度旋转**：
```
[0-6秒] 镜头以产品为中心，水平匀速旋转 360 度（linear），保持中景（medium shot），产品始终位于画面中央，旋转过程中展示正面、侧面、背面的完整细节
```

**爆炸图**：
```
[0-3秒] 产品各部件从组装状态向四周分离（ease-out），每个部件沿各自轴线移动 20-30cm，部件之间保持相对位置关系清晰可见
[3-5秒] 部件悬浮在空中，缓慢自转展示细节
[5-8秒] 部件从四周飞回（ease-in），精准组合为完整产品
```

**特写扫描**：
```
[0-5秒] 镜头从产品左上角缓慢向右下角移动（slow dolly），距离产品表面 5-10cm，焦点跟随镜头移动（rack focus），依次展示 Logo 雕刻、材质纹理、按键细节
```

## 2. 材质与高光描述

### 2.1 常见产品材质特征

| 材质类型 | 视觉特征 | 高光描述 | 光线策略 |
|---------|---------|---------|---------|
| **金属（哑光）** | 柔和反射，无明显高光 | 宽阔的柔和高光带 | 柔光箱大面积照射 |
| **金属（镜面）** | 强烈镜面反射 | 锐利的高光点，环境倒影清晰 | 硬光源点光，控制反射角度 |
| **玻璃** | 透明/半透明，折射 | 边缘高光，内部光线透射 | 背光 + 轮廓光 |
| **塑料（光滑）** | 均匀反光，轻微高光 | 圆润的高光区域 | 45度角柔光 |
| **皮革** | 纹理清晰，柔和反光 | 随纹理起伏的漫反射 | 侧光强调纹理 |
| **布料** | 吸光，几乎无高光 | 极弱或无高光 | 均匀散射光 |
| **陶瓷** | 光滑，釉面反光 | 柔和的弧形高光 | 顶光 + 侧光 |

### 2.2 材质描述提示词示例

**金属镜面**：
```
主体：不锈钢材质智能手表，表面呈镜面抛光（mirror polish），表壳上清晰映射出周围环境的倒影，边缘有锐利的高光线条，表面反射出蓝色和白色的光源
```

**玻璃透射**：
```
主体：透明玻璃香水瓶，瓶身为高透光玻璃材质，内部琥珀色液体清晰可见，瓶身边缘有明亮的轮廓光（rim light），光线透过液体形成柔和的橙色投影
```

**皮革纹理**：
```
主体：棕色真皮钱包，表面纹理细腻可见（grain texture），皮革呈哑光质感，纹理凹陷处形成细微阴影，侧光照射下纹理立体感强烈
```

## 3. 产品登场方式

### 3.1 经典登场动作

| 登场方式 | 动作描述 | 情绪传达 | 适用场景 |
|---------|---------|---------|---------|
| **从暗到亮** | 灯光逐渐照亮产品 | 神秘感、高级感 | 奢侈品、高端电子产品 |
| **旋转落下** | 产品旋转降落到展台 | 动感、轻盈感 | 轻量产品、时尚品 |
| **组装生成** | 部件飞入组合成产品 | 科技感、精密感 | 电子产品、机械产品 |
| **推门展示** | 门打开/幕布拉开露出产品 | 仪式感、期待感 | 新品发布、重要产品 |
| **液态浮现** | 从液体中浮现或凝聚 | 流动感、高端感 | 化妆品、饮料、香水 |
| **爆破出场** | 从碎片/粒子中聚合 | 冲击力、能量感 | 运动产品、游戏周边 |

### 3.2 登场动作提示词示例

**从暗到亮**：
```
[0-2秒] 画面初始为纯黑背景，聚光灯从上方缓慢照射下来（ease-out），光圈从小到大，逐渐照亮位于中央的产品，产品从阴影中显现，金属表面反射出光线
```

**液态浮现**：
```
[0-3秒] 深色液体（如黑色墨水）在画面中缓慢涌动，产品从液体底部缓慢上升浮现（ease-out），液体从产品表面滑落，露出产品完整外观，液滴带有表面张力感
```

## 4. 包装与文案呈现

### 4.1 包装文案位置标注规范

| 文案位置 | 描述方式 | 示例 |
|---------|---------|------|
| **瓶身正面** | 说明朝向+高度比例 | "瓶身正面中央，距瓶口 1/3 处" |
| **包装盒顶部** | 说明面+位置 | "包装盒顶面左上角" |
| **产品背面** | 说明旋转角度 | "产品旋转至背面 180 度位置" |
| **侧面标签** | 说明侧面方向 | "产品右侧面，垂直排列" |
| **底部信息** | 说明俯视角度 | "产品底部，镜头俯拍可见" |

### 4.2 文案呈现提示词示例

**瓶身文案**：
```
主体：500ml 纯净水瓶，透明 PET 材质，瓶身正面中央印有品牌名称"Pure Spring"（白色无衬线字体，字高约占瓶高 1/8），下方印有"天然矿泉水"（灰色小字，宋体），瓶盖为蓝色

动作：
[0-3秒] 瓶身从画面右侧旋转进入（ease-out），旋转 180 度后正面朝向镜头
[3-6秒] 瓶身静止，镜头缓慢推进至中景（slow dolly-in），文字清晰可读
```

**包装盒文案**：
```
主体：长方形产品包装盒，白色底色，盒盖正面中央印有品牌 Logo（金色烫印），Logo 下方印有产品名称"Premium Edition"（黑色衬线字体，居中排列），盒子边缘有细微的凹凸纹理

文案：盒盖正面的"Premium Edition"字样必须在画面定格时清晰可读，字体为 Didot 风格的衬线体
```

## 5. 电商场景搭建

### 5.1 常见电商场景类型

| 场景类型 | 环境描述 | 光线特征 | 适用品类 |
|---------|---------|---------|---------|
| **纯色背景** | 单一背景色，无陈设 | 均匀柔光，无明显阴影 | 所有品类通用，简洁展示 |
| **生活场景** | 桌面、厨房、卧室等 | 自然光感，环境光 | 家居用品、食品、日用品 |
| **工作场景** | 办公桌、工作台 | 明亮均匀，商业感 | 办公用品、电子产品 |
| **户外场景** | 自然光、植物、天空 | 自然光，柔和阴影 | 运动产品、户外装备 |
| **悬浮展示** | 产品悬浮在空中 | 轮廓光，底部投影 | 科技产品、高端品 |

### 5.2 场景搭建提示词示例

**纯色背景（简约风）**：
```
环境：纯白色背景（#FFFFFF），无任何陈设，地面有产品的柔和阴影（软阴影，透明度 20%），背景从上到下有轻微的明度渐变（上亮下暗 5%）

光线：三点布光（three-point lighting），主光源从左前方 45 度照射（柔光），辅光从右侧补光（光比 1:2），轮廓光从后上方勾勒产品边缘
```

**生活场景（温馨感）**：
```
环境：木质餐桌表面，桌面为浅色橡木纹理，产品旁边放置一杯咖啡（作为尺寸参照和氛围营造），背景虚化（景深效果），隐约可见窗户和绿植

光线：窗外自然光从左侧照入（golden hour lighting），光线柔和温暖，桌面上有窗框投下的光影图案
```

## 6. 产品动态功能展示

### 6.1 功能展示策略

| 产品类型 | 展示方式 | 关键动作 |
|---------|---------|---------|
| **可开合产品** | 打开/关闭动作 | 铰链转动、盖板滑动 |
| **液体产品** | 倾倒/倒出 | 液体流动、水花飞溅 |
| **可穿戴设备** | 佩戴展示 | 手腕戴上、调整松紧 |
| **可折叠产品** | 折叠/展开 | 结构变化、空间转换 |
| **电子产品** | 开机/点亮屏幕 | 屏幕亮起、界面显示 |

### 6.2 功能展示提示词示例

**笔记本电脑开合**：
```
[0-2秒] 笔记本电脑处于合上状态，静置在白色桌面上
[2-5秒] 屏幕盖从闭合位置缓慢打开（ease-out），铰链转动流畅，打开角度从 0 度到 120 度
[5-7秒] 屏幕点亮（0.5 秒淡入），显示品牌 Logo，键盘背光同时亮起（蓝色柔光）
[7-8秒] 画面定格，屏幕和键盘背光稳定显示
```

**饮料倾倒**：
```
[0-2秒] 饮料瓶悬浮在玻璃杯上方，瓶口对准杯子
[2-5秒] 瓶身倾斜 45 度（ease-in-out），琥珀色液体从瓶口倒出，液体流动形成光滑的弧线，落入杯中激起轻微气泡和水花
[5-7秒] 液体充满玻璃杯至 80% 高度，杯壁上凝结水珠，瓶身回正
```

## 7. 品牌元素强化

### 7.1 Logo 展示方式

| 展示时机 | 展示方式 | 视觉强化 |
|---------|---------|---------|
| **开场** | Logo 动画登场 | 发光、粒子、描边生长 |
| **产品上** | 特写 Logo 细节 | 推进镜头、聚焦、高光 |
| **结尾** | Logo 定格 | 全屏居中、背景简化 |

### 7.2 品牌强化提示词示例

**Logo 特写强化**：
```
[4-6秒] 镜头从产品整体缓慢推进至 Logo 特写（slow dolly-in to extreme close-up），Logo 位于产品正面中央，金属拉丝材质，光线从侧面扫过 Logo 表面，产生流动的高光效果，Logo 的立体雕刻细节清晰可见
```

## 8. 快速参考速查

### 常用产品运镜英文术语
- 360-degree rotation（360度旋转）
- vertical scan（垂直扫描）
- close-up scan（特写扫描）
- exploded view（爆炸图）
- dolly-in to product（推进产品）
- orbit around product（环绕产品）

### 常用材质英文术语
- mirror polish（镜面抛光）
- brushed metal（拉丝金属）
- matte finish（哑光表面）
- glossy surface（光滑表面）
- transparent glass（透明玻璃）
- leather texture（皮革纹理）

### 常用光线术语
- rim light（轮廓光）
- three-point lighting（三点布光）
- soft light（柔光）
- hard light（硬光）
- backlit（逆光）
- golden hour lighting（黄金时刻光线）
