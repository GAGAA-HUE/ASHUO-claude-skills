# H3 特化场景路由指南

本文档说明如何在使用 `hailuo-h3-director` 时识别并路由到 MiniMax 官方 8 个特化 skill 的对应场景。

## 路由总览

| 触发词 / 用户意图 | 路由方向 | 处理方式 |
|-----------------|---------|---------|
| 极简产品广告、Apple 风电商广告、电商产品视频、新品发布广告 | `minimalist-product-ad-generator` | 见 §1 |
| 品牌宣传片、官网展示、品牌片、品牌广告 | `brand-promo-video-generator` | 见 §2 |
| 双人合作游戏菜单、双人游戏主菜单、合作游戏开场 | `co-op-game-intro-generator` | 见 §3 |
| 手绘实拍融合、15 秒变形追逐、蜡笔发光动画、手绘接触实拍 | `handdrawn-live-video-generator` | 见 §4 |
| MV 歌词贴字、歌词字幕、卡点剪辑、Trap MV、Dark-pop | `music-video-subtitle-generator` | 见 §5 |
| 纸拼贴定格科普、纸拼贴科普视频 | `paper-collage-explainer-generator` | 见 §6 |
| 纸艺定格科普、立体书科普、纸模型动画 | `papercraft-stop-motion-explainer` | 见 §7 |

| 游戏界面/UI 动效、网页展示、AE 片头/MG 动画 | `hailuo-h3-director` 内化处理 | 走对应知识库 |

## §1 minimalist-product-ad-generator

**触发关键词**：minimalist product ad、premium product ad、Apple 风广告、极简产品广告、高质感产品广告、产品广告片、电商产品视频、新品发布广告

**核心特征**：用户提供一张产品图 → Apple 风 5-15s 电商广告。

**已内化内容**（写入 `产品广告知识库.md`）：
- 单行 + 双色 + `SF Pro Display Semibold` 的 Apple 风文字规则
- 三张独立锚定照原则（不用四宫格，防止模型复制版式）
- 产品本体颜色保真（不能因 Apple 风把产品改成白色/银色）
- 产品专属叙事、产品真实动作驱动转场、一节拍一动作、稳定结尾

**路由判断**：
- Apple 风、极简、高质感电商、依赖产品图的完整广告流程 → 推荐 `minimalist-product-ad-generator`
- 仅要一条通用产品广告提示词 → 本 skill 内化处理

---

## §2 brand-promo-video-generator

**触发关键词**：品牌宣传、品牌片、官网展示、品牌广告、品牌发布会、launch film

**核心特征**：品牌资产真伪核查、来源 manifest、真实产品声明/CTA 审核。

**已内化内容**（写入 `H3专用规则.md`）：
- 不仿造 logo、wordmark、包装、官方 UI、吉祥物或真实人物
- 不编造产品功能、性能指标、口号、CTA、合规声明或市场数据
- 身份素材需来自用户原件、官方来源或授权素材；不明来源只能作为非官方概念

**路由判断**：
- 用户要做真实品牌宣传、要核验资产、要成套品牌片流程 → 推荐 `brand-promo-video-generator`
- 用户只想写一条品牌风格概念提示词 → 本 skill 内化处理

---

## §3 co-op-game-intro-generator

**触发关键词**：双人合作游戏、双人游戏菜单、co-op game、玩家卡、player card

**核心特征**：固定 UI 框架 + 双角色身份锁定 + 确认图 → H3 视频。

**已内化内容**（写入 `游戏界面与UI动效知识库.md`）：
- 固定 UI 框架与动态美术风格分离
- 确认图优先于视频；确认后才写时间轴
- 双角色的身份、昵称、位置与体型差异锁定
- 单行菜单、统一图标/字体/材质系统、Z 形阅读路径

**路由判断**：
- 双人合作游戏主菜单/开场 → 推荐 `co-op-game-intro-generator`
- 普通游戏界面动效 → 本 skill 内化处理

---

## §4 handdrawn-live-video-generator

**触发关键词**：手绘实拍融合、蜡笔发光动画、手绘接触实拍、15 秒变形追逐、crayon glow

**核心特征**：手绘平面实体与实拍空间融合，0-3s 接触、连续变形、慢半拍手持追拍。

**已内化内容**（写入 `AE片头与MG动画知识库.md`）：
- 0-3 秒真人手/物与手绘实体的明确接触
- 同一实体连续变形，形态变化保留线条/拖痕/曲线母题
- 15 秒的五段节拍与 13-15 秒空间级变形
- 蜡笔/粉笔/粗糙笔刷/逐帧重画感
- 非恐怖禁止清单及手机追拍慢半拍规则

**路由判断**：
- 用户要固定的手绘实拍融合成片 → 推荐 `handdrawn-live-video-generator`
- 一般手绘/MG 动画 → 本 skill 内化处理

## §5 music-video-subtitle-generator

**触发关键词**：MV、歌词贴字、卡点剪辑、Trap MV、Dark-pop、Cyber-grunge、lyric typography

**核心特征**：Master Audio 全局锁定 + Beat grid 对齐 + 跨镜头 5 大锚链。

**已内化内容**（写入 `MV视觉知识库.md`）：
- Master Audio 锁定
- 歌词所有权：用户歌词逐字不改；歌唱和可见文字逐字匹配
- 字幕是空间图形层，每镜头一个主要文字事件，不遮眼睛、表情、关键口型
- 多段拼接的口型/节奏/美术/动势/文字动势连续性
- Dark-pop / Trap 硬切规则、节拍对应视觉反馈

**路由判断**：
- 带歌词贴字、跨镜头缝合的 30 秒以上 MV → 推荐 `music-video-subtitle-generator`
- 普通无贴字 MV 视觉 → 本 skill 内化处理

---

## §6 paper-collage-explainer-generator

**触发关键词**：纸拼贴、定格拼贴、halftone collage、collage explainer

**核心特征**：halftone 拼贴风格 + 颜色情绪映射 + 拼贴 SFX + 先确认计划与末帧。

**路由判断**：
- 用户明确要纸拼贴风科普/解说、要从概念到成片的流程 → 推荐 `paper-collage-explainer-generator`
- 普通科普或只想写一条 H3 提示词 → 本 skill 内化处理，但可吸收以下最小风格包：
  - bold color field、black-and-white halftone photographic cut-outs、selective cardstock accents、warm cream keylines、soft paper shadows、hand-torn edges、layered paper seams
  - 逐件组装：appear → slide/pop → light bounce → press flat → pause → lock
  - 默认保留拼贴 SFX；不自动添加 BGM、口播、字幕、文字、logo
  - 避免全局淡入、平滑数字层移动、快速旋转、镜头缩放、脏旧 kraft-paper 底色

---

## §7 papercraft-stop-motion-explainer

**触发关键词**：纸艺定格、立体书、纸模型、papercraft、纸艺科普

**核心特征**：多层纸艺景深 + 手工定格运动 + 完整科普包。

**路由判断**：
- 用户要纸艺/立体书风科普的完整包或故事板 → 推荐 `papercraft-stop-motion-explainer`
- 用户只要一条 5 秒纸艺 H3 提示词 → 本 skill 内化处理，采用：
  - 纸纤维、折痕、接缝、剪切边缘、可见纸板厚度、物理层阴影
  - 前景/中景/背景/远背景 4 层深度与轻微视差
  - stepped movement、tiny pauses、slight rebound、hinged gestures、pull-tabs、sliders、page flips
  - 慢推/横移/微距纸艺特写；禁用高速飞行镜头、液体变形、塑料 CG、电子故障效果

---

## §8 3d-animation-short-generator

**触发关键词**：完整 3D 短片、皮克斯 3D、角色卡 + 分镜表、end-to-end 动画工作流

**核心特征**：从故事大纲到最终成片的 18 步流程、六列标准分镜表、角色卡/场景卡/文字分镜。

**路由判断**：
- 用户要完整 3D 角色叙事短片、且愿意逐步确认角色/场景/分镜 → 推荐 `3d-animation-short-generator`
- 用户只要单条 3D 动画片段 → 本 skill 内化处理；用现有三段式输出，不强制完整流程

## 默认行为（无需路由）

以下场景**默认留在 `hailuo-h3-director` 内化处理**：

1. AE 片头 / MG 动画 → `AE片头与MG动画知识库.md`
2. 通用 MV 视觉（无歌词贴字） → `MV视觉知识库.md`
3. 通用产品广告（非 Apple 风完整流程） → `产品广告知识库.md`
4. 游戏界面 / UI 动效 → `游戏界面与UI动效知识库.md`
5. 网页展示 → `网页展示知识库.md`

## 路由选择决策树

```
用户输入
  ├─ 命中 8 个特化 skill 的触发关键词？
  │    ├─ 是 → 告知用户推荐的特化 skill 与原因，等待选择，不自动切换
  │    └─ 否 → 继续判断
  │
  ├─ 属于五大基础场景？
  │    ├─ AE 片头/MG 动画 → 内化处理
  │    ├─ 产品广告 → 内化（除非命中极简产品片完整流程）
  │    ├─ 游戏界面/UI 动效 → 内化
  │    ├─ MV 视觉 → 内化（除非命中歌词贴字/长 MV）
  │    └─ 网页展示 → 内化
  │
  └─ 其他场景 → 本 skill 的通用三段式处理
```
