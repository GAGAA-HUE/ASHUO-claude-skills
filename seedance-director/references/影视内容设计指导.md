# 影视内容设计指导 — 角色、场景、氛围与镜头叙事的创作框架

## 指导理念

本文件不是新的重型模板，也不是要求把所有 prompt 都写成长篇说明书。它的作用，是为高密度视频提示词提供一套内容增厚的创作框架与决策工具，帮助输出在保持轻量可复制的前提下，依然具备足够强的角色识别度、场景质感、气氛控制和镜头叙事能力。

核心原则：
- 轻量不等于稀薄，但高密度也不等于平均分配篇幅。
- 默认情况下，角色信息优先保证外观设计、年龄感、服装轮廓、材质、配色与基础气质的清晰度。
- 默认情况下，场景信息优先承担电影质感的控制责任，应重点决定风格化空间、美术方向、材质层次、空气感、光影组织、时代语义与视觉体系。
- 当角色与场景争夺篇幅时，默认优先保留更能提升画面质感、生成稳定性和电影感的场景信息。
- 行为逻辑、关系状态、复杂心理信息仅在用户明确需要强叙事人物塑造时增强，不作为默认角色写法的主轴。

---

## 一、角色塑造指导

### 1.1 默认角色写法：先保证造型识别度

默认情况下，角色描述的首要任务不是展开复杂人格分析，而是让模型先稳定理解“这个人长什么样、穿什么、呈现什么基础气质”。

优先顺序通常应为：

1. 年龄感
2. 外观轮廓
3. 发型、肤色、体型比例等基础识别特征
4. 服装结构、材质与配色
5. 基础气质

默认情况下，不必主动展开复杂行为逻辑、深层心理结构或人物关系分析，除非用户明确要求角色驱动型叙事，或画面确实需要靠人物表演与关系张力成立。

### 1.2 角色不是外观清单，但默认也不必过度人格化

角色描述不应只剩“年轻、好看、穿白衣服”这类空泛词汇，但也不应默认写成完整人物小传。

对大多数视频生成需求而言，更有效的默认角色信息通常是：
- 年龄感是否明确
- 造型轮廓是否清楚
- 服装设计是否有材质与结构
- 配色是否服务整体画面
- 气质是否足够简洁明确

例如，比起写大量抽象性格说明，更有效的是直接写出：
- 清爽克制的高中毕业生气质
- 疲惫但仍体面的中年刑警状态
- 冷白洁净、近未来医务人员式外观
- 奢华松弛、带假日余温的年轻富家女形象

这些信息更容易先转化成稳定的视觉结果。

### 1.3 基础气质的写法

基础气质的作用，是帮助人物在镜头中具备明确的第一印象，而不是默认展开成复杂表演系统。

常见可直接使用的基础气质方向：
- 冷淡
- 松弛
- 明亮
- 清爽
- 疏离
- 脆弱
- 倔强
- 危险
- 优雅
- 稚气未退

默认情况下，这类气质只需要轻量点明，并尽量与外观、服装、姿态保持一致，不必自动扩写成大量行为细节、表情惯性或关系描述。

### 1.4 只有在必要时，才增强行为逻辑与关系状态

以下情况，才建议进一步补充角色的行为逻辑、身体习惯、关系状态与微表情系统：

- 用户明确要求角色“很有戏”“很有人格”“很有关系张力”
- 画面的核心不是环境质感，而是人物互动
- 存在明确的对峙、试探、压制、依赖、引诱、协作或疏离关系
- 镜头叙事明显依赖人物停顿、目光交换、动作习惯或情绪压抑
- 需要更接近剧情片、表演片段而非风格化画面生成

也就是说，这些能力不是删除，而是从“默认层”改为“条件增强层”。

### 1.5 不同角色类型的默认写法重点

#### 人类角色
默认优先写：
- 年龄感与面部轮廓
- 发型、肤色、体型比例
- 服装层次与材质状态
- 基础气质
- 必要时再补职业痕迹或身体习惯

#### 机器人 / 仿生人 / 机械角色
默认优先写：
- 轮廓结构
- 关节设计
- 表面材质
- 磨损程度
- 发光部位与设计语言
- 必要时再补动作精度、延迟感或故障感

#### 怪物 / 异变体 / 生物装甲角色
默认优先写：
- 非人轮廓
- 表皮、甲壳、骨刺、膜、缝隙等材质结构
- 湿润度、脉动感、污染感或压迫感
- 与环境接触时的视觉异物感
- 必要时再补行走、扑咬、覆盖、生长等行为方式

#### 广告 / 时尚 / 概念角色
默认优先写：
- 造型设计语言
- 配色系统
- 材质表现力
- 姿态是否干净利落、是否具备镜头意识
- 角色是商品化身、品牌代言人、概念具象化还是神话式形象

### 1.6 角色描述的最低完成度

当用户没有要求强叙事人物塑造时，角色描述尽量至少具备：
- 外观轮廓
- 年龄感
- 服装 / 材质 / 配色信息
- 基础气质
- 一个能提升识别度的附加特征

例如：
- 被太阳晒得略微发红的面颊
- 有折痕的白衬衫袖口
- 潮湿发梢贴在额前
- 长时间熬夜后的轻微眼下阴影
- 过于洁净的冷白制服面料

身体行为方式、深层情绪转译、关系状态默认不是最低完成度的必选项，只有在强叙事角色需求中才上升为必要项。

## 二、场景构建指导

### 2.1 场景不是地点说明，而是电影质感的主控制器

默认情况下，场景设定不只是回答“人物在哪里”，而是负责决定整支画面的电影质感、风格方向、时代类型气质、材质层次、空气状态、光影组织和视觉系统。

如果场景设定不够强，人物即使描述得很完整，也容易失去电影感、风格感和高级质感。因此在大多数高要求视频生成任务中，场景信息应当拥有比角色信息更高的默认权重。

### 2.2 场景默认应优先包含六层信息

#### 1. 风格与时代语义
不只是地点或年份，而是它属于什么样的审美世界与文化气质。

例如：
- 当代东亚青春电影
- 90年代旧商场余晖
- 近未来洁净医疗系统
- 后工业港口残响
- 末日之后仍维持奢华体面的私人空间
- 夏季海边广告片式明亮现实

#### 2. 主体空间与背景层级
说明主体空间是什么，次级空间承载什么，背景又保留什么信息。空间是否有前中后层次、是否允许镜头看见纵深、是否存在压迫或留白，都会直接影响画面的高级程度。

#### 3. 美术方向与材质系统
场景不能只写“木头、玻璃、金属”，而应尽量形成成体系的材质组织。

例如：
- 潮湿混凝土与锈蚀钢材
- 漂白木桌与高热自然光
- 白墙、蓝窗帘、旧课桌木面与飞扬纸屑
- 镜面玻璃、乳白灯箱与冷色不锈钢
- 深色皮革、黄铜、石材与低照度暖灯

材质系统越统一，电影质感越稳定。

#### 4. 光影组织
要尽量说明空间中的主光从哪里来，光线是自然散射、硬光切入、侧逆光、顶光压制，还是带体积感的低照度环境光。阴影是否压实，高光是否干净，都会极大影响画面的档次。

#### 5. 空气感与温度感
这是电影质感里极容易被忽视、但非常关键的一层。

例如：
- 夏日下午透明又略带热度的空气
- 漏风废墟中的干冷灰尘感
- 海边盐雾轻微附着的潮润空气
- 空调系统维持下的过度洁净冷空气
- 暴雨前低压而沉闷的室内空气

很多“像不像电影画面”的差别，就来自这层是否被写出来。

#### 6. 叙事性陈设与残留物
空间应尽量像“发生过事情的地方”，而不是空白布景。

可用信息包括：
- 摊开的书本、倒下的椅子、未擦净的黑板字迹
- 半空的酒杯、未收的餐具、折断的花枝
- 泛黄海报、旧报纸、弹孔、警戒带、烟灰、积水
- 被匆忙放下的行李、开着的柜门、被风吹动的窗帘

这些细节不是为了啰嗦，而是为了让空间获得叙事密度与真实存在感。

### 2.3 场景应尽量形成统一的视觉体系

高质量场景描述不应只是元素堆砌，而应形成统一的视觉体系。所谓视觉体系，是指空间风格、材质、光线、空气、色调、陈设彼此属于同一种审美逻辑。

例如：

- 清透青春系：
  高亮自然光、白墙反射、蓝白配色、轻薄棉质校服、透明空气、纸张与汗感肌肤共同构成夏季青春的清爽体系。

- 末日奢华系：
  昂贵陈设、空旷空间、过度整洁但失去使用者痕迹的豪华室内，暖金残照与冷灰阴影并存，形成死寂中的高贵感。

- 近未来洁净失控系：
  极简结构、冷白面光、玻璃与不锈钢、局部有机污染痕迹、低噪声环境与过度秩序感共同构成科技失控前夜的视觉系统。

当场景具备视觉体系时，模型更容易生成真正统一、稳定、具电影感的画面。

### 2.4 复合氛围比单一形容词更有效

用户说“高级感”“电影感”“氛围感”时，往往真正需要的不是单一情绪词，而是复合气质。

更有效的方向通常是：
- 奢华与死寂并存
- 清爽与短暂感并存
- 度假感与灾后残留并存
- 洁净秩序与潜在失控并存
- 明亮自然光与人物沉默并存

复合氛围应尽量通过空间、材质、光影、陈设和空气状态共同实现，而不是只依赖抽象修辞。

### 2.5 场景描述的最低完成度

当用户要求高质感生成时，场景描述尽量至少具备：
- 明确的风格或时代语义
- 主体空间与背景层次
- 至少两类关键材质
- 明确的光线方向或空气状态
- 一到三组叙事性陈设
- 一个清楚的复合氛围或视觉基调

默认情况下，场景最低完成度应高于角色最低完成度，因为场景是电影质感成立的主要支点。

## 三、风格对标指导

### 3.1 当抽象形容词不足以锁定风格时，优先使用精准影视对标

当用户追求明确的类型气质、成熟的美学系统、强烈的影像风格或高辨识度的视觉世界时，单独使用“高级感”“电影感”“末日感”“特摄感”“广告感”这类抽象词通常不够稳定。此时，更有效的方式往往是使用与内容匹配的精准影视对标，直接锁定其可识别的审美系统。

例如，比起只写：
- 日式末日特摄风格
- 冷峻压抑的成人向英雄影像
- 高级的近未来暗黑质感

更有效的写法通常是：
- 参考《仮面ライダーBLACK SUN》的美学风格
- 参考《银翼杀手2049》的空间光影与材质系统
- 参考《花样年华》的色彩克制与室内压迫感
- 参考《情书》的冬季空气感与日式青春影调
- 参考《疯狂的麦克斯：狂暴之路》的废土运动能量与高反差色彩系统

影视对标的价值，不在于“报片名显得专业”，而在于它可以一次性压缩并调用整套成熟的视觉体系，包括：
- 风格类型
- 光影结构
- 色彩与影调
- 场景材质
- 空气感
- 角色造型方向
- 镜头节奏倾向
- 类型片语义

### 3.2 风格对标应尽量精确匹配内容，而不是随意堆叠片名

风格对标必须服务具体内容。不是任何知名电影都能拿来用，而是要选择真正与题材、气质、空间、美术方向相匹配的对标对象。

选择对标时，优先考虑以下匹配维度：
- 题材类型是否一致或接近
- 场景语义是否一致或接近
- 光影与色调是否接近目标效果
- 材质系统是否相似
- 人物造型方向是否兼容
- 镜头节奏是否符合内容需求

例如：
- 青春毕业 MV，不宜默认对标过重、过冷、过压抑的作者电影
- 末日奢华游艇，不宜对标纯写实家庭片
- 成人向特摄异变，不宜对标轻快校园偶像片

对标对象越贴近目标内容，模型越容易生成稳定画面。

### 3.3 一个强对标，通常比多个弱对标更有效

默认情况下，优先使用一个主对标，必要时再补一个辅助对标，不建议堆叠过多参考对象。

推荐顺序：
- 一个主对标：锁定整体美学系统
- 一个辅助对标：补充局部特征，如光影、配色、镜头节奏或材质处理
- 超过两个对标时应谨慎，避免审美系统彼此冲突

例如：
- 主对标：参考《仮面ライダーBLACK SUN》的成人向特摄美学风格
- 辅助对标：局部光影与材质压迫感参考《银翼杀手2049》

这样的写法通常比同时堆叠五六个片名更有效。

### 3.4 对标不是只引用片名，而是要尽量点明引用维度

最稳定的写法，不是只写“参考某电影”，而是尽量说明参考的是它的什么。

推荐引用维度包括：
- 美学风格
- 光影系统
- 色彩与影调
- 场景空间
- 材质系统
- 造型方向
- 镜头运动与节奏
- 氛围结构

例如：
- 参考《仮面ライダーBLACK SUN》的成人向特摄美学风格、压抑城市空间与生物性异变质感
- 参考《花样年华》的室内色彩控制、压缩构图与潮湿闷热的空气感
- 参考《银翼杀手2049》的巨型空间秩序、低饱和未来材质与沉默光影
- 参考《情书》的雪地空气感、柔和自然光与克制的青春影调

这样比单写一个片名更容易让模型抓住重点。

### 3.5 风格对标与原创性的关系

使用影视对标，不等于要求生成结果变成某部作品的复刻。它的作用是帮助模型快速锁定正确的美学区间、材质逻辑、光影语言与类型气质。

因此，更合理的使用方式是：
- 把对标作为风格坐标，而不是内容抄写模板
- 保留当前角色、场景、事件本身的原创内容
- 借用其审美结构，而不是照搬其剧情、人物或具体镜头设计

目标不是“生成那部电影”，而是“让当前内容拥有同等级别、同方向的影像系统”。

### 3.6 适合主动使用风格对标的情况

以下情况，建议主动考虑加入影视对标：
- 用户明确追求高质感、电影级、高级审美
- 用户要求特摄、末日、广告片、预告片、MV、概念短片
- 用户给出的形容词很多，但风格仍然不够锁定
- 画面需要强烈的类型片识别度
- 需要快速建立统一的视觉体系

### 3.7 风格对标的最低使用原则

当使用影视对标时，尽量满足以下要求：
- 对标对象与内容高度匹配
- 以一个主对标为主
- 必要时只补一个辅助对标
- 尽量说明参考维度，而非只报片名
- 对标服务于风格锁定，不替代当前内容本身的角色、场景与事件描述

## 四、氛围与画质指导

### 4.1 推荐四层写法

“氛围与画质”默认优先写成以下四层：

1. 风格核心  
   这支画面最根本的审美方向是什么。  
   例如：写实电影、日式青春广告、成人向特摄、末日美学、复古科幻、冷调悬疑、奢华品牌影像。

2. 视觉基调  
   整体观看感受是什么。  
   例如：克制、清透、潮湿、锋利、洁净、疲惫、压迫、明亮但空心、奢华但死寂。

3. 色彩与影调  
   主色倾向、明暗关系、饱和度、反差、色温、阴影控制、高光滚降方式是否明确。  
   例如：低饱和灰蓝主调，保留高光细节，阴影压实但不糊黑；或蓝白高亮主调，局部皮肤与木色保留自然暖度。

4. 禁用项  
   明确哪些问题不能出现。  
   例如：禁止塑料感肤质、禁止廉价 CG 感、禁止背景脏乱无层次、禁止过曝死白高光、禁止材质混成一片、禁止空气感缺失。

### 4.2 氛围与画质必须从场景中长出来

高质量的“氛围与画质”不应是悬浮的形容词段落，而应与场景的时代语义、材质系统、空气状态和光影组织相互咬合。

也就是说：
- 风格核心应与场景所属的审美世界一致
- 视觉基调应与空间气压、人物状态和环境秩序共同成立
- 色彩与影调应从材质与光线反应里自然长出来
- 禁用项应针对最容易破坏当前风格的常见问题进行约束

### 4.3 画质控制不是一句“电影感”

“电影感”本身过于空泛。真正有效的控制，应尽量落在以下维度：
- 胶片颗粒是否存在，强度如何
- 皮肤、布料、金属、玻璃、木材是否区分清楚
- 画面是柔和卷帘感还是锐利数字感
- 高光是否干净、是否过曝
- 阴影是通透还是压实
- 景深是帮助主体分离，还是帮助空间成立
- 空气是否透明、湿润、尘化、带雾、带热浪或被低压填满

### 4.4 常见视觉方向

#### 写实电影
- 风格核心：现实主义、可信的物理空间、不过度炫技
- 视觉基调：克制、自然、细节真实
- 色彩与影调：中低饱和，不过度磨皮，保留暗部层次
- 禁用项：禁止过度滤镜感、禁止假 HDR、禁止廉价锐化

#### 日式青春 / 清透广告
- 风格核心：清爽、短暂、透明感强的青春影像
- 视觉基调：明亮、轻盈、空气透明、情绪直接
- 色彩与影调：蓝白体系可偏强，肤色自然，允许高亮但不死白
- 禁用项：禁止脏灰、禁止厚重阴影、禁止肤色塑料化、禁止空气浑浊

#### 奢华广告
- 风格核心：高级商品影像、品牌化审美
- 视觉基调：洁净、精致、带控制感的诱惑
- 色彩与影调：高光干净，材质分离明确，允许局部高饱和强调品牌色
- 禁用项：禁止材质发糊、禁止背景杂乱、禁止廉价炫光

#### 末日美学
- 风格核心：文明余烬中的视觉秩序
- 视觉基调：空旷、疲惫、死寂中带残留温度
- 色彩与影调：去饱和主导，可混入暗金、灰蓝、锈红作为残存文明色
- 禁用项：禁止廉价脏乱、禁止颜色胡乱堆叠、禁止失控霓虹

#### 成人向特摄 / 概念奇观
- 风格核心：强造型、强材质、强阶段变化、强视觉识别
- 视觉基调：压迫、异常、冷峻、具生物性或机械性张力
- 色彩与影调：允许高对比与局部发光，但整体控制必须统一
- 禁用项：禁止儿童化玩具感、禁止塑料装甲感、禁止特效与实景脱节

### 4.5 氛围与画质的最低完成度

当用户要求高密度控制时，尽量同时具备：
- 一个清楚的风格核心
- 一个明确的视觉基调
- 一组具体的色彩与影调方向
- 至少一个画质强调点
- 至少两个明确禁用项

## 五、镜头叙事指导

### 5.1 镜头设计必须动态匹配内容

镜头不是默认程序，也不是固定四段结构。镜头设计必须根据以下因素动态决定：
- 画面里最重要的信息是什么
- 观众应先看到空间、人物、动作还是结果
- 情绪是在积累、停滞、失控、释放还是回收
- 人物与环境谁占主导
- 当前重点是质感展示、叙事推进、人物状态还是动作事件

### 5.2 先决定镜头与主体的观察关系

在写镜头之前，先决定镜头如何观察主体：

- 远距离观察：环境压过人物，需要先建立空间秩序与气氛
- 中距离跟随：人物行为是重点，需要同时看到动作与空间关系
- 近距离逼近：情绪、材质、微表情或压迫感是重点
- 环绕审视：主体被展示、被围观、被神化或被困于中心
- 静止凝视：让情绪或空间自行发酵，强调停顿、余韵和结果

### 5.3 不同内容类型对应不同镜头策略

#### 当重点是空间质感
- 优先让观众识别空间结构、材质层次与空气状态
- 镜头可更稳、更缓，避免一上来过碎
- 景别应先帮助场景成立，再进入细部

#### 当重点是人物状态
- 镜头距离比大幅运动更重要
- 特写应当出现在情绪真正聚焦的地方
- 呼吸感、停顿、视线交换比炫技运镜更有效

#### 当重点是动作事件
- 镜头要服务事件链可读性
- 不要为了动感破坏空间理解
- 跟随、预判、延迟反应通常比无意义快摇更有效

#### 当重点是材质细节
- 镜头要像在“触摸”材质
- 特写、慢推、擦过式移动、浅景深都可以强化质地
- 但仍应保留适度整体空间，避免全程只剩碎片

### 5.4 节奏不是快慢二选一

节奏设计应回答：
- 什么时候堆积信息
- 什么时候留白
- 什么时候推进
- 什么时候突然切断
- 什么时候让结尾悬停、收束或抽离

常见节奏方式：
- 缓慢渗透：适合压抑、观察、危险逼近、空间建立
- 稳定推进：适合广告、叙事展示、人物亮相
- 断裂跳切：适合 MV、记忆、混乱、情绪爆点
- 悬停停顿：适合余韵、结果、失语、情绪下坠
- 骤然抽离：适合反讽、结局感、看清代价

### 5.5 结尾画面决定观众最后记住什么

结尾状态不是例行收尾，而是决定观众最后记住什么：
- 留在人脸上，是让人物情绪成为结论
- 留在空间上，是让环境状态成为结论
- 留在动作余波上，是让后果成为结论
- 留在静物或残留物上，是让隐喻成为结论

### 5.6 镜头叙事的最低完成度

当用户要求镜头与内容强绑定时，尽量回答：
- 镜头先看什么
- 为什么这样看
- 在哪里靠近、停顿、转移或拉开
- 节奏如何随内容变化
- 最后把记忆点留在哪里

## 六、声音设计指导

### 6.1 声音不是补充件，而是画面成立的一部分

默认的“声音设计”虽然保持轻量自然语言写法，但内容不应只剩“有氛围感的音效”或“搭配电影感音乐”。有效的声音设计，至少要帮助明确以下信息：
- 这个空间本身在发出什么声音
- 关键动作或材质碰撞会产生什么反馈
- 人物有没有呼吸、停顿、衣料摩擦、脚步、轻笑、吞咽、喘息等身体声音
- 声音是贴身的、空旷的、压抑的、明亮的，还是被环境吞掉的
- 整体节奏是持续铺底、间歇点刺、逐步堆高，还是在关键处突然抽空

### 6.2 默认兼顾三类声音来源

即使最终不拆 Layer 1 / 2 / 3，内部也应优先兼顾：

1. 空间底噪 / 环境音场  
   例如风声、海浪、空调、霓虹嗡鸣、远处交通、电流声、船体轻响、走廊回声。

2. 叙事音效 / 动作反馈  
   例如脚步、拉门、布料摩擦、玻璃轻震、液体晃动、书页拍打、纸张飞散、装甲闭合、骨骼拉伸。

3. 人声肌理 / 身体反馈  
   例如呼吸、吞咽、压低的笑、短促吸气、疲惫喘息、因疼痛或激动而停住的呼气。

### 6.3 不同内容类型的声音重点

#### 人物情绪片段
优先写：
- 呼吸节奏
- 衣料与小动作的近距离接触声
- 环境音是否在关键停顿处被抽空
- 安静本身是否成为压力来源

#### 广告 / 时尚 / 奢侈品画面
优先写：
- 材质被触碰时的精致反馈
- 玻璃、金属、丝绸、皮革、液体的质感声音
- 整体声音是否洁净、极简、带品牌感
- 避免廉价满铺音效与过多 swoosh

#### 末日 / 废土 / 悬疑场景
优先写：
- 风声、结构异响、远处残余噪音
- 空间的空心感、漏风感、断电后的静默感
- 人声是否显得被环境吃掉，是否异常孤立

#### 变身 / 异变 / 生物机械内容
优先写：
- 裂开、生长、脉动、覆盖、渗出、装配、锁定等连续变化的声音层次
- 湿润、有机、金属、能量、蒸汽、纤维拉伸等不同质感
- 声音应服务阶段推进，而不是只用一个爆炸音概括全部变化

### 6.4 声音节奏必须与画面节奏咬合

- 当画面需要沉浸时，环境音可持续铺底
- 当画面需要强调动作或材质时，点状音效应更清晰
- 当画面进入情绪停顿时，声音可收窄、抽空或只保留呼吸
- 当画面逐步升级时，声音也应从稀薄到饱满，而不是一开始就拉满

### 6.5 声音设计的最低完成度

当用户对声音有要求，或画面明显依赖声音成立时，尽量同时具备：
- 一个明确的环境音场
- 两到三个关键动作或材质反馈
- 一组与人物状态相关的身体声音
- 一个清楚的整体声音气质描述

## 七、技术参数指导

### 7.1 技术参数不是装饰尾巴

技术参数段默认保留，不是为了显得专业，而是为了帮助生成结果在画幅、运动方式、质感、时长和风格约束上更稳定。

真正有用的技术参数，应尽量服务以下目标：
- 画面比例和构图重心清晰
- 镜头组织方式明确
- 运动与节奏方向明确
- 画质方向统一
- 禁用项清楚，减少跑偏

### 7.2 技术参数优先控制的内容

默认可优先考虑以下维度：
- 时长：如 5s、8s、10s、15s
- 画幅：如 16:9、2.39:1、9:16、1:1
- 镜头组织方式：长镜头 / 多分镜 / 蒙太奇
- 机位运动倾向：稳定跟拍、手持轻晃、慢推、低角度跟随、静止观察
- 画质倾向：写实电影、轻微胶片颗粒、干净数字感、高动态范围
- 景深倾向：浅景深突出主体 / 中等景深保留空间 / 深景深强调环境
- 光线控制：自然光主导 / 冷暖对冲 / 强对比戏剧光 / 轻微体积光
- 禁用项：禁止字幕、禁止水印、禁止卡通化、禁止塑料感、禁止低质量 CGI 感

### 7.3 技术参数应跟内容匹配

#### 角色展示 / 广告类
优先参数倾向：
- 构图清楚
- 材质与肤质分离明确
- 镜头运动简洁稳定
- 高光受控，画面干净

#### 世界观 / 场景建立类
优先参数倾向：
- 更重视画幅、景深和空间清晰度
- 适合强调环境层次与纵深
- 不要让浅景深吞掉太多场景信息

#### 动作 / 变身 / 异变类
优先参数倾向：
- 时长与阶段划分清楚
- 运动方式服务事件链
- 材质与特效保持统一
- 控制模糊与可读性的平衡

#### 蒙太奇 / MV / 预告片类
优先参数倾向：
- 节奏组织清楚
- 画面风格统一但允许局部变化
- 切换方式与视觉记忆点对应
- 避免参数写成散乱设备清单

### 7.4 技术参数应写成可执行约束

技术参数段尽量写成一段完整约束，而不是孤立名词堆叠。

例如，比起只写：
- 4K，电影感，广角，HDR，景深

更有效的方向是：
- 10秒，2.39:1宽画幅，多分镜蒙太奇组织，镜头节奏由人物动作与音乐卡点共同驱动，整体保持清透写实电影质感，蓝白主调，自然高光不过曝，主体清晰，背景保留空间层次，禁止字幕、禁止水印、禁止塑料肤质、禁止廉价 CG 感。

### 7.5 技术参数的最低完成度

默认保留技术参数时，尽量至少包含：
- 时长
- 画幅
- 镜头组织方式或运动倾向
- 画质 / 光线 / 景深中的至少两项
- 两到四个明确禁用项

## 八、组合使用原则

### 8.1 角色、场景、氛围、镜头不是四段孤立文本

在最终 prompt 中，这几部分应互相牵引：
- 角色决定主体识别度
- 场景决定电影质感与视觉世界
- 氛围决定色调、空气、光影与观看感受
- 镜头决定观众如何接收人物、空间与事件信息
- 声音决定空间是否真正“活着”
- 技术参数决定这些信息能否稳定落地

### 8.2 默认篇幅分配原则

若用户没有明确提出“人物很有戏”或“人物关系很重要”，则角色篇幅应保持克制，以外观、服装、年龄感、基础气质为主。

若用户追求高级感、电影感、广告感、MV 感、预告片感、末日美学、特摄感或世界观浓度，则应优先增加场景、美术、材质、空气、光影与画质控制信息。

当生成结果需要先解决“像不像电影画面”，优先补场景与氛围；当需要先解决“人物有没有辨识度”，再补角色设计。

### 8.3 提升密度时优先补什么

如果篇幅有限，优先补以下内容，而不是增加空洞修辞：
1. 场景的风格化空间与材质系统
2. 氛围中的色彩、影调与空气感
3. 镜头为什么这样观察与推进
4. 角色的造型识别度
5. 必要时再补行为逻辑与关系状态

### 8.4 仍然避免的写法

即使使用本文件补强内容，也应避免：
- 只有审美形容词，没有可视化信息
- 只有片名堆叠，没有说明引用维度
- 只有“电影感”“高级感”“史诗感”，没有材质、光线、空间和空气支撑
- 角色默认写成过重的人物小传
- 场景只剩地点报幕，没有视觉体系
- 强行把内容套成固定四段叙事结构
- 把参考文件理论标签大段原样输出给用户

## 九、加载建议

以下情况建议主动参考本文件：
- 用户要求角色很有辨识度，但不一定需要重剧情化人物塑造
- 用户要求场景有强世界观、强美术方向、强材质层次或高电影感
- 用户要求广告片、预告片、MV、概念短片、特摄、末日美学、高概念叙事
- 用户要求“画面要丰富”“氛围和镜头要更高级”“场景要更有质感”
- 用户希望加入明确影视对标来锁定风格
- 用户给出的描述不短，但整体审美系统仍不够稳定

以下情况可只部分借用：
- 普通单角色短视频
- 轻量产品镜头
- 简单情绪片段
- 信息目标明确、无需高强度风格化控制的普通生成任务

注意：
- 涉及任何打斗、战斗、追逐、变身、异变、强化、大招前摇时，动作设计仍应优先参考 `references/动作戏摄影指导.md`
- 本文件不能替代动作戏专项判断，而是用于补强动作场景中的角色、场景、氛围、声音、技术参数与镜头质感层次
