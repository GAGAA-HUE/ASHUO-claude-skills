# 分镜构图与轴线设计参考

本文档为 Seedance Director 的内部参考，用于指导多分镜模式下的机位设计与轴线守恒。

## 机位四维轮换矩阵

### 景别维度

景别控制画面的信息密度与情感距离。

| 景别 | 用途 | 情感效果 |
|------|------|----------|
| 大远景 | 环境建立、时间流逝、渺小感 | 孤独、壮阔、客观 |
| 远景 | 人物与环境关系 | 疏离、叙事性 |
| 全景 | 完整人物动作 | 客观、完整 |
| 中景 | 对话、互动 | 日常、平等 |
| 中近景 | 表情与对话并重 | 亲近、关注 |
| 近景 | 情感表达 | 亲密、紧张 |
| 特写 | 细节、情绪 | 强烈、聚焦 |
| 大特写 | 极度细节 | 压迫、强调 |
| 极特写 | 微观细节 | 震撼、悬念 |

**轮换原则**：
- 禁止连续 3 个以上相同景别
- 多分镜（≥4 条）必须至少出现 3 种不同景别
- 必须至少包含 1 个大景别（建立/收尾）和 1 个极特写（细节锚点）

### 角度维度

角度控制观众对人物的心理态度。

| 角度 | 用途 | 情感效果 |
|------|------|----------|
| 平视 | 日常场景 | 平等、中立 |
| 微俯 | 弱势人物、困境 | 怜悯、客观 |
| 俯拍 | 环境全景、渺小感 | 支配、观察 |
| 微仰 | 权威、希望 | 尊重、仰慕 |
| 仰拍 | 英雄、压迫感 | 敬畏、紧张 |
| 极端仰拍 | 超人、恐惧 | 震撼、不安 |
| 鸟瞰 | 宏观视角、命运感 | 上帝视角、宿命 |

**轮换原则**：
- 禁止连续 3 个以上相同角度
- 多分镜（≥4 条）必须至少出现 2 种不同角度
- 必须包含非常规角度（俯/仰）与平视的对比

### 视点维度

视点控制观众与画面的心理距离。

| 视点 | 用途 | 情感效果 |
|------|------|----------|
| 客观视点 | 旁观者、叙事 | 中立、观察 |
| 过肩视点 | 对话场景 | 参与感、连接 |
| 主观视点 | 角色体验 | 代入、沉浸 |
| 窥视点 | 悬疑、紧张 | 不安、好奇 |
| 反射视点 | 回忆、幻想 | 虚幻、超现实 |
| 跟踪视点 | 动作、追逐 | 紧张、动态 |
| 升降视点 | 环境建立、时间流逝 | 宏观、命运 |

**轮换原则**：
- 禁止连续 3 个以上相同视点
- 多分镜（≥4 条）必须至少出现 2 种不同视点
- 对话场景必须使用过肩视点
- 动作场景建议使用跟踪视点

### 运动方式维度

运动方式控制画面的节奏与情感张力。

| 运动方式 | 用途 | 情感效果 |
|----------|------|----------|
| 固定 | 静态场景 | 稳定、客观 |
| 推近 | 强调细节、情感聚焦 | 紧张、关注 |
| 后拉 | 揭示环境、情感疏离 | 客观、释放 |
| 横移 | 跟随人物、环境扫描 | 流畅、叙事 |
| 摇摄 | 环境展示、人物关系 | 连接、对比 |
| 跟拍 | 动作场景、追逐 | 紧张、动态 |
| 升降 | 宏观视角、时间流逝 | 壮观、命运 |
| 环绕 | 人物聚焦、情感强化 | 沉浸、强调 |
| 手持 | 纪实、紧张、混乱 | 真实、不安 |
| 快速推拉 | 震惊、转折 | 冲击、紧张 |
| 甩拍 | 快速转场、时间跳跃 | 突然、节奏 |
| 失焦回正 | 心理转变、意识恢复 | 迷离、清醒 |

**轮换原则**：
- 禁止连续 3 个以上相同运动方式
- 多分镜（≥4 条）必须至少出现 3 种不同运动方式
- 动作场景建议包含快速推拉、跟拍、手持

## 轴线守恒规则

### 180度轴线原则

轴线是连接两个主要人物或关键元素的假想线。摄影机必须在轴线同一侧拍摄，以保持空间关系的连贯性。

**核心规则**：
- 摄影机不得跨越轴线（除非使用合法过渡）
- 人物在画面中的相对位置必须保持一致（如 A 在左，B 在右，则始终如此）
- 人物视线方向必须保持一致（如 A 看向右，则始终看向右）
- 人物运动方向必须保持一致（如 A 从左向右走，则始终从左向右走）

### 轴线识别

在多分镜场景中，必须识别以下轴线：

**对话轴线**：连接两个对话人物
- 人物 A 和人物 B 之间的连线
- 摄影机必须保持在轴线同一侧

**动作轴线**：人物运动的主要方向
- 人物从起点到终点的运动轨迹
- 摄影机必须保持人物运动方向一致

**视线轴线**：人物视线的方向
- 人物看向的方向
- 摄影机必须保持视线方向一致

### 轴线违反（越轴）

以下情况为轴线违反，必须避免：

**直接反打跳跃**：
- ❌ 镜头 1：A 在左，B 在右
- ❌ 镜头 2：A 在右，B 在左（无过渡）

**无动机方向反转**：
- ❌ 镜头 1：人物从左向右走
- ❌ 镜头 2：人物从右向左走（无理由）

**视线方向冲突**：
- ❌ 镜头 1：人物看向右
- ❌ 镜头 2：人物看向左（无理由）

**位置关系反转**：
- ❌ 镜头 1：A 在左，B 在中，C 在右
- ❌ 镜头 2：A 在右，C 在中，B 在左（无过渡）

### 合法越轴方式

以下情况允许越轴，但必须使用明确的过渡：

**中性镜头过渡**：
- 插入一个中性镜头（如环境空镜、道具特写、人物背影）
- 然后切换到轴线另一侧
- ✅ 镜头 1：A 在左，B 在右 → 镜头 2：环境空镜 → 镜头 3：A 在右，B 在左

**动作过渡**：
- 人物通过动作改变位置或方向
- ✅ 镜头 1：人物从左向右走 → 镜头 2：人物转身 → 镜头 3：人物从右向左走

**视线过渡**：
- 人物改变视线方向
- ✅ 镜头 1：人物看向右 → 镜头 2：人物转头 → 镜头 3：人物看向左

**摄影机运动过渡**：
- 摄影机通过运动跨越轴线
- ✅ 镜头 1：摄影机在轴线左侧 → 镜头 2：摄影机环绕人物运动 → 镜头 3：摄影机在轴线右侧

## 轴线守恒在提示词中的执行

### 轴线描述方式

在最终提示词中，轴线规则必须以可见的物理事实体现：

**必须写明**：
- 人物的屏幕方位（左/右/中央/前景/后景）
- 人物的朝向与视线方向
- 运动方向（从左入画/向右出画/沿X轴移动）
- 双人/多人的相对位置
- 道具的屏幕位置

**禁止出现**：
- "轴线"、"180度"、"越轴"、"对跳"等理论术语

### 轴线描述正反示例

**正例（轴线守恒）**：
```
镜头1：甲位于画面左侧前景，背向镜头微微转头，露出四分之三侧脸，视线方向朝画面右侧的乙
镜头2：乙位于画面右侧前景，背向镜头微微转头，露出四分之三侧脸，视线方向朝画面左侧的甲
镜头3：甲位于画面左侧后景，正对镜头，呈正侧面
```

**反例（轴线违反）**：
```
镜头1：甲在画面左侧，乙在画面右侧
镜头2：甲在画面右侧，乙在画面左侧（无过渡）
```

### 合法越轴过渡示例

**中性镜头过渡**：
```
镜头1：甲位于画面左侧前景，乙位于画面右侧前景
镜头2：俯视桌面，中性过渡镜头
镜头3：乙位于画面左侧前景，甲位于画面右侧前景（轴线已转换）
```

**动作过渡**：
```
镜头1：人物从画面左侧向右侧行走
镜头2：人物转身，动作过渡
镜头3：人物从画面右侧向左侧行走
```

**视线过渡**：
```
镜头1：人物看向画面右侧
镜头2：人物转头，视线过渡
镜头3：人物看向画面左侧
```

## 常见场景机位组合

### 对话场景

**标准对话机位**：

```
镜头 1：全景，平视，客观视点，固定 → 建立环境
镜头 2：中景，平视，过肩（A），固定 → A 说话
镜头 3：中景，平视，过肩（B），固定 → B 回应
镜头 4：近景，平视，客观，固定 → A 表情反应
镜头 5：近景，平视，客观，固定 → B 表情反应
镜头 6：特写，平视，客观，固定 → A 或 B 的关键细节
镜头 7：全景，平视，客观，固定 → 结束
```

**紧张对话机位**：

```
镜头 1：中景，微仰，客观，固定 → A 强势
镜头 2：中景，微俯，客观，固定 → B 弱势
镜头 3：近景，仰拍，客观，推近 → A 压迫
镜头 4：近景，俯拍，客观，固定 → B 退缩
镜头 5：特写，平视，主观，固定 → A 眼神
镜头 6：特写，平视，主观，固定 → B 眼神
镜头 7：中景，平视，客观，后拉 → 两人关系
```

### 动作场景

**追逐机位**：

```
镜头 1：全景，平视，跟踪，跟拍 → 人物起跑
镜头 2：中景，微俯，跟踪，跟拍 → 人物加速
镜头 3：近景，平视，跟踪，手持 → 人物紧张
镜头 4：特写，平视，跟踪，手持 → 脚步细节
镜头 5：中景，微俯，跟踪，跟拍 → 人物转向
镜头 6：全景，平视，跟踪，跟拍 → 人物接近目标
镜头 7：中景，平视，跟踪，固定 → 人物到达
```

**打斗机位**：

```
镜头 1：全景，平视，客观，固定 → 两人对峙
镜头 2：中景，平视，过肩，固定 → A 出拳
镜头 3：中景，平视，过肩，固定 → B 闪避
镜头 4：特写，平视，客观，快速推近 → 拳头击中
镜头 5：近景，微俯，客观，手持 → B 后退
镜头 6：中景，平视，过肩，固定 → B 反击
镜头 7：特写，平视，客观，快速推近 → 拳头击中
镜头 8：近景，微俯，客观，手持 → A 后退
镜头 9：全景，平视，客观，固定 → 两人对峙
```

### 悬疑场景

**悬疑机位**：

```
镜头 1：全景，微俯，窥视，固定 → 环境建立
镜头 2：中景，微俯，窥视，固定 → 人物进入
镜头 3：近景，微俯，窥视，固定 → 人物观察
镜头 4：特写，平视，窥视，推近 → 人物发现细节
镜头 5：极特写，平视，主观，固定 → 细节特写
镜头 6：近景，微俯，窥视，固定 → 人物反应

镜头 8：全景，微俯，窥视，固定 → 环境变化
```

## 常见错误与修正

### 错误 1：连续相同景别

**错误示例**：
```
镜头 1：中景
镜头 2：中景
镜头 3：中景
```

**修正方法**：
```
镜头 1：中景
镜头 2：近景（景别变化）
镜头 3：中景（景别变化）
```

### 错误 2：轴线违反

**错误示例**：
```
镜头 1：A 在左，B 在右
镜头 2：A 在右，B 在左（无过渡）
```

**修正方法**：
```
镜头 1：A 在左，B 在右
镜头 2：环境空镜（中性过渡）
镜头 3：A 在右，B 在左
```

### 错误 3：运动方向反转

**错误示例**：
```
镜头 1：人物从左向右走
镜头 2：人物从右向左走（无理由）
```

**修正方法**：
```
镜头 1：人物从左向右走
镜头 2：人物转身（动作过渡）
镜头 3：人物从右向左走
```

### 错误 4：视线方向冲突

**错误示例**：
```
镜头 1：人物看向右
镜头 2：人物看向左（无理由）
```

**修正方法**：
```
镜头 1：人物看向右
镜头 2：人物转头（动作过渡）
镜头 3：人物看向左
```

### 错误 5：缺少景别变化

**错误示例**：
```
镜头 1：中景
镜头 2：中景
镜头 3：中景
镜头 4：中景
```

**修正方法**：
```
镜头 1：全景（大景别）
镜头 2：中景
镜头 3：近景
镜头 4：特写（细节）
镜头 5：中景
镜头 6：全景（大景别）
```

## 总结

### 机位丰富原则

1. **四维轮换**：景别、角度、视点、运动方式必须轮换
2. **避免单调**：禁止连续 3 个以上相同维度
3. **包含变化**：必须包含大景别和极特写
4. **服务叙事**：机位变化必须服务于情感和叙事需要

### 轴线守恒原则

1. **识别轴线**：对话轴线、动作轴线、视线轴线
2. **保持一致**：人物位置、视线、运动方向必须一致
3. **避免违反**：禁止直接反打跳跃、无动机方向反转
4. **合法越轴**：必须使用中性镜头、动作、视线、摄影机运动过渡

### 自检原则

1. **四维检查**：检查景别、角度、视点、运动方式的多样性
2. **轴线检查**：检查人物位置、视线、运动方向的一致性
3. **场景检查**：检查对话、动作、悬疑场景的特定要求
4. **错误修正**：发现错误必须重新设计机位序列
